# 論点の提示

判断の分かれる論点を出すときの書式。
Issue / PR のコメントでもドキュメント本文でも同じ書式で書く。

## 書式

```
| 案 | 内容 | メリット | デメリット | 備考 |
| --- | --- | --- | --- | --- |
| A | 先に PoC を挟む | 核心機構の成立を早期に確認できる | 着手が 1 サイクル遅れる | - |
| B | PoC なしで実装に入る | 最短で着手できる | 成立しなければ手戻りが大きい | 既存技術の組み合わせ |

推奨: A

同期の性能が成立条件になっており、実装を進めてから成立しないと分かると設計ごと作り直しになる。
```

<!-- table: data -->

| 項目 | 書き方 |
| --- | --- |
| 第 1 列 | 記号（A / B / C ...）だけを入れる。列見出しは `案` |
| 内容列 | その案が何をするかを書く |
| メリット / デメリット | 対で書く。書けない論点では両方とも置かない |
| 備考 | 任意 |
| 使わない列 | 列ごと落とす（全行が空の列を並べない） |
| 推奨 | 表の下に記号だけを書き、理由は空行を挟んだ次の段落に書く |

<!-- /table -->
