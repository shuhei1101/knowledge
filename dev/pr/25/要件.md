# 要件

## 要望

Next.js のフォームの標準を、shadcn/ui の `<Form>` → `<FormField>` → `<FormItem>` の構造から、React Hook Form の `<Controller>` と shadcn/ui の `<Field>` の構造へ移す。
フォームに触れる Next.js の規約を、新しい構造で 1 通りに読める状態にする。

1 通りに読める状態とは、次のページに `<Form>` / `<FormField>` / `<FormItem>` / `<FormLabel>` / `<FormControl>` / `<FormMessage>` を標準として書いた記述が残らないこと。

移す先の構造は、shadcn/ui の [React Hook Form のガイド](https://ui.shadcn.com/docs/forms/react-hook-form) に合わせる。
入力欄ごとに `<Controller>` の `render` で `<Field>` を返し、`<Field>` の中に `<FieldLabel>`・入力部品・`<FieldError>` を置く。
エラーの状態は `fieldState.invalid` を `<Field>` の `data-invalid` と入力部品の `aria-invalid` へ渡して出す。
`register` 直接使用禁止は、`<Controller>` の `render` を使う形に言い換えて残す。

移す判断の根拠は、shadcn/ui の現行のドキュメントがフォームを `<Controller>` + `<Field>` で案内し、`<Form>` のページはレガシーのドキュメントへ移っていること。

## 影響するユースケース

なし（コードを持たず、ユースケースを持たない）。
