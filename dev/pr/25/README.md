# Next.js のフォームの規約を shadcn/ui の Field + Controller へ移すかを決めて規約を合わせる

## 概要

Next.js のフォームの標準を shadcn/ui の `Field` + `Controller`（React Hook Form）へ移すかを決め、移すなら関係する規約を合わせる。

## 背景

[Issue #19](https://github.com/shuhei1101/knowledge/issues/19) の要望。
規約『フォームコンポーネント』は shadcn/ui の `<Form>` → `<FormField>` → `<FormItem>` の構造を標準とし、shadcn/ui が新しく示す `Field` + `Controller` の書き方に触れていない。
[#16](https://github.com/shuhei1101/knowledge/pull/16) で見つけ、既存プロジェクトのフォームの書き方を変える判断になるため切り出した。
