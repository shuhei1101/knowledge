# 要件

## 要望

規約以外の種類の文書（判定フローチャート・手順・テンプレート）の本文にある出典を、[PR #104](https://github.com/shuhei1101/knowledge/pull/104) が `schemas/common.schema.yaml` の `metadata` に追加した `sources` へ移し、本文には決めたことだけを残す（react移行計画の D-59）。
出典かどうかは [PR #104 の要件.md](https://github.com/shuhei1101/knowledge/blob/develop/dev/pr/104/%E8%A6%81%E4%BB%B6.md) の「出典かどうかの分け方」で判定する。
変更する項目以外の文言は一字一句そのまま残す（規約『既存文章の維持』）。

develop の `docs/flowchart`・`docs/guide`・`docs/template`・`docs/skill` で本文に URL を持つ文書を分け方に当てた結果、出典に当たるのは判定フローチャート 2 件の `sources-01`（出典の表）だけだった。
手順・テンプレートの URL は全て出典ではない（`## スコープ外` に判定を残す）。

移し方:

- 出典の表の 1 行を `sources` の 1 要素にし、`出典` 列のリンクの表示名を `title`、URL を `url`、`取り込んだ要素` 列を `note`（拠り所にした箇所）に入れる
- 出典の項目 `sources-01` を削除する
- 本文に出典を指す略号・`出典` 列は無いので、要素に `id` は付けない
- `rev` を 1 つ上げる（PR #104 と同じ）

終わりの条件:

- `docs/flowchart/flowchart-config-location.yaml` と `docs/flowchart/flowchart-react-state-placement.yaml` の本文に出典の URL が無く、同じ出典（6 件・5 件）が `sources` に入っている
- 2 件が `schemas/flowchart.schema.yaml`（`unevaluatedProperties: false`）に通る
- 出典ではない URL（`## スコープ外` の行）は本文に残っている

## 影響するユースケース

なし（判定フローチャートの文書だけを変え、コードとユースケースを持たない）。
