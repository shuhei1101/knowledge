# 規約『ドキュメントの部品』のファイルツリーの注釈とコードのコピーの記述を mdmark の描画に合わせる

## 概要

規約『ドキュメントの部品』を読んでドキュメントサイトに部品を置く人が、mdmark が描く実際の部品の動きどおりにファイルツリーの注釈とコードの行マーカーを使えるようにする。

## 背景

[Issue #77](https://github.com/shuhei1101/knowledge/issues/77) の要望。
[shuhei1101/ai-monitor#2990](https://github.com/shuhei1101/ai-monitor/issues/2990) で AI Monitor のドキュメントサイトの本文の部品を mdmark v0.7.0 が描くようになり、規約『ドキュメントの部品』の `file-tree-01`（注釈）と `code-line-marker-01`（コピーされる中身にマーカーが残らない）の記述が mdmark v0.7.0 の動きと合わなくなった。
mdmark 側の対応は [shuhei1101/mdmark#137](https://github.com/shuhei1101/mdmark/issues/137)・[shuhei1101/mdmark#138](https://github.com/shuhei1101/mdmark/issues/138) で扱われた。
