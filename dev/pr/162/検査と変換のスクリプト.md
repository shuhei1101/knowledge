## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| マーカーの展開 | 項目の本文の 1 行だけの `<!-- embed: {文書の ID} -->` を、配信元の `docs/word-list/*.yaml` のうち `id` が一致する文書の `entries` を `render_word_list` で表にしたものに置き換える。コードブロックの中のマーカーは置き換えない | インターフェース定義設計で確定（IF-72-2 の `constraints[埋め込みのマーカー]`）。`/`・`#` を含むマーカーは dev-docs のパスの書き方として残す |
| 展開できないマーカー | ID の文書が無い・`kind` が `word-list` でない場合、終了コード 0 のまま、その位置に `> [!WARNING]` で展開できない理由を出す | dev-docs の展開できないマーカーの出し方と揃える |
| 文書の引き方 | 作業ディレクトリ（配信元の直下）の `dev-docs.yaml` の `documents[]` の `word-list` の行の `paths` に当たる対応表を読む（`_common.py` の `load_config`・`list_row_files`） | インターフェース定義設計で確定 |
| 処理時間 | `cache: false` で開くたびに起動する。1 回の起動は 0.17〜0.34 秒（`convention-writing-style.yaml` で 3 回の実測）で、1 文書あたりの処理時間（20 秒）に収まる | - |
