# キーの表の書式を規約『表し方の優先順位』に定め、キーの表や種類ごとの資料を手で記載するときに注入する

## 概要

設定ファイル・スキーマのキーの表や、シナリオ・インターフェース定義などの種類ごとの資料を手で記載するとき、伝えなくても決まった書式と必須の項目で記載されるようにする。

## 背景

[Issue #221](https://github.com/shuhei1101/knowledge/issues/221) の要望。
キーの表を Markdown で手で記載すると、エージェントが毎回違う書式で記載し、利用者が列・`.` でつないだ 1 つの表・コードブロックの見本を毎回伝えている。
規約『表し方の優先順位』は表の決まりを持つが、キーの表の書式を持たない。
設計書の Markdown の表は YAML のスキーマから生成するため、崩れるのは MindStella の資料など手で記載する資料。
