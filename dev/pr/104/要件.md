# 要件

## 要望

規約（`kind: rule`）のメタデータに、参考にした公式ドキュメントの URL・ライブラリとバージョン・確かめた日を持つキーを追加し、本文に書いている出典をそのキーへ移して、本文には決めたことだけを残す（react移行計画の D-59）。
変更する項目以外の文言は一字一句そのまま残す（規約『既存文章の維持』）。

終わりの条件:

- `schemas/common.schema.yaml` の `metadata`（必要なら `schemas/rule.schema.yaml`）に、出典 1 件ごとに URL・ライブラリとバージョン・確かめた日を持てるキーがあり、`unevaluatedProperties: false` の規約のスキーマに通る
- 追加したキーに `title`・`description`・`examples` がある（規約『YAML』の `$ref` と `examples` の決まり）
- 規約『ドキュメントの管理』の `メタデータのキー一覧` に、追加したキーの行がある
- 下の `## 更新ドキュメント` の規約の本文から出典の URL と、出典を確かめたときのバージョンが無くなり、同じ出典が追加したキーに入っている
- 手順の一部として書いた URL（設定の値の例・別の文書へのリンク）は本文に残っている

`未確定`: 追加するキーのスキーマ（決める段: ドキュメント修正）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `common.schema.yaml` の `$defs` に出典 1 件の型（`title`・`url` 必須、`library`・`version`・`checked` 任意）を置き、`metadata` に配列のキー `sources` を追加する | 規約以外の種類（手順・判定フローチャート）も同じキーを使える。出典ごとに確かめた日を持てる | 規約以外の種類にもキーが開く |
| B | `rule.schema.yaml` の `properties` だけに同じ配列のキーを追加する | 規約だけに閉じる | 判定フローチャートの出典の表を移すときに同じ型を書き直す |

推奨: A

`metadata` は全ての種類が `allOf` で読むので、型を 1 か所に置けば規約に通り、後から判定フローチャートの出典を移すときもスキーマを変えずに済むため。

`未確定`: 本文の中で出典を指している記述の扱い（決める段: ドキュメント修正）

出典の URL を移すと、本文に残る略号（`convention-writing-style` の `出典の略号` と確認表の `出典` 列、`ui-*` の `I:`・`V:` など）や、表の行ごとの `出典` 列（`ui-business-screen-elements`・`ui-screen-design-principles`）が指す先を失う。

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 出典のキーの各要素に略号（`id`）を持たせ、本文の略号と表の `出典` 列は残してキーの略号を指す | 行ごとの出典の対応が残る | 本文に略号が残る |
| B | 本文の略号と表の `出典` 列を削除し、出典はキーに並べるだけにする | 本文が決めたことだけになる | どの行がどの出典に拠るかが分からなくなる |

推奨: A

表の行ごとに拠った出典が違い、対応を失うと出典を見直すときに行を特定できなくなるため。

出典かどうかの分け方:

<!-- table: data -->

| 本文の URL・バージョン | 扱い |
| --- | --- |
| `## 出典`・`参考` などの出典の項目に並べた URL | キーへ移し、出典の項目を削除する |
| 表の `出典` 列・文末に添えた出典の URL | キーへ移す（略号の扱いは上の `未確定`） |
| 値を確かめる先として手順の中で読ませる URL（「公式の参照先に従う」等） | キーへ移し、本文は参照先の名前を残す（規約『文章の書き方』の時期で古くなる値の行は、公式の参照先を書くと決めている） |
| 設定の値の例・別の文書へのリンク | 出典ではないので残す |
| 本文に書いた、出典を確かめたときのライブラリのバージョン | キーの各要素のバージョンへ移す |
| 決めたこととしてのバージョンの指定（`requires-python >= 3.14` 等） | 決めたことなので残す |

<!-- /table -->

## 影響するユースケース

なし（規約の文書とスキーマだけを変え、コードとユースケースを持たない）。
