# 規約のスキーマに出典・ライブラリとバージョン・確認日のメタデータのキーを追加し、本文の出典を移す

## 概要

規約を読む AI が、本文で決めたことだけを読み、参考にした公式ドキュメントの URL・ライブラリとバージョン・確かめた日はメタデータから引けるようになる。

## 背景

[Issue #101](https://github.com/shuhei1101/knowledge/issues/101) の要望。
react移行計画の D-59 で、規約が参考にした公式ドキュメントの URL・ライブラリとバージョン・確かめた日はメタデータに持たせ、本文には決めたことだけを書くと決めた。
ところが `schemas/rule.schema.yaml` は `unevaluatedProperties: false` で、`schemas/common.schema.yaml` の `metadata` にもこれらを持つキーが無い（鮮度のキーは `last_reviewed` だけ）。
このため [PR #100](https://github.com/shuhei1101/knowledge/pull/100)（起点 Issue [#99](https://github.com/shuhei1101/knowledge/issues/99)・[#81](https://github.com/shuhei1101/knowledge/issues/81)）では Python の規約の出典をメタデータへ移せず、[#81](https://github.com/shuhei1101/knowledge/issues/81) と [#82](https://github.com/shuhei1101/knowledge/issues/82) の D-59 の分をこの Issue へ移した。
