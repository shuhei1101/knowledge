# AI slop の単語の対応表と、書き込んだ中身を対応表で調べて通知するプラグイン slop-check を追加し、SessionStart の注入を廃止する

## 概要

エージェントが Write・Edit・NotebookEdit・書き込む MCP ツールで AI slop の単語を書き込んだとき、プラグイン slop-check が書き込んだ中身を対応表で調べ、書き込みを止めずに NG と OK の単語を通知する。
対応表は knowledge の YAML（`docs/word-list/word-list-ai-slop.yaml`）を正本にし、規約『文章の書き方』はその対応表を参照する。

## 背景

[Issue #135](https://github.com/shuhei1101/knowledge/issues/135) の要望。
規約『文章の書き方』の単語の対応表を SessionStart で毎回注入している（[#53](https://github.com/shuhei1101/knowledge/issues/53)）が、Claude 5 世代が書き込む中身には対応表の単語が出続けている（直近 2 週間の 3,179 万字で、対応表の 14 単語が 1 万字あたり約 21 件）。
今の対応表は規約の本文の Markdown の表で、OK を複数持てず、漢字 1 文字の単語を熟語と分けて検出する方法も無い。
検出の方式は話し合いで、別プラグインの PostToolUse で通知し書き込みを止めない案に決まり、rule-inject の `detect` を使う案（shuhei1101/rule-inject#89）は取り下げた。
Issue への [追加の要望](https://github.com/shuhei1101/knowledge/issues/135#issuecomment-6596780967) で、「語の選び方」「語の対応表」を「用語の選び方」「用語の対応表」へ改名する作業も含める。
