# 要件

## 要望

使い方『規約の索引を当てる』（`docs/guide/guide-setup-apply-rule-index.yaml`）を、rule-inject の今の手順（[rule-inject#105](https://github.com/shuhei1101/rule-inject/issues/105)）に合わせる。
変える項目の外の文言は一字一句そのまま残す（規約『既存文章の維持』）。

| 項目 | 変更 |
| --- | --- |
| `step-env-var-01` | `group`・`name` を設定ファイルに索引のパスを記載する手順にする。本文は、`${XDG_CONFIG_HOME:-~/.config}/rule-inject/settings.yaml` の `global.indexes` に `{clone した先の絶対パス}/rules.yaml` を並べる手順にし、設定ファイルを既定と違う場所に置くときだけ `~/.claude/settings.json` の `env` に `RULE_INJECT_CONFIG` を書くと記載する |
| `step-env-var-01` の `RULE_INJECT_INDEXES_USER` と rule-inject#52 の段落 | 削除する。rule-inject は `RULE_INJECT_INDEXES_USER` を廃止し、設定ファイルを読まないバージョンを案内する理由が無い |
| `reflection-01` | 設定ファイルの変更は次のフックの呼び出しから効くため、`即時` にする。`env` に `RULE_INJECT_CONFIG` を書いたときだけ Claude Code を再起動すると記載する |
| `rollback-01` | 設定ファイルの `global.indexes` からこの索引のパスを削除する手順にする。再起動は `env` を書いたときだけにする |
| `prerequisite-01` | rule-inject のセットアップ（端末の設定は `/rule-inject:global-setup`）を前提に記載したままにし、リンク先は変えない |

変えたページは `rev` を 1 つ上げ、`last_reviewed` を変えた日にする。

`未確定`: `step-env-var-01` で、設定ファイルを手で記載する手順にするか、`/rule-inject:global-setup --index` に任せる手順にするか（決める段: ドキュメント修正のレビュー）

| 案 | 内容 |
| --- | --- |
| A | 設定ファイルの `global.indexes` に手で記載する手順にする。`global-setup` は前提の rule-inject のセットアップに含める |
| B | `/rule-inject:global-setup --index {clone した先の絶対パス}/rules.yaml` を実行する手順にする |

推奨: A

`global-setup` は端末ごとに 1 回で、既に済んだ端末に knowledge の索引だけを加える手順にも使えるため。
