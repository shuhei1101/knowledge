# 語の選び方の要点を knowledge のプラグインの SessionStart フックで注入する

## 概要

knowledge のプラグインを入れた利用者のセッションで、チャットの返答やコードのコメントにも、規約『文章の書き方』の語の選び方の原則と代表的な語の対応が効くようになる。

## 背景

[Issue #53](https://github.com/shuhei1101/knowledge/issues/53) の要望。
規約『文章の書き方』の `## 語の選び方`（[#52](https://github.com/shuhei1101/knowledge/pull/52) で追加）は、rules.yaml で `**/*.md` と、コメント・本文を書く MCP ツールにしか当たらない。
ユーザーの CLAUDE.md の NG 用語の表は理由を持たず、表に無い語には効かず、規約と二重になっている。
ui、ドキュメントの文章ベストプラクティスの D-11 で、表を消して要点をプラグインの SessionStart で注入すると決め、表の削除（T-7）は注入が入るまで保留している。
プラグインとマーケットプレイスは [#98](https://github.com/shuhei1101/knowledge/pull/98) でリポジトリの直下に置かれている。
