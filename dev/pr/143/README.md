# ボタンのラベルの規約（アイコンと文字の使い分け・ツールチップ・文言）を追加する

## 概要

画面を作る人が、ボタンをアイコンだけにするか文字を出すかと、ツールチップ・アイコン・文言の決まりを 1 つの規約で参照できるようにする。

## 背景

[Issue #142](https://github.com/shuhei1101/knowledge/issues/142) の要望。
UI の規約には、アイコンだけのボタンの読み上げ名（『操作とアクセシビリティ』）と押せる領域（『レイアウト』）はあるが、アイコンだけにするか文字を出すかの使い分けが無く、画面ごとにばらついている。
ツールチップは『共通コンポーネント規約』でアイコンボタンの「決めるべき観点」に挙げているだけで、必須かが決まっていない。
Apple の HIG はアイコンを優先する場所を、標準のシンボルで意味が伝わる操作に限っている（調査 R-4）。
