# 資源の値の決め方を待ちの種類で分けて knowledge へ移し、タイムアウト・フォールバックの判定フローチャートと VS Code 拡張機能の配布の規約を追加する

## 概要

どのプロジェクトの開発エージェントと手元のセッションでも、タイムアウト・フォールバックの値を決めるときと VS Code 拡張機能を配布するときに、knowledge の規約が案内されるようにする。

## 背景

[Issue #181](https://github.com/shuhei1101/knowledge/issues/181) の束（[#165](https://github.com/shuhei1101/knowledge/issues/165)・[#175](https://github.com/shuhei1101/knowledge/issues/175)）の要望。

- shuhei1101/ai-monitor#3151 で、反映作業のスクリプトの応答の上限（120 秒）が導出の元の値の無い数字で、dev-docs の `reload`（実測 約 110 秒）が時間切れになった。規約『資源の値の決め方』は ai-monitor にだけあり、値を書く場面で案内されず、自分の処理の完了を待つだけの処理も応答を待つ要求と同じ式で扱う
- フォールバックの決まりは `fallback-01` の 2 行だけで、「極力」の判断がエージェントごとに分かれる
- mdmark の VS Code 拡張機能は `vscode-v0.1.0` の後にコードの変更が 11 件あるのにバージョンが上がらず、利用者に届いていない。拡張機能のバージョン・.vsix・公開・入れ替えの依頼の決まりが無い（shuhei1101/mdmark#84）
