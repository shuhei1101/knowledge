## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 資源の値の決め方 | 移す元の導き方の表・既定値・出典を値を変えずに項目へ分け、「下流を待つタイムアウト」の行を待ちの種類の 3 行に分ける。判定は『タイムアウトの決め方』へリンクする | 1 ルール 4KB 以内 |
| タイムアウトの決め方 | A-20 の 5 つの判定と 6 つの注記を、テンプレート『判定フローチャート』の書式で作る | ノードの位置と線の `points` は A-20 のまま |
| フォールバックを置くか | A-20 の 3 つの判定と 5 つの注記を、同じ書式で作る | ※1 から `fallback-01` へリンク |
| fallback-01 | 既存の 2 行の後に『フォールバックを置くか』へのリンクの行を追加する | `dev-coding-general` の `rev` を上げる |
| VS Code 拡張機能の配布 | 要件.md の表の 5 項目を項目にし、概要に対象と Claude プラグインとの違いを記載する | タグの `vscode-v{X}.{Y}.{Z}` は例として記載する |
| rules.yaml | 要件.md の `### rules.yaml の行` で決めた案の行を追加する | `未確定`（決める段: ドキュメント修正）。追加後に rule-inject の `check_indexes` で違反が 0 件であることを確認する |
