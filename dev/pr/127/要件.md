# 要件

## 要望

knowledge の `docs/` 配下の YAML の文書が持つ既存のタグのうち、規約『タグと用語の登録』の `tag-name-01` に合わないものを改名する。

対象は origin/develop（8e5f697）の `docs/` 配下の YAML の文書 252 件のタグ。

終わりの条件:

- 道具の公式の名前の `topic:` を、小文字・ハイフン区切りの `tool:` にする
  - 8e5f697 の時点で当たるのは `topic:fastapi`（10 件）
- 言語（プログラミング言語・マークアップ言語・問い合わせ言語）とファイルの形式の名前の `topic:`（`topic:python`・`topic:html`・`topic:yaml`・`topic:typescript`・`topic:css`・`topic:json`・`topic:js`・`topic:markdown`・`topic:sql`・`topic:rust`・`topic:csv`・`topic:svg`・`topic:pdf`）は、同じ名前の `scope:` を持つ文書では外し、持たない文書では公式の名前の `tool:` へ移す（`topic:js` は `tool:javascript`）
  - 外す `topic:X` が `main: true` を持つ文書（`typescript-core-style`・`typescript-core-type-location`・`markdown-editing`）は、同じ名前の `scope:` へ `main: true` を移す
- フォルダの位置から付けた英語の `topic:` は、`topic:frontend` → `topic:フロントエンド`、`topic:backend` → `topic:バックエンド`、`topic:components` → `topic:部品`、`topic:scripts` → `topic:スクリプト` へ改名し、`topic:shared`・`topic:core` は外す。`topic:llm` は残す
- 改名先のタグを同じ文書が既に持つときは 1 つにまとめる
- 改名・削除するタグが `main: true` を持つときは、改名先のタグか、残るタグのうち最も分量の多い主題のタグへ移し、各文書でちょうど 1 つにする（スキーマの `tags` の制約・`tag-attach-01`）
- 書き換えた文書は `rev` を 1 増やし、`last_reviewed` は変えない（#121・#124 の一括の書き換えと同じ扱い）
- `tags` と `rev` 以外のキー・本文は一字一句変えない（規約『既存文章の維持』）

## 影響するユースケース

なし（knowledge はシナリオを持たない。変わるのは文書のメタデータの `tags` だけ）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| フォルダの位置に由来しない一般の概念の英語の `topic:`（`topic:api`・`topic:naming`・`topic:id`・`topic:url` など） | `tag-name-01` は topic の語を日本語にすると定めていない。要望は道具の名前とフォルダ由来のタグに限る | 予定なし |
| 通信の方式の名前の `topic:`（`topic:http`・`topic:websocket`・`topic:sse` など） | 言語でもファイルの形式でもなく、通信の方式という概念を指す。`tag-name-01` は topic の語を日本語にすると定めていない | 予定なし |
| 規約『タグと用語の登録』の記述の変更 | 要望は既存のタグを命名規則に合わせることで、命名規則は変えない | 予定なし |
| `skills/text-review/SKILL.md`・`schemas/` 配下・`rules.yaml` | 文書のメタデータの `tags` を持たない | 予定なし |
