# knowledge の既存のタグのうち、規約『タグと用語の登録』の tag-name-01 に合わないものを改名する

## 概要

knowledge の `docs/` 配下の YAML の文書が持つ既存のタグのうち、規約『タグと用語の登録』の `tag-name-01` に合わないものを改名する。

## 背景

[Issue #125](https://github.com/shuhei1101/knowledge/issues/125) の要望。
[#124](https://github.com/shuhei1101/knowledge/pull/124)（起点 Issue #122）の要件.md の `## スコープ外` から切り出した後続で、[レビュー](https://github.com/shuhei1101/knowledge/pull/124#discussion_r4423958398)でスコープ外にすると確定した。
#124 は既存のタグを外さず、新しく付けるタグを既存のタグに寄せた（`tag-attach-02`）ため、道具の名前の `topic:` と、文書を YAML へ移したときにフォルダの位置から付けた英語の `topic:` が残っている。

## 計画書

| ファイル | 中身 |
| --- | --- |
