# 規約『MCP サーバー作成ルール』の読み取りのツールに、本文を返すときは文書ごとの場所と範囲を rule-inject の載せ方で載せる、と追加する

## 概要

文書の MCP を作る人が、規約『MCP サーバー作成ルール』どおりに読み取りのツールを作れば、そのツールで読んだルールが rule-inject で既読になるようにする。

## 背景

[Issue #75](https://github.com/shuhei1101/knowledge/issues/75) の要望。
rule-inject は、文書の MCP の結果に載った文書の場所と範囲で既読を判定する（[shuhei1101/rule-inject#46](https://github.com/shuhei1101/rule-inject/issues/46)、作業 PR [shuhei1101/rule-inject#47](https://github.com/shuhei1101/rule-inject/pull/47)。書式は rule-inject の [MCPの結果の書式](https://github.com/shuhei1101/rule-inject/blob/master/docs/%E3%83%AA%E3%83%95%E3%82%A1%E3%83%AC%E3%83%B3%E3%82%B9/MCP%E3%81%AE%E7%B5%90%E6%9E%9C%E3%81%AE%E6%9B%B8%E5%BC%8F.md)）。
規約『MCP サーバー作成ルール』の `read-tool-11` は、複数の本文を `<document>` で包むとだけ決めていて、場所と範囲を載せる決まりが無い。
MCP ベストプラクティスの話し合い（D-124〜D-126・D-128）で決めた。
