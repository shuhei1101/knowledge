# スキルの設計書のテンプレートと、文章を点検して修正するスキルを追加する

## 概要

スキルを作る人が、手順のフローチャートと外部とのやり取りのシーケンス図でスキルの設計書を書けるようになる。
利用者が範囲（ファイル・フォルダ・Git のコミットか範囲）を渡すと、文章の規約に合わせて文書を点検して修正し、サマリーを受け取れるようになる。

## 背景

[Issue #87](https://github.com/shuhei1101/knowledge/issues/87) の要望。
スキルの設計書の書き方が無く、シナリオのテンプレート（`docs/template/template-scenario.yaml`）は Mock・テストの項目を持つためスキルに合わない。
文章の規約（『文章の書き方』『既存文章の維持』『論点の提示』『ドキュメントの部品』『ユーザ配下ルール記載時の規約』）に合わせて文書を点検し、修正する手段が無い。
スキルのテストは書かず、実装した後に設計書とスキルの手順を突き合わせて確かめると、mdmark改善の D-31 で決めた。
テンプレートの項目・各セクションの説明と、点検して修正するスキルの設計書のサンプルは、mdmark改善の A-8 にある。
