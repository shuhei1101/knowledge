# 要件

## 要望

[Issue #132](https://github.com/shuhei1101/knowledge/issues/132) の `## 決まったこと`（D-201〜D-207）と [確認事項](https://github.com/shuhei1101/knowledge/issues/132#issuecomment-6539093572) の案 A に沿って、次のとおりにする。
規約と判定フローチャートに入れる中身は、Issue の `## 必読` の A-44 の「規約」「判定フローチャート」のセクションを正とする。

- `docs/rule/convention-doc-presentation.yaml`（`id: convention-doc-presentation`、規約『表し方の優先順位』）を新設する
  - A-44 の「規約」の原則・図・表・箇条書きと文・ページの分け方・本文に出さないものを持たせる
  - 図の種類を選ぶ表の「図」の各行は、mdmark の部品で描く（Mermaid は使わない）
- `docs/flowchart/flowchart-presentation-choice.yaml`（`id: flowchart-presentation-choice`、判定フローチャート『表し方の選び方』）を新設する
  - A-44 の「判定フローチャート」の 6 つの質問を、改訂後の `template-flowchart` の書き方で描く
- 既存の規約と重なる記述は片方を参照にして、二重に書かない
  - A-44 の「文は 1 文 1 行で書く」は、規約『Markdown 編集規約』（`markdown-editing`）の `line-length-01` と重なる
  - 規約『文章の書き方』（`convention-writing-style`）の確認表の「同じファイルの中で同じ説明を繰り返していないか」は、A-44 の原則の「見出し・図・表を読めば分かることを、本文で繰り返さない」と重なる
- `docs/rule/markdown-mermaid.yaml` を削除し、rules.yaml の行を削除する
- `docs/rule/markdown-flowchart.yaml` の中身（ノードの種類・エッジの順序・ラベル・用語のマーカー・括弧）を `docs/template/template-flowchart.yaml` へ統合し、`markdown-flowchart.yaml` と rules.yaml の行を削除する
  - 統合する決まりのうち Mermaid の記法に依る部分（`Q{N}{...}`・`|YES|` など）は、mdmark の部品での書き方に置き換える
- `docs/template/template-flowchart.yaml` を、判定フローチャートを mdmark の部品で描く書き方へ改訂する（Mermaid ブロックを必須とする `section-list-01`・`mermaid-block-01` などを置き換える）
- rules.yaml の `template-flowchart` の paths を `**/判定フローチャート/**/*.{md,yaml}`・`**/docs/flowchart/*.yaml` にする（#82 の react移行計画の A-16 の判定から移した）
- `docs/flowchart/` の既存の判定フローチャート（`flowchart-config-location`・`flowchart-react-state-placement`・`flowchart-related-link`・`flowchart-tag-attach`・`flowchart-term-registration`・`flowchart-word-choice`・`flowchart-yaml-file-unit`）を、改訂後の `template-flowchart` の書き方で描き直す
- rules.yaml に新しい規約と判定フローチャートの行を追加する
  - 規約は、人が読む文書・設計書を書くときと、文書を描くビュワーの変換を作るときに当たる paths にする
  - 判定フローチャートは、規約と同じ文書を書くときに当たる paths にする

判定フローチャートは、mdmark のフロー図の部品に追加する判定フローチャート用の箱の種類（質問・結果）で描く（[確認事項](https://github.com/shuhei1101/knowledge/pull/134#discussion_r4430660874) の案 B）。
その種類は [shuhei1101/mdmark#251](https://github.com/shuhei1101/mdmark/issues/251) で追加する。
`template-flowchart` の改訂・`markdown-flowchart` の統合と削除・`markdown-mermaid` の削除・判定フローチャートの新設と描き直しは、mdmark#251 のリリース後に反映する。

`未確定`: 規約をビュワーの変換に当てる rules.yaml の paths（決める段: ドキュメント修正）。dev-docs・mdmark の描画のコードの置き場所を確かめてから決める。

終わりの条件:

- 新しい規約と判定フローチャートが A-44 と食い違わない
- knowledge の規約・テンプレート・判定フローチャートに、Mermaid で描くことを求める記述が残らない（`## スコープ外` に回したものを除く）
- 新しい規約と既存の規約に、同じ内容が重ねて書かれていない
