# 規約『表し方の優先順位』と判定フローチャート『表し方の選び方』を追加し、判定フローチャートを mdmark の部品で描く書き方へ改める

## 概要

図 → 表 → 箇条書き → 文の順に表し方を選ぶ規約と、迷ったときの判定フローチャートを knowledge に追加し、文書を書くエージェントと文書を描くビュワーが同じ基準を読めるようにする。
あわせて Mermaid の規約を廃止し、判定フローチャートを mdmark の部品で描く書き方へ改める。

## 背景

[Issue #132](https://github.com/shuhei1101/knowledge/issues/132) の要望（検討事項 A-44・D-201〜D-207）。
aituber の設計書を dev-docs で見ると、キーと値の羅列・図と同じ内容の表・タイトルとリードの重複が多く読みづらい（R-39）。
「図 → 表 → 文字の順に優先する」原則は [shuhei1101/mdmark#185](https://github.com/shuhei1101/mdmark/issues/185) の『文書の書き方』ページの中身としてだけ決まっていて、knowledge には規約も判定フローチャートも無い。
新しい規約の「Mermaid は使わない」が既存の `markdown-mermaid`・`markdown-flowchart`・`template-flowchart` と矛盾するため、[確認事項](https://github.com/shuhei1101/knowledge/issues/132#issuecomment-6539093572) の案 A で、Mermaid の規約の廃止と既存の判定フローチャートの描き直しをこの PR に含めた。
`markdown-mermaid`・`markdown-flowchart`・`template-flowchart` の rules.yaml の見直しは [#82](https://github.com/shuhei1101/knowledge/issues/82) から移した。
