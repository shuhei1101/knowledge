# 要件

## 要望

規約『YAML』（`docs/rule/dev-yaml.yaml`）の `## スキーマ`（`schema-01`〜`schema-09`）を別の文書へ切り出すかを判断し、切り出す場合は移して参照を修正する。

| 項目 | 要件 |
| --- | --- |
| 判断の基準 | 移し先が規約『ルール索引への登録』の強制注入の 4 つの基準（`index-decision-01`）を満たすかで判断する。満たさない文書へ移す場合は、`rules.yaml` に記載せずタグと `aliases` で案内する |
| 書き方の正本との分担 | [PR #192](https://github.com/shuhei1101/knowledge/pull/192) で YAML のスキーマの書き方の正本になった `schemas/meta.schema.yaml`・`schemas/template.schema.yaml` と、同じ決まりを 2 か所に記載しない |
| 機械で判定できる決まり | 移す決まりのうち、メタスキーマ・yamllint で判定できるものは検査へ移し、本文から削除する（`index-decision-01` の 2 つ目の基準） |
| 意味の維持 | `schema-01`〜`schema-09` の決まりは、移し先・規約『YAML』・検査のどれかに残す |
| 参照の修正 | `## スキーマ` を指す参照（`dev-yaml.yaml` の `inspection-01`、規約『プロンプトファイル』の `prompt-file.yaml` の `スキーマと検査の参照先`）を、移した後の配置先へ向ける |
| 切り出す場合に決めること | 移し先の文書の ID・名前、`rules.yaml` の当て先（glob）、規約『YAML』に残す参照 |

### 切り出し先

スキーマのファイルの書き方は `schemas/meta.schema.yaml` へ切り出し、新しい規約は作らない。
`rules.yaml` は変えず、既存の案内（`**/schemas/**/*.schema.yaml` へのメタスキーマ）で案内する。

| 決まり | 配置先 |
| --- | --- |
| `schema-01`（スキーマを適用する YAML の範囲） | 規約『YAML』に残す |
| `schema-02`（JSON Schema 2020-12） | メタスキーマの `$schema` の `const` で検査する。文は削除する |
| `schema-03`（ファイル名）・`schema-05`（共通の型の `$defs`）・`schema-06`（ブロック形式） | メタスキーマの最上位の `x-rules` へ移す |
| `schema-04`（`title`・`description` の付与） | 本文をメタスキーマの最上位の `x-rules` へ移し、規約『YAML』の `schema-04` はメタスキーマを指す 1 行にする |
| `schema-07`〜`schema-09`（リポジトリをまたぐ正本と取り込み） | 規約『YAML』に残す |

`schema-03`・`schema-06` は今の検査では判定できない（`schema-06` を yamllint で判定すると既存のスキーマに違反が出る）ため、`x-rules` に記載する。
