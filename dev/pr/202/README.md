# 規約『YAML』のスキーマの定義の決まりを別の規約へ切り出すかを判断し、切り出す場合は移して参照を修正する

## 概要

YAML のスキーマを書くエージェントが、スキーマの定義の決まりを規約『YAML』の他の決まりと分けて参照できるかを判断し、分ける場合は移し先へ移す。

## 背景

[Issue #178](https://github.com/shuhei1101/knowledge/issues/178) の要望。
規約『YAML』（`docs/rule/dev-yaml.yaml`）は、YAML の正本・スキーマの定義・検査・書き込み・設定ファイルの決まりを 1 つの規約に持つ。
[PR #176](https://github.com/shuhei1101/knowledge/pull/176)（[#82](https://github.com/shuhei1101/knowledge/issues/82)）の `## スコープ外` から切り出した項目で、[PR #192](https://github.com/shuhei1101/knowledge/pull/192)（[#172](https://github.com/shuhei1101/knowledge/issues/172)）で YAML のスキーマの書き方の正本が `schemas/meta.schema.yaml`・`schemas/template.schema.yaml` になった。
