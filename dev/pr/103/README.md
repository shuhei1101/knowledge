# 規約『Claude 共通』の文の書き方の例文から、存在しない旧パスの参照を無くす

## 概要

規約『Claude 共通』の文の書き方の例文を読む AI が、存在しないパスの参照に当たらずに、文の折り返しの見本だけを読めるようになる。

## 背景

[Issue #97](https://github.com/shuhei1101/knowledge/issues/97) の要望。
`docs/rule/claude-common.yaml` の `sentence-style-01` の例文が、規約の YAML 化（[#64](https://github.com/shuhei1101/knowledge/pull/64)）で無くなった `html/shared/vendor.md`・`html/tooling/tsc運用.md` を参照しており、規約『ドキュメント管理』の「文書どうしの参照は ID で記載し、パスで記載しない」に外れる。
[PR #95](https://github.com/shuhei1101/knowledge/pull/95) の作業中に implementer が見つけて切り出した。
