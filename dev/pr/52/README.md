# 規約『文章の追記』を『文章の書き方』に改名し、語の選び方の決まりを追加する

## 概要

規約『文章の追記』を文章全般の書き方の規約『文章の書き方』に改名し、語の選び方の決まりと判定フローチャートを追加する。
画面に固有の文言の型は『入力と文言』へ追加する。

## 背景

[Issue #34](https://github.com/shuhei1101/knowledge/issues/34) の要望（[shuhei1101/ai-monitor#2363](https://github.com/shuhei1101/ai-monitor/issues/2363) から移した Issue）。
エージェントが書く日本語に、辞書に無い和語の造語・一字の語・比喩・話し言葉の動詞（送る・足す・版・節・口・形・段・写し 等）が入ると指摘されている。
規約『文章の追記』は中身が文章全般の確認なのに、名前が追記の規約に見える。
ユーザーが手元で調べて話し合った結論（[コメント](https://github.com/shuhei1101/knowledge/issues/34#issuecomment-6371243477)）を、決まりの元にする。
