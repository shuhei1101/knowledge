# 要件

## 要望

エージェントが次の 8 単語を記載したとき、プラグイン slop-check が置き換え先を通知する。

| NG | OK | 対象の意味 | 例 |
| --- | --- | --- | --- |
| 旧い | 旧 | 名詞の前に付けたとき | 旧い環境変数 → 旧環境変数 |
| 確度 | 確信度 | 確信度の意味 | 確度 高 → 確信度 高 |
| 語り | ナレーション・話し方 | - | 語りの型 → ナレーションスタイル |
| 正本 | 原本 | - | Git で持つ正本 → Git で持つ原本 |
| 出どころ | 出典 | - | 出どころ: TH-1 → 出典: TH-1 |
| 起こす | 作成・記載 | 資料・設計書にする意味 | 設計書に起こす → 設計書に記載する |
| 当たる | 該当・ヒット | 条件に合う意味 | 項目に当たるとき → 項目に該当するとき |
| ビューアー | ビュワー | - | 成果のビューアー → 台本ビュワー |

- 対応表 `docs/word-list/word-list-ai-slop.yaml` に上の 8 単語の行を追加する。`pattern` は対応表の `pattern-rules-01` の書き方に従う
- 各行の `examples` の `hit` にヒットすべき文を、`pass` に誤検出させない文を記載し、`check_all.py` の検査に合格させる
- 次の単語を含む別の単語はヒットさせない

  | 行 | ヒットさせない単語 |
  | --- | --- |
  | 旧い | 「旧い。」のように名詞が続かないとき・旧 |
  | 確度 | 正確度・精確度 |
  | 語り | 物語・語り合う |
  | 正本 | 修正本文・訂正本 |
  | 起こす | 書き起こし・引き起こす・掘り起こす・起きる |
  | 当たる | 当たり前・突き当たる・心当たり・行き当たる・該当する |
  | ビューアー | レビューアー・プレビューアー |

- 「起こす」は `pattern` で意味を区別できないため、`note` に対象の意味（資料・設計書にする）を記載する
- 「当たる」は既存の行 `ateru`（当てる）と別の行にする
- 既存の行 `go`（語）が「語り」にヒットしないよう、`pattern` か `allow` で除き、`examples.pass` に「語り」を追加する
- 規約『文章の書き方』の `word-choice-principle-02` の良い例「確度」を「確信度」へ修正する
- 対応表のコピー `plugins/slop-check/hooks/post-tool-use/word-list-ai-slop.json` を `scripts/build_word_list.py` で再生成する

対応表の行のキーは追加せず、スキーマ・`build_word_list.py`・`slop_check.py` は変更しない。
