# 話し合いで指摘した 8 単語（旧い・確度・語り・正本・出どころ・起こす・当たる・ビューアー）を AI slop の対応表に追加する

## 概要

エージェントが旧い・確度・語り・正本・出どころ・起こす・当たる・ビューアーを記載したとき、プラグイン slop-check から置き換え先を通知されるようになる。

## 背景

[Issue #196](https://github.com/shuhei1101/knowledge/issues/196) の要望。
AI が資料・返信にこの 8 単語を記載し、利用者が 11-03〜11-05 に話し合いのスレッドで 1 件ずつ指摘した。
対応表（[#148](https://github.com/shuhei1101/knowledge/pull/148)・[#169](https://github.com/shuhei1101/knowledge/pull/169) で追加）には、この 8 単語の行が無い。
規約『文章の書き方』は「確からしさ」の置き換え先に「確度」を良い例として記載しており、追加する NG と食い違う。
既存の文書を移行して AI slop を修正する [#145](https://github.com/shuhei1101/knowledge/issues/145) は、この PR の後に着手する。
