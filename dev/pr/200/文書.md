## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 対応表の行（動詞） | 起こす・当たるを、`pattern-rules-01` の動詞の書き方（語幹 + 活用語尾、前に漢字の否定の後読み）で追加する。書き起こし・引き起こし・掘り起こし・当たり前・突き当たり・心当たり・行き当たりは `allow` で除く | 「起こす」は `note` に「資料・設計書にする意味のとき」と記載する。「当たる」は行 `ateru` と別の行にする |
| 対応表の行（名詞・形容詞） | 旧い・確度・語りを、前後の文字の先読み・後読みで追加する。旧いは名詞（漢字・カタカナ）が続くときだけ、確度は前に漢字が続かないときだけ、語りは「語り合」を除いてヒットさせる | - |
| 対応表の行（2 文字以上の名詞） | 正本・出どころ・ビューアーは `pattern` を省く。正本が「修正本文」「訂正本」に、ビューアーが「レビューアー」「プレビューアー」にヒットしないよう、`allow` か前の文字の否定の後読みで除く | 除く単語を `examples.pass` に記載する |
| 対応表の `examples` | 各行の `hit` に要望の例の NG の文を、`pass` に要望の「ヒットさせない単語」を記載する | `check_all.py` が照合を検査する |
