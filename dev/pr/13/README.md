# プロンプトのファイルを触るときの規約を作る（1 ノード 1 枚の YAML・英日をキーで持つ）

## 概要

プロンプトのファイル（`**/prompts/**`・`**/prompt/**`）を触るときに当たる、1 ノード 1 枚の YAML（英日を `text.en`・`text.jp` のキーで持つ）の規約を作り、今の『プロンプト執筆』『プロンプトローダー』をこの形に合わせる。

## 背景

[Issue #8](https://github.com/shuhei1101/knowledge/issues/8) の要望。
今の規約は [#3](https://github.com/shuhei1101/knowledge/issues/3)（[#10](https://github.com/shuhei1101/knowledge/pull/10)）で ai-monitor から移した python/llm『プロンプト執筆』『プロンプトローダー』で、部品ごとの `.j2`・`.md` と `.jp.*` のミラーを `content/prompts/index.yaml` で組み立てる形になっている。
aituber ではプロンプトを 1 ノード 1 枚の YAML で持つと決めており（[shuhei1101/aituber#47](https://github.com/shuhei1101/aituber/issues/47)）、今の規約の形と合わない。
`**/prompts/**`・`**/prompt/**` に当たる規約が無く、置き方・書き方がその都度ばらばらに決まっている。
