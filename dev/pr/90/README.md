# Python の FastAPI の規約に operationId・ProblemDetail・camelCase のキー・StrEnum・例外の名前と HTTP へのマップの決まりを記載する

## 概要

FastAPI のバックエンドを React へ移行する人が、orval で生成するフック・型の名前とキーを決める operationId・エラーのスキーマ・JSON のキー・選択肢の型・例外の HTTP へのマップを、規約から読めるようになる。

## 背景

[Issue #84](https://github.com/shuhei1101/knowledge/issues/84) の要望。
各リポジトリの React 移行は openapi.json から orval でフックと型を作る（D-22）。生成物の名前と型はバックエンドの operationId・エラーのスキーマ・JSON のキーで決まるため、移行より先に決まり（D-44・D-45・D-47）を規約へ入れる。
この 3 件は Python の規約の見直し [#81](https://github.com/shuhei1101/knowledge/issues/81) から切り出した。決定の記録はローカルのワークスペース `tmp/react移行計画` にある。
