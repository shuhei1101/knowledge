## 要望

[#84](https://github.com/shuhei1101/knowledge/issues/84) の `## やること` の 3 件（D-44・D-45・D-47）を、develop の `docs/rule/` の Python の規約へ記載する。
変更する項目以外の文言は一字一句そのまま残す（規約『既存文章の維持』）。
各リポジトリのバックエンドへ当てるのは後続の移行の Issue で行い、この PR では規約の文書だけを変える。

### D-44: operationId とエラーレスポンスのスキーマ

- operationId は `FastAPI(generate_unique_id_function=...)` で `{tag}-{関数名}` にする（`python-fastapi-application`）
- `APIRouter(tags=)` の tag は 1 つ必須にする（`python-fastapi-route` の `writing-01`）
- エラーレスポンスは `ProblemDetail` モデルを `APIRouter(responses=...)` で一括宣言する（`python-fastapi-route` の `writing-04`）
- `RequestValidationError`（422）も ProblemDetail に揃える。「カスタム可」を必須にする（`python-fastapi-auth-error` の `exception-handler-04`）
- openapi.json のスナップショットテストを置き、破壊的変更を検知する（`python-testing-pytest` の FastAPI ルートのテストのグループ）

### D-45: JSON のキーと選択肢

- API のスキーマの基底クラスに `alias_generator=to_camel`・`validate_by_name=True`・`serialize_by_alias=True` を置き、JSON のキーを camelCase にする（`python-fastapi-schema` の `camelcase-01` を置き換える）
- API に出る選択肢は `StrEnum`（名前付きのスキーマ）、内部は `Literal` にする（`python-fastapi-schema` の `field-01`、`python-shared-constant` の `fixed-choices-01`）

### D-47: 自前の例外の名前と HTTP へのマップ

- `ValidationError` を `InvalidInputError` に改名する（`python-shared-error-definition` の例外階層の表と `handling-place-02`、`python-fastapi-auth-error` の対応表）
- `LlmRateLimitError`・`LlmServerError` は 503（Retry-After 付き）にする（`python-fastapi-auth-error` の `exception-handler-01`）
- 例外から HTTP へのマップは `python-fastapi-auth-error` の `exception-handler-01` の 1 か所にし、ほかは参照だけにする（今の HTTP の表はこの 1 か所だけで、`python-shared-error-definition` の `handling-place-01` は参照になっている。表を増やさない）
