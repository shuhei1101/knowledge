# 索引の、範囲から外すために列挙を分けたエントリを exclude で書き直す

## 概要

`rules.yaml` のうち、当てる範囲から一部を外すために広いパターンを細かく分けて列挙したエントリを、`exclude` を使った書き方へ書き直す。

## 背景

[Issue #35](https://github.com/shuhei1101/knowledge/issues/35) の要望（[shuhei1101/ai-monitor#2587](https://github.com/shuhei1101/ai-monitor/issues/2587) から移した Issue）。
rule-inject の索引は `paths` から外すパスを `exclude` で書けるが、`rules.yaml` には外したい範囲を避けて列挙し直したエントリが残っている。
[#37](https://github.com/shuhei1101/knowledge/pull/37)・[#39](https://github.com/shuhei1101/knowledge/pull/39) で `exclude` を使うエントリが入った。
