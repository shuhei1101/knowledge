# 規約『タグと用語の登録』と判定フローチャート『タグの付与』に、単語まで分ける付け方・action: の命名・拾う範囲・ファイルの種類ごとの書き出す範囲を入れる

## 概要

文書にタグを付ける AI（dev-docs・MindStella・aituber・AI Monitor の task-planner）が、この規約を参照するだけで、タイトル・見出しの語を単語まで分けて `topic:`・`action:` などのタグを判断なしに付けられるようになる。

## 背景

[Issue #111](https://github.com/shuhei1101/knowledge/issues/111) の要望。
規約『タグと用語の登録』と判定フローチャート『タグの付与』は [#85](https://github.com/shuhei1101/knowledge/issues/85)（[PR #100](https://github.com/shuhei1101/knowledge/pull/100)）で「取りこぼさない付け方」に改めたが、タグの分け方（単語まで分解するか）・拾う範囲・ファイルの種類ごとの扱いが決まっておらず、「A の B」の名詞句のタグが乱立して同じ概念で付く先が割れる。
その後の話し合いで、件名付与の標準（LOC の TGM・Z39.19・PMEST）と照らして D-179〜D-182 を決めた（決定の記録はローカルのワークスペース `tmp/mcpベストプラクティス検討`）。
