# 設計書のスキーマを knowledge の正本に移し、各プロジェクトのコピーの差分を取り込む

## 概要

各プロジェクトが、ai-monitor のスキーマのコピーを持たずに、knowledge の設計書のスキーマをタグで指して使えるようにする。

## 背景

[Issue #161](https://github.com/shuhei1101/knowledge/issues/161) の要望。
設計書のスキーマ（`dev/テンプレート/*.schema.yaml`）は ai-monitor が正本で、各プロジェクトがコピーを持ち、コピーはほぼ全て ai-monitor とずれている。
knowledge にスキーマを 1 つだけ置き、各プロジェクトは dev-docs のほかの配信元のスキーマの参照（[shuhei1101/dev-docs#94](https://github.com/shuhei1101/dev-docs/issues/94)）でタグつきで指す。

AI Monitor の検査の切り替えとコピーの廃止は [shuhei1101/ai-monitor#3188](https://github.com/shuhei1101/ai-monitor/issues/3188)、人が読むテンプレートの生成は [#163](https://github.com/shuhei1101/knowledge/issues/163) が持つ。
