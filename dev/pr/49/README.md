# 判定フローチャートのテンプレートの補足を、実在する README.md の目次に合わせる

## 概要

判定フローチャートのテンプレートの補足が指す、無い `index.yaml` の `summary` を、実在する `README.md` の目次に合わせて直す。

## 背景

[Issue #43](https://github.com/shuhei1101/knowledge/issues/43) の要望。
`dev/テンプレート/判定フローチャート.md` の冒頭は置いたフォルダの `README.md` の目次に 1 行追加するとしているが、`## タイトル` の補足はタイトル直下の 1 行を同フォルダの `index.yaml` の `summary` に揃えるとしており、`dev/判定フローチャート/` に `index.yaml` は無い。
文書の置き方の規約は [#42](https://github.com/shuhei1101/knowledge/issues/42)（[PR #48](https://github.com/shuhei1101/knowledge/pull/48)）で入った。
