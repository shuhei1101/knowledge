# テンプレート『概要・クイックスタート』『リファレンス』『チェックシート』の配置先・形式の記述を規約『ドキュメント管理』に合わせる

## 概要

テンプレート『はじめに』『リファレンス』『チェックシート』を読んで文書を作る人が、規約『ドキュメント管理』どおりの置き場所・ファイル名・YAML の書式で文書を作れるようにする。

## 背景

[Issue #119](https://github.com/shuhei1101/knowledge/issues/119) の要望。
3 つのテンプレートは `docs/template/` の YAML へ移った後も、実体ページの配置先・形式を markdown の前提で記載している。
作業 PR [#117](https://github.com/shuhei1101/knowledge/pull/117)（起点 Issue [#66](https://github.com/shuhei1101/knowledge/issues/66)）でテンプレート『テンプレート』『判定フローチャート』『セットアップ手順』の同じ型の記述を修正し、この 3 つは [reviewer のレビュー](https://github.com/shuhei1101/knowledge/pull/117#discussion_r4421892406) で別の Issue に切り出した。
