# ai-monitor の規約・判定フローチャート・チェックシート・テンプレートのうち、AI Monitor を前提にしないものを knowledge へ移行する

## 概要

AI Monitor を使用しない開発や手元のセッションでも、ai-monitor にあった一般の規約・判定フローチャート・チェックシート・テンプレートを knowledge から検索・参照できるようにする。

## 背景

[Issue #170](https://github.com/shuhei1101/knowledge/issues/170) の要望。
ai-monitor の `dev/エージェント運用/` の規約・判定フローチャート・チェックシートと `dev/テンプレート/` に AI Monitor を前提にしない一般の決まりが混ざり、AI Monitor のエージェントの起動プロンプトにだけ届いている。
話し合いの A-21 で移行・一部移行・統合・維持に分類し、D-29（ai-monitor 側は削除し knowledge の文書を参照する）・D-30（プロジェクトが独自のテンプレートを持つ条件）を決めた。
『データフロー作成判定』『PoC要否』は A-26 で判定表へ書き換えると決め、判定表のテンプレートは [#174](https://github.com/shuhei1101/knowledge/pull/174) で追加済み。
ai-monitor 側の削除と参照の付け替えは [shuhei1101/ai-monitor#3195](https://github.com/shuhei1101/ai-monitor/issues/3195) が受け持つ。
