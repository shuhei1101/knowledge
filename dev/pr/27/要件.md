# 要件

## 要望

規約『プロンプトファイル』の日本語のミラーのキーを `text.jp` から `text.ja` にする。
終わりの条件は、規約・文書（PR ドキュメント `dev/pr/` の過去の記録を除く）に言語コードとしての `jp` が残っていないこと。

`origin/develop` で言語コードとしての `jp` が残るのは次の箇所だけで、ほかの規約・文書には無い。

| ページ | 箇所 |
| --- | --- |
| [dev/コーディング規約/prompt/プロンプトファイル.md](https://github.com/shuhei1101/knowledge/blob/develop/dev/%E3%82%B3%E3%83%BC%E3%83%87%E3%82%A3%E3%83%B3%E3%82%B0%E8%A6%8F%E7%B4%84/prompt/%E3%83%97%E3%83%AD%E3%83%B3%E3%83%97%E3%83%88%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB.md) | `## 形` の部品のキーの表の `text.jp`・YAML の例の `jp:`・`## 本文` の 2 行の `text.jp`・`## 検査` の `text.jp` |
