# 要件

## 要望

`dev-docs.yaml` の `documents[]` のうち、`tags` を `- name:` の要素で持つ種類（`rule`・`template`・`flowchart`・`guide`・`changelog`・`skill`）の行に `metadata` の `tags: tags[].name` と `main_tags: tags[main].name` を記載する。
`tags` を文字列の配列で持つ `hooks`・`skills`・`scripts`（`files.yaml`）の行には記載しない。

記載後、dev-docs#43 の入った dev-docs（develop の [9bac461](https://github.com/shuhei1101/dev-docs/commit/9bac4618a08befce2a121928a6267d26cf28000c) 以降）で次を確かめる。

- `search_docs` の `group_by: tags` が `topic:*`・`scope:*` などのタグの名前で数え、`{'name': ...}` の値を返さない
- `search_docs` の `fields: [tags]` が各文書のタグを名前の文字列の配列で返す
- `filter` の `tags` の `eq` でタグの名前に一致する文書が当たる
- `search_docs` の `fields: [main_tags]` が `main: true` のタグの名前だけを返す

完了したら [shuhei1101/rule-inject#95](https://github.com/shuhei1101/rule-inject/issues/95) に着手できる旨をコメントする。

`main_tags: tags[main].name` は、knowledge の文書が主題のタグに `main: true` を付けており、同じ行の 1 キーで主題のタグで絞れるようになるため、あわせて記載する。
