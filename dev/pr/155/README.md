# 規約『YAML』の mcp-write-04 の expected_version の記述を dev-docs の write_docs の挙動と一致させる

## 概要

規約『YAML』の `mcp-write-04` の `expected_version` の値と照合の単位の記述を、dev-docs の `write_docs` の挙動と一致させる。

## 背景

[Issue #153](https://github.com/shuhei1101/knowledge/issues/153) の要望。
規約『YAML』（`docs/rule/dev-yaml.yaml`）の `mcp-write-04` は、書き込みの `expected_version` を項目ごとの `rev` と定めているが、dev-docs の `write_docs` の `expected_version` は文書ごとに中身から作るバージョン（`search_docs` の `version` 列の値）で、`rev` ではない。
[#152](https://github.com/shuhei1101/knowledge/pull/152)（起点 Issue [#151](https://github.com/shuhei1101/knowledge/issues/151)）の現状調査で見つかり、切り出した。
