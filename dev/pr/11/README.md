# 設計書テンプレートのスキーマから Markdown のテンプレートを組み立てて置く

## 概要

ai-monitor の設計書テンプレートのスキーマ 15 件から、1 スキーマ 1 ページの Markdown のテンプレートを組み立てて `dev/テンプレート/` に置く。

## 背景

[Issue #9](https://github.com/shuhei1101/knowledge/issues/9) の要望。
[#3](https://github.com/shuhei1101/knowledge/issues/3)（[#10](https://github.com/shuhei1101/knowledge/pull/10)）は Markdown のテンプレートだけを写し、スキーマに移った設計書のテンプレートを外した。
ai-monitor 側で書き出す処理を作る [shuhei1101/ai-monitor#2705](https://github.com/shuhei1101/ai-monitor/issues/2705) の代わりに、このリポジトリで組み立てる（[ユーザーの指示](https://github.com/shuhei1101/knowledge/issues/1#issuecomment-6231177426)）。
