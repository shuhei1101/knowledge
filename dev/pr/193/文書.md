## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 公開仕様の調査 | 主要な LLM の API の公開仕様と stamina・SDK の既定値を一次情報で調べ、導出の元として使用できる値を `要件.md` の表の値ごとに決める | 調査の結果で `要件.md` の `未確定` を確定する |
| 入れ子の関係 | クライアントの各回のタイムアウト < stamina の `timeout`（全試行）< `@with_timeout`（全体）の関係を、規約『資源の値の決め方』の「入れ子の待ち」「リトライ」の式で `timeout-01` に記載する | 間隔の上限は `retry_after` で `wait_max` まで待つ場合を含める。Instructor の再試行は各回の待ちに含める |
| 値の置き場所 | 値の導き方は `python-llm-exception-retry` の `timeout-01` だけに記載し、他の項目はそこへ参照する | - |
| Retry-After | `wait_max` の導き方を決めた後に `exception-handler-01` の 3 行と照らし、意味が変わらなければ変更しない | - |
