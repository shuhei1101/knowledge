# Python の規約のタイムアウト・リトライの値を、規約『資源の値の決め方』の導き方に合わせる

## 概要

Python の規約を参照したエージェントが、タイムアウト・リトライの値を規約『資源の値の決め方』の導き方どおりに決められるようにする。

## 背景

[Issue #186](https://github.com/shuhei1101/knowledge/issues/186) の要望。[PR #183](https://github.com/shuhei1101/knowledge/pull/183) の `要件.md` の `## スコープ外` から切り出した。
規約『資源の値の決め方』は値の横に導出の元の値と導き方を記載すると定めるが、Python の規約の例の 30・60 秒は導出の元を持たず、エージェントが例の値をそのまま各プロジェクトへ写す。
