# プラグインの設定は env に設定ファイルのパスだけを置き、本体を ~/.config の YAML（global・projects）に書くと規約に書く

## 概要

プラグインを作る人が、利用者ごと・プロジェクトごとの設定を `env` の設定ファイルのパスと `~/.config` の YAML（`global`・`projects`）で受け取る決まりを、規約から読めるようになる。

## 背景

[Issue #58](https://github.com/shuhei1101/knowledge/issues/58) の要望。
`claudeプラグイン.md` は利用者の環境ごとに変わる値を `env` から環境変数で受け取るとだけ書いており、`env` はキーと値しか持てないため、プロジェクトごとに違う設定や、項目ごとに複数の値を持つ設定を書けない。
knowledge のワークスペース `tmp/mcpベストプラクティス検討` の話し合い（TH-121・D-87）で、設定の持ち方を決めた。
