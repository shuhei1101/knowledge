# 要件

## 要望

`rules.yaml` で画面の実装の規約を当てるエントリが、設計書の Markdown（`{名前}.html.md`・`{名前}.css.md`・`{名前}.py.html.md` 等）に当たらないようにする。

対象は、拡張子の後ろに `*` を付けた glob をフォルダで絞らずに持つ次のエントリ。

| 規約 | 当たる glob |
| --- | --- |
| [html/core/iframe禁止.md](https://github.com/shuhei1101/knowledge/blob/develop/dev/%E3%82%B3%E3%83%BC%E3%83%87%E3%82%A3%E3%83%B3%E3%82%B0%E8%A6%8F%E7%B4%84/html/core/iframe%E7%A6%81%E6%AD%A2.md) | `**/*.html*` |
| [html/モバイル対応.md](https://github.com/shuhei1101/knowledge/blob/develop/dev/%E3%82%B3%E3%83%BC%E3%83%87%E3%82%A3%E3%83%B3%E3%82%B0%E8%A6%8F%E7%B4%84/html/%E3%83%A2%E3%83%90%E3%82%A4%E3%83%AB%E5%AF%BE%E5%BF%9C.md) | `**/*.html*`・`**/*.css*` |
| `ui/` の『画面の分け方』・『業務画面のUI要素』・『画面デザインの原則』・『情報の階層と見た目』・『操作とアクセシビリティ』・『入力と文言』・『表示の安定』・『対応ブラウザ』 | `**/*.html*`・`**/*.{tsx,jsx,vue,svelte}*` |

`ui/` のエントリは `**/設計書/画面設計/**` にも当てており、画面設計の設計書には当て続ける。
`.html`・`.css` の実装と、Jinja2 のテンプレート（`.html.j2` 等）には当て続ける。

言語の書き方の規約（『html/html/コメント』・『html/html/ネイティブ要素』・『html/css/コメント』・『html/css/ネスト』・『html/naming/cssクラス』）は、設計書の Markdown に当て続ける。
ai-monitor の規約『ドキュメント管理』の `## ファイル命名規約` が、`.{lang}.md` で設計書へ言語の規約を当てると定めているため。

## 影響するユースケース

なし（コードを持たず、ユースケースを持たない）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| `**/*.py*`・`**/*.{ts,tsx}*` 等、他の言語の規約のエントリが `.py.md`・`.ts.md` の設計書に当たる | 規約『ドキュメント管理』の `.{lang}.md` の命名が意図した当たり方で、規約の逸脱ではない | 予定なし |
| 規約『コーディング全般』・『YAML』の `**/*.{py,html,js,css,j2,ts,tsx,yaml,yml}*` | 実装全般の規約で、画面の実装の規約ではない | 予定なし |
| `frontend/`・`templates/` 等のフォルダで絞ったエントリ | 設計書の Markdown はそのフォルダに置かれない | 予定なし |
| 範囲から外すために列挙を分けた既存のエントリの `exclude` での書き直し | 既存の書き方の整理は別の Issue が扱う | [#35](https://github.com/shuhei1101/knowledge/issues/35) |
