# 要件

## 要望

規約『Claude プラグインルール』（`docs/rule/claude-plugin.yaml`）の `## 設定ファイル` に、設定ファイルを持つプラグインでも `env` に置く値の例外を記載する（mcpベストプラクティス検討の D-95）。
変える項目の外の文言は一字一句そのまま残す（規約『既存文章の維持』）。

- 設定はできる限り設定ファイルにまとめる原則は `settings-file-01` のまま変えない
- `.mcp.json` など YAML を読めない仕組みも読む値（例: [MCP サーバー作成ルール](id:claude-mcp) の `## 登録` の `{リポジトリ}_PORT`）は、設定ファイルを持つプラグインでも `env` に置き、サーバーと `.mcp.json` の両方が同じ `env` を読む、と記載する
  - 同じ値を設定ファイルと `env` の 2 か所に書かない
- `settings-file-06` の「受け取る値が増えたり…したら、設定ファイルへ移す」は、上の例外に当たる値を移す対象から外す形に書き換える
- `settings-file-06` の例の `{リポジトリ}_PORT` は、上の例外の例へ移すか、単純な値の例として残すかを、例外の項目との重なりが無いように決める
- [MCP サーバー作成ルール](id:claude-mcp) の `## 登録`（`{リポジトリ}_PORT` を `env` に書いて上書きし、サーバーも同じ値を読む）と食い違わないことを確かめる

変えた規約は `rev` を 1 つ上げ、`last_reviewed` を変えた日にする。
