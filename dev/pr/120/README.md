# 規約『Claude プラグインルール』の設定ファイルに、.mcp.json も読む値は設定ファイルを持つプラグインでも env に置く例外を追加する

## 概要

設定ファイルを持つプラグインでも、`.mcp.json` など YAML を読めない仕組みも読む値（MCP サーバーのポート `{リポジトリ}_PORT`）は `env` に置く例外を、規約『Claude プラグインルール』の `## 設定ファイル` に記載する。

## 背景

[Issue #63](https://github.com/shuhei1101/knowledge/issues/63) の要望。
`settings-file-06` は `env` で直接受け取ってよい例外を「単純な値 1 つだけを受け取るプラグイン」に限り、受け取る値が増えたら設定ファイルへ移すと定めている。
このままでは設定ファイルを持つプラグインはポートも設定ファイルへ移すことになるが、ポートはサーバーとプラグインの `.mcp.json`（接続先の url）の両方が読み、`.mcp.json` は環境変数の展開しかできず YAML を読めない。
mcpベストプラクティス検討の D-95 で、ポートは `env` の `{リポジトリ}_PORT` 1 つで持つと決まった。
依存の [#44](https://github.com/shuhei1101/knowledge/issues/44) は close 済みで、規約は `docs/rule/claude-plugin.yaml` へ移っている。
