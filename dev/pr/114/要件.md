# 要件

## 要望

開発ドキュメントサーバーは dev-docs を使うことと、dev-docs での文書の配信の決まりを規約に記載し、ポートの台帳の文書の MCP の行を修正する。
変える項目の外の文言は一字一句そのまま残す（規約『既存文章の維持』）。

規約『MCP サーバー作成ルール』（`docs/rule/claude-mcp.yaml`）:

- `## 登録` の `registration-01`・`registration-03`〜`registration-05` を、文書の MCP は dev-docs のプラグイン（ユーザースコープで入れる）が配る、に置き換える。各リポジトリは文書の MCP のプラグインとマーケットプレイスを持たない
- 文書の MCP の接続先は `http://127.0.0.1:${DEV_DOCS_PORT:-8781}/mcp` の 1 つで、配信元はツールの引数 `source` で指す、と記載する
- `registration-06` の接続先の例（`KNOWLEDGE_PORT`）を、台帳にある自分のツールの MCP の例（rule-inject・`RULE_INJECT_PORT`・8783）に置き換える
- `server-tool-unit-01` の「文書の置き場所（リポジトリ）ごとにサーバーを 1 つにする」を、文書の MCP のサーバーは dev-docs の 1 つにし、配信元ごとに分けない（`## 登録`）、に書き換える
- `registration-12` の台帳の knowledge の行（`KNOWLEDGE_PORT`・8781）を、dev-docs の行（`DEV_DOCS_PORT`・8781）に置き換える。ほかの行（observability・ai-monitor・claude-balancer・mdmark・rule-inject・MindStella）は今のまま
- `mdmark-yaml-role-01` の「YAML の正本と、それを扱う MCP・開発ドキュメントサーバーは、文書を持つ各プロジェクトが持つ」を、YAML の正本・スキーマ・検査と変換のスクリプトは各プロジェクトが持ち、MCP と開発ドキュメントサーバーは dev-docs が持つ、に修正する

規約『ドキュメント管理』（`docs/rule/dev-document-management.yaml`）:

- `## 配信` に、開発ドキュメントサーバーは dev-docs を使い、各リポジトリは直下に `dev-docs.yaml`・スキーマ・検査と変換のスクリプトだけを置く、と記載する
- 立て方（`/dev-docs:global-setup` で端末を準備し、`/dev-docs:setup {リポジトリ}` で配信元を登録する）を記載する。手順の詳細は dev-docs の使い方のページ（`docs/使い方/dev-docsを入れる.md`・`docs/使い方/配信元を配信する.md`）を参照し、knowledge に写さない
- どの作業場所からどの配信元を読み書きできるかは、端末の設定 `~/.config/dev-docs/settings.yaml` の `sources[]` の `scope.read`・`scope.write` で決める、と記載する
- 文書のメタデータとエイリアスは、`dev-docs.yaml` の documents の行の `metadata` で文書の列と対応づける（`metadata` は列の対応だけ。`alias_type` は行の属性）、と記載する。エイリアスの共通のスキーマは alias-inject の [エイリアスのスキーマ](https://github.com/shuhei1101/alias-inject/blob/develop/docs/%E3%83%AA%E3%83%95%E3%82%A1%E3%83%AC%E3%83%B3%E3%82%B9/%E3%82%A8%E3%82%A4%E3%83%AA%E3%82%A2%E3%82%B9%E3%81%AE%E3%82%B9%E3%82%AD%E3%83%BC%E3%83%9E.md) を参照する
- Markdown・ソースコードなど YAML でない文書は、検索したいものをすべてフォルダの直下の管理用の YAML（`files.yaml`）の行に載せ、パス・タグ・説明を記載する、と記載する
- 設定のキーは dev-docs の設定のページ（`docs/リファレンス/設定.md`）を参照し、knowledge にキーの一覧を写さない

規約『Claude プラグインルール』（`docs/rule/claude-plugin.yaml`）:

- `plugin-division-02` を、各リポジトリは文書の MCP のプラグインを持たない（規約『MCP サーバー作成ルール』の `## 登録`）に合わせる

変えた 3 ページは `rev` を 1 つ上げ、`last_reviewed` を変えた日にする。
