# 規約に dev-docs での文書の配信（立て方・dev-docs.yaml・接続先）を記載し、文書の MCP のポートの台帳を修正する

## 概要

開発ドキュメントサーバーは dev-docs を使うことと、dev-docs での文書の配信（立て方・`dev-docs.yaml`・接続先・読み書きできる範囲・メタデータの対応づけ・`files.yaml`）を規約に記載し、ポートの台帳の文書の MCP の行を修正する。

## 背景

[Issue #73](https://github.com/shuhei1101/knowledge/issues/73) の要望。
規約『MCP サーバー作成ルール』の登録とポートの台帳、規約『ドキュメント管理』の配信、規約『Claude プラグインルール』は、リポジトリごとに開発ドキュメントサーバーとポートを持ち、`{リポジトリ}-docs` のプラグインで文書の MCP を配る前提で書かれている。
MCP ベストプラクティスの話し合い（D-82・D-107・D-131・D-132・D-152・D-161・D-164・D-165・D-171）で、文書の配信は dev-docs 1 つに寄せると決まり、依存の shuhei1101/dev-docs#3・shuhei1101/dev-docs#4・shuhei1101/dev-docs#14・shuhei1101/dev-docs#32・shuhei1101/alias-inject#20・shuhei1101/alias-inject#37 は close 済み。
