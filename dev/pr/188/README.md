# 埋め込みのマーカーの結合テストが、表のセルと一致する対応表の examples.hit で失敗するのを修正する

## 概要

埋め込みのマーカーの結合テスト `test_normal_when_embed_marker` が、対応表の NG・OK の表を正しく出した変換の結果で失敗しないようにする。

## 背景

[Issue #179](https://github.com/shuhei1101/knowledge/issues/179) の不具合。
[#169](https://github.com/shuhei1101/knowledge/pull/169) で AI slop の対応表に追加した 1 単語の値の行（`utsusu-move`・`nokosu`・`utsusu-copy`・`ireru`・`wakeru`）は、`examples.hit` に `'| 移す |'` などの表のセルの文字列を持つ。
[#162](https://github.com/shuhei1101/knowledge/pull/162) で追加した結合テストは「`examples.hit` の文字列が変換の出力に含まれない」を検証しており、NG の列を `| {ng} |` で出す変換の出力がこの文字列を含むため、develop（`4fc7266`）で失敗する。
CI（`docs-check.yml`）は pytest を実行しないため、他の PR のマージは止まっていない。
[PR #176](https://github.com/shuhei1101/knowledge/pull/176) の結合テストの実行で見つけた。
