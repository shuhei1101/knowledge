# プロンプトの YAML の規約をフックの注入文・MCP の instructions・ツールの description に広げ、キーを見直してスキーマを schemas/ に置く

## 概要

規約『プロンプトファイル』の対象を、LLM の呼び出しに加えてフックの注入文・MCP の instructions・ツールの description に広げ、キーを言語を縛らない形と入れ子の変数の定義に見直し、各プロジェクトが指すスキーマ `schemas/prompt.schema.yaml` を knowledge に置く。

## 背景

[Issue #128](https://github.com/shuhei1101/knowledge/issues/128) の要望（検討事項 D-190〜D-200）。
`docs/rule/prompt-file.yaml` は LLM の呼び出しのプロンプトだけを対象にしており、フックの注入文・MCP の instructions・ツールの description は各プラグインがコードに埋め込んでいる。
これらも同じ YAML に置き、dev-docs の画面で利用者が読めるようにする。
後続に [#129](https://github.com/shuhei1101/knowledge/issues/129)・[shuhei1101/dev-docs#47](https://github.com/shuhei1101/dev-docs/issues/47)・[shuhei1101/dev-docs#48](https://github.com/shuhei1101/dev-docs/issues/48) がある。
