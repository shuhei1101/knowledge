# 要件

## 要望

表のセル・ラベル・ボタン・分類の値など、1 単語だけを配置する箇所に和語の動詞を記載したとき、プラグイン slop-check が漢語への置き換えを通知する。

| NG | OK |
| --- | --- |
| 移す | 移行・移動 |
| 残す | 維持・保持 |
| 写す | 複製・コピー |
| 入れる | 登録・追加・格納 |
| 分ける | 分割・分類 |

- 対応表 `docs/word-list/word-list-ai-slop.yaml` に上の 5 単語の行を追加し、「一部を移す」のような短い句もヒットさせる
- 各行の `examples` の `hit` に 1 単語の値（表のセル）を、`pass` に誤検出させない文を記載し、`check_all.py` の検査を通す
- 規約『文章の書き方』の用語の選び方の原則（`word-choice-principle-02`）と、対応表の説明（`pattern-rules-01`）に、1 単語の値の扱いを記載する
- 対応表のコピー `plugins/slop-check/hooks/post-tool-use/word-list-ai-slop.json` を `scripts/build_word_list.py` で作り直す

ヒットさせる範囲は、`pattern` の前後に表の区切り（`|`）・行頭と行末・かぎ括弧とバッククォートの条件を付け、1 単語の値か「一部を移す」のような短い句のときだけヒットさせる。
文中の「ログを残す」「値を入れる」はヒットさせない。
対応表の行のキーは追加せず、スキーマ・`build_word_list.py`・`slop_check.py` は変更しない。
