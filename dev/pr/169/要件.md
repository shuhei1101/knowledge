# 要件

## 要望

表のセル・ラベル・ボタン・分類の値など、1 単語だけを配置する箇所に和語の動詞を記載したとき、プラグイン slop-check が漢語への置き換えを通知する。

| NG | OK |
| --- | --- |
| 移す | 移行・移動 |
| 残す | 維持・保持 |
| 写す | 複製・コピー |
| 入れる | 登録・追加・格納 |
| 分ける | 分割・分類 |

- 対応表 `docs/word-list/word-list-ai-slop.yaml` に上の 5 単語の行を追加し、「一部を移す」のような短い句もヒットさせる
- 各行の `examples` の `hit` に 1 単語の値（表のセル）を、`pass` に誤検出させない文を記載し、`check_all.py` の検査を通す
- 規約『文章の書き方』の用語の選び方の原則（`word-choice-principle-02`）と、対応表の説明（`pattern-rules-01`）に、1 単語の値の扱いを記載する
- 対応表のコピー `plugins/slop-check/hooks/post-tool-use/word-list-ai-slop.json` を `scripts/build_word_list.py` で作り直す

`未確定`: ヒットさせる範囲の指定方法（決める工程: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `pattern` の前後を表の区切り（`\|`）・行頭と行末・引用符の先読みと後読みにして、1 単語の値のときだけヒットさせる（例: `(?<=\| )移す(?= \|)`） | スキーマ・`build_word_list.py`・`slop_check.py` を変更せず、対応表の行の追加だけで完結する | 区切りの種類ごとに後読みを並べるため `pattern` が長くなる |
| B | 対応表の行に、ヒットさせる範囲のキー（例: `scope: value`）を追加し、`slop_check.py` が値の範囲だけを照合する | 範囲の判定を 1 か所に集約でき、後から行を追加するときは `scope` を指定するだけになる | スキーマ・`build_word_list.py` の `COPY_KEYS`・`slop_check.py`・結合テスト 2 本を変更する |
| C | 既存の動詞の行（置く・使う 等）と同じく、文中でもヒットさせる | 既存の行と同じ書き方で、判定が単純になる | 「ログを残す」「値を入れる」のような文中の用法も全て通知する |

推奨: A

既存の行の追加と同じ書き方で完結し、文中の「残す」「入れる」を通知しないため誤検出が少ない。
区切りの種類が増えて `pattern` が読めない長さになる場合は、インターフェース定義設計で B へ切り替える。
