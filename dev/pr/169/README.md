# 表のセル・ラベルなど 1 単語だけを配置する箇所の和語の動詞を AI slop の対応表に追加する

## 概要

エージェントが表のセル・ラベル・分類の値に和語の動詞（移す・残す・写す・入れる・分ける）を記載したとき、プラグイン slop-check から漢語への置き換えを通知されるようになる。

## 背景

[Issue #167](https://github.com/shuhei1101/knowledge/issues/167) の要望。
資料の表の「判定」の列に「移す」「一部を移す」「残す」と記載し、利用者から「移行」「維持」のような漢語にするよう指摘を受けた。
周りに文が無い 1 単語の値は文中よりも和語が目立ち、「残す」が維持・保留・除外のどれかが分からない。
対応表（[#135](https://github.com/shuhei1101/knowledge/issues/135)・[#148](https://github.com/shuhei1101/knowledge/pull/148) で追加）には、この 5 単語の行が無い。
既存の文書を移行して AI slop を修正する [#145](https://github.com/shuhei1101/knowledge/issues/145) は、この PR の後に着手する。
