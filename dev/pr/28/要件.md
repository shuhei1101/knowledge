# 要件

## 要望

Next.js の規約の一覧読み取りの命名を、複数形（`{Feature}s`）をやめて `List` 接尾辞（`{Feature}List`）にそろえ、次のページで 1 通りに読める状態にする。
フックと対になる取得関数（`query.ts` の `fetch`・`client.ts` の `get`）も同じ形にそろえる。

一覧読み取りの名前は `use{Feature}List` / `fetch{Feature}List` / `getXxxList` にする。
一覧画面（`{Feature}ListScreen`）・URL 定数（`{FEATURE}_URL.list`）・URL state のフック（`useResourceListUrlState`）が既に `List` で一覧を表しており、同じ語で引けるため。

## 影響するユースケース

なし（コードを持たず、ユースケースを持たない）。
