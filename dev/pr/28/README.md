# Next.js の一覧読み取りの命名を 1 つにそろえる

## 概要

Next.js の規約で 2 通りに書かれている一覧読み取りの命名を 1 つに決め、関係する規約をそろえる。

## 背景

[Issue #20](https://github.com/shuhei1101/knowledge/issues/20) の要望。
一覧読み取りのフックの名前が、規約『useQuery パターン』では `use{Feature}s` / `use{Feature}List` の併記、規約『一覧スクリーン-tsx』では `use{Feature}s`、規約『命名規約』では `use{Feature}List` と食い違っている。
[#16](https://github.com/shuhei1101/knowledge/pull/16) で見つけ、既存プロジェクトの命名に関わるため切り出した。
