# 規約『ドキュメントの部品』の概要が指す書き方の参照先を、実在するものへ修正する

## 概要

規約『ドキュメントの部品』の概要が指す部品の書き方の参照先を、実在するものへ修正する。

## 背景

[Issue #147](https://github.com/shuhei1101/knowledge/issues/147) の要望。
`docs/rule/doc-parts.yaml` の `overview` は、書き方を規約『ドキュメント管理』の `### タブとステップ` と `### ファイルツリー・コードの行の印・バッジ` に委ねているが、knowledge の `docs/rule/dev-document-management.yaml` にそのセクションは無い（ai-monitor の規約『ドキュメント管理』にだけある）。
[#134](https://github.com/shuhei1101/knowledge/pull/134) の要件.md の `## スコープ外` から切り出した。
