# knowledge の文書を、道具が markdown を前提にするファイルを除いて YAML に移す

## 概要

エージェントが knowledge の規約・テンプレートを、種類ごとのスキーマを持つ YAML の正本から、タグ・概要文などのメタデータで引き、必要な部分だけを取得・注入できるようになる。

## 背景

[Issue #44](https://github.com/shuhei1101/knowledge/issues/44) の要望。
[#42](https://github.com/shuhei1101/knowledge/issues/42) で入った規約『ドキュメント管理』は、道具が markdown を前提にするファイルを除いて文書の正本を YAML にするとしているが、knowledge 自体は md の文書がメタデータ・タグ・索引を持たず、規約に合っていない。
依存の [#42](https://github.com/shuhei1101/knowledge/issues/42)・[shuhei1101/rule-inject#31](https://github.com/shuhei1101/rule-inject/issues/31) は閉じている。
mdmark は YAML を読まず、YAML の描画は knowledge が変換して mdmark で行う（話し合いの D-85）。
移した後の文書は [#51](https://github.com/shuhei1101/knowledge/issues/51) の開発ドキュメントサーバーと MCP が読む。
