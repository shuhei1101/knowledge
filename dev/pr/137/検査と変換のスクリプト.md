## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 公開の文書の取り出し | `dev-docs.yaml` の `documents` の `paths` に当たる文書を読み、`visibility` が `public` の文書だけを選ぶ | `records: files` の行（hooks・skills・scripts の files.yaml）は `visibility` を持たないため入れない |
| 変換 | 選んだ文書ごとに `knowledge_markdown.py` を子プロセスで呼び、Markdown を作業用のフォルダへ書く | 終了コードが 0 以外なら、文書のパスと標準エラーを出して 0 以外で終わる |
| 参照の書き換え | Markdown の `[表示](id:{文書の ID}#{項目の ID})` を、公開の文書へはまとめた HTML の中のリンクに、それ以外へは GitHub の master の YAML の URL に書き換える | 変換のスクリプトは変えず、成果物を作る側で書き換える |
| mdmark の設定 | 作業用のフォルダに mdmark の設定（`build.include`・`build.entry`・`build.out`）を書き、mdmark の `build` を呼んで 1 枚の HTML にまとめる | 要件.md の `## 要望` |
| 出力 | 指定した出力のフォルダに HTML だけを置き、作業用のフォルダは出力に含めない | 出力のフォルダが Pages の成果物になる |
| 処理時間 | 変換は 1 文書あたり 20 秒で打ち切り、全体は CI の 5 分に収める | 非機能要件のスクリプトの処理時間と CI の所要時間 |
