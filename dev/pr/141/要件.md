# 要件

## 要望

規約『MCP サーバー作成ルール』（`docs/rule/claude-mcp.yaml`）の既定のポートの台帳をリポジトリから削除し、端末のローカルの `~/.config/mcp-ports.yaml` を参照する記載に変更する。
knowledge に他リポジトリの MCP サーバーのポートの一覧を記載せず、新しいサーバーは `~/.config/mcp-ports.yaml` に行を追加するだけで済む状態にする。
変える項目の外の文言は一字一句そのまま残す（規約『既存文章の維持』）。

- `registration-12`（既定ポートの表）を削除する
- `registration-11`（ポート台帳の案内）を、既定のポートの台帳は端末のローカルの `~/.config/mcp-ports.yaml` に置き、`ports[]` の各行が `repo`・`env`・`port` を持つ、新しいサーバーは空いている番号で行を追加する、の記載に変更する
- `registration-08`（url の形式）の「次の台帳の環境変数と既定のポート」と、`registration-10`（サーバー側のポート）の「台帳の既定のポート」を、`~/.config/mcp-ports.yaml` の台帳を指す記載に変更する
- `registration-06`（接続先の記載）の例の `rule-inject`・`RULE_INJECT_PORT`・8783 を、他リポジトリの名前を出さない例（`{リポジトリ}` などのプレースホルダ）に置き換える
- `registration-05`（文書の MCP の接続先）の URL の例 `http://127.0.0.1:${DEV_DOCS_PORT:-8781}/mcp` を削除し、接続先は dev-docs のサーバーの 1 つで、`url` は `registration-08` の形式、ポートは台帳の行による、の記載にする。dev-docs の名前は `registration-03` で文書の MCP の配り手として出すため残す
- `tags` の `topic:ポート台帳`・`topic:台帳` は、規約が台帳の参照と行の追加を記載し続けるため残す

変えたページは `rev` を 1 つ上げ、`last_reviewed` を変えた日にする。
