# html・ui の規約を React 前提に見直し、キーボード操作とタグの絞り込みの規約を ui に新設する

## 概要

React で画面を作る人の `.tsx`・`vite.config.ts`・Tailwind の CSS に、バニラ TS 前提の html の規約が注入されなくなる。
画面を作る人が、トークン・レイアウト・タップ領域・WCAG 2.2・閉じ方・キーボード操作・タグの絞り込みと保存ビューの決まりを ui の規約から読めるようになる。

## 背景

[Issue #80](https://github.com/shuhei1101/knowledge/issues/80) の要望。
各リポジトリのフロントエンドをバニラ TS から React へ移すにあたり、knowledge のワークスペース `tmp/react移行計画` で html・ui の規約の扱いを決めた（D-30〜D-39・D-64・D-72〜D-79・D-86〜D-92）。
タグのデータ設計は、ワークスペース `tmp/mcpベストプラクティス検討` の D-169（タグのマスターを持たない）で決め直した。

- html の規約（47 件）の glob が React のファイルに当たり、「React・Vite を使わない」が `.tsx` と `vite.config.ts` に、`css-token` の `--color-*` が Tailwind v4 の名前空間に、`mobile` の 768px の max-width が Tailwind のモバイルファーストと逆向きに当たる
- ui の規約は、`.tsx` を 1 つ編集すると 8 件が当たり、同じ規約にエントリが 2 本ずつある
- キーボードの決まりは 2 行だけで、タグを付けたデータの絞り込みの決まりが無い

React の規約と共通の `typescript/`・`testing/` は [#89](https://github.com/shuhei1101/knowledge/pull/89)（[#79](https://github.com/shuhei1101/knowledge/issues/79)）で develop に入っている。
React の規約のうち `react-core-tailwind`・`react-keyboard-shortcut`・`react-keyboard-component` は、トークンの名前と段階・スタックによらないキー操作をこの PR が置く ui の規約に任せている。
