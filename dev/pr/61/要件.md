### プラグインの名前（`mcp.md` の `## 登録`）

- 文書の MCP のプラグインの名前は `{リポジトリ}-docs` にする（例: `knowledge-docs`・`mdmark-docs`）（D-84）
- 今の「文書の MCP のプラグインは、文書を持つリポジトリごとに 1 つにし、ほかのプラグインと分ける」の行（131 行目）の直後に置く

### mdmark と YAML の正本・MCP の役割の分担（`mcp.md` に新しいセクション）

- YAML の正本と、それを扱う MCP・開発ドキュメントサーバーは、文書を持つ各プロジェクトが持つ（D-85）
- mdmark は Markdown の記法と共通スタイルの描画だけを受け持ち、YAML を読まない。用語集の表の印など Markdown の機能は mdmark に残す（D-85）
- 配信するときは、各プロジェクトのスクリプトが YAML を mdmark の記法の Markdown に変換し、mdmark で描く（D-85）
- mdmark と YAML の正本・MCP は互いに依存せず、使う側のプロジェクトが両方を取り入れる（D-85）
- セクションは `## サーバーとツールの単位` の直後に置く
