## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 照合の相手 | `dev-docs.yaml` の `documents[]` のうち `alias_type` を持つ行の `paths` に当たる文書の `name`・`aliases`。検査する文書と ID が同じ文書は除く | `changelog`・`word-list` と files.yaml の行は `alias_type` を持たない |
| 正規化 | NFKC → 前後の空白の除去 → 英字の大文字小文字をそろえる（`casefold`）を、検査する文書の `aliases` と相手の値の両方に適用する | 判定表の ※6・規約『タグと用語の登録』の一致前の正規化と同じ |
| 違反 | 衝突した `aliases[n]` ごとに 1 件。`path` は `aliases[{n}]`、`rule` の先頭は `{行} 行目: ` で、相手の文書の ID と `name`・`aliases` の別を記載する | 相手が複数あれば 1 件の `rule` に並べる |
| 検査の順 | 項目の ID の重複 → 参照 → `aliases` の衝突 → mermaid → 対応表の examples | 位置はモジュール構成設計で確定する |
| 名前の索引 | `未確定`（要件.md の `## 要望`。決める段: インターフェース定義設計） | - |
| 既存の文書 | develop の文書に違反が 0 件のまま入る | 11-06 に確認済み。実装後に全ての文書の検査で確認する |
| 処理時間 | 名前の索引は ID の索引と同じ `docs/**/*.yaml` の読み込みから作り、ファイルの読み込みを増やさない | 1 文書あたり 20 秒の上限（NFR-72-1）を変えない |
