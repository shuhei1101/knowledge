# knowledge-checks に、文書どうしの aliases の衝突を違反として返す検査を追加する

## 概要

文書の `aliases` が、ほかの文書の `name`・`aliases` と衝突するとき、validator `knowledge-checks` が違反として返却する。

## 背景

[Issue #206](https://github.com/shuhei1101/knowledge/issues/206) の要望。
判定表『エイリアスを登録しない条件』の 5 行目「ほかの文書・用語の name か aliases に既にある → 登録しない」は機械検査で判定できる。
規約『ルール索引への登録』の強制注入の基準 2 は、機械検査で判定できる部分を検査へ移すとしている。

[PR #204](https://github.com/shuhei1101/knowledge/pull/204)（[Issue #158](https://github.com/shuhei1101/knowledge/issues/158)、マージ済み）で全ての文書に `aliases` が入り、その後に追加される `aliases` の衝突を防ぐ検査は、[レビュー](https://github.com/shuhei1101/knowledge/pull/204#discussion_r4486987073)で別の Issue にすると決めた。
develop の `check_document` の検査は、項目の ID の重複・参照先の実在・mermaid の文法・対応表の examples の 4 つで、`aliases` の衝突は調べていない。
