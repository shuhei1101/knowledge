# スキーマのファイルの書き方に、ツールの引数の制約を持たせるキーを JSON Schema の一部（required・properties・const・enum・pattern）で記載する決まりを追加する

## 概要

スキーマでツールの引数の制約を持たせるキーを、どのスキーマでも JSON Schema の一部（`required`・`properties` と、値の `const`・`enum`・`pattern`）の同じ記法で記載できるようにする。

## 背景

[Issue #216](https://github.com/shuhei1101/knowledge/issues/216) の要望。
aituber の手順のページの `tools[].args` は独自の記法（`"*"` は必須、`"?"` は任意）にしたが、説明が無いと伝わらず、値の候補や書式を記載できなかった。
スキーマのファイルの書き方を定める `schemas/meta.schema.yaml` は、引数の制約の記法を決めていない。
記法は Issue の話し合いで、MCP のツールの `inputSchema` と同じ JSON Schema の一部に決まった。
