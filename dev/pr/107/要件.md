# 要件

## 要望

規約『ドキュメント管理』（`docs/rule/dev-document-management.yaml`）の `related` から、本文のリンクと重なる次の 3 要素を削除し、本文のリンクだけを残す（`related-04`: 本文でリンクしている相手は重ねない）。

| `related` の要素 | 本文のリンク |
| --- | --- |
| `claude-mcp`（references） | `metadata-03` の `[MCP サーバー作成ルール](id:claude-mcp)` |
| `dev-tag-term-registration`（requires） | `metadata-01` の表の `[タグと用語の登録](id:dev-tag-term-registration)` |
| `flowchart-yaml-file-unit`（requires） | `placement-03` の `[YAML ファイルの単位](id:flowchart-yaml-file-unit)` |

3 要素を削除すると `related` の要素が無くなるので、任意のキー `related`（`metadata-01`）ごと削除する。
本文の項目（`items`）の文言は一字一句そのまま残す（規約『既存文章の維持』）。
