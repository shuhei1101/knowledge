# 規約『文章の追記』の出典列の略号に定義を持たせる

## 概要

規約『文章の追記』の確認の表を読む人が、出典列の略号から元の資料を辿れるようにする。

## 背景

[Issue #17](https://github.com/shuhei1101/knowledge/issues/17) の要望。
確認の表は [#10](https://github.com/shuhei1101/knowledge/pull/10) で ai-monitor から写したもので、出典列の略号（`A`・`C`・`P`・`GT`・`T`）の定義はファイルの中に無い。
略号の定義は、行を足した ai-monitor の Issue（[shuhei1101/ai-monitor#1713](https://github.com/shuhei1101/ai-monitor/issues/1713)）の本文にだけある。
[#16](https://github.com/shuhei1101/knowledge/pull/16) で見つけ、全ての文章に当たる基準のため切り出した。
