# 文書のスキーマの Markdown の本文のキーに contentMediaType: text/markdown を追加する

## 概要

エージェントが dev-docs の `write_docs` で knowledge の文書を書き込むとき、Markdown の本文の図の部品の誤りを、書き込みの前に mdmark の点検で検出できるようにする。

## 背景

[Issue #187](https://github.com/shuhei1101/knowledge/issues/187) の要望。依頼元は [shuhei1101/dev-docs#111](https://github.com/shuhei1101/dev-docs/pull/111) の要件の `## スコープ外`。
`write_docs` は、種類のスキーマで `contentMediaType: text/markdown` を持つ文字列のキーを Markdown のキーとみなし、操作で変えた値を `mdmark check --text -` で点検する。
knowledge の文書のスキーマは、Markdown の本文のキーに `contentMediaType` を持たず、点検の対象にならない。
