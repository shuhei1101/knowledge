## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 項目の本文 | `$defs/item.properties.body` に `contentMediaType: text/markdown` を追加する | 他のキーの文言は変えない |
| スキルの図 | `skill.schema.yaml` の `flow`・`sequence` に `contentMediaType: text/markdown` を追加する | 同上 |
| 既存の文書の確認 | 対象のキーを持つ全ての文書の値を `mdmark check --text -` に通し、書き込みを止める警告が出た値は本文を直す | `unknown_mark` は書き込みを止めないため直さない |
| 検査 | `uv run --frozen --script scripts/check_all.py` を流し、ログを `テスト結果/` に置く | - |
