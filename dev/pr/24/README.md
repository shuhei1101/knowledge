# 「ダーク」の扱いを規約・テンプレートでそろえる

## 概要

デザインを決める人が、「ダーク」を色の明暗（テーマ）とデザインスタイルのどちらとして選ぶかを、規約とテンプレートで迷わず読めるようにする。

## 背景

[Issue #18](https://github.com/shuhei1101/knowledge/issues/18) の要望。
コーディング規約『業務画面のUI要素』とテンプレート『デザイン方針』はダークを明暗（テーマ）として扱い、規約『デザインスタイル』はスタイル一覧に「業務系 | ダーク」の行を持つ。
[#16](https://github.com/shuhei1101/knowledge/pull/16) で見つけ、テンプレート『デザイン方針』が #16 のスコープ外のため切り出した。
