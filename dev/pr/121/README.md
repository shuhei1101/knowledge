# knowledge の既存の文書の description を、1 文で受け持つことと読むときを記載する書き方へ書き換える

## 概要

knowledge の `docs/` 配下の YAML の文書のメタデータ `description` を、何を受け持つかとどんなときに読むかを記載する 1 文へ書き換える。

## 背景

[Issue #118](https://github.com/shuhei1101/knowledge/issues/118) の要望。
[#116](https://github.com/shuhei1101/knowledge/pull/116) で規約『タグと用語の登録』に description の書き方（`description-01`・`description-02`）を記載したが、既存の文書の `description` は「どんなときに読むか」を持たない。
#116 の要件.md の `## スコープ外` から切り出した後続。

| --- | --- |
| [要件](./要件.md) | 要望の整理・更新ドキュメント・スコープ外 |
