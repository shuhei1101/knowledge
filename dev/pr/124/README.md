# knowledge の既存の文書のタグを、規約『タグと用語の登録』の tag-scope-01・tag-scope-02 に沿って付け直す

## 概要

knowledge の `docs/` 配下の YAML の文書の全件のタグを、規約『タグと用語の登録』の `tag-scope-01`・`tag-scope-02` が定める範囲の語から付け直す。

## 背景

[Issue #122](https://github.com/shuhei1101/knowledge/issues/122) の要望。
[#113](https://github.com/shuhei1101/knowledge/pull/113) で規約『タグと用語の登録』にタグにする語の範囲（`tag-scope-01`・`tag-scope-02`）を記載したが、既存の文書のタグはこれに揃っていない。
[#121](https://github.com/shuhei1101/knowledge/pull/121)（起点 Issue #118）の要件.md の `## スコープ外` から切り出した後続で、#121 が書き換えた `description` の語も含めて付け直す。
