## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| yamllint の対象 | `check_lints` が、`documents[]` の YAML と `YAMLLINT_EXTRA` に加えて、`schemas/*.schema.yaml`・`schemas/design/*.schema.yaml` のうち在るファイルに yamllint を適用する | 違反の行は `{スキーマのパス}:{行}: -: yamllint/{ルール}: {内容}` の既存の書式で出す |
| yamllint のルール | `schemas/` のスキーマに `brackets`・`braces` の `forbid: non-empty` を適用し、`docs/` の文書・`dev-docs.yaml`・`rules.yaml` には適用しない | `未確定`（設定の持ち方。要件.md の `## 要望`） |
| 検査のテスト | `schemas/` のスキーマのフロー形式が違反になり、同じ記法の `docs/` の文書が違反にならないことを単体・結合テストで確認する。シナリオに異常シナリオを追加するかは単一ユースケース設計で決める | - |
