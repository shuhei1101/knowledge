# 既存のスキーマのフロー形式をブロック形式へ書き直し、schemas/ のスキーマにフロー形式を違反にする yamllint の検査を追加する

## 概要

スキーマを記載するエージェントが、フロー形式で記載したスキーマを全ての文書の検査の違反として受け取れるようにし、既存のスキーマのフロー形式をブロック形式へ書き直す。

## 背景

[Issue #203](https://github.com/shuhei1101/knowledge/issues/203) の要望。
スキーマをブロック形式で記載する決まりは、[PR #202](https://github.com/shuhei1101/knowledge/pull/202)（[#178](https://github.com/shuhei1101/knowledge/issues/178)）で `schemas/meta.schema.yaml` の最上位の `x-rules` へ移した。
既存のスキーマに違反が残っていたため、#202 では検査へ移さず文の決まりのまま残した。
全ての文書の検査（`scripts/check_all.py`）は、今は `schemas/` のファイルに yamllint を適用していない。
