# SessionStart・MCP の instructions・ツールの description などに書く内容の書き分けと、注入文の書き方の規約を新設する

## 概要

SessionStart のフックの `additionalContext`・MCP の instructions・ツールの description・CLAUDE.md・スキル・フックのどこに何を書くかと、注入文の書き方の規約を `docs/rule/` に新設し、`claude-hook.yaml`・`claude-mcp.yaml` からは参照の 1 行にする。

## 背景

[Issue #129](https://github.com/shuhei1101/knowledge/issues/129) の要望（検討事項 D-183〜D-189）。
dev-docs の注入文を読んだエージェントが、dev-docs の MCP をほとんど使わず grep・Read で文書を読んでいた。
置き場所ごとに何を書くかの決まりが knowledge に無く、MCP を強制せずに使う場面・使わない場面を伝える指針（A-41 の「指針」）を規約にする。
文の置き場所は、前提の [#128](https://github.com/shuhei1101/knowledge/issues/128)（[#130](https://github.com/shuhei1101/knowledge/pull/130)）で規約『プロンプトファイル』が定めている。
後続に [shuhei1101/dev-docs#48](https://github.com/shuhei1101/dev-docs/issues/48) がある。
