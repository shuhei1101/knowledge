# 要件

## 要望

[Issue #129](https://github.com/shuhei1101/knowledge/issues/129) の `## 決まったこと`（D-183〜D-189）に沿って、注入文の書き分けと書き方の規約を次のとおりにする。
規約に入れる中身は、Issue の `## 必読` の A-41 の「指針」の「何をどこに書くか」の表と「書き方」の 9 項目を正とする。

- `docs/rule/claude-context-placement.yaml`（`id: claude-context-placement`）を新設する
  - 「何をどこに書くか」の表（SessionStart の `additionalContext`・MCP の instructions・ツールの description・CLAUDE.md・スキル・フック（PreToolUse など）ごとの書くこと・書かないこと）と、同じ文を 2 か所に置かず移すときは元の場所を参照先の 1 行にする決まり（D-183）を持たせる
  - 「書き方」の 9 項目（事実の文で書きフックで担保する・使う場面と使わない場面を対にする・参照先を示す・長さと要点の位置・compact での入れ直し・サブエージェントへの届け方・最小の文から始める・使われないときはツールの結果を疑う）を持たせる（D-184〜D-188）
  - 文の置き場所（`content/prompts/` の YAML）は書かず、規約『プロンプトファイル』（`prompt-file`）を参照する
  - 出典（A-41 の根拠の R-38）は `sources` に置く
- `docs/rule/claude-hook.yaml` の `rules-02`（`additionalContext` の上限）を、新しい規約への参照の 1 行にする
- `docs/rule/claude-mcp.yaml` の `tool-schema-01` の description の行に、書く内容は新しい規約に従う旨の参照を追加する（instructions・description に書く内容の決まりは claude-mcp に無く、重なる記述は無い）
- `rules.yaml` に新しい規約の行を追加し、paths をフック（`**/hooks/**`）・MCP サーバー（`**/mcp/**`・`**/mcp_server.py*`・`**/.mcp.json`）・CLAUDE.md（`**/CLAUDE.md`）・スキル（`**/skills/**/SKILL.md`）のファイルと、文の本文を置く `content/prompts/`（`**/content/prompts/**`）に当てる
- `additionalContext` 10,000 字・instructions 4,096 字の公式の上限は、D-186 のとおり数値を本文に書き、公式の hooks・MCP のリファレンスを `sources` に置く

終わりの条件:

- 新しい規約が A-41 の指針と食い違わない
- `claude-hook.yaml`・`claude-mcp.yaml` に新しい規約と同じ内容が重ねて書かれていない
