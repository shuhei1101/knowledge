# MCP・フックの渡し方と SessionStart・instructions の使い分けの判定フローチャートを追加し、claude の規約を改める

## 概要

MCP・フックをセッションへ渡す方法（プラグイン・起動の引数・リポジトリのファイル）と、エージェントに渡す文・処理の置き場所（SessionStart のフック・MCP の instructions・ツールでの取得）を判定フローチャートで決められるようにし、claude の規約をその判定に合わせる。

## 背景

[Issue #154](https://github.com/shuhei1101/knowledge/issues/154) の要望。
規約『MCP サーバー作成ルール』（`claude-mcp`）は常駐の MCP サーバーをプラグインで配ると定め、規約『注入文の書き分けと書き方』（`claude-context-placement`）は SessionStart の `additionalContext` にその時点で変わる事実を書くと定めている。
そのため、起動する場所が決まっているセッション（AI Monitor のエージェント・aituber のノードの `claude -p`）にもプラグインを求め、使い方の案内を SessionStart に置く文書が出ている。
判定フローチャートの描き方は [#132](https://github.com/shuhei1101/knowledge/issues/132) のテンプレート『判定フローチャート』に従う。
SessionStart と instructions の判定フローチャートの追加と R-6 の棚卸しの訂正は、[Issue #154 のコメント](https://github.com/shuhei1101/knowledge/issues/154#issuecomment-6602682302) で要件に加わった。
