# 人が読む設計書のテンプレートを、knowledge の設計書のスキーマから生成する

## 概要

設計書を記載するエージェントと利用者が、`schemas/design/` のスキーマと同じ内容のテンプレートを `docs/template/` で参照できるようにする。

## 背景

[Issue #163](https://github.com/shuhei1101/knowledge/issues/163) の要望（話し合いの検討事項 D-22）。
`docs/template/` の設計書の種類のテンプレート 15 件は手で管理しており、[#182](https://github.com/shuhei1101/knowledge/pull/182) で knowledge へ移したスキーマ（`schemas/design/`）と中身が二重になっている。
[#192](https://github.com/shuhei1101/knowledge/pull/192) でスキーマへ追加した `x-rules`・`x-bad-examples` は、テンプレートにまだ出ていない。
