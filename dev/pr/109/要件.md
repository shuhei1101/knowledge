# 要件

## 要望

develop の `docs/template/` の 4 つのテンプレートの例に残る mypy と Python 3.12 を、Python の規約（`python-core-style`・`python-packaging-pyproject`）の D-41・D-42 に揃える。
終わりの条件は、develop の `docs/`・`dev/`（`dev/pr/` を除く）に、型検査を mypy とする例と Python 3.12 を前提とする例が残っていないこと。
変更する値以外の文言は一字一句そのまま残す（規約『既存文章の維持』）。

<!-- table: data -->

| ファイル | 今の記述 | 改訂後 |
| --- | --- | --- |
| `template-test-procedure.yaml` | lint 層の description の「mypy で型検査を」 | 「pyright で型検査を」（D-41） |
| `template-test-procedure.yaml` | lint 層の run_all の `uv run mypy . \|\| rc=1` | `uv run pyright \|\| rc=1`（D-41。dev 依存の名前は `python-packaging-pyproject` の雛形の `pyright`、strict の設定は `[tool.pyright]` が持つ） |
| `template-test-procedure.yaml` | 前提の `- Python 3.12 と uv` | `- Python 3.14 と uv`（D-42） |
| `template-dev-command.yaml` | 前提の `- Python 3.12 と uv` | `- Python 3.14 と uv`（D-42） |
| `template-getting-started.yaml` | `## 前提` の記述例の `- Python 3.12 と uv` | `- Python 3.14 と uv`（D-42） |
| `template-architecture.yaml` | バックエンドの `runtime: Python 3.12` | `runtime: Python 3.14`（D-42） |

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| master の `dev/テンプレート/` に残る同じ記述 | master の `dev/テンプレート/` は develop で `docs/template/` へ移した前の配置で、develop が release で master へ入ると置き換わる | 予定なし |
| lint 層の例に ty の並行実行を加えること | D-41 で ty は試験的な並行実行の扱いで、正にする型検査は pyright。テンプレートの例は正の構成だけを示す | 予定なし |
