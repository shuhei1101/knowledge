# テンプレート『テンプレート』『判定フローチャート』『セットアップ手順』の配置先・形式の記述を規約『ドキュメント管理』に合わせる

## 概要

テンプレート『テンプレート』『判定フローチャート』『セットアップ手順』を読んで文書を作る人が、規約『ドキュメント管理』どおりの置き場所・ファイル名・YAML の書式で文書を作れるようにする。

## 背景

[Issue #66](https://github.com/shuhei1101/knowledge/issues/66) の要望。
作業 PR [#64](https://github.com/shuhei1101/knowledge/pull/64)（起点 Issue [#44](https://github.com/shuhei1101/knowledge/issues/44)）でテンプレートを `docs/template/` の YAML へ移したが、中身の配置先・ファイル名・見出しの記述は markdown の前提のまま残った。
規約『ドキュメント管理』は、文書の正本を YAML にし、`docs/` の下を種類だけのフォルダにすると決めている。

## 計画書

| ファイル | 中身 |
| --- | --- |
| [要件](./要件.md) | 要望の整理と影響する UC 一覧 |
| [確認ログ](./確認ログ.md) | ユーザーへの確認事項の決着 |
