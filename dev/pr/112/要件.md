# 要件

## 要望

規約『ドキュメント管理』（`docs/rule/dev-document-management.yaml`）以外の文書の `related` から、本文のリンク（`(id:...)`）と重なる要素を削除し、本文のリンクだけを残す（`related-04`: 本文でリンクしている相手は重ねない）。
対象は `## 更新ドキュメント` の 38 文書・53 要素。
重なる要素の `type` は全て `requires` か `references` で、`change_together` は無いので、どの要素も判定フローチャート『関連の張り方』（`flowchart-related-link`）の Q1（本文でリンクしている相手か → YES → 関連を張らない）で削除と決まる。

- `related` の要素が全て無くなる文書は、任意のキー `related`（規約『ドキュメント管理』の `metadata-01`）ごと削除する
- 変えた文書の `rev` を 1 上げる（`metadata-01`。[#107](https://github.com/shuhei1101/knowledge/pull/107) と同じ扱い）
- 本文の項目（`items`）・残る `related` の要素・他のメタデータは一字一句そのまま残す（規約『既存文章の維持』）

終わりの条件: develop の `docs/` の全 YAML で `related` の `to` と `items` の本文の `(id:...)` を突き合わせ、重なりが `docs/rule/dev-document-management.yaml`（#96 の対象）以外に無い。
