## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 照合の相手 | 検査する文書の `name` と、`aliases` の前の要素 | 名前の索引と `dev-docs.yaml` は使用しない |
| 正規化 | `normalize_name`（NFKC → 前後の空白の除去 → `casefold`）を、`aliases` の要素と `name` の両方に適用する | PR #212 で追加した関数 |
| 違反 | 一致した `aliases[n]` ごとに 1 件。`path` は `aliases[{n}]`、`rule` の先頭は `{行} 行目: ` で、一致した相手（`name` か `aliases[{m}]`）を記載する | `name` と前の要素の両方に一致したら、`name` との一致の 1 件にする |
| 検査の順 | 項目の ID の重複 → 参照 → `aliases` の衝突 → 文書の中の `aliases` の重複 → mermaid → 対応表の examples | 位置はモジュール構成設計で確定する |
| `dev-docs.yaml` が無い場合 | `aliases` の衝突は今のとおり `path: $` の違反 1 件にし、文書の中の `aliases` の重複は適用する | - |
| 既存の文書 | develop の文書に違反が 0 件のまま入る | 11-06 に確認済み。実装後に全ての文書の検査で確認する |
| 処理時間 | ファイルを参照せず、検査する文書の値だけで判定する | 1 文書あたり 20 秒の上限（NFR-72-1）を変えない |
