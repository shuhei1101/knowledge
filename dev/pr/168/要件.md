# 要件

## 要望

E2E が files.yaml の行の文書を指す ID とページの path を、dev-docs の今の形式（[文書の検索](https://github.com/shuhei1101/dev-docs/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E3%82%A4%E3%83%B3%E3%82%BF%E3%83%BC%E3%83%95%E3%82%A7%E3%83%BC%E3%82%B9%E5%AE%9A%E7%BE%A9/%E9%96%8B%E7%99%BA%E3%83%89%E3%82%AD%E3%83%A5%E3%83%A1%E3%83%B3%E3%83%88%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC/%E6%96%87%E6%9B%B8%E3%81%AE%E6%A4%9C%E7%B4%A2.yaml) の `id` の制約）に合わせる。

| 対象 | 今の形式 | 合わせる形式 |
| --- | --- | --- |
| files.yaml の行の文書の ID | 本文のファイルのパス（拡張子なし）。例: `skills/text-review/SKILL` | 本文のファイルのパス（拡張子付き）。例: `skills/text-review/SKILL.md` |
| files.yaml の行の文書のページの path | `{files.yaml のパス（拡張子なし）}/{本文のファイルのパス（拡張子なし）}` | `{files.yaml のパス（拡張子なし）}/{文書の ID}`。例: `skills/files/skills/text-review/SKILL.md` |

終わりの条件は、次の E2E が develop の dev-docs で全て pass すること。

- E2E『利用者が画面で knowledge の文書を読む』（Issue の対象）
- E2E『エージェントが knowledge の文書を検索・取得する』（同じ型の箇所。`_SKILL_ID` が拡張子なしの ID で `search_docs` の `id` を `eq` で絞っており、同じ原因で当たらない）
