# 判断・作業の決まりの表し方を選ぶ判定フローチャートと、判定表のテンプレートを追加する

## 概要

規約・手順に判断や作業の決まりを記載する人が、判定フローチャート・判定表・チェックシート・手順のどれで表すかを判定フローチャートで決め、判定表をテンプレートの書式で記載できるようにする。

## 背景

[Issue #171](https://github.com/shuhei1101/knowledge/issues/171) の要望。
knowledge にはテンプレート『判定フローチャート』『チェックシート』と、判定フローチャート『表し方の選び方』（図・表・箇条書き・文のどれにするか）があるが、決まりの種類を判定する文書と、判定表のテンプレートが無い。
そのため、結果を決める条件の一覧がチェックシートや判定フローチャートとして記載されている（knowledge では判定フローチャート『エイリアスの登録』）。
ai-monitor から移行する『データフロー作成判定』『PoC要否』を判定表に書き換える [#170](https://github.com/shuhei1101/knowledge/issues/170) は、この PR のテンプレートを使う。
