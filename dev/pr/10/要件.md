# 要件

## 要望

ai-monitor の `dev/` にある、AI Monitor が無くても使える規約とテンプレートを、このリポジトリへ写して ai-monitor 固有の記述を直し、直下の `rules.yaml` に載せる。

写す文書と判定は移す文書の一覧（`/mnt/c/Users/shuhe/repo/ai-monitor/tmp/ルール分離検討/.mindstella/docs/A-4.md`）、直す行は直す行の一覧（同じフォルダの `A-5.md`）に従う。
写す元は ai-monitor の `origin/develop` の今の版にする（一覧を作った `c74c929d2` から進んでいるため、直す行は行番号ではなく記述で探す）。

- 判定が「移す」「二重管理」の文書を写し、「残す」「配らない」は写さない
- 写す先は次のとおりにする

  | `dev/テンプレート/` の Markdown のテンプレート（`テンプレート.md`・`プロジェクトREADME.md`・`はじめに.md`・`セットアップ手順.md`・`リファレンス.md`・`テストフィクスチャ.md`・`デザイン方針.md`・`定数.md`・`コンテナ構成.md`・`チェックシート.md`・`判定フローチャート.md`・`プロジェクトCLAUDE.md`・`方針決め/` の 8 件・`観点/` の 8 件） | `dev/テンプレート/` の同じ並び |

  - `エージェント運用/` の階層だけを落とした並びにし、移した文書どうしの相対リンクの書き換えを深さの違いだけにする
  - 目次は各フォルダの `README.md` だけを写し、`index.yaml` は写さない（[#6](https://github.com/shuhei1101/knowledge/pull/6) で目次を `README.md` だけで持つと決めた）。新しいタブのフォルダには `README.md` の目次を書き、`dev/README.md` の目次に行を足す
- 直す行の一覧のとおりに、ai-monitor 固有の記述を直す
  - 見出しの「AI Monitor」を消す
  - ai-monitor の Issue・PR を指す出典を外す
  - 移した文書どうしのリンクを新しい置き場所へ直し、ai-monitor に残る文書（モック画面構成など）へのリンクは外す
  - 規約『ルール索引への登録』は、rule-inject の索引（置き場所は各プロジェクトの直下の `rules.yaml`、除外のキーは `exclude`）に合わせて書き直す
  - 二重管理の文書（`プロジェクトREADME.md`・`プロジェクトCLAUDE.md`）は一般の版として書く
- 写し終えた文書に、ai-monitor に残る文書へのリンク・ai-monitor の Issue / PR へのリンク・見出しの「AI Monitor」が残っていない
- 直下の `rules.yaml` の `rules` に、一覧で索引が「必須」の文書の行を載せる
  - `paths` / `tools` は ai-monitor の `rules.global.yaml` の同じ文書の行に合わせ、`rule` を `rules.yaml` からの相対パス（写した先）にする
  - `rule` の指す先が全てこのリポジトリに実在する
