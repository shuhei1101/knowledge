# ai-monitor から、AI Monitor が無くても使える規約とテンプレートを移す

## 概要

ai-monitor の `dev/` にある、AI Monitor が無くても使える規約とテンプレートをこのリポジトリへ写し、ai-monitor 固有の記述を直して直下の `rules.yaml` に載せる。

## 背景

[Issue #3](https://github.com/shuhei1101/knowledge/issues/3) の要望。
[#2](https://github.com/shuhei1101/knowledge/issues/2)（[#6](https://github.com/shuhei1101/knowledge/pull/6)）で置いた土台は、目次と空の索引だけを持ち、規約・テンプレートの中身が無い。
ai-monitor の文書は、ai-monitor が rule-inject へ切り替わって動くと確かめてから ai-monitor の Issue で消す。
スキーマに移ったテンプレートは [#9](https://github.com/shuhei1101/knowledge/issues/9) で Markdown に組み立て、移した規約をベストプラクティスと突き合わせて直すのは [#4](https://github.com/shuhei1101/knowledge/issues/4)。
