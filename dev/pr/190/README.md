# 端末の設定の既定のパスと、上書きの環境変数の名前の付け方を、規約と判定フローチャートに記載する

## 概要

自作のツールを作る人が、端末の設定の既定のパス・状態の置き場所・上書きの環境変数の名前と、MCP をプラグインで配る決まりを、規約と判定フローチャートで参照できるようにする。

## 背景

[Issue #184](https://github.com/shuhei1101/knowledge/issues/184) の要望。
判定フローチャート『設定値の置き場所』は端末の設定を `~/.config/{project}/settings.yaml` と定めているが、`XDG_CONFIG_HOME`・状態の置き場所・上書きの環境変数の名前の付け方の記載が無い。
そのため自作のツール（dev-docs・mdmark・rule-inject・alias-inject）で、環境変数が無いときの動きと環境変数の名前がばらついている。
規約『MCP サーバー作成ルール』はポートの環境変数を `{リポジトリ}_PORT`、規約『Claude プラグインルール』は設定のパスの環境変数を `{プラグイン名のアッパースネークケース}_CONFIG` と、別々に定めている。
