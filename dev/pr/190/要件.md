# 要件

## 要望

自作のツールの端末の設定・状態の置き場所・上書きの環境変数の名前の付け方と、MCP をプラグインで配る決まりを、規約と判定フローチャートに記載する（Issue の決定 D-145・D-146）。
変える項目の外の文言は一字一句そのまま残す（規約『既存文章の維持』）。

| 項目 | 記載する決まり |
| --- | --- |
| 端末の設定 | `${XDG_CONFIG_HOME:-~/.config}/{ツール名}/settings.yaml` を既定で読む。環境変数が無くても既定のパスを読み、ファイルが無ければツールの既定値で動く |
| 状態・ログ | `${XDG_STATE_HOME:-~/.local/state}/{ツール名}` に配置する |
| 上書きの環境変数 | `{ツール名}_CONFIG`（設定のパス）・`{ツール名}_PORT`（ポート）・`{ツール名}_STATE_DIR`（状態の置き場所）。`{ツール名}` はツール名を大文字にし、`-` を `_` にした名前 |
| MCP の配り方 | MCP を持つツールは、プラグインの `.mcp.json`（`http://127.0.0.1:${{ツール名}_PORT:-{既定のポート}}/mcp`）で配る |

修正する文書と項目は次のとおり。

- 判定フローチャート『設定値の置き場所』（`docs/flowchart/flowchart-config-location.yaml`）: `three-layers-02` の環境の値の置き場所を `${XDG_CONFIG_HOME:-~/.config}` の書き方にし、状態の置き場所と、`three-layers-05` の上書きの環境変数の名前の付け方を記載する。`sources` の XDG の `note` に `XDG_STATE_HOME` を追加する
- 規約『Claude プラグインルール』（`docs/rule/claude-plugin.yaml`）: `settings-file-01`〜`03` を「`env` が無くても既定のパスを読み、`{ツール名}_CONFIG` で上書きする」記載に変更し、`settings-file-06`・`08` の例と参照を `{ツール名}_PORT` に合わせる。MCP はプラグインの `.mcp.json` で配ることを記載する。規約『MCP サーバー作成ルール』の `sdk-transport-06` と判定フローチャート『MCP・フックの渡し方』に同じ決まりがあるため、記載はそこへの参照にする
- 規約『MCP サーバー作成ルール』（`docs/rule/claude-mcp.yaml`）: `registration-06`〜`registration-11` の `{リポジトリ}_PORT` を `{ツール名}_PORT` に統一する
- 規約『YAML』（`docs/rule/dev-yaml.yaml`）: `config-file-04`・`config-file-08` の表・`two-layer-choice-04` の端末の設定のパス（`~/.config/{名前}/settings.yaml`・`~/.config/{project}/settings.yaml`）を、判定フローチャート『設定値の置き場所』と同じ既定のパスの書き方にする
- 規約『pydantic-settings による設定管理』（`docs/rule/python-shared-settings.yaml`）の `loading-07` と、テンプレート『セットアップ手順』（`docs/template/template-setup-procedure.yaml`）の `unmanaged-files-01` の `~/.config/{...}` を、同じ既定のパスの書き方にする

変えたページは `rev` を 1 つ上げ、`last_reviewed` を変えた日にする。

`未確定`: 既定のポートの台帳（`~/.config/mcp-ports.yaml`）の扱い（決める段: ドキュメント修正）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 台帳を残して新しいサーバーのポートを選ぶ元にし、`env` の列の名前を `{ツール名}_PORT` に合わせる。既定のポートは今どおり `.mcp.json` の `url` に直接記載する | ポートがぶつからないよう番号を選ぶ元が残る | 台帳と `.mcp.json` の 2 か所に既定のポートが記載される |
| B | 台帳を廃止し、既定のポートは `.mcp.json` とサーバーのコードにだけ記載する | 既定のポートの記載が 1 か所になる | 新しいサーバーのポートを選ぶとき、使用中の番号を一覧で確認できない |

推奨: A

台帳は [#141](https://github.com/shuhei1101/knowledge/pull/141) で、ポートがぶつからないよう番号を選ぶ元として Git の外へ移したもので、D-145 の名前の統一はこの目的を変えない。
