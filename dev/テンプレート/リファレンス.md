# テンプレート: リファレンス

`リファレンス` タブのうち、`リファレンス/API.md` と `リファレンス/コマンド.md` の書式。
1 ページに一覧と、1 件 1 セクションの詳細を持つ。

配置先は `docs/リファレンス/API.md`（API を公開するプロジェクトのみ）と `docs/リファレンス/コマンド.md`。
新規作成時は `docs/リファレンス/index.yaml`（目次）の `items` に 1 行追加し、README を再生成する。

## セクション一覧

| セクション | サブセクション | 必須or条件 |
| --- | --- | --- |
| 冒頭リード | - | 必須 |
| `## 一覧` | - | 必須 |
| `## {名前}` | コマンド: `### 使い方` / `### 引数` / `### 終了コード`<br>API: `### リクエスト` / `### レスポンス` / `### エラー` | 必須（一覧の 1 行につき 1 セクション） |

## `冒頭リード`

### 記述例

```markdown
# コマンド

リポジトリのクローンの直下で実行するコマンドの一覧。
どれも前に `uv run` を付けて実行する。
```

### 補足

- 何の一覧かと、全てに共通する実行の前提（実行する場所・前に付けるもの・読む設定）を書く
- 初回に書いた内容のまま保ち、後から情報を追加しない。
  個別のことは各節に書く。
  対象そのものが変わったときだけ既存の記述を書き換える

## `## 一覧`

### 記述例

```markdown
## 一覧

| 名前 | コマンド | 説明 |
| --- | --- | --- |
| [サーバーを起動する](#サーバーを起動する) | `python -m taskflow` | API サーバーを起動する |
| [データを移す](#データを移す) | `python -m taskflow.migrate` | 旧形式のデータを新しい保存先へ写す |
```

### 補足

**名前列:**
- 短い日本語の名前にし、同じページの 1 件 1 セクションへのリンクにする

**コマンド列:**
- 引数を除いたコマンドを書く。
  API のページでは列名を `エンドポイント` にし、`{メソッド} {パス}` を書く

**説明列:**
- 何をするかを 1 行で書く（セクションの冒頭の 1 行と同じ文言）

**補足:**
- 詳細の列は置かない（詳細はセクションに書く）

## `## {名前}`

### 記述例（コマンド）

````markdown
## データを移す

旧形式のデータを新しい保存先へ写す。
既にある行は飛ばす。

### 使い方

```bash
uv run python -m taskflow.migrate [--dry-run]
```

### 引数

| 引数 | 必須 / 任意 | 説明 | 例 |
| --- | --- | --- | --- |
| `--dry-run` | 任意 | 写す行を出すだけで、書き込まない | `--dry-run` |

### 終了コード

| コード | 意味 |
| --- | --- |
| `0` | 全てコピーした |
| `2` | 写せなかった行がある |
````

### 記述例（API）

````markdown
## タスクを作る

タスクを 1 件作る。

### リクエスト

```json
{ "title": "決算資料の作成" }
```

| フィールド | 必須 / 任意 | 説明 |
| --- | --- | --- |
| `title` | 必須 | タスク名（100 文字以内） |

### レスポンス

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `id` | str | 作ったタスクの ID |

### エラー

| ステータスコード | 発生条件 |
| --- | --- |
| `400` | `title` が無い・100 文字を超える |
````

### 補足

- 見出しは `## 一覧` の名前列と同じ日本語の名前にする（コマンドやパスを見出しにしない）
- セクションの冒頭に何をするかを 1〜2 行で書く
- `### 使い方` はコマンドの全形を 1 本のコードブロックで書き、任意の引数は `[角括弧]` で囲む
- `### 引数` は引数を取らないとき本文に `なし` と書く
- 詳しい仕様を設計書が持つときは、セクションの末尾に設計書へのリンクを置く（Pages に出ないページへは GitHub の `blob/develop` のリンクで書く）
