# テンプレート: 状態遷移

1 エンティティが取りうる状態と、許可された遷移。1 ファイル = 1 エンティティ。
副作用・実装の関数は別の設計書に書く。

## 記載例

```yaml
title: '状態遷移: 記事'
lead: '`記事` が取りうる状態と許可された遷移の一覧。'
state_transitions:
  states:
  - name: 下書き
    identifier: status = draft
  - name: 公開
    identifier: status = published
  initial: 下書き
  final:
  - 公開
  transitions:
  - from: 下書き
    to: 公開
    trigger: 承認
```
