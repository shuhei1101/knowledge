# テンプレート: モジュール構成

サブシステム × 分類 1 つ分の構成要素（データモデル / クラス / 関数 / 関数型 / 定数 / 画面・コンポーネント / フック / ストア / スタイル）。
1 ファイル = 分類 1 つ。分類は業務ドメインの軸で切り、プロセスの入口は専用の分類に切り出す。
分類を細分化したフォルダは、細分類のページどうしのつながりの図とフォルダ全体の決まりを、束ねの設計書 `全体.yaml`（`diagrams` と `notes`）に置く。
