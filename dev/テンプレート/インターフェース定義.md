# テンプレート: インターフェース定義

1 操作（API エンドポイント / MCP ツール / 画面操作 / 周期・イベント起動の処理）の入出力・制約・正常系と異常系のフロー。
1 ファイル = 1 操作 = 結合テストの 1 ファイル。外部依存は Mock 前提。

## 記載例

```yaml
title: タスク作成
entry:
  kind: operation
  value: '`create_task`（サービス層の公開関数）'
lead: タイトルとサブタスクを受け取ってタスクを永続化し、採番済みのタスクを返す。
test_file: tests/integration/task/test_create_task.py
request:
- name: title
  type: str
  required: true
  location: argument
  description: タスク名
  constraints: 100 文字以内
exceptions:
- name: なし（正常終了）
  condition: 作成成功
- name: ValidationError
  condition: タイトルが 100 文字を超える
constraints:
- item: タイムアウト
  constraint: 制限なし
flows:
- name: 正常系
  summary: タスクを作成する
  setup:
  - name: Mock
    description: DB を stub に差し替え
  flow: "```mermaid\nsequenceDiagram\n  participant C as クライアント\n  participant IF as create_task\n  participant DB as DB\n\n  C->>IF: title\n  IF->>DB: タスクを保存\n  IF-->>C: 採番済みのタスク\n```"
  expected:
  - 採番済みのタスクが返る
  - DB にタスクが 1 件ある
  test: test_normal
```
