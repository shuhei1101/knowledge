# テンプレート: プロジェクト README

リポジトリルートの `README.md` の書式。
読み手は GitHub でリポジトリを開いた人で、ドキュメントへの入口だけを置く。

`dev/` と `docs/` 配下の `README.md`（目次ページ）は書式が違う。

## セクション一覧

| セクション | サブセクション | 必須or条件 |
| --- | --- | --- |
| `# {プロジェクト名}` | - | 必須 |

## `# {プロジェクト名}`

### 記述例

```markdown
# TaskFlow

チームのタスクを 1 画面で共有・編集できるタスク管理ツール。

ドキュメント: [docs/](./docs/)
```

### 補足

- 見出し・1 行・ドキュメントへのリンクの 3 つだけを置く
- 見出しはプロダクト名にする（リポジトリ名と同じでもよい）
- 1 行は GitHub の repository description と同じ文言にし、「誰の何を解決するか」を書く
- リンクはドキュメントのトップ 1 本だけにする
- 初回に書いた内容のまま保ち、後から情報を足さない。
  概要・機能・セットアップはドキュメントの `はじめに` / `使い方` に書く。
  対象そのものが変わったときだけ既存の記述を書き換える
