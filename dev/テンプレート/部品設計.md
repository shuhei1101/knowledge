# テンプレート: 部品設計

画面の要素が使う部品 1 つの仕様（引数・スロット・イベント・CSS カスタムプロパティ・状態）。1 ファイル = 1 部品。状態 1 つが Storybook のストーリー 1 つに当たる。

## 項目

## 記載例

```yaml
title: 列見出し
lead: 表の列見出しの中身。見出しの文字（押すと並べ替え）と、絞り込み・固定のボタンを並べる。
implementation: src/app/screen/templates/macros.html#header_controls
story: Plan/HeaderControls
test_file: tests/integration/storybook/test_計画画面の部品.py
args:
- name: key
  type: 文字列
  required: true
  description: 列のキー。並べ替え・絞り込み・固定の対象を指す
- name: label
  type: 文字列
  required: true
  description: 見出しの文字
- name: numeric
  type: 真偽値
  required: false
  default: 'false'
  description: 数値の列か。右揃えにする
- name: filterable
  type: 真偽値
  required: false
  default: 'false'
  description: 絞り込みのボタンを出すか
events:
- name: 並べ替え
  when: 見出しの文字を押したとき
  value: key（`data-sort`）
  description: 使う側が 既定 → 昇順 → 降順 → 既定 と巡る
- name: 固定
  when: ピンのボタンを押したとき
  value: key（`data-pin`）
  description: 使う側が押した列より左を横スクロールでも固定する
states:
- name: Text
  description: 文字の列（絞り込みできる）
  args:
  - name: key
    value: title
  - name: label
    value: タイトル
  - name: filterable
    value: 'true'
- name: Numeric
  description: 数値の列（右揃えで、絞り込みのボタンを持たない）
  args:
  - name: key
    value: created_at
  - name: label
    value: 作成日時
  - name: numeric
    value: 'true'
accessibility:
- 絞り込み・固定のボタンは `aria-pressed` で押した状態を伝える
- アイコンだけのボタンに `{label} で絞り込む` などの読み上げ名を付ける
```
