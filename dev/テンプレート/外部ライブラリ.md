# テンプレート: 外部ライブラリ

採用した外部ライブラリ 1 つにつき 1 ファイル。そのプロジェクトで使う部分だけを公式ドキュメントから抜き出す。
参照はモジュール構成 → 外部ライブラリの一方向。自プロジェクトのファイル・モジュールには言及しない（使用箇所を除く）。

## 記載例

```yaml
title: react-image-crop
lead: |-
  React 用の画像トリミング（クロップ）UI ライブラリ。
  選択範囲のプレビューを提供し、トリミング後の画像を Blob / dataURL で出す。
kind: ライブラリ
purl: pkg:npm/react-image-crop
dependency_scope: 必須
adoption: 採用
used_in:
- components/AvatarCropModal.tsx
upstream: DominicTobias/react-image-crop
verification:
  state: 済
  date: '2026-07-24'
  detail: 円形の選択とプレビューを最小のコードで動かした
version:
  current: 11.0.5
  latest: 11.0.5
  checked_on: '2026-07-24'
  source: package.json
  pinning: 完全一致で固定
license: ISC
official_url: https://github.com/DominicTobias/react-image-crop
docs_url: https://github.com/DominicTobias/react-image-crop#readme
install: |-
  ```bash
  npm install react-image-crop@11.0.5
  ```

  CSS の読み込みも要る。

  ```ts
  import "react-image-crop/dist/ReactCrop.css";
  ```
catalogs:
- name: API
  version: 11.0.5
  entries:
  - name: centerCrop
    kind: 関数
    purpose: クロップ範囲を画像の中央に置く
    params:
    - name: crop
      type: Crop
      required: true
      description: 中央に置きたいクロップ範囲
    - name: mediaWidth
      type: number
      required: true
      description: 画像の幅（px）
    - name: mediaHeight
      type: number
      required: true
      description: 画像の高さ（px）
    params_example: |-
      ```ts
      const initial = centerCrop({ unit: "%", x: 0, y: 0, width: 50, height: 50 }, 1280, 720);
      ```
    returns:
    - name: '-'
      type: Crop
      description: 中央に置いたクロップ範囲
issues:
- title: onCrop が初回マウント時に発火しない
  summary: 初期値を渡しても最初の 1 回だけコールバックが呼ばれない
  occurred_on: '2026-08-02'
  state: 回避策あり
  description: '`crop` に初期値を渡してマウントしても、`onCrop` が最初の 1 回だけ呼ばれない。'
  conditions:
  - v11.0.0 以降
  - '`crop` を制御コンポーネントとして親から渡している'
  workarounds:
  - method: マウント直後に親側で初期値を 1 度流す
    result: 初回から値が揃う
    recommended: true
  - method: v10 系に固定する
    result: 発火するが、v11 の性能改善を受け取れない
```
