# テンプレート: 開発コマンド

開発者が開発で使うコマンドの、分類ごとの前提・実行の順序・コマンド・料金や副作用や所要時間・確かめた記録。1 プロジェクト 1 ファイル。

## 項目

| title | タイトル | string | 必須 | - | - | `開発コマンド`。 | - |

## 記載例

```yaml
title: 開発コマンド
lead: 開発で使うコマンドの、分類ごとの前提・順序・コマンド・確かめた記録。
prerequisites:
- Python 3.12 と uv
categories:
- name: 環境構築（クローン直後）
  commands: '1. 依存を lock どおりに入れる


    ```bash

    uv sync --frozen

    ```'
  effects: 数分かかる（依存のダウンロード）
  verification:
    state: 済
    date: '2026-01-15'
    detail: 空の作業ツリーで流して依存が入ることを確かめた
- name: テスト
  refs:
  - dev/設計書/テスト/テスト実行方法#
- name: 静的検査
  refs:
  - dev/設計書/テスト/テスト実行方法#layers[lint]
- name: 管理作業
  commands: '```bash

    uv run python scripts/migrate_users.py

    ```'
  effects: 本番の DB へ書き込む（戻せない）
  verification:
    state: 未確認
    detail: 本番の DB へ書き込むため走らせていない
```
