# テンプレート: テスト実行方法

テスト種別ごとの実行コマンドと前提。1 プロジェクト 1 ファイル。

## 記載例

```yaml
title: テスト実行方法
lead: テスト種別ごとの実行コマンドと前提。
prerequisites:
- Python 3.12 と uv
- 'DB: PostgreSQL 16 のローカル起動（`docker compose up -d postgres`）'
layers:
- name: 単体テスト（バック）
  description: pytest で実行する。DB / API に依存しない。
  prerequisites:
  - 外部依存なし（純粋関数と Mock だけ）
  run_all: '```bash

    uv run pytest tests/unit/

    ```'
  run_one:
    label: ファイル
    command: '```bash

      uv run pytest {単体テストファイルパス}

      ```'
  parallel: true
- name: 外部疎通テスト
  description: 実 API に繋いで疎通を確かめる。
  prerequisites:
  - 実 API の認証情報を環境変数に設定する
  - 料金と副作用が出ることを認識した上で実行する
  - 誤実行を防ぐため `--run-external` を必須にする
  run_all: '```bash

    uv run pytest tests/external/ --run-external

    ```'
  run_one:
    label: テスト
    command: '```bash

      uv run pytest {外部疎通テストファイルパス} --run-external

      ```'
  external_cost: テストごとの料金は外部API の設計書の料金を見る
- name: lint
  description: ruff で linter・formatter の check を、mypy で型検査を、import-linter で依存の向きを検査する。型検査と依存の向きの検査はプロジェクト全体に回す。
  prerequisites:
  - 検査の設定は `pyproject.toml` が持つ
  run_all: '```bash

    (rc=0; uv run ruff check . || rc=1; uv run ruff format --check . || rc=1; uv run mypy . || rc=1; uv run lint-imports || rc=1; exit $rc)

    ```'
```
