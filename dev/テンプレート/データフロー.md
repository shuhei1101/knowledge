# テンプレート: データフロー

1 つのデータがシステムをどう流れるか（DFD）。1 ファイル = データ 1 つ。
実装の関数とは 1:1 に対応させない。

## 項目

## 記載例

```yaml
title: 'データフロー: 問い合わせメッセージ'
lead: '`問い合わせメッセージ` がシステムを流れる過程。'
source: 問い合わせ者
sink: 問い合わせ DB とサポート担当
levels:
- name: Level 0
  diagram:
    nodes:
    - id: USER
      label: 問い合わせ者
      kind: actor
    - id: S
      label: 問い合わせ処理システム
      shape: circle
      kind: process
    - id: SUP
      label: サポート担当
      kind: actor
    edges:
    - from: USER
      to: S
      label: 問い合わせメッセージ
    - from: S
      to: SUP
      label: 問い合わせ通知
- name: Level 1
  diagram:
    nodes:
    - id: USER
      label: 問い合わせ者
      kind: actor
    - id: P1
      label: 1. 受付
      shape: circle
      kind: process
    - id: P2
      label: 2. 保存
      shape: circle
      kind: process
    - id: DB
      label: 問い合わせ DB
      shape: cylinder
      kind: store
    - id: P3
      label: 3. 通知
      shape: circle
      kind: process
    - id: SUP
      label: サポート担当
      kind: actor
    edges:
    - from: USER
      to: P1
      label: 問い合わせメッセージ
    - from: P1
      to: P2
      label: 検証済みメッセージ
    - from: P2
      to: DB
      label: 問い合わせレコード
    - from: P2
      to: P3
      label: 保存完了イベント
    - from: P3
      to: SUP
      label: 通知ペイロード
    subgraphs:
    - id: SYS
      label: '信頼境界: システム'
      nodes:
      - P1
      - P2
      - DB
      - P3
dictionary:
- name: 問い合わせメッセージ
  from: 問い合わせ者
  to: 1. 受付
  structure: '{name, email, subject, body}'
  crosses_boundary: true
  sensitivity: 個人情報
  threats:
  - 改ざん
  - 情報漏えい
- name: 問い合わせレコード
  from: 2. 保存
  to: 問い合わせ DB
  structure: '{id, name, email, subject, body, received_at}'
```
