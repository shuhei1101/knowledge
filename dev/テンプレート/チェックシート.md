# テンプレート: チェックシート

チェックシートを作るときの書式定義。

チェックシートは **やるべき作業が既に決まっていて、それが全部済んでいるか / 大丈夫か** を確認するためのシート。
「◯◯していること」「◯◯していないこと」のような **確認文** を並べる。
新規作成時は置いたフォルダの `README.md` の目次に 1 行追加する。

## セクション一覧

| セクション | 必須or条件 |
| --- | --- |
| 冒頭リード | 必須 |
| `## チェック項目` | 必須 |

## `冒頭リード`

### 記述例

```markdown
# {対象作業} チェックシート

（このチェックシートが何を確認するツールか 1〜2 行）
```

### 補足

- 1 行目はページタイトル + `チェックシート` 接尾辞
- 何を完了確認するかを 3 秒で把握できる 1〜2 行で書く
- 初回に書いた内容のまま保ち、後から情報を足さない。
  確認する内容は `## チェック項目` の表に書く（両方に書くと同じ内容を 2 箇所で持つことになる）。
  対象そのものが変わったときだけ既存の記述を書き換える

## `## チェック項目`

### 記述例

```markdown
## チェック項目

| 項目 | 補足 |
| --- | --- |
| 単体テストが全部通っていること | ローカル + CI 両方確認 |
| 関連ドキュメントを更新していること | ドキュメント + Rules + CLAUDE.md |
| Draft を Ready に変換していること | - |
| レビュー承認が 2 件以上あること | - |
```

### 補足

**「項目」列:**
- 文末を `〜していること` / `〜していないこと` に揃え、肯定と否定を読み分けられるようにする
- YES / NO で答えられる 1 文
- 決定を含まない（決定するなら判定フローチャート / 判定表を使う）

**「補足」列:**
- 追加の説明・実行環境・注意点を 1 行で
- 該当なしなら `-`

**並び順:**
- 実行順があるなら時系列で並べる
- 独立チェックなら重要度順で並べる
