# 操作とアクセシビリティ

キーボード・支援技術・色覚の違いによらず操作を完了できるようにする。
出典の略号は I = Impeccable、V = Vercel Web Interface Guidelines、W = WCAG 2.2（リンクは `## 出典`）。

<!-- table: data -->

| 要素 | 出典 |
| --- | --- |
| アイコンだけのボタンには読み上げ用の名前を付ける。飾りのアイコンは読み上げから外す | V |
| フォーカスの表示を非表示にしない。固定ヘッダーでフォーカス中の要素を隠さない | V |
| 主な操作をキーボードだけで完了できる。重なる画面はフォーカスを閉じ込め、閉じたら元の位置へ戻す | V / I |
| 色だけで意味を伝えない。コントラストは本文 4.5:1、大きな文字と部品・フォーカス表示は 3:1 以上 | I |
| 見出しの階層を飛ばさない。画面の拡大を禁止しない。動きを減らす設定に従う | V / I |
| 非同期で変わる通知や検証結果は、支援技術にも伝える | V |
| 押す部品は 24 x 24 CSS px 以上にする。小さい部品は、周りの押す部品との間を空ける | W |

<!-- /table -->

## 出典
