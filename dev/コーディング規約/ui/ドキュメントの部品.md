# ドキュメントの部品

ドキュメントサイトに置く部品（タブ・ステップ・ファイルツリー・コードの行マーカー・バッジ）と使いどころ。
書き方は規約『ドキュメント管理』の `### タブとステップ` と `### ファイルツリー・コードの行の印・バッジ`。

## 部品と使いどころ

| 部品 | 使うとき | 使わないとき |
| --- | --- | --- |
| タブ | 読み手が 1 つだけ選んで読む並列の内容（OS・言語・導入方法） | 順に読ませる内容、全てを読ませたい内容 |
| ステップ | 順に実行する手順 | 順序の無い項目 |
| ファイルツリー | フォルダ構成を見せる | フォルダの役割を説明する文（表か地の文で書く） |
| コードの行マーカー | 変えた行・注目させる行をコードの中で示す | マーカーの無い行だけで足りるコード、行コメントを持たない言語（JSON 等） |
| バッジ | 状態・バージョンなど短いラベル | 文になる説明、色で意味を分けたい区別 |

## タブ

| 要素 | 置き方 |
| --- | --- |
| 同じ軸のタブ | 同じページに同じ軸（OS 別など）のタブが複数あるときは `group=` を同じ値にして選択を揃える |
| タブの中の見出し | タブ名の見出しの 1 段下にする |

## ステップ

| 要素 | 置き方 |
| --- | --- |
| 1 ステップ | 1 操作を書く |

## ファイルツリー

| 要素 | 置き方 |
| --- | --- |
| 注釈 | 説明の要る項目にだけ付ける |

## コードの行マーカー

| 要素 | 置き方 |
| --- | --- |
| マーカーを付ける行 | 変えた行・注目させる行に限る。コピーされる中身にはマーカーが残らない |

## バッジ

| 要素 | 置き方 |
| --- | --- |
| 文言 | 状態・バージョンなど短いラベルにする。色は 1 色で、意味は文言で伝える |

## 部品を追加するとき

範囲を HTML コメントで包む記法で追加する。
範囲で包めない部品（コードの行マーカー・バッジ）は、GitHub で読んでも書いた文字が残る記法で追加し、打ち消し方を持たせる。
部品と使いどころの表に行を追加し、その部品のセクションを追加する。
