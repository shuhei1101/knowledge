# 入力と文言

入力・送信・エラー・通知の振る舞いと、画面に出す言葉。
画面の状態をどこに保持するか。
出典の略号は I = Impeccable、V = Vercel Web Interface Guidelines、GOV = GOV.UK Design System、C = IBM Carbon Design System、MS = Microsoft Japanese Localization Style Guide、SH = SmartHR Design System、BK = 公用文作成の考え方、APG = WAI-ARIA Authoring Practices Guide（リンクは `## 出典`）。

## 入力と送信

| 要素 | 出典 |
| --- | --- |
| ラベルは常に見せる。入力欄の中の例示文をラベルの代わりにしない | V / I |
| 入力し終える前にエラーを出さない（1 文字ごとに検証しない） | GOV |
| 送信中は二重送信を防ぎ、処理中であることを見せる | V / I |
| 押せない理由が画面から読み取れないボタンを無効にしない。理由を近くに書くか、押したときに理由を示す | GOV |
| 取り返しのつかない操作には確認か取り消し猶予を置く。安全に戻せるなら確認より取り消しを選ぶ | V / I |

## エラーと通知

| 要素 | 出典 |
| --- | --- |
| エラーは原因の近くに、何が起きたかと修正方法を書く。入力内容は消さない | V / I |
| 検証エラーが出たら、フォームの先頭にエラーの一覧を出し、各項目へのリンクを付けてフォーカスを移す。一覧と各項目の文言を揃える | GOV |
| 対応が要る通知（エラー・警告）は関係する場所に置き、自動で消さない。自動で消える通知は短い完了の知らせに限り、後から見返せる場所を用意する | C |
| 通知に置く操作は 1 つにする | C |

## 文言

| 要素 | 出典 |
| --- | --- |
| ボタンは起きることを動詞で書く（「OK」ではなく「Issue を作成」）。確認のボタンも操作名にする | V / I |
| 同じ概念は最後まで同じ言葉で呼ぶ（「公開」の結果は「公開しました」） | I |
| 内部の用語やエラーコードを主なメッセージにしない | I |
| 見れば分かるものにラベルを付けない（切り替えの部品の前の「ビュー:」等） | - |
| 文言は識別子より意味を先に書く（「v3.0.0（現在）」ではなく「現在（v3.0.0）」） | - |

### 語と書式

語の選び方の一般の決まりは規約 [文章の書き方](../../規約/文章の書き方.md) の `## 語の選び方` に従う。
ここは画面に固有の型を決める。

| 要素 | 出典 |
| --- | --- |
| 一般の Web アプリと同じ形式的な語にする。やわらかさを狙った言い換えをしない（「直す」ではなく「修正」、「消す」ではなく「削除」）。長い文言は短くする（「選んだ n 件をコピー」ではなく「選択 n 件をコピー」） | MS / SH |
| 品詞を揃える。タブ・列名・見出し・状態は名詞、ボタンは操作語、説明文は敬体で述語まで書く | SH |
| ボタンの漢語は「する」を省き、目的語は「を」でつなぐ（追加・権限を追加）。画面タイトルは名詞にする（権限の追加） | SH |
| トグルは、ラベルを変えないチェックボックスかスイッチにする（状態によって「表示」と「非表示」を切り替えるボタンにしない） | APG |
| エラーのメッセージは「〜できませんでした」「〜が見つかりません」で終える。意思の確認は「〜しますか?」にする（「〜してもよろしいですか?」にしない） | MS |
| 長音は語末の -er / -or / -ar / -y に付ける（ユーザー・サーバー・メモリー） | BK |

### 状態名の型

状態名は次の型に当てはめる。

| パターン | 使うとき | 例 |
| --- | --- | --- |
| 未〇〇 | 始まっていない | 未着手・未対応 |
| 〇〇中 | 進行している | 対応中・確認中 |
| 〇〇待ち | 他者の入力や作業を待っている | 確認待ち・返信待ち |
| 〇〇済み | その作業が終わった | 対応済み・確認済み |
| 完了 | 全体が終わった | 完了 |
| 要〇〇 | 人の対応が要る | 要確認・要対応 |

### 空の表示の型

| 場所 | パターン | 例 |
| --- | --- | --- |
| 一覧 | 〇〇はありません。 | タスクはありません。 |
| 検索の 0 件 | 該当する〇〇はありません。別の条件を試してください。 | 該当するタスクはありません。別の条件を試してください。 |
| 項目の値の欄 | なし か — | なし |

## 状態の保持

| 保持するもの | 置き場所 | 出典 |
| --- | --- | --- |
| 共有したいもの（タブ・ビュー・絞り込み・並べ替え） | URL | - |
| 端末ごとの好み（列の表示・密度） | localStorage | - |
| 1 回の作業中だけのもの（入力途中の下書き・スクロール位置） | sessionStorage | - |
| 保存ビュー | サーバー（画面が書き込みの経路を持たないときは localStorage） | - |

未保存の入力があるまま画面を離れるときは警告する（V）。
