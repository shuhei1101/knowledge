# 表示の安定

読み込み・待ち時間・動きで表示が崩れたり揺れたりしないようにする。
出典の略号は I = Impeccable、V = Vercel Web Interface Guidelines、N = Nielsen Norman Group、MW = modern-web-guidance（リンクは `## 出典`）。

<!-- table: data -->

| 要素 | 出典 |
| --- | --- |
| 画像は寸法を先に確保し、読み込みで周りを動かさない | V |
| タブ・ビュー・絞り込みを切り替えても、周りの枠の幅や高さを変えない | - |
| ポップオーバーとダイアログは、外側のクリックと Esc で閉じる | MW |
| 幅・高さ・余白を動きの対象にしない | V / I |
| メニューやツールチップが、親の枠で切れないようにする | I |
| 文字が他の要素に隠れたり、枠からはみ出したりしない | I |
| 動きは状態の変化と操作への反応にだけ使う。頻繁に繰り返す操作には付けない | I / V |
| 日時と数値は、言語標準の書式化機能で整形する | V |
| 待ち時間で表示を変える。1 秒未満は出さない、10 秒未満は回る表示、10 秒以上は進み具合を割合で出す | N |

<!-- /table -->
