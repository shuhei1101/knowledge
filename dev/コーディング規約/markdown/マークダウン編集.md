# Markdown 編集規約

## フロントマターの配置

YAML フロントマター（`---` ブロック）を持つ Markdown ファイルでは、開き `---` より前に HTML コメントも空行も置かない。

## `---`について
マークダウン内で指定がない場合、`---`による区切り線は使わないこと。

## `**`について
マークダウンで指定がない場合、`**` による太字、`*` による斜体、`>` による引用は使わない。

## 一行の長さについて
- 本文の段落・箇条書きは句点（。）ごとに改行する（1 文 = 1 行）
  - 文を書き足すときも既存行への連結ではなく新しい行に足す
- 表のセル・見出しは対象外（セル内の改行は `<br>`）

## テーブルの No / # カラムについて
- 連番だけの No / # カラムは付けない
- 番号自体に意味がある場合（不変 ID・Issue / PR 番号など、番号で参照する運用があるもの）のみ付けてよい

## テーブルの同上マーク（〃）について
- 同列で値が連続しても `〃` で省略せず、セルごとに実値を書く
