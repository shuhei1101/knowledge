# ビルドレス原則（バンドルしない）

- バンドラを使わない。
  - webpack / vite / esbuild などでブラウザ用にバンドル・最適化しない。
  - ネイティブ ES Modules と素の CSS をそのまま配信する。起動を軽く保つのが目的。
  - ただし TypeScript の型システムを使うため、`tsc` による `.ts` → `.js` のトランスパイル 1 段だけは許可する。
  - 開発時のツールは使ってよい（`html/tooling/tsc運用.md`）。

## ブラウザのスクリプトの拡張子

- `tsc` を挟める配信（サーバーが配る画面など）では、ブラウザのスクリプトを `.ts` で書き、`.js` を手で書かない。
  - スクリプトを置くフォルダの名前（`frontend/`・`static/`・`assets/` など）によらない。
- `.js` で書いてよいのは、ビルドせずにそのまま配るもの（GitHub Pages・モックのプレビューなど）だけ。
