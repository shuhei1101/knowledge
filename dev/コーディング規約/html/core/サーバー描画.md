# サーバー描画

サーバーがテンプレートから HTML を組み立てる画面の決まり。
ツール名は候補で、前提にしない。

- HTML はテンプレートで組み立てる
- 自動エスケープを、テンプレートの拡張子で有効にする設定を明示する（`select_autoescape`）
- 未定義の値はエラーにする。空文字で描かない（`StrictUndefined`）
- テンプレートの環境はアプリの起動時に 1 つ作って使い回す
- 計算・判断は Python 側で済ませ、テンプレートには表示する値だけを渡す
- 共通の骨格は継承（`extends` + `block`）、繰り返す部品はマクロにする
- エスケープを外すのは信頼できる変換（Markdown の変換器など）の出力だけにし、テンプレートの `safe` ではなくコード側で `Markup` にして渡す
- `<script>` の中・イベント属性・属性名には値を直接置かない。JS へ値を渡すときは HTML の中で安全な JSON 化にする（`tojson`）
- URL はルート名から組み立て、文字列で直書きしない（`url_for`）
