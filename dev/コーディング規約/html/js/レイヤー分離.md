# レイヤー分離 UI / State / API

| レイヤー | 役割                                                      |
| -------- | --------------------------------------------------------- |
| UI       | DOM アクセス・イベント・描画。state と api を import する |
| State    | メモリ上の状態・派生計算。DOM を触らない                  |
| API      | 通信。fetch ラッパー。DOM を触らない                      |

- 呼び出しは下方向のみ（UI → State → API）。
  - State と API は UI を import しない。UI から `fetch` を直叩きしない（api 層に集約）。
