# モジュール解決

import maps でモジュールを解決する（バンドルしない）。
- 1 ドキュメント 1 importmap。`<head>` 先頭、最初の `type="module"` より前。
  - 共通 partial で管理。
- bare specifier はディレクトリ単位でマップ（`lib/` `core/` `api/` `components/`）。
  - 画面コードは相対パスでなく bare 名で参照する。
- 著作は `.ts` だがブラウザが読むのは `tsc` 生成の `.js`。
  - importmap・`<script src>` は生成 `.js` の拡張子（`.js`）で書く。
    - 同階層 emit のためパスは `.ts` と同じ（`html/tooling/tsc運用.md`）。

`<link rel="modulepreload">` はエントリ + 重要依存のみ絞って付ける。
