# エンドポイント（URL 定数）

- URL 文字列を画面・api 層にハードコードしない。
  - 定数に集約し、そこだけ見れば全 URL が分かる状態にする。
  - リファクタ時の変更漏れを防ぐ。

- 置き場所は使う範囲に従う（`html/共通化の判断.md`）。
  - 画面ローカルなら `state.ts`
  - ドメイン共有なら `pages/{domain}/_shared/`
  - 全画面共有なら `shared/core/` の `.ts`

## 2 つの形式

単発 URL は flat const。

```ts
export const HOME_URL = "/home"
```

関連 URL は機能ごとにオブジェクトでまとめる。ID 付きは関数形式。

```ts
const COST = "/api/cost"

export const COST_API_URL = {
  summary: COST,
  detail: (id: string) => `${COST}/${id}`,
}
```

ベース URL（`COST`）は export しない private const にして合成だけに使う。
