# ユニットテスト（vitest）

vitest + jsdom で素の ES modules を直接テストする。

- `tests/unit/` に対象ファイルの階層をミラーして `{name}.test.ts` で置く（`tests/unit/shared/lib/fmt.test.ts` 等）。
- テスト対象は純関数・派生計算・状態ロジック（DOM や通信に依存しない部分）。
  - `state.ts` や `shared/lib` が主対象。描画の細部は結合テストに任せる。
- import 別名 `shared/` は `vitest.config.js` の alias で解決される（相対パスに書き換えない）。
- 時刻系は固定日時を渡して JST 変換を検証する。
