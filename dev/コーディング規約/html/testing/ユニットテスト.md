# ユニットテスト（vitest）

vitest + jsdom で素の ES modules を直接テストする。React プラグインは使わない。

- `tests/unit/` に対象ファイルの階層をミラーして `{name}.test.ts` で置く（`tests/unit/shared/lib/fmt.test.ts` 等）。
- `.ts` で著作する（`// @ts-check` は不要）。
  - `import { describe, it, expect } from "vitest"`。
- 単体の単位 = 1 ファイル。同一ファイル内のヘルパーは実物のまま、ファイル外の依存は Mock する
- 分岐ごとに 1 テスト以上置き、分岐カバレッジを極力 100% にする
- テスト対象は純関数・派生計算・状態ロジック（DOM や通信に依存しない部分）。
  - `state.ts` や `shared/lib` が主対象。描画の細部は E2E に任せる。
- import 別名 `shared/` は `vitest.config.js` の alias で解決される（相対パスに直さない）。
- `location` 等のブラウザ API を使う関数は jsdom 環境で動く。時刻系は固定日時を渡して JST 変換を検証する。
