# HTML コメント

## 書く場所・内容

| 対象                         | コメントの書き方                                          |
| ---------------------------- | --------------------------------------------------------- |
| セクション・ブロックの区切り | セクションの直上に `<!-- セクション名 -->` を置く         |
| 非自明な属性・data 属性      | 属性の役割や JS との連携を説明する                        |
| hidden 要素                  | なぜ最初から非表示にしているかを書く                      |
| Jinja2 ブロック              | {% raw %}`{% block %}`{% endraw %} の用途を 1 行コメントで補足する |
| 共通レイアウト               | head に置いた各タグの意図（importmap・viewport 等）を書く |

## 書き方の例

```html
<!-- importmap: "shared/" プレフィックスを /shared/ に解決する -->
<script type="importmap">
{ "imports": { "shared/": "/shared/" } }
</script>

<!-- 送信フォーム: POST /api/notify/completion を直接テストする -->
<section class="card" id="send-section">
  ...

  <!-- .preset-row[data-target]: JS が data-target の id を持つ input にプリセット値をセットする -->
  <div class="row preset-row" data-target="input-summary">
    ...
  </div>

  <!-- 送信結果: screen.ts の showResult() が innerHTML で描画する。初期は hidden -->
  <div id="result-area" class="hidden"></div>
</section>
```

## 注意

- Jinja2 の `{# ... #}` はレンダリング後に消えるので、ブラウザで見えるコメントは `<!-- -->` を使う
- セクションが自明でも区切りコメントは書く（長い HTML でスクロールしたときの道しるべになる）
- コメントを入れ子にしない（`<!-- <!-- --> -->` はパーサーが誤動作する）
