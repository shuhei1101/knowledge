# ネイティブ要素を第一選択にする

JS で作る前に標準要素で済むか確認する。

| 用途                       | 要素                      |
| -------------------------- | ------------------------- |
| モーダル                   | `<dialog>`                |
| アコーディオン / 開閉      | `<details>` / `<summary>` |
| 日付・色・範囲・ファイル等 | `<input type="...">`      |
| 非モーダルの浮遊 UI（メニュー・トースト等） | `popover` 属性 |

操作はボタン（`<button>`）、移動はリンク（`<a href>`）の要素で作る。
