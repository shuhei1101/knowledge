# 共通化の判断（どこに置くか）

- 新しい部品・関数・スタイルを書く前に、共通化できるかを先に考える。
  - 同じコードを 2 か所に書きそうになったら共通化の合図。
  - 画面にロジックやスタイルを重複させない。

- 置き場所は「使う範囲がいちばん狭い階層」を選ぶ。
  - 範囲が広がったら上の階層へ昇格する。

| 使う範囲                                    | 置き場所                                                                                           |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| その 1 画面だけ                             | 画面直下（`pages/{domain}/{screen}/`）に直接書く                                                   |
| 同じ画面の複数タブ / 同じドメインの複数画面 | `pages/{domain}/_shared/`                                                                          |
| ドメインをまたいで使える                    | `shared/`（UI 部品は `shared/components/`、汎用関数は `shared/lib/`、定数・環境は `shared/core/`） |
