# shared/vendor

- 外部依存は vendoring してここに固定する（mermaid 等）。
  - CDN ランタイム依存にしない。
  - バンドルの代わりに、固定済みファイルをそのまま配信する。
- 配布ファイル先頭の著作権・ライセンスのヘッダーを消さない・書き換えない（minify し直さない）。
- OSS でない独自ライセンスのもの（例: GSAP の Standard License）は、`vendor/{ライブラリ}/` にライセンスの所在（URL とバージョン）を書いたファイルを置く。
  - 禁止されている使い方（例: GSAP は演出を GUI で組むツールへの利用）は、外部ライブラリの設計書の `license` に書く。
