# CSS クラス命名

- 役割（component / layout / utility）は `@layer` とフォルダ分割で担保するので、ハンガリアン記法（`c-` / `l-` / `u-` 等）は用いない。
  - 素直な名前にする。

| 種類                 | 例                                                                              |
| -------------------- | ------------------------------------------------------------------------------- |
| コンポーネント       | `.button` `.card` `.task-card`                                                  |
| 要素（BEM 風の連結） | `.card__title` `.card__body`                                                    |
| 状態                 | `.is-open` `.is-active`、または `[aria-expanded]` / `[data-state]` 属性セレクタ |

状態は `:has()` や属性セレクタで表せるものはクラスを増やさず表現する。連結（`__`）はネイティブ Nesting で生成できないのでフル記述する（css/ネスト）。
