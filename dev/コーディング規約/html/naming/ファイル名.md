# ファイル名

- kebab-case で統一する（`task-card.ts`, `tuning.css`）。
  - Custom Element クラスを書くファイルだけ例外で PascalCase でもよい（`WsClient.ts` 等の既存に合わせる）。

- 画面の slug に複数概念をハイフンで詰め込まない。
  - 概念の区切りはフォルダで分ける（`pages/prompt/tuning/` であって `pages/prompt-tuning/` ではない）。
  - 詳細は `html/フォルダ構成.md` のドメイン階層を参照。
  - 複合語（`personal-chat` 等・1 概念）はハイフンのまま 1 セグメントにする。
