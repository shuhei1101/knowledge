# モバイル対応ルール

## 基本方針

- ブレークポイントは `@media (max-width: 768px)` 単一。タブレット中間は設けない。
- スマホ対応は各画面の `screen.css` 末尾に `@media` ブロックを追加するだけで完結させる。
  - 新規 CSS / TS / HTML ファイルは作らない（`screen.mobile.css` 等は禁止）
  - サブディレクトリ（`_mobile/` 等）も作らない
- DOM 構造の切替が本当に必要な画面のみ `screen.ts` 内で関数を増やす。別ファイルに切り出さない。
- デスクトップレイアウトはピクセル単位で維持。`@media` の外側を触らない。

- モバイル時に横幅が足りず、文字が縦積みになる問題
  - まず、横スクロールに対応して解消する。（ただし、画面全体の横スクロール化は禁止。一部分のみなら可）
  - 次に、文字列の変更。例えば、モバイル時のみ絵文字だけにするとか、文字量を減らすとか
  - 縦積みになっていないかをテストすること


## 共通シェル（`frontend/shared/`）の責務

- ヘッダー・サイドバー・ドロワー化は `app-shell` / `app-sidebar` / `layout.css` に集中させる。
  - 各画面でハンバーガーやスクリムを個別実装しない
- サイドバーはスマホ時に `position: fixed` + `transform` でドロワー化。
  - スクリム・ESC で閉じる・フォーカストラップ・開時 `<body>` の `overflow: hidden` をシェル側で持つ
  - 閉時のサイドバーは `inert` で操作不可にする
- z-index は `tokens.css` に集約し、ドロワー / debug-fab / モーダルの重なりを一元管理する。

## 対象外画面

- 他のアプリへ埋め込む透過画面（`<style>` で `html, body { background: transparent }` を宣言、または `app-shell` 不使用の透過全画面）はモバイル対応スコープ外。

## 落とし穴チェックリスト

### テキスト・コード

- 長い URL / トークン / ファイルパス / 半角混在の日本語長文を含む親に `overflow-wrap: anywhere` を当てる
- `<pre>` / `<code>` は `overflow-x: auto` + `white-space: pre-wrap` を両立させる
- `text-overflow: ellipsis` で省略する場合、タップ全文表示の導線を用意する

### テーブル

- 多列 `<table>` は親に `overflow-x: auto` のラッパを付けて横スクロール許容
- スマホで「行を縦積み変換」する場合、`tr { display: grid }` で 1 行 1 ブロック化
- `overflow-x: auto` ラッパ内では `position: sticky` の thead が機能しない

### タブ・横並び

- ヘッダーの外に並べた横並びタブが多い場合は `overflow-x: auto` + `flex-wrap: nowrap` で横スクロール（ヘッダーの中では横スクロールさせない）
- `.row` のフォーム行はスマホで `flex-direction: column` に倒す
- `inline-flex` を連続で並べる親には `flex-wrap: wrap` を必ず付ける

### 入力フォーム

- `input` / `textarea` / `select` の `font-size` は 16px 未満にしない
- 固定 width の input は `max-width: 100%` を保証
- `<input type="number">` のスピンボタンはスマホで `-webkit-appearance: none` を検討
- `label` + `input` の横並びはスマホ時に縦積み

### ビューポート・高さ

- `100vh` / `min-height: 100vh` / `100svh` は使わず `100dvh` を使う
- `100vw` は使わず `100%` を使う
- viewport meta は `templates/_layout.html` に集約。各画面 HTML で再宣言しない

### Flexbox / Grid

- flex 子要素には `min-width: 0` を明示
- `grid-template-columns: repeat(N, 1fr)` の N 列固定は使わず、`repeat(auto-fit, minmax(MIN, 1fr))` か `@media` で 1 列化
- flex/grid の子に `position: sticky` を使うときは `align-self: start` を付ける

### タッチ・操作性

- ボタン / リンクの実効タップ領域は最小 44×44px
- `:hover` 前提の UI は `click` トグルに切替、または `@media (hover: hover)` で分岐
- ドラッグ&ドロップを持つ UI はタップ操作の代替手段を用意
- 連続クリック想定の要素には `touch-action: manipulation` を付ける

### メディア要素

- `<img>` / `<canvas>` / `<svg>` は `max-width: 100%; height: auto`
- アバター画像など固定 width はコンテナ側で `max-width` を制約

### レイヤ・重なり

- `position: fixed` の座標は `right` / `bottom` 基準にして `max-width` で制約
- モーダル・ポップオーバーはビューポート境界判定で flip
- `debug-fab` のキーボード重なりは `visualViewport` API か `position: sticky` で回避
