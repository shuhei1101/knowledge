# 共通層の先読み

- 画面を実装する前に共通層を見て、再利用する。

1. `shared/css/tokens.css` — デザイントークン
2. `shared/css/components/` と `shared/js/components/` — 共通コンポーネント
3. `shared/js/core/routes` `constants` — ルート・定数

- 必要なコンポーネントが既にあれば import / 参照する。
  - 汎用的だが無ければ共通層に足してから使う。
  - 画面モジュールにトースト・ダイアログ等をインライン再実装しない。
  - 色・URL・マジック文字列を画面コードにハードコードしない。
