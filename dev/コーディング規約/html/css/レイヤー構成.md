# レイヤー構成

エントリ CSS の冒頭で `@layer` の順序を固定する。

```css
@layer reset, tokens, base, layout, components, utilities;
```

- 全ての CSS をいずれかのレイヤーに入れる。
  - レイヤー外（unlayered）のスタイルは全レイヤーより強くなり、事故の元になる。

- `utilities` は最終レイヤーなので、単一クラス（低 specificity）でも components を確実に上書きできる。
  - ユーティリティで `!important` を使わない。

<!-- table: data -->

| レイヤー   | 役割                      |
| ---------- | ------------------------- |
| reset      | normalize                 |
| tokens     | `:root` 変数・`@property` |
| base       | 要素デフォルト・タイポ    |
| layout     | 骨格・グリッド            |
| components | UI 部品                   |
| utilities  | 単一目的                  |

<!-- /table -->
