# フック作成ガイド

## ルール
- settings.json内にインラインで書かないでください。
  - pythonファイルは`.claude/hooks/*.py`: スクリプト名はフックイベントと同じにしてください。
    - 例: `user_prompt_submit.py`
  - プロンプトファイルは`.claude/hooks/*.md`
    - 変数を埋め込みたい場合は`.claude/hooks/*.j2`にする
- hooksの`additionalContext`でコンテキストを注入する場合の文字数の上限は公式の hooks リファレンス（`https://code.claude.com/docs/en/hooks`）に従う

## ワンタイムトークン付き条件ブロック
- PreToolUseなどで特定のBashコマンドを一度だけ防ぐときの方法
- 例えば、Push時に一度だけ確認させたい場合等に使う
  - 「確認 → 通過 → 確認 → 通過」を交互に繰り返す。
  - トークンなし時 → トークン作成 → ブロック（確認表示）
  - トークンあり時 → トークン削除（消費）→ 通過
- トークン命名規約:
  - フックごとに一意のトークンファイル名を使う。
  - トークン名に `session_id` を含める。
