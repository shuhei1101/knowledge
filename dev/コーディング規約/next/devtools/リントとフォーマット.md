# Next.js App Router — ESLint, Prettier, TypeScript Config

> Next.js 16 の変更: `next lint` 廃止、ESLint CLI を直接呼ぶ。設定は Flat Config（`eslint.config.mjs`）。

## tsconfig.json

`create-next-app` が生成した値を土台にし、次を追加する。

- `strict: true` に加えて `noUncheckedIndexedAccess` / `noUnusedLocals` / `noUnusedParameters` / `noFallthroughCasesInSwitch` / `noImplicitOverride` / `forceConsistentCasingInFileNames`
- `target: ES2022` / `allowJs: false`
- `paths` で `@/*` → `./*`

## ESLint

- `eslint-config-next`（`core-web-vitals` と `typescript`）を Flat Config で読む
- `eslint-config-prettier/flat` が Prettier と競合する ESLint ルールを無効化する
- `@typescript-eslint/no-deprecated` を有効にし、型情報つきの設定（`parserOptions.projectService`）で動かす
