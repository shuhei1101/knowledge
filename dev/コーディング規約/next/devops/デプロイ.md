# Next.js App Router — Deploy

## デプロイ先の選択

| プロジェクト種別                                | 推奨                                                             |
| ----------------------------------------------- | ---------------------------------------------------------------- |
| Web サービス（フロント + API）                  | Vercel                                                       |
| ローカル動作のみ（デスクトップツール等）        | デプロイなし（`pnpm dev` で起動）                                |
| セルフホストしたい                              | Node.js サーバー（`pnpm build && pnpm start`）+ リバースプロキシ |
| 完全静的サイト                                  | Vercel / Cloudflare Pages / Netlify                              |
| エッジに寄せたい                                | Cloudflare Workers + OpenNext                                    |
Vercel を標準とする。

セルフホストの設定（複数台の暗号鍵・キャッシュ・`after`）は公式の [Self-hosting](https://nextjs.org/docs/app/guides/self-hosting) に従う。
