# URL 定数管理 — app/(shared)/endpoints.ts

全 URL を集約。コンポーネント・hook・client.ts での URL ハードコード禁止。

## 形式

```ts
// フィーチャグループ（基本形）
export const RESOURCE_URL = {
  list: `/resources`,
  new:  `/resources/new`,
  view: (id: string) => `/resources/${id}`,
  edit: (id: string) => `/resources/${id}/edit`,
}

export const RESOURCE_API_URL = {
  list:    `/api/v{N}/resources`,
  detail:  (id: string) => `/api/v{N}/resources/${id}`,
  publish: (id: string) => `/api/v{N}/resources/${id}/publish`,
}
```

- list / new / view / edit の単発のみ Flat const
- ID 付き URL は関数形式 `(id: string) => ...`
- ベース URL（`RESOURCES` 等）は file-private（export しない）
- サブフィーチャは別オブジェクトに切り出す（深いネスト禁止）

## 命名

| 定数 | 意味 |
|---|---|
| `{FEATURE}_URL` | フロントエンドルート群 |
| `{FEATURE}_API_URL` | API ルート群（`/api/v{N}/...`） |
