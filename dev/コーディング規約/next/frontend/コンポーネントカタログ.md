`pnpm dlx shadcn@latest add {name}` で追加。

## 用途別

### ボタン

| 用途 | コンポーネント |
|---|---|
| 通常 | shadcn `<Button>` |
| 非同期処理 | `<LoadingButton>` |
| リンク遷移 | `<Button asChild><Link>` |

### フォーム入力

<!-- table: data -->

| 用途 | コンポーネント |
|---|---|
| 基本ラベル+エラー構造 | `<FormField>` + `<FormItem>` + `<FormControl>` + `<FormLabel>` + `<FormMessage>` |
| Text | `<Input>` |
| Select | `<Select>` |
| Multi-select | `<Command>` + `<Popover>` |
| Tag | `<TagInput>` |
| Toggle | `<Switch>` |
| Date | `<Calendar>` + `<Popover>` |

<!-- /table -->

### フィードバック

| 用途 | コンポーネント |
|---|---|
| Loading | `<Skeleton>` / `loading.tsx` |
| Toast | `toast.success` / `toast.error` (sonner) |
| 確認 dialog | `useConfirmDialog()` |
| 空状態 | `<EmptyState>` |
| Autosave 状態 | `<AutosaveIndicator>` |

### ダイアログ系

| 用途 | コンポーネント |
|---|---|
| コンテンツ dialog | shadcn `<Dialog>` |
| 確認 dialog | `useConfirmDialog()` |
| サイドパネル | shadcn `<Sheet>` |
| モバイル下シート | shadcn `<Drawer>` |
| Popover | shadcn `<Popover>` |

## 新規コンポーネントを作る前

1. 本カタログをチェック
2. shadcn primitive をチェック（`shadcn add` で取れるか）
3. Radix UI を直接使う
4. 3 回目に同じものを書きそうになったら `app/(shared)/components/` に追加
