# 型定義の置き場所と表現

## 置き場所

<!-- table: data -->

| 型 | Location |
| --- | --- |
| フォームスキーマ + 型 | `{feature}/form.ts` |
| 共通スキーマプリミティブ | `app/(shared)/schema.ts` |
| API リクエスト型 | `app/api/v{N}/{resource}/route.ts`（export） |
| API クエリ / 読み取り戻り値型 | `app/api/v{N}/{resource}/query.ts` |
| Server Action 入出力型 | `form.ts` の型を再利用 |
| DB row 型 | `drizzle/schema.ts`（`$inferSelect` / `$inferInsert`） |
| Component Props | コンポーネントファイル内（export 不要） |
| Hook の引数 / 戻り値型 | hook ファイル内 |
| 複数フィーチャ共通の domain 型 | `app/(shared)/types.ts`（3+ ファイルで使うもの） |

<!-- /table -->

グローバル `types.d.ts` は使わない。型は所有するコードの近くに置く。

## Zod schema → 型推論

- 型は必ず `z.infer<>` で導出

## Drizzle 型の導出

- Insert は自動管理カラムを `Omit<..., "id" | "createdAt" | "updatedAt">`
- Update は `Partial<Insert>` から不変フィールドを Omit
- 複合戻り値は `{ resource, children, tags }` のような object 型を定義

## API リクエスト / レスポンス型

- リクエスト schema は route.ts で定義し export、client.ts は `import type` で参照
- レスポンス型は `Awaited<ReturnType<typeof fetchResource>>` で query.ts の戻り値から導出

## Next.js 16 型ヘルパー

`params` / `searchParams` は Promise 化済み。`next typegen` 生成の `PageProps<'/path'>` / `LayoutProps<...>` / `RouteContext<'/api/...'>` を使い、`await props.params` で取り出す。
