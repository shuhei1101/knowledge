# QueryProvider — TanStack Query 設定

- QueryClient は `getQueryClient()` で作る（サーバーはリクエストごとに新規、ブラウザは 1 つを使い回す）。`useState` で初期化しない
- `app/layout.tsx` で wrap

## defaultOptions

| Option | 値 | 理由 |
|---|---|---|
| `staleTime` | `60 * 1000` | SSR 直後の即時再取得を避ける |
| `refetchOnWindowFocus` | `false` | |
| `retry` | `false` | 即エラー表示（個別 hook で override 可） |
