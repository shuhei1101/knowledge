# QueryProvider — TanStack Query 設定

- `useState(() => new QueryClient(...))` で初期化（SSR 複数 instance 防止）
- `app/layout.tsx` で wrap

## defaultOptions

| Option | 値 | 理由 |
|---|---|---|
| `staleTime` | `0` | 常にサーバーを真実扱い |
| `gcTime` | `5 * 60 * 1000` | 再ナビゲーションで即表示 |
| `refetchOnWindowFocus` | `false` | |
| `refetchOnReconnect` | `true` | ネットワーク復帰時 |
| `retry` | `false` | 即エラー表示（個別 hook で override 可） |
