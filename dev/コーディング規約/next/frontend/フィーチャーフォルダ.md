# フィーチャフォルダ構成

```
app/(authenticated)/{feature}/
├── page.tsx                       # Server Component: 一覧
├── {Feature}ListScreen.tsx        # Client Component
├── form.ts                        # Zod schema + Type（new/edit 共用）
├── actions.ts                     # Server Actions（'use server'）
├── components/
├── hooks/
├── new/
│   ├── page.tsx
│   └── {Feature}NewScreen.tsx
└── [id]/
    ├── page.tsx                   # View 画面
    ├── {Feature}ViewScreen.tsx
    ├── components/
    ├── hooks/
    └── edit/
        ├── page.tsx
        ├── {Feature}EditScreen.tsx
        ├── components/
        └── hooks/
```

## components / hooks の配置

| Scope | Location |
|---|---|
| フィーチャ全体 | `{feature}/components/`, `{feature}/hooks/` |
| view/edit 共用 | `{feature}/[id]/components/`, `{feature}/[id]/hooks/` |
| edit 専用 | `{feature}/[id]/edit/components/`, `{feature}/[id]/edit/hooks/` |
| 複数フィーチャ共通 | `app/(shared)/components/`, `app/(shared)/hooks/` |

## ルール

- フィーチャ名は kebab-case 複数形（`resources/`, `family-members/`）
- `form.ts` / `actions.ts` はフィーチャ直下（`[id]/edit/` 配下に置かない）
- `[id]/page.tsx` が View 本体（`view/` サブルートは作らない）
- Screen 接尾辞: `ListScreen` / `NewScreen` / `ViewScreen` / `EditScreen`
- `_components/` / `_hooks/` 禁止（アンダースコア prefix 廃止）
