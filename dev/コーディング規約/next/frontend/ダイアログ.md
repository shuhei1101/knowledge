# Dialog / Modal / Popup

## コンポーネント選択

| Suffix | 用途 |
|---|---|
| `*Dialog` | コンテンツ（フォーム・詳細表示） |
| `*AlertDialog` | 確認系（破壊的アクション） |
| `*Sheet` | 横 / 縦スライドパネル |
| `*Drawer` | モバイル下から出るシート |
| `*Popover` | 小フローティングコンテンツ |

## 配置

| Scope | Location |
|---|---|
| 1 画面専用 | `{feature}/components/` |
| 複数画面共通 | `app/(shared)/components/` |
| view/edit 共通 | `{feature}/[id]/components/` |

## Props

- `open: boolean`, `onOpenChange: (open: boolean) => void`（親が制御、内部管理しない）
- 複数 Dialog は各 Dialog ごとに `useState` を持つ

## 確認ダイアログ

`useConfirmDialog()` を使う（`window.confirm` 禁止）。詳細: `frontend/確認ダイアログ.md`

## Draft 確定方式

| パターン | 使いどき |
|---|---|
| 内部 draft state → `onConfirm` で親へ | 複数値・複雑な選択 |
| 操作ごとに即 onChange | 単純な選択 |

## 使わない場合

| 用途 | 代替 |
|---|---|
| 一覧→詳細 | 別ルート遷移 |
| 一時的メッセージ | `toast.info()` |
| 検索 / コマンド | `<Command>` |
