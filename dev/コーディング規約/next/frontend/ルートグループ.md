# Route Groups

3 グループのみ（増やすときは PR で議論）。

| Group | 用途 |
|---|---|
| `(authenticated)` | 認証必須エリア。`layout.tsx` で認証ガード + AppShell |
| `(auth)` | login / signup 等。ログイン済みなら `/home` に redirect |
| `(shared)` | 共通 UI / hook / provider / schema / logger / endpoints |

## `(shared)/` に置くもの

複数フィーチャで使うもの限定（単一フィーチャ専用は `(authenticated)/{feature}/` へ）

## ルール

- フィーチャは `(authenticated)/{feature}/` 配下
- `(shared)/` は複数フィーチャ共通のみ
- `_components/` 等アンダースコア prefix 禁止
