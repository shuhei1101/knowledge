# `<Controller>` + `<Field>` パターン

react-hook-form + Zod + shadcn/ui の標準組み合わせ。

## 構造

`<form onSubmit={form.handleSubmit(onSubmit)}>` → `<Controller>` の `render` → `<Field>` → `<FieldLabel>` + 入力部品 + `<FieldError>`

- `register` 直接使用禁止（`<Controller render={({ field, fieldState }) => ...}>` を使う）
- エラーの状態は `fieldState.invalid` を `<Field>` の `data-invalid` と入力部品の `aria-invalid` へ渡して出す
- `<FieldLabel>` の `htmlFor` と入力部品の `id` を揃える

## 入力タイプ別ポイント

<!-- table: data -->

| 型 | ポイント |
|---|---|
| Text / Textarea | `{...field}` でそのまま渡す |
| Number | `onChange` で `Number()` 変換、空文字→ `null` |
| Select | `value` を `toString()`、`onValueChange` で `Number()` 変換 |
| Switch | `checked={field.value} onCheckedChange={field.onChange}` |
| Tag | `<TagInput value={field.value} onChange={field.onChange}>` |
| Date | `<Calendar>` + `<Popover>` 組み合わせ |

<!-- /table -->

## ルール

- 必須フィールドには `<FieldLabel>` 内に `<RequiredMark />`
