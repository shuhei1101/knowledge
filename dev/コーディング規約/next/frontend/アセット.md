# Assets (Image / Font / Static)

## next/image

- `images.domains` は廃止 → `remotePatterns` 必須（Next.js 16）
- LCP 画像は preload させる（指定の仕方は [Next.js の Image のドキュメント](https://nextjs.org/docs/app/api-reference/components/image)）
- `sizes` を必ず指定（srcset 最適化）
- `fill` 使用時は親を `relative` + `aspect-*` に
- 意味のある画像は alt 必須、装飾は `alt=""`
- `placeholder="blur"` + static import で blur 自動生成
- `qualities: [75]` / `minimumCacheTTL: 4h` がデフォルト（Next.js 16）

## next/font

- `next/font/google` / `next/font/local` で self-host（CLS ゼロ、preload 自動）
- CSS variable で Tailwind に渡す（`--font-xxx`）
- `app/layout.tsx` の `<html className={...}>` に適用

## SVG

| 種類 | 方法 |
|---|---|
| インラインアイコン | `lucide-react` |
| ロゴ・装飾 | `next/image` |
| 動的カラー変更 | インラインコンポーネント |

## 静的アセット

- `public/` 配下に配置、URL は `/path/to/file` で参照
- ファビコン / apple-icon / OG は `app/` 直下に置くだけで自動認識

## CDN

| アセット | 配信 |
|---|---|
| `public/` 静的画像 | Vercel CDN 自動 |
| ユーザーアップロード | Supabase Storage / Vercel Blob / S3 |
| OG image（動的） | `opengraph-image.tsx` + `next/og` |
| 動画 | Mux / Vercel Blob |
