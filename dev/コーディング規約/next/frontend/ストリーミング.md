# Streaming / Suspense

## Suspense 境界

- `<Suspense>` 内の async Server Component は並列に fetch・独立してストリーム
- `loading.tsx`: ページ全体の fallback（ナビゲーション中）
- `<Suspense>`: ページ内部分の fallback
- fallback は CLS が出ないよう同じ高さの `<Skeleton>` を使う
- `cookies()` / `headers()` を不必要に呼ぶとページ全体が動的化（PPR が効かなくなる）

キャッシュ API（`"use cache"` / cacheLife / PPR の有効化）は `backend/キャッシュ.md`。

## React 19 `use()`

- promise を `<Suspense>` と組み合わせてストリーム（promise を await せず子に渡し、子が `use()` で待つ）

## View Transitions（React 19.2）

- `<ViewTransition>` でナビゲーション間アニメーション
