# Autosave パターン

## useAutosave

```ts
const { status, lastSavedAt, retry } = useAutosave({ values, save, debounceMs })
```

- `status`: `"idle" | "saving" | "saved" | "error"`
- 値変更後 `debounceMs`（デフォルト 1000ms）で debounce 保存
- 前回保存値と同じなら保存しない
- 古いリクエストの結果は無視（inflight ref で判定）
- online イベントで error 状態なら自動 retry
- `isValid` で保存対象を絞れる

## ルール

- Server Action の `refresh()` は呼ばない（client router の再フェッチが毎回走る）
- 離脱検知（`useBeforeUnload`）は error 状態のみ（成功する保存に対しては出さない）
- `form.watch()` を `values` に渡す、`mode: "onChange"` を忘れずに
