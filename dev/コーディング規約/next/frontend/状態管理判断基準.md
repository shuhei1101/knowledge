# State の置き場所

## 決定フロー

```
サーバーから来るデータ？ → TanStack Query（Server Component で初期取得）
URL に保持したい？ → URL クエリ（nuqs）
複数コンポーネントで共有？ → Context（更新少）/ Zustand（頻繁更新・selector 必要）
prop drilling 3+ レベル？ → Context または hook 抽出
それ以外 → useState
```

## 用途別早見表

<!-- table: data -->

| 状態 | 置き場所 |
|---|---|
| 取得データ（一覧・詳細） | TanStack Query |
| フィルタ / ソート / ページ / タブ | URL クエリ |
| Modal 開閉（deep link 不要） | useState |
| Modal 開閉（deep link したい） | URL クエリ |
| Sidebar 開閉（永続） | Zustand / Context |
| 編集中のフォーム値 | react-hook-form |
| 確認ダイアログ | `useConfirmDialog`（Zustand） |
| Toast | sonner |
