# app/(shared)/actions/auth.ts — 認証 Server Action

ログイン・サインアップ・ログアウトの Server Action 群。

- ファイル冒頭に `'use server'`、配置は `app/(shared)/actions/auth.ts`（共通 action）
- 入力は Zod パース（LoginSchema / SignupSchema をファイル内に定義）
- Better Auth API を使う: `auth.api.signInEmail` / `signUpEmail` / `signOut`（いずれも `headers: await headers()` を渡す）
- 結果は `ActionResult<T>` 形式（`signOutAction` は redirect のみなので void 可）
- 成功時は `redirect(HOME_URL)` 等（redirect の扱いは `shared/エラーアクションハンドラー.md`）
- ログイン試行は監査ログとして記録（`action:auth` タグ）
