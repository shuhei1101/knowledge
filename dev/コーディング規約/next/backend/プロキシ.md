# proxy.ts（旧 Middleware）

Next.js 16 で `middleware.ts` → `proxy.ts` にリネーム（export 関数名も `proxy`）。配置はプロジェクト直下。

- 用途: 認証ガード（未認証を `/login` へ redirect）・レートリミット・ヘッダ書き換え・rewrite
- ランタイムは `nodejs` 固定で `runtime` は設定できない（edge が必要なら `proxy.ts` にせず `middleware.ts` を使う）
- `config.matcher` で適用パスを指定。静的アセット・auth API・webhook は negative lookahead で除外する

```ts
export const config = {
  matcher: ["/((?!_next/static|_next/image|favicon.ico|api/v{N}/auth|api/v{N}/webhooks).*)"],
}
```

- 認証チェックは cookie の有無等の軽量判定に留める（本判定は `getAuthContext()` 側）。Server Action は matcher の対象外パスでは proxy を通らないため、各 Action で認証する
- 未認証 redirect 時は `?from=` に元パスを付けてログイン後に戻せるようにする
