# proxy.ts（旧 Middleware）

Next.js 16 で `middleware.ts` → `proxy.ts` にリネーム（export 関数名も `proxy`）。配置はプロジェクト直下。

- 用途: 認証ガード（未認証を `/login` へ redirect）・権限ガード・レートリミット・ヘッダ書き換え・rewrite
- ランタイムは `nodejs` 固定（edge が必要なら `middleware.ts` を併用、共存可能）
- `config.matcher` で適用パスを指定。静的アセット・auth API は negative lookahead で除外する

```ts
export const config = {
  matcher: ["/((?!_next/static|_next/image|favicon.ico|api/v{N}/auth).*)"],
}
```

- 認証チェックは cookie の有無等の軽量判定に留める（本判定は `getAuthContext()` 側）
- 未認証 redirect 時は `?from=` に元パスを付けてログイン後に戻せるようにする
