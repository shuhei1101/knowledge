# lib/auth.ts — Better Auth セットアップ

 採用認証プロバイダ: Better Auth（DB 非依存・TypeScript ファースト）。
- `lib/auth.ts` は 1 つだけ（複数 instance NG）
- セッション期限は 30 日 + sliding renewal
- `cookieCache` を有効化（DB クエリ削減）。失効が他端末に反映されるまで最大 `maxAge` かかるため、機微な操作は `disableCookieCache: true` で DB を引く
- Server Action で cookie を設定する認証呼び出し（`signInEmail` 等）のため、`nextCookies()` プラグインを `plugins` の最後に置く
- シークレットの置き場所は [設定値の置き場所](../../../判定フローチャート/設定値の置き場所.md) と `shared/環境変数.md` に従う
