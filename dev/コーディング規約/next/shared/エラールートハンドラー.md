# withRouteErrorHandling — route.ts のエラー変換

- 全 `route.ts` handler を `withRouteErrorHandling(async () => { ... })` で wrap（handler 内に try/catch を書かない）
- Zod / AppError 派生を構造化 JSON `{ error: { code, message, field? } }` に自動変換
- 予期しないエラーはログに stack を記録して 500 を返す（raw message / stack をレスポンスに出さない）

## レスポンス封筒

<!-- table: data -->

| Error                | Status       | code                                          |
| -------------------- | ------------ | --------------------------------------------- |
| ZodError             | 400          | VALIDATION（最初の issue の message + field） |
| ClientValueError     | 400          | VALUE（field? あり）                          |
| ClientAuthError      | 401 / 403    | AUTH                                          |
| VersionConflictError | 409          | CONFLICT                                      |
| AppError（404 等）   | e.statusCode | e.code                                        |
| 予期しない           | 500          | INTERNAL（汎用文言）                          |

<!-- /table -->
