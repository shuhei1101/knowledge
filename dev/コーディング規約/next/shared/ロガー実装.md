# logger.ts — JSON Lines ロガー

- サーバー / クライアント両用、出力は JSON Lines（1 行 = 1 JSON、装飾なし）
- レコード形式: `{ ts, level, component?, msg, ctx? }`
- `logger`（デフォルト）/ `logger.create("tag")`（component 付き）を使う。`console.log` は使わない
- レベル: debug / info / warn / error
  - `NEXT_PUBLIC_LOG_LEVEL` で設定、dev は `localStorage.setItem("log.level", ...)` で動的変更可
  - production のクライアント側は warn 以上に強制クランプ（情報漏洩防止）

## ctx の書き方

- 文字列補間せず `ctx` で構造化（`log.info("registered", { id })`）
- Error オブジェクトを直接入れない（シリアライズ崩れ）→ `e.message` を取り出す。stack は 500 系のみ
- 含めてはいけないもの: パスワード / トークン / API key / セッション ID / フルメールアドレス / カード番号 / PII
