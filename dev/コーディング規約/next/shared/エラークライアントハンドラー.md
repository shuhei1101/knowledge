# handleAppError — クライアント側エラー処理

- `useQuery` / `useMutation` のエラーは `handleAppError(error, router)` 経由で処理
- raw error / `error.message` を JSX に直接出さない
- Server Action 直接呼びには使わない（`result.ok` で分岐する方式）

## エラー種別ごとの挙動

| Error                  | UX                                  |
| ---------------------- | ----------------------------------- |
| `ClientAuthError`      | toast + ログイン画面へ遷移          |
| `VersionConflictError` | toast + `router.refresh()` で最新化 |
| `RateLimitError`       | 長め（5 秒）の toast                |
| 上記以外の AppError    | toast                               |
| 予期しない             | 汎用文言の toast                    |
