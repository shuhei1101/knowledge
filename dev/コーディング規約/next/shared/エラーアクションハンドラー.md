# handleActionError — Server Action のエラー変換

- 全 Server Action を try/catch で囲み、catch で `handleActionError(e)` を返す
- 戻り値は `ActionResult<T>` 形式
  - `{ ok: true, data: T } | { ok: false, error: { code, message, field? } }`
- ZodError は最初の issue を `code: "VALIDATION"` + `field` に変換
- AppError 派生は `code` / `message`（ClientValueError は `field` も）に変換
- 予期しないエラーはログに stack を記録し `code: "INTERNAL"` の汎用メッセージを返す
- `redirect()` は catch しない
  - `isRedirectError(e)` なら再 throw、または redirect を try の外に出す
