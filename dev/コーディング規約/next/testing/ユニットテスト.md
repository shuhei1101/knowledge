# Unit / Component テスト（Vitest + Testing Library）

## vitest.config.ts の要点

- `environment: "jsdom"`、`globals: true`、`setupFiles: ["./tests/setup.ts"]`（jest-dom 読み込み）
- coverage は v8、`app/**` を include、page.tsx / layout.tsx を exclude

## 何をどうテストするか

<!-- table: data -->

| 対象                    | 方法                                                           |
| ----------------------- | -------------------------------------------------------------- |
| Zod schema              | `safeParse` で有効値 / 各バリデーションエラーを網羅            |
| 純粋関数                | 入出力のみ検証                                                 |
| コンポーネント          | Testing Library + userEvent で振る舞いを検証                   |
| カスタム hook           | `renderHook` + `waitFor`                                       |
| service.ts              | 実 DB（test 用 schema / branch、dev と分離）で integration     |
| クライアント API モック | MSW（setupServer、setup.ts で listen / resetHandlers / close） |

<!-- /table -->

## 単体の単位

- 単体の単位 = 1 ファイル。
  同一ファイル内のヘルパーは実物のまま、ファイル外 / プロセス外の依存は Mock する
- 分岐ごとに 1 テスト以上置き、分岐カバレッジを極力 100% にする
