# asyncio 規約

Python 3.12+ の asyncio 機能を前提に書く。

| やりたいこと                       | 使う API                                     | 使わない旧 API             |
| ---------------------------------- | -------------------------------------------- | -------------------------- |
| 並行実行                           | `asyncio.TaskGroup`                          | `asyncio.gather`           |
| タイムアウト                       | `async with asyncio.timeout(N)`              | `asyncio.wait_for`         |
| sync ブロッキングを async から呼ぶ | `asyncio.to_thread`                          | 直接呼び（ループが止まる） |
| async を sync から呼ぶ             | `asyncio.run`（エントリポイントで 1 度だけ） | ネスト呼び出し             |
| コンテキストマネージャ             | `@asynccontextmanager` 関数                  | `__aenter__` クラス自作    |

- TaskGroup の利点: 1 つの例外で他もキャンセル、`ExceptionGroup` で複数失敗を扱える、ブロック終了 = 全タスク完了保証
- `CancelledError` は catch してもクリーンアップ後に必ず再 raise（キャンセル伝播を止めない）
- ストリーミング（LLM 応答等）は `AsyncIterator[str]` を返す async generator
- Producer / Consumer は `asyncio.Queue`（終了は `None` センチネル）
- 排他は `asyncio.Lock`、同時実行数制限は `asyncio.Semaphore(N)`
- CPU バウンドを async 関数内に直書きしない（`to_thread` か `concurrency/並列処理.md` へ）
