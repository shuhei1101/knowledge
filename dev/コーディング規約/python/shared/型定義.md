# shared/types.py — 共通型エイリアス

複数 feature で共有される型だけを置く。

## 配置方針

- 横断的な識別子型（`UserId` 等）→ `shared/types.py`
- 特定 feature でしか使わない型 → `features/{feature}/types.py`
- 複数 feature で使われるようになってから shared に引き上げる（YAGNI）
- `User` のような業務 DTO を shared に置かない（feature 間の密結合になる）
- `type ListOfInt = list[int]` のような標準型の別名は不要

## type vs NewType

使い分けは `core/型ヒント.md`。プロジェクト内で統一し、新規は `type` 文を使う。

## 共通の関数型エイリアス

テストで差し替えたい横断関数は型で抽象化して shared に:
`type NowFn = Callable[[], datetime]` / `type GenerateId = Callable[[], str]` / `type AsyncHttpFetch = Callable[[str], Awaitable[dict]]` 等。composition root で本物 / 固定値 Mock を注入。

## 共通 DTO

`Pagination` / `Page[T]` のような真に横断的なものだけ。ほとんどの DTO は feature 内に閉じる。
