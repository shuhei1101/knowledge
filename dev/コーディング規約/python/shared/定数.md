# shared/constants.py — 計算済み定数

計算済みの不変値だけを置く。実行時可変な値（env 切替）は `settings.py` へ。

| 配置先                | 内容                                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------------------- |
| `constants.py`        | 構造から計算されるパス（`PROJECT_ROOT` / `LOG_DIR`）、業務固定値（`MAX_TAGS_PER_POST` / `DEFAULT_PAGE_SIZE`） |
| `settings.py`         | env で切り替える値（API キー / モデル名 / log_level）                                                         |
| feature の `types.py` | feature 専用の定数・業務 Enum                                                                                 |

## 書き方

- `UPPER_SNAKE_CASE` + 型注釈必須 + 説明 docstring
- `PROJECT_ROOT: Path = Path(__file__).resolve().parents[2]` のように 1 度だけ計算（カレントディレクトリ非依存、同じパス計算を散在させない）
- 巨大な dict（プロンプト等）は constants でなくファイル / config に

## 固定の選択肢

`Literal` を基本に（`type Status = Literal["draft", "published", "archived"]`）。`StrEnum` はライブラリが要求するときだけ。
