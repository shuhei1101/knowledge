# pydantic-settings による設定管理

`.env` / 環境変数を `Settings(BaseSettings)` で型安全に読む（`shared/settings.py`）。

## 標準実装の要点

```python
class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        env_nested_delimiter="__",
        extra="ignore",
    )

    openai_api_key: SecretStr = Field(description="OpenAI API キー（必須）")
    openai_model: str = Field(description="使うモデル名（必須）")
```

- API キーは `SecretStr`（ログに出ない）。外部クライアントに渡す時だけ `get_secret_value()`
- `extra="ignore"` で未知の env を無視
- 計算済みパス（`project_root` 等）は `default_factory` / `@property` で
- 検証は `@field_validator`（log_level の許可値チェック等）
- ネスト設定は `BaseModel` 入れ子 + `env_nested_delimiter="__"`（`DB__HOST=...`）

## 運用

- `Settings()` は main.py で 1 度だけインスタンス化し、partial で各関数に埋める（関数内で毎回作らない）
- `os.environ` を直接読まない（型も検証もない）
- YAML を読むのは「プロンプト定義・構造化設定・リスト的なもの」だけ（`model_post_init` で読み込み可）。単純な値は `.env` で十分
