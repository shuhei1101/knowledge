# プロンプトローダー実装

`prompts/{node}.yaml` を読み、`when` に当たる部品の `text.en` を Jinja2 でレンダリングして 1 つのプロンプトに組み立てる。書き方は [プロンプトファイル](../../prompt/プロンプトファイル.md)。

## 構成

```
src/{pkg}/integrations/llm/prompts/
├── node_loader.py        # prompts/{node}.yaml の読み込みとキャッシュ
├── builder.py            # when の評価 + 部品結合 + Jinja2 レンダリング
└── types.py              # PromptFile / PromptPart 等の DTO
```

プロンプト本体はリポジトリ直下の `content/prompts/`、ローダーは `src/` 配下。場所は `shared/constants.py` の `PROJECT_ROOT` から解決。

## node_loader.py

- `@cache` で node ごとに 1 プロセス 1 回だけ読む（ホットリロードは `cache_clear()`）
- 戻り値は TypedDict（`PromptFile`: id / node / tags / vars / output / parts）

## builder.py

- Jinja2 `Environment` は `StrictUndefined`（未定義変数で即例外）
- `build_prompt(node, **vars)`: `vars` の必須が渡されているかを確かめ、`parts` を順に見て `when` が真の部品の `text.en` をレンダリングし `"\n\n".join`
- `when` は `vars` を使う Jinja2 の式として評価し、無い部品は常に使う
- role 別に分けたいときは `build_bundle` で `PromptBundle(system, user)` を返す
  - Anthropic の `system=` 引数と分離でき、system 全体を 1 つの `cache_control` ブロックに包める
- 読むのは `text.en` だけ（`text.jp` は読まない）

## ルール

- ローダーは pure な変換に限る（外部 API を叩かない）
- ファイルのパスをハードコードしない（`prompts/{node}.yaml` の `parts` が SoT）
- プロンプトをグローバル変数に持たない（vars が変わると不整合）
- 結合テストは実 LLM を呼ばず `build_prompt` の結果文字列だけ検証（未定義変数で例外が出ることも確認）
