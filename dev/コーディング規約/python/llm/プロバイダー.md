# LLM プロバイダ実装

LLM API（Claude / OpenAI / Gemini 等）を関数で抽象化して注入できる形にする。

## 構成

- `integrations/llm/types.py` に `Message`（TypedDict: role / content）と `type AsyncChatFn = Callable[[ChatRequest], Awaitable[ChatResponse]]`
- 各プロバイダは `make_{provider}_chat(*, api_key, model, timeout, max_tokens) -> AsyncChatFn` のファクトリ関数
  - クライアント生成をクロージャに閉じ、`AsyncChatFn` 互換の関数を返す
- Mock も同じ形: `make_mock_chat(*responses)` で固定文字列を順に返す
- composition root でプロバイダを 1 つ選んで配線。切り替えは設定 1 行（service のシグネチャは不変）

## 実装の要点

- vendor 例外をドメイン例外にラップ
  - RateLimitError → `LlmRateLimitError` / 5xx → `LlmServerError` / 400 → `LlmBadRequestError` / timeout → `IntegrationTimeoutError`、すべて `raise ... from e`
- 呼び出しごとにトークン使用量を構造化ログ（provider / model / input_tokens / output_tokens / cache_read_tokens）
- Anthropic は system メッセージを別パラメータに分離する必要がある
- fallback は primary を try し `LlmServerError` / `IntegrationTimeoutError` で secondary へ
- ストリーミングは `type AsyncChatStreamFn = Callable[[ChatRequest], AsyncIterator[str]]` の async generator
