# 結合テストの Mock パターン

関数の型エイリアスで DI している依存は Mock も普通の関数で書く（`AsyncMock` より読みやすい）。引数注入していない依存は `monkeypatch` / `mock.patch` で差し替えてよい。

<!-- table: data -->

| 対象         | パターン                                                             |
| ------------ | -------------------------------------------------------------------- |
| LLM          | `make_chat_mock(*responses)` — 固定文字列を順に返すファクトリ        |
| 呼び出し検証 | クロージャに `calls` リストを持つ spy 関数（`_chat.calls` で参照）   |
| エラー注入   | `make_chat_error(LlmRateLimitError("..."))` — raise するだけの関数   |
| HTTP         | fetch を型エイリアス化していれば Mock 関数注入。httpx 直なら `respx` |
| 時刻         | `NowFn` に固定時刻関数を渡す（freezegun より関数注入がシンプル）     |
| ID 生成      | `iter(["id-1", ...])` + `next` を返す関数                            |
| 永続化       | クロージャの dict による in-memory `save` / `find`                   |
| 環境変数     | `monkeypatch.setenv` → `Settings()`                                  |

<!-- /table -->

- よく使う Mock は conftest の fixture に集約
- 本物の外部サービスに通信するテストを結合テストに書かない（課金・不安定 → 外部疎通テスト（`tests/external/`）へ）
