# FastAPI アプリ構成

- `server/app.py` の `build_fastapi() -> FastAPI` で組み立て、`uvicorn {pkg}.server.app:build_fastapi --factory` で起動
- 依存配線は `main.py` の `build_handlers(settings)` から流す

## lifespan

- `@asynccontextmanager` の lifespan で startup / shutdown（`on_event` は非推奨）
- startup で `Settings()` を読み `app.state.settings` / `app.state.handlers` にセット
- settings をグローバル変数で持たない（モジュールロード時に env が読まれてテストしづらい）

## ルートからの参照

- `request.app.state.handlers` で直接、または `server/deps.py` に `get_handlers` を作り `Annotated[Handlers, Depends(get_handlers)]` でラップ
- `Annotated[T, Depends(...)]` パターンを基本にする

## CORS

- `allow_origins=["*"]` のハードコード禁止。Settings の `cors_origins: list[str]` + `cors_origin_regex: str` で管理
- .env で開発は regex（`http://localhost:3[0-9]{3}$`）、本番は origins にドメイン列挙
- pydantic-settings が JSON 配列を自動パースする

## カスタム middleware

`BaseHTTPMiddleware` 継承のクラスベースが標準（FastAPI 要求）。例: X-Request-Id の付与。

## その他

- ヘルスチェック `/healthz` は DB 等の外部依存を持たせない（`fastapi/ヘルスチェック.md`）
- OpenAPI メタデータは `FastAPI(title=, version=, openapi_tags=)`、ルーター側の `tags` でグループ化
- 例外ハンドラは `register_exception_handlers(app)` で一括登録（`fastapi/認証とエラー.md`）
