# 配布

- ビルドは `uv build`（`dist/` に sdist + wheel）、公開は `uv publish`（Test PyPI は `--publish-url`）
- バージョンは SemVer（PATCH=バグ修正 / MINOR=機能追加 / MAJOR=破壊的変更）。`0.x` の間は MINOR を破壊的変更扱いにできる
- `CHANGELOG.md` を Keep a Changelog 形式で維持（リリース時に `[Unreleased]` を `[x.y.z] - 日付` へ移す）

## CLI エントリポイント

- `[project.scripts]` に `mypkg = "mypkg.__main__:main"`
- `main() -> int` を返す関数、`__main__.py` で `sys.exit(main())`
- サブコマンドは argparse の `add_subparsers(dest="cmd", required=True)`

## 非 .py ファイルの同梱

プロンプト / YAML 等は `[tool.hatch.build]` の `include` で指定。

## GitHub Actions 自動公開

`on: push: tags: ["v*"]` で `uv build` → `pypa/gh-action-pypi-publish`（`id-token: write` で trusted publishing）。`git tag v0.2.0 && git push --tags` で発火。
