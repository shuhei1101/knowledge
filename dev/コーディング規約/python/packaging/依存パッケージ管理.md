# 依存管理 — uv 標準

`uv` を標準とする（pip / poetry は使わない）。高速・venv 管理込み・lockfile・Python バージョン管理を統合。

## コマンド早見表

<!-- table: data -->

| 操作                      | コマンド                                       |
| ------------------------- | ---------------------------------------------- |
| 初期化                    | `uv init mypkg --package`（src レイアウト）    |
| Python 固定               | `uv python pin {版}`（`.python-version` 生成） |
| 本番依存追加              | `uv add httpx "pydantic>=2.6"`                 |
| dev 依存追加              | `uv add --dev pytest mypy ruff`                |
| 削除                      | `uv remove httpx`                              |
| 同期                      | `uv sync`（`--all-extras` / `--no-dev`）       |
| 実行                      | `uv run pytest` / `uv run python -m mypkg`     |
| requirements.txt から移行 | `uv add -r requirements.txt`                   |

<!-- /table -->

venv の activate は不要（`uv run` が .venv を見る）。`pip install` で venv に直接入れない（uv の状態と乖離）。

## Git 管理

| ファイル | 管理 |
| --- | --- |
| `pyproject.toml` / `.python-version` | Git 管理 |
| `uv.lock` | Git 管理（再現性のため必須、手動編集禁止） |
| `.venv/` | gitignore |

CI では `uv sync --locked` でロックとの乖離を検証（`--frozen` は検証せずロックをそのまま使う）。

## 依存グループ

- `optional-dependencies`: 外部ユーザー向け追加機能（`pip install mypkg[redis]`）
- `[dependency-groups]`（PEP 735）: 開発者用作業グループ（dev / docs / benchmark）。`uv sync --group docs`
