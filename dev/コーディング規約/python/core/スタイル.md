# スタイル

## ツール構成

| ツール    | 役割                                                 |
| --------- | ---------------------------------------------------- |
| `ruff`    | フォーマッタ + リンタ（black + isort + flake8 相当） |
| `mypy`    | 型チェック（CI / 厳格）                              |
| `pyright` | エディタ統合の高速型チェック（任意）                 |
| `pytest`  | テストランナー                                       |

## ruff 設定

```toml
[tool.ruff]
line-length = 100
target-version = "py312"

[tool.ruff.lint]
select = [
    "E", "F", "I", "B", "UP", "SIM", "RUF",
    "PLR2004",  # マジックナンバー禁止（dev/コーディング全般）
    "BLE001",   # 広い except は最上位だけ（python/core/言語ルール）
    "TRY400",   # 例外は logger.exception で出す（python/shared/ロガー）
    "DTZ",      # 保存する日時はタイムゾーン付き（dev/コーディング全般）
    "ASYNC",    # async の中でブロックする処理を呼ばない（python/concurrency/非同期処理）
    "S101",     # assert を実行時の検査に使わない（python/core/言語ルール）
    "S602", "S604",  # 外部コマンドはシェルを通さない（dev/コーディング全般）
    "S301", "S506",  # 外部から来たデータを pickle / yaml.load で読まない（dev/コーディング全般）
    "PT011", "PT012",  # pytest.raises の型の絞り込みとブロックの 1 文（python/testing/pytest）
]
ignore = [
    "E501",     # 行長は formatter に任せる
    "RUF001", "RUF002", "RUF003",   # 日本語の文字列 / docstring / コメントの全角記号を紛らわしい Unicode として指すため外す
]

[tool.ruff.lint.per-file-ignores]
"tests/**" = ["S101", "PLR2004"]   # テストの assert と期待値の数値は許す

[tool.ruff.format]
quote-style = "double"
indent-style = "space"
```

## mypy 設定

```toml
[tool.mypy]
python_version = "3.12"
strict = true
pretty = true
plugins = ["pydantic.mypy"]   # Pydantic 使用時
```

pyright を使う場合は `typeCheckingMode = "strict"`。

## 書き方

- 長いモジュールはセクションマーカー（`# === DTO ===` 等）で区切ってよいが、セクションが必要なほど長くなったらまずファイル分割（`types.py` / `service.py`）
