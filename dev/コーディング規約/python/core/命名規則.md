# 命名規約

<!-- table: data -->

| 対象                        | 規則                                   | 例                               |
| --------------------------- | -------------------------------------- | -------------------------------- |
| モジュール / ファイル       | `snake_case`                           | `user_service.py`                |
| 関数                        | `snake_case`                           | `create_user`                    |
| 内部専用関数 / モジュール   | 先頭 `_`                               | `_validate_input`, `_helpers.py` |
| 型エイリアス                | `UpperCamel`                           | `UserId`, `CreateUserInput`      |
| dataclass / Pydantic クラス | `UpperCamel`                           | `User`                           |
| Protocol                    | `UpperCamel`（`I` プレフィックス禁止） | `UserFinder`                     |
| 定数                        | `UPPER_SNAKE_CASE`                     | `MAX_RETRY_COUNT`                |
| TypeVar                     | 1 文字大文字 or `UpperCamel + T`       | `T`, `UserT`                     |

<!-- /table -->

- 関数の型エイリアスは動詞ベース可（`AsyncChatFn`, `SaveUser`）
- 識別子型エイリアス（`UserId` 等）は名詞で揃える

## feature フォルダ内の標準ファイル名

`{pkg}/{feature}/` 内で使う名前と役割。小さい feature は `types.py` + `service.py` だけでも可。

<!-- table: data -->

| ファイル名    | 役割                                                     |
| ------------- | -------------------------------------------------------- |
| `__init__.py` | 公開シンボルの再エクスポート                             |
| `types.py`    | 型エイリアス + DTO + Protocol                            |
| `query.py`    | 読み取り系（`find_*` / `list_*` / `get_*`）              |
| `service.py`  | ビジネスロジック（`create_*` / `update_*` / `delete_*`） |
| `route.py`    | FastAPI ルーター（Web 公開する場合のみ）                 |
| `client.py`   | 外部 API 呼び出し（主に `integrations/`）                |
| `db.py`       | 永続化操作（DB を使う場合のみ）                          |
| `_helpers.py` | feature 内部専用ヘルパー                                 |

<!-- /table -->

## 関数名の動詞接頭辞

<!-- table: data -->

| プレフィックス | 用途                         | 戻り値                       |
| -------------- | ---------------------------- | ---------------------------- |
| `create_*`     | 新規作成                     | 作ったエンティティ           |
| `update_*`     | 更新                         | 更新後エンティティ or `None` |
| `delete_*`     | 削除                         | `None`                       |
| `find_*`       | 1 件検索                     | `Entity \| None`             |
| `get_*`        | 1 件取得（必ず存在する想定） | `Entity`（無ければ raise）   |
| `list_*`       | 複数取得                     | `list[Entity]`               |
| `search_*`     | 条件検索                     | `list[Entity]`               |

<!-- /table -->

## 公開 API

- 各 feature は `__init__.py` + `__all__` で公開シンボルを明示
- 外部から内部モジュールの `_` 付きシンボルを直接 import させない
