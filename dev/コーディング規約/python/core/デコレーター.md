## ハンドラーデコレータ（横断関心事）

例外キャッチ / リトライ / タイムアウト / メトリクスは関数デコレータで束ねる（クラスベース AOP は使わない）。`{pkg}/shared/decorators.py` に定義。

| デコレータ                              | 用途                                                            |
| --------------------------------------- | --------------------------------------------------------------- |
| `@catch_and_log(*exc_types, level=...)` | 指定例外をログに出して再送出する                                |
| `@catch_and_map(SrcError, to=DstError)` | 例外型を変換（vendor 例外 → ドメイン例外）。`raise from` で連鎖 |
| `@with_retry(retries=3, on=(...))`      | 指数バックオフでリトライ（引数は `llm/例外とリトライ.md`）      |
| `@with_timeout(seconds=60)`             | `asyncio.timeout` ラッパー。超過で `IntegrationTimeoutError`    |
| `@measure_time(metric="...")`           | 実行時間メトリクス                                              |

## 合成

外側から順に適用、読み方は下から上:

```python
@with_timeout(seconds=60)                                   # 3. 全体 60 秒で打ち切り
@with_retry(retries=3, on=(LlmRateLimitError, LlmServerError))  # 2. 3 回までリトライ
@catch_and_map(openai.APIStatusError, to=LlmServerError)        # 1. vendor 例外を変換
async def chat(req: ChatRequest) -> ChatResponse: ...
```

## 自作デコレータの注意

- 必ず `@functools.wraps(fn)` を付ける
- 型ヒントは PEP 695 の `[**P, R]` パラメータ仕様
- async / sync は別関数に分ける
- 1 デコレータ 1 責務（ログだけ・例外変換だけ）

## @overload

戻り値が引数型で分岐する関数のみ。ほとんどは型エイリアス + Callable / Protocol で済むので出番は少ない。
