# トップレベルレイアウト + feature 内構造

標準は機能フォルダ型レイアウト（純 DDD の domain / application / infrastructure / interface は廃止）。

## トップレベル構成

```
src/{pkg}/
├── __init__.py
├── __main__.py                   # 任意: python -m {pkg} で起動
├── main.py                       # composition root（必須）
├── shared/                       # 横断インフラ（必須）
├── features/                     # ビジネス機能（任意）
├── integrations/                 # 外部サービス連携（任意）
├── runtime/                      # 実行時インフラ（任意: queue / workflow / state）
└── server/                       # HTTP/WS サーバ（任意: FastAPI 使用時）
```

任意フォルダはプロジェクトで使う場合のみ作る。

## feature フォルダ

```
{pkg}/features/{feature}/
├── __init__.py             # 公開 API（必須。公開シンボルの再エクスポート）
├── types.py                # DTO + 型エイリアス + Protocol
├── query.py                # 読み取り関数（find_* / list_* / get_*）
├── service.py              # ビジネスロジック関数（create_* / update_* / delete_*）
├── route.py                # HTTP ハンドラ（Web 公開する場合のみ）
├── client.py               # 外部 API 呼び出し（主に integrations/）
├── db.py                   # 永続化（DB 使う場合のみ）
└── _helpers.py             # 内部専用ヘルパー
```

- 小さい feature は `__init__.py` + `types.py` + `service.py` だけで可
- 機能が大きくなったら同じ構造でサブフィーチャのサブフォルダを切る

## shared/

```
{pkg}/shared/
├── logger.py               # JSONL logger
├── settings.py             # Pydantic Settings
├── errors.py               # 例外階層
├── types.py                # 共通型エイリアス
├── constants.py            # 計算済みパス（PROJECT_ROOT, LOG_DIR）
└── utils.py                # 業務横断ヘルパー
```

`core/` フォルダは作らない（shared/ に統合）。

## integrations/

```
{pkg}/integrations/
└── llm/                    # サービス種別ごとにサブフォルダ
    ├── types.py            # 関数の型エイリアス（AsyncChatFn 等）と DTO
    ├── openai_client.py    # ベンダー実装（ファイル単位）
    ├── claude_client.py
    └── mock_client.py      # テスト用 Mock も同じフォルダ
```

プロンプトファイルは `content/prompts/` に置く（`integrations/llm/` にはローダーと provider 実装のみ）。
置き場所は [コンテンツの置き場所](../../dev/コンテンツの置き場所.md) に従う。

## server/（FastAPI 使用時）

```
{pkg}/server/
├── app.py                  # build_fastapi() -> FastAPI
├── lifespan.py             # startup / shutdown
├── middleware.py           # CORS / 認証 / ログ
├── routes/
└── ws/
```

route の置き場所は `features/{feature}/route.py` を基本にする（feature 内で完結）。`server/app.py` から `include_router` で集約。

## tests/

`tests/` の構成は `testing/テスト戦略.md` のファイル配置。

## 単一ファイルスクリプト

pyproject.toml を作らない簡易スクリプトは `script.py` + `log/` + `run.bat` の 3 点構成（`scripts/Pythonスクリプト.md`）。
