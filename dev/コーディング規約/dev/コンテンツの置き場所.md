# コンテンツの置き場所

リポジトリ直下の `content/` に、Git で差分を見たい、コードではない正本を置く。

`content/` に置くのは、アプリが素材・定義として読む本体で、設定の 3 段（既定値・環境の値・checkout の上書き）で上書きしないもの。

## 置くもの

- プロンプト（`content/prompts/`）
- キャラクターなどの定義
- 素材の一覧と説明文
- 評価のケース
- 禁止語などのカタログ
- モデルと単価の一覧

## 置かないもの

次の値は `content/` に置かず、[設定値の置き場所](../../判定フローチャート/設定値の置き場所.md) が決めた場所に置く。

| 値 | 置き場所 |
| --- | --- |
| 設定の既定値 | `config/defaults.yaml` |
| 定数の YAML | `config/constants.yaml` |
| ランタイムの状態 | `data/` |
