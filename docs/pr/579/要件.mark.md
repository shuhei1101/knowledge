# 要件

## 要望

`schemas/design/agent_flow.schema.yaml` の `$defs/step/properties` の次の `description` を、それぞれ `。` が 2 つ以下（2 文以内）にする。
外した決まりは、同じキーの `x-rules` へ移して内容を残す。

- `id`: `工程の識別子。エージェントフローの中で重ねない。`gates`・`proposals`・`unit` を記載する工程は必須。`
- `unit`: `工程の成果の単位。`single`（1 件）か `per_script`（台本 1 本に 1 件）。記載しなければ `single`。`gates` を持つ工程にだけ記載する。`

スキーマから生成する `docs/template/template-agent-flow.yaml` と `docs/template/markdown/agent-flow.md`・`agent-flow.example.md` を、`scripts/build_templates.py`・`scripts/build_markdown_templates.py` で再生成する。

終了の条件:

- `tests/integration/scripts/test_check_all.py::test_normal_when_repository_schemas` が pass する
- `schemas/design/` の全てのスキーマで、`。` が 3 つ以上の `description` が 0 件になる
- `id`・`unit` の検査の結果（必須・`enum`・`dependentRequired`）は変えない

同じ型の箇所は、`schemas/design/` の全てのスキーマをテストと同じ条件で調べ、この 2 件だけが該当した。
