# フォルダ構成の設計書のテンプレート（layout）を追加する

## 概要

設計書を記載するエージェントとレビュアーが、リポジトリのフォルダ構成を 1 枚の設計書（入れ子の `entries[]`）で設計し、切る観点とレビューの観点で穴を洗い出せるようにする。

## 背景

[#219](https://github.com/shuhei1101/knowledge/issues/219) の要望。
フォルダ構成を設計する設計書が無く、共通で参照するものが深いフォルダに配置される・平らに並ぶ・生成物が Git に入る、といった問題が実装の後に見つかる（mdmark・mindstella・AI Monitor での試用 A-78）。
今のスキーマでは、ディレクトリ構成はアーキテクチャ図の `repository.layout` とモジュール構成の分類ごとの `directory` に分かれ、共通のフォルダを決める場所が無い。
