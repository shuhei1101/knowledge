## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 対応表 | `TEMPLATE_IDS` に `"layout": "template-layout"` を追加する | - |
| シナリオ | SC-201-1 の前提と結果のテンプレートの件数を、件数を書かない「設計書の種類の全ての／他の／残りのテンプレート」に書き換える | - |
| E2E テスト | `_TEMPLATES` に `template-layout` を追加する | - |
| 再帰する `$ref` | `layout.schema.yaml` の `children[]` は同じエントリの定義（`#/$defs/entry`）を `$ref` で指すので、キーの表の行を辿ると止まらない（`RecursionError`）。辿っている途中の `$ref` を再び指すキーは、行を出して子を辿らない | IF-201-1 の「キーの表」と MOD-201-1 の `_iter_keys` で確定した |
| 入れ子からパスを生成する変換・リポジトリとの突き合わせの検査 | この PR では作らない（`要件.yaml` のスコープ外） | AI Monitor へ起票する |
