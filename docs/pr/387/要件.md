# 要件

## 要望

`schemas/design/common.schema.yaml` の ER 図の関連（`relations.items.properties`）の `x-used-by` の「実装で、…」を、次の向きにする。

| キー | 変更後の `x-used-by` |
| --- | --- |
| `from_column` | 実装で、外部キーが参照する列にする。 |
| `to_column` | 実装で、外部キーの列にする。 |

`生成で、線の元の列にする。`・`生成で、線の先の列にする。` は変えない。
生成物の `docs/template/template-er.yaml` は `scripts/build_templates.py` で生成し直して揃える。

同じ型の箇所（外部キーの向きを記載する `x-used-by`）をリポジトリ全体から探し、`from_column`・`to_column` のほかに無いことを確かめた（`tables[].columns[].foreign_key` は参照先を持つ側の列に置くキーで、向きは例と一致する）。
