# エイリアスの判定フローチャートと description のチェックシートを追加する

## 概要

エイリアスを登録するかを決める判定フローチャートと、description を点検するチェックシートを knowledge に追加し、文書を作成するエージェントが knowledge だけを参照してエイリアスと description を決められるようにする。

## 背景

[Issue #144](https://github.com/shuhei1101/knowledge/issues/144) の要望（検討事項 A-6・A-7・A-8）。
規約『タグと用語の登録』（`dev-tag-term-registration`）のうち、タグと用語には判定フローチャート（`flowchart-tag-attach`・`flowchart-term-registration`）があるが、エイリアスと description には無い。
エイリアスの判定フローチャートは alias-inject の使い方にだけあり、規約は GitHub の URL で参照しているため、dev-docs で knowledge だけを参照するプロジェクトから届かない。
description は検索結果とフックの注入で AI のコンテキストにそのまま入るが、点検の項目も文字数の上限も無い。
判定フローチャートは [#132](https://github.com/shuhei1101/knowledge/issues/132)（[PR #134](https://github.com/shuhei1101/knowledge/pull/134)）で改訂した mdmark の部品の書き方で描く。
