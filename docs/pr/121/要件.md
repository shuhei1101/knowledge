# 要件

## 要望

knowledge の `docs/` 配下の YAML の文書のメタデータ `description` を、規約『タグと用語の登録』の `description-01`・`description-02` の書き方へ書き換える。

対象は origin/develop（5139c59）の `docs/` 配下の YAML の文書の全件（規約 198・テンプレート 42・判定フローチャート 7・手順 3・スキル 1・変更履歴 1）。

終わりの条件:

- 全件の `description` が、「何を受け持つか／何について書いてあるか」と「どんなときに読むか」を持つ 1 文になっている
  - 例: `タスクの保存と取得を受け持ち、保存先や検索の条件を変えるときに読む。`
- `description` に関数の一覧・実装の手順を含まない
- 「どんなときに読むか」は、文書の本文（`overview` と各項目）から読み取った、その文書を読むべき作業の場面で書く
- 文末は句点（`。`）で終える。
  今の 252 件のうち 245 件が句点で終わっているのに合わせ、句点の無い判定フローチャート 7 件にも付ける
- 書き換えた文書は `rev` を 1 増やし、`last_reviewed` は変えない（#112・#116 の一括の書き換えと同じ扱い）
- `description` と `rev` 以外のキー・本文は一字一句変えない（規約『既存文章の維持』）

## 影響するユースケース

なし（knowledge はシナリオを持たない。変わるのは文書のメタデータの `description` の文言だけ）。
