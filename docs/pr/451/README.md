# 種類「ノウハウ」（docs/knowhow）を配信できるようにし、規約のうち知見に該当するものを移す

## 概要

利用者とエージェントが、台本・演出・ゲーム作りなどの規約ではない知見を、knowledge の種類「ノウハウ」（`docs/knowhow/`）に配置して参照できるようになる。
今の規約のうち、決まりではなく知見に該当するものをノウハウに移す。

## 背景

[Issue #418](https://github.com/shuhei1101/knowledge/issues/418) の要望。
knowledge の文書の種類は規約・テンプレート・判定フローチャートなどで、決まりでない知見を配置する種類と基準が無く、aituber の話し合いで得たノウハウの移す先が無い。
種類「ノウハウ」のスキーマは [#419](https://github.com/shuhei1101/knowledge/issues/419)（作業 PR [#438](https://github.com/shuhei1101/knowledge/pull/438)）で develop に入っており、配信の設定の行・目次・テンプレート・設計書・規約『ドキュメント管理』の修正がこの作業 PR の範囲として残っている。
