# 検査と変換のスクリプト

## 現状

| 分類 | ページ / ファイル | 概要 | 補足 |
| --- | --- | --- | --- |
| 実装 | [scripts/knowledge_markdown.py](https://github.com/shuhei1101/knowledge/blob/5d4f69b/scripts/knowledge_markdown.py) | 文書の Markdown への変換。種類に固有のキーは `schemas/{kind}.schema.yaml` の `title` を見出しにして変換する | 変更しない |
| 実装 | [scripts/knowledge_checks.py](https://github.com/shuhei1101/knowledge/blob/5d4f69b/scripts/knowledge_checks.py) | 文書の違反の検査。種類によらない検査（`word-list` だけ固有の検査を持つ） | 変更しない |
| 実装 | [scripts/check_all.py](https://github.com/shuhei1101/knowledge/blob/5d4f69b/scripts/check_all.py) | 全ての文書の検査。`project-index.yaml` の `documents[]` の行を全て検査する | 変更しない |
| テスト | [tests/integration/scripts/](https://github.com/shuhei1101/knowledge/tree/5d4f69b/tests/integration/scripts) | 検査・変換・全ての文書の検査の結合テスト | ノウハウの文書のケースを追加 |

## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 既存機能への影響 | スクリプトのコードは変えない。`knowhow` の行は `project-index.yaml` の追加だけで、変換・検査・全ての文書の検査の対象になる | ノウハウに固有のキー（`necessity`・`scenes`・`cases`・`evidence`・`confidence`）が見出しと表で変換されることを結合テストで確認する |
| 結合テスト | ノウハウの文書 1 件が、スキーマの検査・文書の違反の検査・Markdown への変換を通るケースを追加する | 実行範囲は判定フローチャート『結合テストの実行範囲』で決め、実行前に reviewer の確認を受ける |
