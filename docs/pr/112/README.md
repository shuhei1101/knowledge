# related から本文のリンクと重なる要素を削除する（規約『ドキュメント管理』以外の文書）

## 概要

規約『ドキュメント管理』以外の 38 文書の `related` から、本文でリンクしている相手と重なる要素を削除し、規約『ドキュメント管理』の `related-04` に合わせる。

## 背景

[Issue #108](https://github.com/shuhei1101/knowledge/issues/108) の要望。
規約『ドキュメント管理』の `related-04` は「本文でリンクしている相手は重ねない」と定めているが、develop の `docs/` には `related` の要素が本文のリンクと重なっている文書が残っている。
作業 PR [#107](https://github.com/shuhei1101/knowledge/pull/107)（[Issue #96](https://github.com/shuhei1101/knowledge/issues/96)）の受付で、同じ型の逸脱をリポジトリ全体から探して見つけ、規約『ドキュメント管理』以外の文書をこの Issue へ切り出した。
