# UI の規約に、書き込みをするボタンの、応答を待つ間の状態（二重の実行の防止）を追加する

## 概要

画面を設計・実装・レビューする人が、書き込み（送信・保存・更新・削除）をするボタンの応答を待つ間の状態（もう一度押せない・待っていることが分かる）を、knowledge の規約・画面設計のテンプレート・レビューのチェックシートで参照できるようになる。

## 背景

[Issue #557](https://github.com/shuhei1101/knowledge/issues/557) の要望。
MindStella のプレビューで、送信・更新のボタンを応答を待つ間に何度も押せて、押した回数だけ反映される不具合が出た（[shuhei1101/mindstella#677](https://github.com/shuhei1101/mindstella/issues/677)）。
規約『入力と文言』には送信の二重送信を防ぐ 1 行だけがあり、更新・削除のボタンの決まりと、画面設計のテンプレートの項目と、実装した画面のレビューの観点が無いため、実装とレビューで見落とされた。
画面設計のテンプレートはスキーマ（`schemas/design/screen.schema.yaml`）から生成し、各プロジェクトは `design-schemas/v*` のタグで指すため、キーを追加した後にタグを上げる。
