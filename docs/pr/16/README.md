# 規約を分野ごとにベストプラクティスと突き合わせて直す

## 概要

移した規約を、分野ごとに世の中のベストプラクティスと突き合わせて直す。

## 背景

[Issue #4](https://github.com/shuhei1101/knowledge/issues/4) の要望。
規約は [#3](https://github.com/shuhei1101/knowledge/issues/3)（[#10](https://github.com/shuhei1101/knowledge/pull/10)）で ai-monitor から写したもので、ai-monitor 固有の記述を直しただけで、中身をベストプラクティスと突き合わせていない。
各言語の環境変数の規約と判定フローチャート『設定値の置き場所』のように、分野をまたいで同じことを書いている箇所がある。
YAML の決まりを 1 つの規約へ集めるのは [#15](https://github.com/shuhei1101/knowledge/issues/15)。
