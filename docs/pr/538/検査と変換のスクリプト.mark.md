## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 生成としての呼び出し | 書き込んだ文書のパスを引数に受けても失敗しない。引数に対応表の原本が無い書き込みでは、コピーを書き換えずに終了コード 0 で終わる | ノウハウ・用語集・規約の書き込みでもコピーの差分を出さない |
| コピーの書式 | 変えない（全ての文書の検査が同じ書式で再作成して比べる） | - |
