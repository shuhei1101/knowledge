# 要件

## 要望

規約『コンテンツの置き場所』に、`data/` に配置する大きいファイル（音声・画像・動画）を、端末を移したとき・失ったときに復元する方法を記載する。
記載を読めば、新しい端末で `data/` の大きいファイルを元の状態に戻す手段が 1 つに決まる。

復元の方法は、メタデータの YAML にファイルの取得元を記載し、取得元から取得し直して復元する（[確認事項](https://github.com/shuhei1101/knowledge/pull/562#discussion_r4658350102) の案 D）。
取得し直せないファイルと取得元を記載していないファイルは、そのファイルを配置する `data/` のサブフォルダだけを外部の保管先へ同期して残す。

この作業では、取得元を記載するキーの構成を規約に定める。既存のファイルの取得元は、ユーザーが後から記入する。
