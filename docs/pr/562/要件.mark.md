# 要件

## 要望

規約『コンテンツの置き場所』に、`data/` に配置する大きいファイル（音声・画像・動画）を、端末を移したとき・失ったときに復元する方法を記載する。
記載を読めば、新しい端末で `data/` の大きいファイルを元の状態に戻す手段が 1 つに決まる。

`未確定`: 復元の方法（決める段: ドキュメント修正の前にユーザーへ確認する。費用・外部サービスの利用に関わるため）

| 案 | 内容 |
| --- | --- |
| A | 大きいファイルだけを持つ別のリポジトリ（Git）に配置し、clone で復元する |
| B | Git LFS で同じリポジトリに配置し、`git lfs pull` で復元する |
| C | `data/` をクラウドストレージのバックアップ先へ同期し、同期し直して復元する |
| D | メタデータの YAML にファイルの取得元（URL・生成の条件）を記載し、取得し直して復元する。取得し直せないファイルは C で残す |

推奨: C

音声・画像・動画は差分を確認しないため、Git の履歴に残す利点が無く、A・B はリポジトリの容量と LFS の容量の上限に当たる。C は同期し直すだけで元の状態に戻る。
