# 規約『コンテンツの置き場所』に、data/ に配置した大きいファイル（音声・画像・動画）の復元の方法を記載する

## 概要

`data/` に配置した大きいファイル（音声・画像・動画）を、端末を移したとき・失ったときに復元する方法を、規約『コンテンツの置き場所』で決められるようにする。

## 背景

[Issue #561](https://github.com/shuhei1101/knowledge/issues/561) の要望。
[#560](https://github.com/shuhei1101/knowledge/pull/560)（起点 Issue [#559](https://github.com/shuhei1101/knowledge/issues/559)）で、アセットのメタデータの YAML だけを `content/` に配置し、画像・音声のファイルは `data/`（Git の管理外）に配置すると記載した。
`data/` のファイルは Git に残らないため、端末を移したとき・失ったときに復元する方法が決まっていない。#560 ではスコープ外にした。
