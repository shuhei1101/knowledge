# 判定フローチャート『結合テストの並列数』のスワップの条件を、メモリが空けば満たせる条件へ修正する

## 概要

結合テストを実行する人が、メモリが空いたときに判定フローチャート『結合テストの並列数』の Q1 を満たして、結合テストを実行できるようにする。

## 背景

[Issue #425](https://github.com/shuhei1101/knowledge/issues/425) の要望。
Q1 の「スワップの空きが半分以上か」は、Linux のスワップの使用量が一度使われるとメモリが空いても減らないため、メモリが空いても満たされない。
[shuhei1101/ai-monitor#3483](https://github.com/shuhei1101/ai-monitor/pull/3483) の結合テスト作成の工程で、available が 11773MB まで空いてもスワップの空きが 1300MB（合計 8192MB）のままで、合計 1 時間 30 分待った。
