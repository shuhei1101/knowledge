# 要件

## 要望

判定フローチャート『結合テストの並列数』（`docs/flowchart/flowchart-integration-test-parallelism.yaml`）の Q1 を、スワップの使用量が残っていても、メモリの available が空けば YES になる条件へ修正する。
Q1 の質問と ※2 の補足を、選んだ案のとおりに修正する。

`未確定`: スワップの条件の扱い（決める段: ドキュメント修正）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | スワップの条件を、待っている間にスワップの入出力が続いているか（`vmstat` の `si`・`so`）で見る | 他のプロセスがスワップを入出力している最中に実行しない | 判定に計測の時間と、続いているとみなす閾値が要る |
| B | スワップの条件を外し、メモリの available と残しておくメモリだけで判定する | 判定が `free -m` の 1 回で済む | スワップの入出力が続いているときも、available が足りれば実行する |

推奨: B

※2 は available から残しておくメモリと固定のメモリを引いた分だけで並列数を求めるため、テストのプロセスはスワップに入らない。
他のプロセスがスワップを入出力しているときは available が減り、Q1 が NO になる。
