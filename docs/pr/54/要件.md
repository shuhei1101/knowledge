### トランスポート（`## SDK とトランスポート`）

- MCP サーバーは HTTP（Streamable HTTP）の常駐サーバーにし、stdio を禁止する
- 禁止の理由として、stdio はセッションごとに同じサーバーのプロセスが立ち依存解決も毎回走るため、並行で起動するセッションの数だけプロセスが増えることを書く
- stdio と HTTP の選び方の表と、選び方の前置き（「トランスポートは、同時に走るセッション数で選ぶ」）を消す
- `alwaysLoad` の行から「上限に収まらないなら HTTP へ移す」を消す
- 「HTTP を選ぶときは常駐サーバをどう起動するかもセットで決める」を、選ぶ前提の無い書き方（常駐サーバーの起動の仕方を決める）に直す

### 構成（`## 構成`）

- stdio のサーバープロセスに渡る環境変数（`CLAUDE_PROJECT_DIR`・`CLAUDE_CODE_SESSION_ID`）の記述を消し、HTTP の常駐サーバーでのパスの解決の仕方に置き換える

### 登録（`## 登録`）

- stdio の起動コマンドの例を消し、HTTP の接続先の例だけにする
- `.mcp.json` の `url` は `http://127.0.0.1:${{リポジトリ}_PORT:-{既定のポート}}/mcp` の形で書く
- 利用者はポートがぶつかるときだけ `~/.claude/settings.json` の `env` に `{リポジトリ}_PORT` を書いて上書きする
- リポジトリごとの既定のポートの台帳を載せる

| リポジトリ | 環境変数 | 既定のポート |
| --- | --- | --- |
| observability | `OBSERVABILITY_PORT` | 8766 |
| ai-monitor | `AI_MONITOR_PORT` | 8767 |
| claude-balancer | `CLAUDE_BALANCER_PORT` | 8770 |
| knowledge | `KNOWLEDGE_PORT` | 8781 |
| mdmark | `MDMARK_PORT` | 8782 |
| rule-inject | `RULE_INJECT_PORT` | 8783 |
| MindStella | `MINDSTELLA_PORT` | 8784 |

台帳は `mcp.md` の中に置く。
`.mcp.json` を書くときに当たるのが `mcp.md`（`rules.yaml` の `**/.mcp.json`）で、別ページにすると書く場面で読まれない。
