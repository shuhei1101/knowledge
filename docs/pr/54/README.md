# MCP サーバーを HTTP の常駐サーバーに統一して stdio を禁止し、既定のポートの台帳と環境変数での上書きを規約に書く

## 概要

MCP サーバー作成ルールを、HTTP（Streamable HTTP）の常駐サーバーだけを作る書き方に直し、stdio を禁止する。
リポジトリごとの既定のポートの台帳と、環境変数でのポートの上書きの仕方を載せる。

## 背景

[Issue #50](https://github.com/shuhei1101/knowledge/issues/50) の要望（knowledge のワークスペース `tmp/mcpベストプラクティス検討` の決定 D-60・D-61・D-59）。
[dev/コーディング規約/claude/mcp.md](https://github.com/shuhei1101/knowledge/blob/develop/dev/%E3%82%B3%E3%83%BC%E3%83%87%E3%82%A3%E3%83%B3%E3%82%B0%E8%A6%8F%E7%B4%84/claude/mcp.md) は、同時に走るセッション数で stdio と HTTP を選ぶ書き方になっている。
セッションを並行で起動することが多く、stdio の MCP（rule-inject・MindStella・mdmark）はセッションの数だけプロセスが立っている。
HTTP の MCP の待ち受けのポートは各リポジトリが個別に決めていて、一覧も上書きの決まりも無い。
後続の [#51](https://github.com/shuhei1101/knowledge/issues/51)・shuhei1101/rule-inject#36・shuhei1101/mindstella#338・shuhei1101/mdmark#111 がこの規約を前提にする。
