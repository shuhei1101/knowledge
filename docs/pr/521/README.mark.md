# 規約『表し方の優先順位』のはみ出す表のピン止めを mdmark の既定（列を留めない）に合わせる

## 概要

規約『表し方の優先順位』の「はみ出す表」の決まりを、mdmark の既定（はみ出す表のどの列も留めない）に合わせて書き換える。

## 背景

[Issue #519](https://github.com/shuhei1101/knowledge/issues/519) の要望。
規約『表し方の優先順位』の項目 `table-04` は「はみ出す表は先頭の列をピン止めし」と定めている。
[mdmark#735](https://github.com/shuhei1101/mdmark/pull/735) で、mdmark のはみ出す表は既定でどの列も留めなくなり、列を留めるには表のマーカーの `columns.{列名}.pinned` か設定 `table.pin_default: true` の指定が要るようになった。
規約のとおりに書いた文書の表が、描くと先頭の列が留まらず、規約と描画が食い違う。
