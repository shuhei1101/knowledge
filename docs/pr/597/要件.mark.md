# 要件

## 要望

- 規約『Claude 成果物の共通ルール』（`claude-common`）に、次の項目を追加する
  - 認証領域（`~/.claude*`）の `.credentials.json` を別の場所へコピーして `claude` を起動しない（コピーした先で token が取り直されると元の認証領域がログアウトする）
  - 認証が要る確認は claude-balancer から借りて起動する（`claude-balancer exec --client {名前} -- claude ...`）
  - 認証の要らない確認（プラグイン・スキル・フックの読み込み等）は、認証情報を配置しない一時の認証領域で起動し、`--debug-file` で確認する
- 追加した項目に合わせて、`claude-common` の `description`・`tags` を修正する
- develop へマージした後に、release の手順でバージョンのタグを打つ
