# 規約『コンテンツの置き場所』に、アプリが実行中に書き換える定義・メタデータ・一覧を content/ に配置して直コミットで残す判定を追加する

## 概要

アプリが実行中に書き換えるデータを、リポジトリの `content/` に配置するか Git の管理外に配置するかを、規約『コンテンツの置き場所』と判定フローチャート『設定値の置き場所』で判定できるようにする。

## 背景

[Issue #559](https://github.com/shuhei1101/knowledge/issues/559) の要望。
規約『コンテンツの置き場所』は定義・一覧を `content/`、ランタイムの状態を `data/` に配置すると定めているが、アプリが実行中に書き換える定義・メタデータ・一覧（aituber のアセットのメタデータ・キャラクター・ゲームインフォ・プリセットの YAML）がどちらに当たるかの記載が無い。
aituber では初めに Git の管理外へ配置すると設計し、後から `content/sources/` に配置して直コミットする実装になり、資料と実装が食い違った。
直コミット方式（[shuhei1101/project-index#209](https://github.com/shuhei1101/project-index/pull/209)）で、実行中の書き込みも Git に残せるようになっている。
