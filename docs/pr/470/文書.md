## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 記録の参照 | 記録 R-3 の技法の行ごとに中身を確かめ、技法を 1 文書の単位に切り分ける | 似た技法は 1 文書にまとめる |
| 配置先の判定 | 技法ごとに、ノウハウ・規約・knowledge に配置しないもののどれかを `knowhow-01`・`knowhow-02` で判定し、判定の一覧をこの計画書に記載してレビューで確定する | 既存の規約・ノウハウと同じ内容なら登録しない |
| ノウハウの文書 | `write_docs` で `kind: knowhow` の文書を作る。ID は `knowhow-script-{topic}`、`visibility` は `internal`、`last_reviewed` は登録した日 | `necessity`・`scenes`・`cases`・`evidence`・`confidence` はスキーマの `x-rules` で決める。記録の確度（高・中・低）を `confidence` に写す |
| タグ | 付ける前に `search_docs` の `group_by: tags` で使用中のタグを確認し、同じ意味のタグを再利用する | `topic:ノウハウ` は全ての文書に付ける |
| 出典 | 記録の出典名から URL を引き直して `sources` に記載する | URL を引けなかった出典は、引けなかった旨をこの計画書に記載し、レビューで扱いを確定する |
