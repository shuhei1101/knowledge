# 要件

## 要望

- aituber の話し合いの記録 R-3（台本の技法）の技法ごとに中身を確かめ、テンプレート『ノウハウ』のとおり 1 技法 1 文書で `docs/knowhow/knowhow-script-{topic}.yaml` に登録する。似た技法は 1 文書にまとめる
- 技法ごとに、規約『ドキュメント管理』の規約とノウハウの分け方（`knowhow-01`）と知見の配置先（`knowhow-02`）で、ノウハウ・規約・knowledge に配置しないもののどれにするかを判定する
- 既に knowledge にある規約・ノウハウ（`knowhow-script-axis-only` など）と同じ内容の技法は、新しく登録せず既存の文書を指す
- 記録は出典名だけで URL を持たないため、出典の URL を引き直してから `sources` に記載する。公開リポジトリに手元のパスを記載しない（#460 の[確認事項](https://github.com/shuhei1101/knowledge/pull/460#discussion_r4597420523)の決定）
- ノウハウの `visibility` は `internal` にする
- 登録した文書は、書き込みの検査と全ての文書の検査に通る
- 着手後に 8pt を超えると分かったら、記録の筋の分類（A〜E）で分け直す

記録 R-33・A-71（No 11〜12）は [#469](https://github.com/shuhei1101/knowledge/issues/469) が受け持つ。
