# 台本の技法（ノウハウの一覧 A-157 の No 10、記録 R-3）を、種類「ノウハウ」の文書として登録する

## 概要

利用者とエージェントが、aituber の話し合いで調べた台本の技法（飽きさせない持っていき方・笑いの技法・体験談のまとめ方・演者に合わせる方法・レビューの観点）を、knowledge の種類「ノウハウ」（`docs/knowhow/`）から参照できるようになる。

## 背景

[Issue #464](https://github.com/shuhei1101/knowledge/issues/464) の要望。
[#453](https://github.com/shuhei1101/knowledge/issues/453)（作業 PR [#460](https://github.com/shuhei1101/knowledge/pull/460)）で、ノウハウの一覧 A-157 の No 10〜20 は分野ごとの後続の Issue に分けると決まり（[確認事項](https://github.com/shuhei1101/knowledge/pull/460#discussion_r4597421534)）、この Issue は台本の技法（記録 R-3）を受け持つ。
