## 概要

利用者とエージェントが、aituber の話し合いで調べた台本の技法（元ネタから台本を作る工程・演出メモの原則の元の技法・笑いの技法・体験談のまとめ方と、#470 で出典の URL を引けなかった持っていき方）を、knowledge の種類「ノウハウ」（`docs/knowhow/`）から参照できるようになる。
