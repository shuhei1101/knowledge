# 要件

## 要望

記録 R-3・R-33・A-71 の技法を、テンプレート『ノウハウ』のとおり 1 技法 1 文書で `docs/knowhow/knowhow-script-{topic}.yaml` に登録する。
似た技法は 1 文書にまとめ、既に knowledge にある規約・ノウハウ（`knowhow-script-*` など）と同じ内容の技法は新規登録せず既存の文書を指す。
技法ごとに、規約『ドキュメント管理』の `knowhow-01`・`knowhow-02` で、ノウハウ・規約・knowledge に配置しないもののどれにするかを判定する。
記録は出典名だけで URL を持たないため、出典の URL を引き直してから `sources` に記載する。公開リポジトリに手元のパスを記載しない（#460 の[確認事項](https://github.com/shuhei1101/knowledge/pull/460#discussion_r4597420523)の決定）。
判定と書き方は #470 の `docs/pr/470/文書.md` の `## 変更方針` に合わせる。
登録した文書は、書き込みの検査と全ての文書の検査に通る。
