# 要件

## 要望

規約『見積もりポイント』（`docs/rule/dev-estimate-points.yaml`）を、AI が作業する前提に作成し直す。

- 13 pt の行の「分割必須（スプリントに含めない）」を削除し、分割を求める記載を規約から無くす
- 1 件の Issue の最大を 20 pt とし、最大に届くまでほかの未着手の行をまとめてから 1 件の Issue にする（最小の線は引かない）
- 1 Sprint の容量を 50 pt とする
- 分割しない・まとめる・コンテキスト（設計書・規約・コード）の読み直しがコストになる、という考え方を規約に記載する
- 値の刻み（1・2・3・5・8・13）と「変更の広がりと pt」の表は、1 件の変更の規模の目安として残す
- 完了したら、後続の [shuhei1101/ai-monitor#3405](https://github.com/shuhei1101/ai-monitor/issues/3405) に着手できる旨をコメントし、`確認:task-planner` を付ける。コメントには、ai-monitor の `docs/rule/見積もりポイント.md`（13 pt が「分割必須（スプリントに載せない）」のまま）を knowledge の規約への参照に切り替えるか削除する旨を含める
