# 要件

## 要望

全ての文書の検査（`scripts/check_all.py`）と Pages の成果物の作成（`scripts/build_pages.py`）が呼ぶ mdmark を、既定で mdmark の develop の最新（`npx -y github:shuhei1101/mdmark#develop`）にする。
設定でタグ（`v{MAJOR}.{MINOR}.{PATCH}`）か commit の SHA を指定すると、その参照に固定して呼ぶ。

- 設定が無いときに呼ぶ参照が `develop` になる
- 設定でタグか commit の SHA を指定したときに、その参照で呼ぶ
- 外部ライブラリ『mdmark』・インターフェース定義『Pages の成果物の作成』『全ての文書の検査』・モジュール構成（`MOD-72-2`・`MOD-137-1`・`MOD-176-1`）・開発コマンド（`CMD-72-1`）の、タグに固定する記載を合わせる
- 単体・結合テストを、既定と固定の参照に合わせる
- [#173](https://github.com/shuhei1101/knowledge/issues/173) の「`MDMARK_TAG` を mdmark#562 を含むタグへ上げる」範囲を引き取る（develop の最新には [mdmark#562](https://github.com/shuhei1101/mdmark/issues/562) が入っている）

固定の設定は `scripts/_common.py` の定数に配置し、既定値を `develop` にする（判定フローチャート『設定値の置き場所』で、秘匿値でも環境の値でもなく、同じ言語の複数のファイルで使用する定数のため、定数モジュール）。

同じ所有者が作るライブラリは既定で develop の最新を参照し、固定するときはタグか、develop の配布物を作り直した commit の SHA で行う決まりを、テンプレート『外部ライブラリ』の `version.pinning` の説明（生成元は `schemas/design/library.schema.yaml`）に追加する（確認ログの 1 行目）。
