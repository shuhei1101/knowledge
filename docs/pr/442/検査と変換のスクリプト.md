## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| mdmark の参照 | 既定を `develop` にし、タグか commit の SHA を指定すると固定する。commit の SHA は develop の配布物を再作成した commit に限る | 配置先は `scripts/_common.py` の定数。測った記録は `### mdmark の参照ごとの CLI のバージョン` |
| mdmark の設定の `version` | Pages の成果物の作成が一時フォルダに記載する `mdmark.config.yaml` に `version` を記載しない | `version` は mdmark の `upgrade` だけが読み込む |
| 既存機能への影響 | 呼ぶ参照の値だけを変え、検査と成果物の作成の流れ・出力は変えない | - |
| 外部ライブラリ | develop の最新は mdmark の develop へ入った変更がすぐ有効になるため、mdmark の develop が壊れたときは固定の設定でタグか commit の SHA に戻す | - |

配布物を再作成した commit の SHA は、その元の commit の配布物を呼ぶ。
