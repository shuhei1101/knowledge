# 要件

## 要望

- 規約『共通コンポーネント規約』（`convention-common-components`）に、次の項目を追加する
  - アプリの画面で表・ボード・グラフ・図・本文へのコメントを出すときは、mdmark の部品のカスタム要素を使用する（表は `<mdmark-table>`、ボードと表形式の切り替えは `<mdmark-view>`、グラフは `<mdmark-graph>`、スライダーとグラフは `<mdmark-param-graph>`、図は `<mdmark-map>`、本文へのコメントは `<mdmark-comments>`）
  - mdmark の部品で足りない機能があるときは、自前で組む前に、mdmark 側へ機能を追加することを利用者に相談する
- 同じ規約の shadcn/ui の部品名との対応表の、テーブル・チャートの行を mdmark の部品のカスタム要素に修正し、ボード・図・本文へのコメントの行を追加する（マップは地図なので `自前` のまま）。対応表の列名・group・項目名は「採用する部品」に修正する
- 表を TanStack Table で組むと定めた React の規約を、同じ決まりに合わせて修正する
  - 規約『採用するライブラリ』（`react-core-libraries`）の用途別の表の `表` の行
  - 規約『コンポーネントカタログ』（`react-component-catalog`）の `ui-library-02`
  - 規約『部品・表・フォーカスのキー操作』（`react-keyboard-component`）の `table-01`
- 修正した規約の `description`・`tags` を、追加した項目に合わせて修正する
