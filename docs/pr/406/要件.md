# 要件

## 要望

`schemas/design/interface.schema.yaml` の `examples` の IF-2（入口が `trigger` の GitHub Actions の workflow の記載例）を、全ての文書の検査（IF-72-3）の workflow の突き合わせに通る記載へ修正し、`docs/template/template-interface.yaml` を再生成する。
修正した後の記載は [#404](https://github.com/shuhei1101/knowledge/pull/404) の IF-352-1 に統一する。

| 箇所 | 修正した後 |
| --- | --- |
| `request[layer].type` | `choice`。選択肢（`unit`・`integration`）は `description` に記載する |
| `overall_flow` のジョブ | step のノードをジョブ `test` の `subgraph` に入れる |
| `overall_flow` の判定のノード `q{全ての step が成功したか}` | 除外し、最後の step から終わり（`([成功])`・`([失敗])`）への線のラベルで成否を表す |

記載例の他の項目（`flows` など）と、テンプレートの決まり（`x-rules`）は変えない。
全ての文書の検査（`uv run --frozen --script scripts/check_all.py`）が終了コード 0 で終わることを確認する。
