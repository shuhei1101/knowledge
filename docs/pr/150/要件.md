# 要件

## 要望

`docs/rule/doc-parts.yaml`（規約『ドキュメントの部品』）の `overview` の「書き方は規約『ドキュメント管理』の `### タブとステップ` と `### ファイルツリー・コードの行の印・バッジ`。」を、部品の書き方を実際に持つ mdmark の使い方『本文を部品で組む』（使い方集の `components`）への参照に置き換える。

- 『本文を部品で組む』は、タブ・ステップ・ファイルツリー・コードの行マーカー・バッジの書き方を全て持つ
- knowledge の文書は mdmark の使い方を `mdmark の使い方『{タイトル}』` と呼んでいる（`template-flowchart` の `mdmark の使い方『図を描く』`）ので、同じ呼び方に統一する

終わりの条件:

- `doc-parts` の `overview` が、knowledge に存在しないセクションを参照していない
- 参照先に、`doc-parts` が扱う 5 つの部品の書き方がある
