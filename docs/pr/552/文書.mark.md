## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 呼び名の候補 | ノウハウごとに `name`・`description`・本文から、その技法を指す呼び名（括弧の中の技法名・略称・英語名）を書き出す | 例: `knowhow-script-callback` の「コールバック」「天丼」、`knowhow-script-act-out` の「act-out」 |
| `aliases` | 候補ごとに判定フローチャート『エイリアスの登録』と判定表『エイリアスを登録しない条件』を上から当て、登録すると決定した呼び名だけを追加する | 概念を指す呼び名は判定フローチャートのとおり用語の登録の判定へ回し、`aliases` に入れない。ほかの文書・用語の name か aliases に既にある呼び名は追加しない |
| タグ | 呼び名・本文の題材のうち今のタグに無いものを、`group_by: tags` で使用されているタグから選んで追加する | 既存のタグは削除しない。`main` のタグは変えない |
| 書き込み | `write_docs` の `update` で、作業ブランチの worktree に `aliases`・`tags` だけを書き込む | 本文・`name`・`description` は変えない |
| 検査 | 書き込んだ後に、全ての文書の検査を実行して合格を確認する | - |
