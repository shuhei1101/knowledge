# 要件

## 要望

`docs/knowhow/` の全てのノウハウに、規約『ドキュメント管理』の `knowhow-01` の届け方（`aliases` とタグ）で案内される呼び名とタグを補う。

- ノウハウごとに呼び名の候補（本文・`description` の括弧の中の技法名・略称・英語名）を書き出し、判定フローチャート『エイリアスの登録』と判定表『エイリアスを登録しない条件』で登録すると決定した呼び名を `aliases` に追加する（例: `knowhow-script-callback` の「コールバック」「天丼」）
- 判定で登録しないと決定した呼び名は追加しない。`aliases` に追加する呼び名が 1 つも無いノウハウは `aliases` を持たないままにする
- 呼び名と本文の題材のうち、今のタグに無いものを、`search_docs` の `group_by: tags` で使用されているタグから選んで補う（無ければ `topic:` で始まるタグを新規作成する）
- 変更はメタデータ（`aliases`・`tags`）だけにし、本文・`name`・`description` の文言は変えない
- 変更した全てのノウハウが、全ての文書の検査（`aliases` のキーの検査を含む）に合格する
