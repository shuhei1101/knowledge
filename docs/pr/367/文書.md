## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| フローの図 | 3 つのフローの `flows[].flow` を、通る step だけを並べた一本道の `flowchart` にし、全体の流れの結末「deploy の失敗」のフロー「異常系（配信の失敗・ジョブの失敗）」を追加する。step は `pages.yml` の step の `name`、どちらへ進んだかは矢印のラベルに記載する | 図は mdmark の map のまま |
| 全体の流れ | `overall_flow` を追加し、起動から `build` の各 step・`deploy` までの分岐と、成功・失敗の結末を描く | 分岐は step の成否と `deploy` の `needs: build` で記載する |
| `pages.yml` の step の `name` | `name` を持たない step に `name` を追加し、図はその `name` で記載する。`actions/checkout` に「ブランチを取得する」、`actions/setup-node` に「Node を入れる」、`astral-sh/setup-uv` に「uv を入れる」、`actions/configure-pages` に「Pages を設定する」、`actions/upload-pages-artifact` に「成果物をアップロードする」、`actions/deploy-pages` に「Pages へ配信する」を追加する | `name` の追加は実装の工程で行う |
| 確認 | 全ての文書の検査（`scripts/check_all.py`）を実行する | ログを `テスト結果/` に配置する |
