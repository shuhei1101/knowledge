# 要件

## 要望

公開文書の配信のワークフロー（IF-137-2）を、`design-schemas/v8.2.0` のインターフェース定義の書式で記載し直し、全ての文書の検査に違反 0 件で合格させる。

- 3 つのフロー（正常系・異常系 2 件）の `flows[].flow` を、そのフローで通る step だけを並べた一本道の `flowchart` にする。どちらへ進んだかは矢印のラベルに記載する
- 図の step は、`.github/workflows/pages.yml` の step の `name` で記載する
- 省略できる `overall_flow`（全体の流れ）に、全ての分岐と結末を描く。分岐の判定は workflow のファイルの `if` の条件と step の成否で記載する
- 既存のフローの名前・期待値・`callers` は変えない（シナリオ SC-137-1 の呼び出し先を保つ）
- `pages.yml` の `name` を持たない step（`actions/checkout`・`actions/setup-node`・`astral-sh/setup-uv`・`actions/configure-pages`・`actions/upload-pages-artifact`・`actions/deploy-pages`）に `name` を追加し、図はその `name` で記載する（レビューで確定）
- 全体の流れの結末は、どれも 1 つのフローを持つ
