## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| textlint の適用 | `knowledge_checks.py` の `check_textlint` が、書き込む文書の Markdown の項目を `_lint.py` で取り出し、`_lint.py` の `run_textlint` で textlint を呼ぶ | `main` だけが呼び、全ての文書の検査が使用する `check_document` には含めない。依存に `yamllint==1.38.0` を加える |
| 違反の返却 | error の違反を、元の文書の行（`{行} 行目: `）と項目のパスの違反にして、既存の違反と同じ配列で返却する。warning は返却しない | 全ての文書の検査と同じ行の対応 |
| textlint が無い・失敗したとき | 書き込みを止め、`npm ci --prefix scripts/lint` を案内する `path: $` の違反を返却する | lint のフォルダは `--lint-dir`（既定は `scripts/lint/`）。結合テストで差し替える |
| 処理時間 | 最も大きい文書の書き込みの検査を実測し、20 秒に収まるかを確認する | 超える場合は呼び出しの回数を 1 文書 1 回にする |
| 既存の検査 | ID の重複・参照・`aliases`・対応表の `examples` の検査の結果は変えない | - |
