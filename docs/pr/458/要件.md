# 要件

## 要望

次の文書の表のセルの `※n` を、mdmark の注記の記法（参照は `※[ID]`、定義は行頭の `※[ID]: 本文`）へ移す。

| 文書 | 移す注記 |
| --- | --- |
| 判定表『エイリアスを登録しない条件』（`docs/decision-table/decision-table-alias-exclusion.yaml`） | 表のセルの ※1〜※6 と、注記だけの項目 `alias-exclusion-table-02`〜`07` |
| 判定表『PoC を実施する条件』（`docs/decision-table/decision-table-poc.yaml`） | 表のセルの ※1〜※5 と、注記だけの項目 `poc-table-02`〜`06` |
| テンプレート『判定表』（`docs/template/template-decision-table.yaml`） | 記述例の `※1`、項目 `term-01` の記述例と補足、セクション一覧の「`※n` の注記の項目」の行 |
| テンプレート『画面設計』（`docs/template/template-screen-design.yaml`） | `elements[].args[].value` の行の例の `※2`。生成元の `schemas/design/screen.schema.yaml` の `examples` を修正して生成し直し、`design-schemas/v*` のタグを打つ |

終了の条件:

- 対象の文書に `※n`（番号の注記）が残っていない（テンプレート『画面設計』の `※必須` / `※任意` は表示の文言で、注記ではないので対象外）
- 注記だけを持っていた項目を削除し、注記の定義を判定表の項目の本文の表の下に配置する
- テンプレート『判定表』の注記の記載方法が、テンプレート『判定フローチャート』（`docs/template/template-flowchart.yaml` の `term-01`・`term-02`）と同じ注記の記法と ID の付け方になる
- 全ての文書の検査（`scripts/check_all.py`）が pass する

`screen.schema.yaml` の `examples` の「※2 で絞り込みを持つ列なら `true`」は、ドキュメント修正で案 A で修正した（レビューで確定する）。

| 案 | 内容 |
| --- | --- |
| A | 注記の参照をやめ、例を「絞り込みを持つ列なら `true`」の文言にする |
| B | 例を `true` の値だけにする |

推奨: A

スキーマの `examples` は注記の定義を持てず、`※[ID]` にしても参照先が無い。値の条件を文言で残せば、例の意図（固定の値を指定する場面）が読み手に伝わる。
