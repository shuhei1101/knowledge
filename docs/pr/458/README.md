# 判定表とテンプレート『判定表』『画面設計』の表のセルの ※n の注記を mdmark の注記の記法へ移す

## 概要

判定表 2 件とテンプレート『判定表』『画面設計』の表のセルに残る `※n` の注記を、判定フローチャートと同じ mdmark の注記の記法（`※[ID]` の参照と `※[ID]: 本文` の定義）へ移す。

## 背景

[#448](https://github.com/shuhei1101/knowledge/issues/448) の要望。
[#396](https://github.com/shuhei1101/knowledge/pull/396)（起点 Issue [#173](https://github.com/shuhei1101/knowledge/issues/173)）で判定フローチャートとテンプレート『判定フローチャート』の注記を mdmark の注記の記法へ移したが、表のセルの `※n` はスコープ外とした。
判定表とテンプレート『判定表』は、注記を `※n {用語}` の名前を持つ項目として 1 つずつ持ち、テンプレート『画面設計』は生成元のスキーマ `schemas/design/screen.schema.yaml` の `examples` に `※2` が残っている。
