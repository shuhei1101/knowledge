# 要件

## 要望

ai-monitor の reviewer のチェックシート・規約・判定フローチャートのうち、話し合いの資料 A-150 で「移行」「一部移行」にした 20 件を knowledge の文書にする。
「移行」は全文を、「一部移行」は AI Monitor の行（エージェント・MCP のツール・ラベル・PR ドキュメント・タスク一覧・計画書を前提にする行）を除いた一般の行だけを移す。
移す元は ai-monitor の develop（[5e1beae](https://github.com/shuhei1101/ai-monitor/commit/5e1beae1c782200aeed17ea194564a259b90c592)）。

- reviewer のチェックシートは、`docs/checksheet/` に成果物の種類ごとの「レビュー観点」のチェックシートとして追加する
- 本文の「外部規約『事前確認』」のような名前だけの参照は、knowledge の中の参照（`[名前](id:{ID})`）に置き換える。knowledge に無い ai-monitor の文書（規約『参照リンク』『モック画面構成』、テンプレート『PRドキュメント/要件』など）を指す行・補足は、一般の言い方に修正するか移さない
- 「reviewer」「エージェント」など AI Monitor の役割の単語は、レビューする人・作業する人の一般の言い方に修正する
- 移す行の最終の判定は、移す元の本文を確認して行う（Issue の行の数は 2026-11-11 の develop で数えたもの）
- 完了したら、後続の [shuhei1101/ai-monitor#3195](https://github.com/shuhei1101/ai-monitor/issues/3195) に着手できる旨をコメントし、`確認:task-planner` を付ける

### 記載方法

- チェックシートはテンプレート [チェックシート](id:template-checksheet)、判定フローチャートはテンプレート [判定フローチャート](id:template-flowchart)、規約は規約のスキーマの書式で記載する
- ファイル名は [knowledge のフォルダ構成](id:LAY-72-1) の `naming`（`checksheet-{name}.yaml`・`flowchart-{name}.yaml`）に従い、規約は既存の `dev-` の接頭辞に統一する
- タグと description は規約 [文書のタグと description の記載](id:dev-doc-tag-description) に従う
- 新しい文書を案内する場面を決め、規約 [ルール索引への登録](id:dev-rule-index-registration) に沿って `rules.yaml` の行・`aliases` を登録する
- 移す行の文言は、意味を変えない言い換えをしない（[既存文章の維持](id:convention-keep-existing-text)）。修正するのは AI Monitor の単語・名前だけの参照と、knowledge の対応表 [AI slop の単語の対応表](id:word-list-ai-slop) に当たる単語
- 文書を書き込んだ後、`uv run --frozen --script scripts/check_all.py` が合格する
