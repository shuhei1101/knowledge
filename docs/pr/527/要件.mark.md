# 要件

## 要望

用語集のスキーマ（`schemas/terms.schema.yaml`）の用語（`$defs.term`）に、その用語を説明するページを指す任意のキーを追加し、マージの後に `design-schemas/v*` のタグを上げる。

- キーの値は、ページの表示名とリンク先の組の並び（0 件以上）にする
- リンク先は、用語集の YAML のあるフォルダからの相対パスか URL で、見出しのアンカー付きを含む
- キーを省いた今の用語集（knowledge の `docs/terms.yaml`・mdmark の `docs/guide/用語集.yaml`）は、そのまま検査を通る
- mdmark は、このキーを alias-inject の行の `metadata` で列として指してエイリアスに取り込み、用語集の表の `詳細` の列のリンクに描く

キーは `details` にし、要素を `title`（表示名）と `href`（リンク先）の組にする。
表示名のキーは、共通の出典（`knowledge-common.schema.yaml` の `sources[]`）の `title` に合わせる。
alias-inject の `related`（要素の `to` が文書の ID）には合わせない。
ID を持たないページと見出しのアンカーを指せず、表示名とリンク先を ID から引き直す仕組みが利用側に要るため。
