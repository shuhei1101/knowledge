### #244 の決まり

- PreToolUse のフックが JSON を出力するときは、`hookSpecificOutput` に `hookEventName: PreToolUse` と `permissionDecision`（`allow`・`deny`・`ask`・`defer`）を記載する。`updatedInput` を返すときは必須
- 自分の MCP のツールの入力に値を追加するだけのフックは `allow` にする
- 判断を出さないフックは、出力なしで終了コード 0 にする
- 最上位の `decision`・`reason` は PreToolUse では使用しない。理由は `permissionDecisionReason` に記載する
- 出力の JSON の見本は、文より短く伝わる場合だけ 1 つ付ける（規約『文章の書き方』の確認表）
- `rules.yaml` の `claude-hook.yaml` の行の `paths` に `**/hooks/**` を追加する（すぐ下の `claude-context-placement.yaml` の行と同じ glob）
