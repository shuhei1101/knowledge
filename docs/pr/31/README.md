# YAML の規約を 1 つにまとめ、スキーマの書き方・検査・MCP からの読み書きの決まりを足す

## 概要

YAML を扱う決まりを 1 つの規約に集め、スキーマの書き方・検査・MCP からの書き込みと読み取りの決まりを足す。

## 背景

[Issue #15](https://github.com/shuhei1101/knowledge/issues/15) の要望。
YAML の決まりが `yaml-sot.md`・`コンテンツの置き場所.md`・`コーディング全般.md`・`ローカルYAML開発DB.md`・`プロンプトファイル.md` などに分かれている。
スキーマで YAML の形を決めて検査する決まりと MCP から YAML を書き込む決まりは、プロンプトの規約（[#13](https://github.com/shuhei1101/knowledge/pull/13)）にプロンプト向けに書いてあるだけで、プロジェクトごとに書き方が違う。
読み取りのツールの決まりは、[ユーザーのコメント](https://github.com/shuhei1101/knowledge/issues/15#issuecomment-6232559039)で足された。
