# ネットミームのリサーチャーと登録のエージェントフロー・知名度の判定表を配置し、最初の 19 作品と 73 用語を登録する

## 概要

利用者が knowledge のプラグインのスキルで、作品・話題からセリフに入れる用語を確認しながら、ネットミームとして登録できるようにする。
あわせて、最初の作品 19 件と用語 73 件をネットミームの配信元に登録する。

## 背景

[Issue #526](https://github.com/shuhei1101/knowledge/issues/526) の要望。
MindStella の話し合いで、ネットミームの登録のスキル（A-241）・リサーチャーのエージェントフロー（A-238）・知名度の判定表（A-242）と、最初に登録する作品と用語（A-244）を決めた。
作品とネットミームの種類・スキーマ・検査と直コミットの許可は [#514](https://github.com/shuhei1101/knowledge/issues/514)（[#530](https://github.com/shuhei1101/knowledge/pull/530)）で入ったが、配信元 `knowledge-memes` には文書がまだ無い。
完了後に [shuhei1101/aituber#163](https://github.com/shuhei1101/aituber/issues/163) が着手できる。
