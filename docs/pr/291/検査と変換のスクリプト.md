## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 配布物の判定 | `schemas/` 直下からコピーが無くなるため、`check_all.py` の配布物の判定（`find_distributed_schemas`・`DISTRIBUTED_SCHEMA_NAMES`）と、それに依る検査・lint の除外を削除する（IF-72-3） | - |
| 文書の行のスキーマの `$ref` | `check_all.py` は行の `schema` と同じフォルダの `*.schema.yaml` をファイル名で登録して `$ref` を解く。今は `schemas/` 直下だけを登録しており、コピーを削除すると設計書の行の `common.schema.yaml` が解けなくなる（IF-72-3） | - |
| 用語集との `aliases` の衝突 | `knowledge_checks.py` は、`records` を持つ行の文書の要素ごとの `name`・`aliases` を照合の相手にする（IF-72-1） | - |
