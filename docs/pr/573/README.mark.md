# 画面の規約に、並べた操作の部品（ボタンとボタンの見た目のリンク・入力欄）の高さをそろえる決まりを追加する

## 概要

画面を作る・レビューする人が、同じ行や近くに並べたボタン・ボタンの見た目のリンク・入力欄・選択欄の高さをそろえる決まりと、そろっているかのレビューの観点を参照できるようになる。

## 背景

[Issue #572](https://github.com/shuhei1101/knowledge/issues/572) の要望。
[shuhei1101/aituber#292](https://github.com/shuhei1101/aituber/pull/292) のモックで、フォームの末尾に並べた「保存」（ボタン）と「キャンセル」（ボタンに似せたリンク）の高さが違っていた（[利用者の指摘](https://github.com/shuhei1101/aituber/pull/292#discussion_r4688118971)）。
規約『情報の階層と見た目』には同じ種類の操作部品の高さを統一する行があるが、種類の違う部品（ボタンとボタンの見た目のリンク・入力欄）を並べたときと、タップ領域を広げる幅での決まりが無く、チェックシート『モック HTML のレビュー観点』には高さの観点が無い。
