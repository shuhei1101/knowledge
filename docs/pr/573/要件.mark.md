# 要件

## 要望

同じ行や近くに並べた操作の部品の高さをそろえる決まりと、レビューで確認する観点を knowledge の UI の規約とチェックシートに持ち、画面を作る・レビューする人が参照できるようにする。

- 規約『情報の階層と見た目』に、同じ行や近くに並べたボタン・ボタンの見た目のリンク・入力欄・選択欄は、部品の種類が違っても高さをそろえる決まりがある
- 同じ規約に、ボタンに似せたリンクはボタンと同じ見た目のクラス（React は部品の variant）を使用し、高さを別に記載しない決まりがある
- 規約『レイアウト』のタップ領域に、タップ領域を広げる幅では同じ行に並べた部品をまとめて広げ、高さをそろえる決まりがある
- チェックシート『モック HTML のレビュー観点』に、同じ行・近くに並べた操作の部品の高さがそろい、並びが崩れていないかを確認する行がある
- チェックシート『実装した画面のレビュー観点』の寸法の行が、種類の違う部品を並べたときの高さも確認する行になっている
- マージの前に、[Issue #572](https://github.com/shuhei1101/knowledge/issues/572) の「やりたいこと」の 3 点と修正した内容を突き合わせ、ずれが無いことを確認する
