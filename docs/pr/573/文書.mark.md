## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 規約『情報の階層と見た目』 | 「同じ種類の操作部品…高さを 1 つの値に統一する」の行の後に、同じ行や近くに並べたボタン・ボタンの見た目のリンク・入力欄・選択欄は種類が違っても高さをそろえる行と、ボタンに似せたリンクはボタンと同じ見た目のクラス（React は部品の variant）を使用し、高さを別に記載しない行を追加する | 既存の行の文言は変えない |
| 規約『レイアウト』 | `tap-target-01` の表の後に、タップ領域を広げる幅では同じ行に並べた部品をまとめて広げ、高さをそろえる文を追加し、規約『情報の階層と見た目』を参照する | 表の値は変えない |
| チェックシート『モック HTML のレビュー観点』 | 同じ行・近くに並べたボタン・ボタンの見た目のリンク・入力欄・選択欄の高さがそろい、PC 幅とスマホ幅で並びが崩れていないことを確認する行を追加する | 補足の列に規約『情報の階層と見た目』へのリンク |
| チェックシート『実装した画面のレビュー観点』 | 寸法の行を、同じ行・近くに並べた種類の違う操作部品の高さも確認する行へ修正する | 補足の列は今のリンクのまま |
