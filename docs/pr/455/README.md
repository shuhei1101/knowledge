# 開発ドキュメントのタブの並びとサイドバーのグループを規約『開発ドキュメントのナビゲーション』に従って定義し、目次を並べない

## 概要

利用者が dev-docs の画面で knowledge を開いたとき、入口になるタブ（はじめに・使い方）が左にあり、タブが画面の幅に収まり、サイドバーがグループでまとまった状態で文書を探せるようになる。

## 背景

[Issue #422](https://github.com/shuhei1101/knowledge/issues/422) の要望。
今の knowledge のタブは種類ごとに 9 件（規約・ノウハウ・テンプレート・判定フローチャート・判定表・チェックシート・使い方・スキル・ファイル）並び、画面の幅に収まらず、入口の使い方が右寄りにある。
設計書の種類（アーキテクチャ図・シナリオ・インターフェース定義など）はどのタブにも並んでいない。
並びの決まりは [#421](https://github.com/shuhei1101/knowledge/issues/421) で規約『開発ドキュメントのナビゲーション』（`dev-docs-navigation`）として登録済み。
