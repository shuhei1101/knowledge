## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スキーマの文言 | `title`・`description`・`examples`・`x-rules`・`x-bad-examples` の `reason` の `ng` の単語を、dev-docs#148 と #240 の置き換えに統一した単語に置き換える | キー・型・形式・`enum`・`const`・`pattern`・`x-bad-examples` の `value` は変えない |
| `test_files` の `description` | 括弧の中の `1 物理ファイル = 1 テストファイル。規約『V字モデル』` の `。` を `、` にして 2 文にする | 置き換えた後の全ての `description` が 2 文以内であることを、結合テストで確認する |
| 設計書のテンプレート | `uv run --frozen --script scripts/build_templates.py` で再生成し、手で編集しない | - |
| 置き換えの確認 | 置き換えた後に、対象のファイルを slop-check の対応表のコピーで照合し、残るヒットが `enum`・`const`・キーなど変えない値か、`x-bad-examples` の `value` だけであることを確認する | 残ったヒットと理由を `## テスト結果` に列挙する |
| 確認 | 全ての文書の検査（`scripts/check_all.py`）と、`tests/integration/scripts/` の結合テストを実行する | 違反が増えないことと、`test_normal_when_repository_schemas` が pass することを確認し、ログを `テスト結果/` に配置する |
