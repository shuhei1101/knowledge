# 要件

## 要望

次のスキーマの `title`・`description`・`examples`・`x-rules`・`x-bad-examples` の `reason` の文言を、[AI slop の単語の対応表](https://github.com/shuhei1101/knowledge/blob/66b2066/docs/word-list/word-list-ai-slop.yaml) の `ng` の単語を使用しない文言に置き換える。

| 対象 | ファイル |
| --- | --- |
| 設計書のスキーマ | `schemas/design/*.schema.yaml` |
| 文書のスキーマ | `schemas/meta.schema.yaml`・`schemas/word-list.schema.yaml`・`schemas/template.schema.yaml` |

- 置き換え先は、[shuhei1101/dev-docs#148](https://github.com/shuhei1101/dev-docs/pull/148) の `要件.md` の修正前後の表と、[#240](https://github.com/shuhei1101/knowledge/pull/240) の置き換え（確かめる → 確認する、読む → 参照する、当たる → 該当する、使う → 使用する、外す → 除外する、語 → 単語 など）に統一する
- 対応表の `ok` が複数ある単語は、文の意味に合う方を選ぶ（形 → スキーマ・構造・形状、段 → レイヤー・工程）
- キー・型・形式・`enum`・`const`・`pattern` の値は変えない
- `x-bad-examples` の `value` は悪い例の値のため変えない
- `schemas/design/*.schema.yaml` の全ての `description` を 2 文以内（`。` が 2 個以内）にする。今 3 文の `module.schema.yaml` の `test_files` の `description` も 2 文にする
- `scripts/build_templates.py` で `docs/template/` の設計書のテンプレートを再生成し、スキーマと一緒に commit する
- develop へマージした後に、設計書のスキーマのタグ `design-schemas/v1.0.1` を作成する（文言だけの変更のため、パッチを上げる）

`schemas/skill.schema.yaml` は [#224](https://github.com/shuhei1101/knowledge/issues/224) が削除するため対象から外す。
