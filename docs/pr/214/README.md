# knowledge-checks に、文書の中の aliases の重複と、自分の name と同じになる aliases を違反として返す検査を追加する

## 概要

文書の `aliases` の要素が、同じ文書のほかの `aliases` の要素か自分の `name` と正規化して同じになるとき、validator `knowledge-checks` が違反として返却する。

## 背景

[Issue #213](https://github.com/shuhei1101/knowledge/issues/213) の要望。
判定表『エイリアスを登録しない条件』の 4 行目「正規化で吸収できる表記ゆれである → 登録しない」は機械検査で判定できる。

[PR #212](https://github.com/shuhei1101/knowledge/pull/212)（[Issue #206](https://github.com/shuhei1101/knowledge/issues/206)、マージ済み）で、ほかの文書の `name`・`aliases` との衝突の検査 `check_aliases` を追加した。
1 つの文書の中の重複は、[レビュー](https://github.com/shuhei1101/knowledge/pull/212#discussion_r4489181937)で PR #212 のスコープ外とし、別の Issue にすると決めた。
`check_aliases` は自分の文書を照合の相手から除くため、1 つの文書の中の重複と自分の `name` との一致は調べていない。
