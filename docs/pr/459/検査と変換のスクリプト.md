## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スキーマの title の参照 | 最上位のキーに加え、入れ子のキーの定義を `properties`（オブジェクト）・`items`（配列）・同じスキーマの中を指す `$ref`（`#/` で始まるもの）でたどって `title` を参照する | 定義が見つからないキー・`title` を持たないキーは、キー名のまま出す |
| オブジェクトの中の配列 | オブジェクトのキーごとに `title` の行を出し、その下に配列の要素を入れ子の箇条書きで出す | `json.dumps` の文字列を出さない |
| オブジェクトの配列 | `<!-- table: {"kind": "data"} -->` の表にし、列名を要素のスキーマの `title` にする | セルの値が配列なら要素を、オブジェクトなら `{title}: {値}` を `<br>` でつなぐ |
| 列挙の値 | 値のまま出す | スキーマは値ごとの意味を構造で持たない |
| 既存機能への影響 | 文字列・文字列の配列・最上位の見出し・項目・関連・出典・埋め込みのマーカーの出力は変えない | 既存の結合テストの期待値（`test_normal`・`test_normal_when_kind_specific_keys`・埋め込み）が変わらないことで確認する |
| 単体テスト | `title` の参照（入れ子・`$ref`・定義なし）と、値の描き分け（オブジェクトの中の配列・オブジェクトの配列）のケースを追加する | - |
| 結合テスト | `test_normal_when_knowhow` に、`scenes` の箇条書き・`cases`・`evidence` の列名の期待値を追加する | 実行範囲は判定フローチャート『結合テストの実行範囲』で決め、実行前に reviewer の確認を受ける |
