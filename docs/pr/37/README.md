# サーバー側で描画する画面の規約を足し、置き場所によらない Web の規約の当たる範囲を広げる

## 概要

サーバーがテンプレートから HTML を組み立てる画面にも規約が当たるようにする。
サーバー描画の規約を新しく作り、置き場所によらない Web の規約を `frontend/` の外へも当てる。

## 背景

[Issue #33](https://github.com/shuhei1101/knowledge/issues/33) の要望（[shuhei1101/ai-monitor#2183](https://github.com/shuhei1101/ai-monitor/issues/2183) から移した Issue）。
ai-monitor の計画画面・claude-balancer の管理画面のように、サーバーがテンプレートから HTML を組み立てる画面に当たる規約が無い。
規約『iframe禁止』・『モバイル対応』・『CSS クラス命名』・『画面テンプレート』は置き場所によらない決まりなのに、`rules.yaml` で `frontend/` の中にしか当たっていない。
