### #248: 検知した単語の画面への表示

- `slop_check.py` は、ヒットした単語があるとき、今の `hookSpecificOutput.additionalContext`（NG と OK の表）に加えて、同じ JSON の `systemMessage` に利用者向けの 1 行を返却する
- 1 行の書式は `AI slop を検知: {NG の単語を・でつないだ並び}（{書き込みの名前}）`。置き換え先は出さない
- 書き込みの名前は、組み込みのツールはツール名（`Write` 等）、MCP ツールは `{プラグインの名前} の {ツール名}`（例: `mindstella の reply`）にする
- 検知するたびに出す。ヒットが無いときは何も出さない（今のまま）
- 表示される場所は Claude Code の画面だけ
- `systemMessage` と `additionalContext` を同時に返却したときに、利用者の画面に 1 行が出て、エージェントに表が届くことを、実装のときに Claude Code で確認する

### #312: SKILL.md の生成

- `scripts/` に、`docs/skill/` の `type: skill` の文書から、`skill.path` の SKILL.md を書き出す生成のスクリプトを作る
- frontmatter と本文への変換は、スキーマ `schemas/design/agent_flow.schema.yaml` の各キーの使用先（「生成で、…にする」）に従う
- `skills/text-review/SKILL.md` を、`docs/skill/text-review.yaml` から生成したものに置き換える。生成した SKILL.md は今の SKILL.md と同じ手順で動く
- 生成のコマンドを開発コマンドに記載し、既存の生成のスクリプト（`build_word_list.py`・`build_templates.py`）と同じ並びに配置する

### #313: dev-docs と project-index の MCP の名前の両対応

- `slop_check.py` の照合の対象に、project-index の `write_docs` に加えて dev-docs の `write_docs`（`mcp__plugin_dev-docs_dev-docs__write_docs`）を入れる
- 規約を参照するツールの案内（`NOTICE_TAIL`）は、project-index と dev-docs のどちらの `search_docs` でも参照できるように両方の完全名を出す
- スキル text-review の規約の参照方法は、project-index と dev-docs のどちらの `search_docs` が使えても参照でき、どちらも無いときは今のとおりファイルを参照する
- スキル text-review は `docs/skill/text-review.yaml` を書き換えて SKILL.md を生成し直す（SKILL.md を手で修正しない）
