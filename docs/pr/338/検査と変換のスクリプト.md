## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 生成のスクリプト | `scripts/` に、`docs/skill/` の `type: skill` の文書ごとに `skill.path` の SKILL.md を書き出す単一ファイルのスクリプトを新設する | ファイル名は `build_templates.py`・`build_word_list.py` に合わせた `build_*.py` にし、モジュール構成設計で決める |
| frontmatter | `name`（`skill.name`、無ければ `skill.path` のフォルダ名）・`description`（`summary`）・`argument-hint`・`arguments`・`allowed-tools`・`skill.frontmatter` を書き出す | スキーマの使用先のとおり |
| 本文 | `title` の見出し・引数の説明・`steps[]` の工程（`name` の見出し・`when`・`body`・`calls`）を書き出す | 今の `skills/text-review/SKILL.md` と同じ手順で動く本文にする |
| 依存のロック | 既存の生成のスクリプトと同じく、PEP 723 の依存と `.lock` を配置する | - |
| 設計書 | 単一 UC・インターフェース定義・モジュール構成を新設し、MOD-72-1 の一覧に加える | 先例は SC-201-1・IF-201-1・MOD-201-1 |
| テスト | 単体・結合テストを `tests/unit/scripts/`・`tests/integration/scripts/` に新設する | - |
| 既存機能への影響 | 既存の検査と変換のスクリプトは変えない | 生成物と生成元の一致を全ての文書の検査で比べるかは `要件.yaml` のスコープ外の行で判断する |
