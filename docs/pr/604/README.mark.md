# 画面の規約に、スプリッター・上タブを戻ったときのページ・アイコンの既定・Web Storage のキーの付け方・保持の欄を記載する基準を追加する

## 概要

画面を設計・実装する人が、サイドバーと補助のペインのスプリッター、上タブを移って戻ったときに開くページ、標準の操作のアイコンの既定、Web Storage のキーの付け方、設計書に保持する状態を記載する基準を規約から参照できるようにする。

## 背景

[Issue #601](https://github.com/shuhei1101/knowledge/issues/601) の要望。
aituber の管理画面で、上タブを移るとページとスクロール位置が戻らない・サイドバーの幅を変えられない・アイコンで分かるボタンに長いラベルが付く、が起きている（[shuhei1101/aituber#312](https://github.com/shuhei1101/aituber/issues/312)〜[#314](https://github.com/shuhei1101/aituber/issues/314)）。
画面の規約は、サイドバーを「左に固定・常に表示」とし、スプリッター・領域を戻ったときのページ・アイコンの既定・キーの付け方・保持の欄を記載する基準を持たない。
画面設計のスキーマへの欄の追加は後続の [#602](https://github.com/shuhei1101/knowledge/issues/602) が扱う。
