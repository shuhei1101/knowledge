## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スプリッター | `ui-layout` に項目を追加し、`layout-pattern-01` のサイドバーの行と `convention-common-components` の `components-layout-01` のサイドバーの行を合わせる。`ui-keyboard` の `composite-widget-02` に分割線の行（APG の Window Splitter）を追加し、`ui-operation-accessibility` の `wcag22-01` の 2.5.7 の行からスプリッターの代替の手段を示す | 既定の値は `未確定`（下の表） |
| 上タブを戻ったときのページ | `ui-input-wording` の `state-retention-01` に、領域ごとに最後に開いたページを sessionStorage に持ち、上タブを押したら開く行を追加し、`scroll-restoration-01` にサイドバーのスクロール位置の行を追加する | URL で開いたときは URL を優先する（今の行と同じ） |
| アイコンの既定 | `ui-button-label` の `icon-or-text-01` に、標準の操作は既定でアイコンを付け、広い幅はアイコンと文字・狭い幅はアイコンだけにする行を追加する | 狭い幅の対処は `flowchart-short-text-overflow` の `r3` を参照する |
| Web Storage のキー | `ui-input-wording` に、キーの書式（アプリの接頭辞・版・画面とタブ）と、sessionStorage と localStorage で同じキーを使わない決まりの項目を追加し、`flowchart-screen-state-retention` の `r6` から参照する | 区切り文字は `未確定` |
| 保持の欄を記載する基準 | `ui-input-wording` に、画面設計で保持する状態の記載を必須にする要素の基準の項目を追加する | 画面設計のスキーマの欄は #602 |
| メタデータ | 修正した規約・判定フローチャートの `description`・`tags` を内容に合わせる | タグは `group_by: tags` で既存のタグを確認して再利用する |

スプリッターの最小と最大の幅は、規約に値を固定せず画面設計で決め、規約は「最小はペインの主な操作が収まる幅・最大はメインに主な操作が残る幅」の基準だけを持つ（画面ごとに中身の幅が違うため）。
キー操作は APG の Window Splitter に合わせて矢印で幅を変え、Home / End で最小・最大、Enter で閉じる・開くにした。キーの書式の区切り文字は、既存の例 `detail:{itemId}:{tab}` に合わせて `:` にした。
