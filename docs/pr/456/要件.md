# 要件

## 要望

AI Monitor v0.5.0（`v0.4.0..v0.5.0`）の配布物へ追従する。

| 分類 | 対応 |
| --- | --- |
| 配布先の反映作業 | 反映作業『配布先の mdmark の設定へのノードの種類の記載』のスクリプトで、直下に `mdmark.config.yaml` を作り、`map.kinds` に 7 つのノードの種類、`map.lines` に 2 つの線の種類を記載する |
| 準拠バージョン | 直下の `ai-monitor-version.ini` を `v0.5.0` にする |
| フォルダ構成 | フォルダ構成の設計書 [LAY-72-1](https://github.com/shuhei1101/knowledge/blob/3a4bde93c2e2983d28a73025a331264c85b69984/docs/layout/LAY-72-1.yaml) の直下のファイルに `mdmark.config.yaml` の行を追加し、`ai-monitor-version.ini` の中身を AI Monitor の配布物への準拠バージョンに修正する |
| サイトのレイアウト | 対象なし。knowledge は `docs/_theme/`・`ai-monitor-theme.yaml` を持たない |
| テンプレート・規約・判定・観点 | 対象なし。変わったのは mdmark のマーカーの JSON の記法・依存先待ちの `wait_for_issues`・計画書の `### 結合テストの実行範囲` で、knowledge の文書にある旧記法のマーカー（`<!-- table: data -->`）は検査のテストの入力として意図して配置したものだけ |
| フェーズ手順・MCP ツール | 対象なし。AI Monitor 側の設定で、knowledge に修正する箇所は無い |

`ai-monitor-version.ini` の中身の説明は、[#283](https://github.com/shuhei1101/knowledge/issues/283) で `schemas/` の配布物のコピーを削除した後も「`schemas/` 直下に取り込んだ AI Monitor の配布物のバージョン」のままで、今の用途（配布物への準拠バージョン）と合わないため、同じ行を修正する。
