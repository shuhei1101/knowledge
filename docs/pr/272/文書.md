## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| map の型 | map で記載する本文の型を定め、`title`・`description`・`x-rules`・`x-used-by`・`examples` を付ける | 置き場所は `common.schema.yaml` の `$defs/map`。map の印と補足の書き方は mdmark の使い方集の map のページに合わせる |
