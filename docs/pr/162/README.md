# 規約の本文の埋め込みのマーカーを、dev-docs の画面で対応表の NG・OK の表に展開する

## 概要

利用者が dev-docs の画面で規約『文章の書き方』を開いたとき、`word-choice-table-02` の埋め込みのマーカーの位置で、対応表『AI slop の単語の対応表』の NG・OK の表を読める。

## 背景

[Issue #160](https://github.com/shuhei1101/knowledge/issues/160) の要望。
[#148](https://github.com/shuhei1101/knowledge/pull/148) で `word-choice-table-02` の本文を、埋め込みのマーカー `<!-- embed: word-list-ai-slop -->` と対応表へのリンクに置き換え、展開は [#148 の要件.md の `## スコープ外`](https://github.com/shuhei1101/knowledge/blob/develop/dev/pr/148/%E8%A6%81%E4%BB%B6.md) からこの Issue へ回した。
dev-docs は converter の出力にある `<!-- embed: {パス}#{項目} -->` を、配信元の直下からのパスの YAML の値の表に置き換える（[embed.py](https://github.com/shuhei1101/dev-docs/blob/develop/src/dev_docs/features/convert/embed.py)）。
マーカーは文書の ID を指しているため、dev-docs の develop の実装ではパスとして読めず、表の代わりに「埋め込めません」の注意書きになる。
