# 要件

## 要望

`schemas/design/agent_flow.schema.yaml` の工程（`$defs/step`）に次のキーを追加し、テンプレート『エージェントフロー』を再生成して、develop へマージした後に `design-schemas/v*` の新規のタグを作成する。
キーの名前・型・必須はユーザーが決定済み（[shuhei1101/aituber#228 の確認事項への回答](https://github.com/shuhei1101/aituber/pull/228#discussion_r4664258566)）で、原本はエージェントフローのテンプレートの案 A-73 の「キーの表」の `steps[].id`〜`steps[].unit` の行。

<!-- table: {"kind": "data"} -->

| キー | 型 | 必須 | 説明 | 例 |
| --- | --- | --- | --- | --- |
| `steps[].id` | string | `gates`・`proposals`・`unit` を記載する工程は必須 | 工程の識別子。ゲートと進み具合のデータが工程を指すときに使用する。エージェントフローの中で一意 | `plan` |
| `steps[].gates` | object | 任意 | この工程に挟むゲート。省くとゲートを挟まない | `{agent: {toggle: {}}, human: {toggle: {}}}` |
| `steps[].gates.agent` | object | 任意 | エージェントゲート（レビュアーのレビュー）を挟む。`toggle` を記載すると、制作の設定でオンとオフを切り替えられる | `{toggle: {}}` |
| `steps[].gates.human` | object | 任意 | ヒューマンゲート（利用者の確認）を挟む。`toggle` の意味は `agent` と同じ | `{toggle: {}}` |
| `steps[].proposals` | object | 任意 | 複数の作成者の案を並べて 1 つを選ぶ工程にだけ記載する | `{authors: [{author: node}, {author: chatgpt, toggle: {}}], min_per_author: 3}` |
| `steps[].proposals.authors[]` | object[] | `proposals` があるとき必須（1 件以上） | 案を出す作成者 | - |
| `steps[].proposals.authors[].author` | string | 必須 | 作成者の識別子。`node`（エージェントフローを進めるノード）か、外部の作成者 | `chatgpt` |
| `steps[].proposals.authors[].toggle` | object | 任意 | 記載がある作成者は、制作の設定で工程ごとにオンとオフを切り替えられる | `{}` |
| `steps[].proposals.min_per_author` | int | `proposals` があるとき必須 | 作成者ごとに依頼する案の数の下限 | `3` |
| `steps[].unit` | enum | 任意 | 工程の成果の単位。`single`（1 件）・`per_script`（台本 1 本に 1 件）。省くと `single` | `per_script` |

<!-- /table -->

`proposals`・`unit` は、`gates` を持つ工程にだけ記載できる。

終了の条件:

- `id`・`gates`・`proposals`・`unit` を持つ工程（A-181 の `script-creation/main` の工程）が `agent_flow.schema.yaml` の検査に合格し、`gates` を持たない工程に `proposals`・`unit` を記載したものと、`gates` を持つ工程で `id` を省いたものが不合格になる
- 既存のエージェントフロー（このキーを持たないもの）の検査の結果が変わらない
- `docs/template/template-agent-flow.yaml` が再生成され、全ての文書の検査（`scripts/check_all.py`）で違反が 0 件
- develop の squash commit に `design-schemas/v*` のタグが作成され、[shuhei1101/aituber#228](https://github.com/shuhei1101/aituber/pull/228) へタグの名前を連絡している
