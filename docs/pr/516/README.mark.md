# キーの表を持つテンプレートと規約に、ほかのキーの値で必須が変わることを記載する「条件」の列を追加する

## 概要

設計書を書く人が、ほかのキーの値で必須か・持つかが変わるキーを、キーの表の「条件」の列で一覧できるようになる。

## 背景

[Issue #515](https://github.com/shuhei1101/knowledge/issues/515) の要望。
設定・データ・インターフェース定義などのキーの表（列は、キー・型・必須・説明・例。規約『表し方の優先順位』の「キーの表」）には、判別のキーで分かれるキーの条件を書く列が無い。
今は「必須」を `-` にして「説明」に文で書いており、どのキーがどの値のときに要るかを表で一覧できない。
設計書のスキーマ（`schemas/design/`）の `required` も真偽の値だけを持つ。
