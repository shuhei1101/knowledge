# 要件

## 要望

- 規約『ビルドレス原則』（`html-core-buildless`）の `script-extension-02` を書き換え、ブラウザのスクリプトを `.js` で記載してよいのを tsc を挟めないもの（使い捨てのモックなど）だけに限る
  - 生成した `.js` を commit すれば配れるもの（GitHub Pages・プラグインの同梱物・配布物）は `.ts` で記載し、生成した `.js` を `.ts` と同じ階層へ commit する
  - 規約『tsc 運用』（`html-tooling-tsc`）の `generated-js-gitignore-01` と、GitHub Pages・配布先の扱いが一致する
- 『ビルドレス原則』に、HTML に直接記載する `<script>`（インラインのスクリプト）の処理を `.ts` へ分け、生成した `.js` を `<script src>` で読み込む決まりを追加する（1 枚の HTML で配る雛形も同じ）
  - 値だけを持つ `<script>`（`type="importmap"`・`type="application/json"`）は対象に含めない。規約『モジュール解決』の `module-resolution-01`（importmap）と規約『サーバー描画』の `server-rendering-08`（`tojson` で JS へ値を渡す）と食い違わない
- レビューの観点（設計と実装の両方でブラウザのスクリプトを `.js` で手書きしていないこと）は、置き場が ai-monitor の reviewer のチェックシートで、knowledge への移行は [#267](https://github.com/shuhei1101/knowledge/issues/267) が扱うため、この PR ではスコープ外にする
