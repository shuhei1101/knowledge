## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `.js` の例外 | `script-extension-02` を、`.js` で記載してよいのは tsc を挟めないもの（使い捨てのモックなど）だけ、に書き換える | GitHub Pages を例外の例から除外する |
| 生成 `.js` を commit して配るもの | 新しい項目で、GitHub Pages・プラグインの同梱物・配布物は `.ts` で記載し、生成 `.js` を `.ts` と同じ階層へ commit すると定め、[html/tooling/tsc運用](id:html-tooling-tsc) を参照する | commit の運用の本文は『tsc 運用』に配置し、重複させない |
| インラインのスクリプト | 新しい項目で、HTML に直接記載する `<script>` の処理は `.ts` へ分け、生成 `.js` を `<script src>` で読み込むと定める | 値だけを持つ `type="importmap"`・`type="application/json"` は対象外 |
| 『tsc 運用』の配布先 | `generated-js-gitignore-01` の「ビルドしない配信先（GitHub Pages・配布先）」の例にプラグインの同梱物を加える | 他の行は変えない |
