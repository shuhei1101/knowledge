# インターフェース定義 IF-352-1 の判定フローチャート『タイムアウトの決め方』の旧注記の番号 ※5 の参照を修正する

## 概要

インターフェース定義 IF-352-1 の `notes` に残る判定フローチャート『タイムアウトの決め方』の旧番号 `※5` の参照を、今の判定フローチャートの結果を指せる書き方へ修正する。

## 背景

[#461](https://github.com/shuhei1101/knowledge/issues/461) の要望。
[#396](https://github.com/shuhei1101/knowledge/pull/396) で判定フローチャート『タイムアウトの決め方』の注記は mdmark の注記の記法（`※[timeout-n5]`）へ移ったが、参照する側の `docs/interface/IF-352-1.yml.yaml` に旧番号の `※5` が残っている。
[#458](https://github.com/shuhei1101/knowledge/pull/458) のレビューで、reviewer が対象外の逸脱として報告した。
