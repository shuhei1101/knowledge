# 要件

## 要望

| 検査 | 決めること |
| --- | --- |
| actionlint | GitHub Actions の workflow のファイルを持つリポジトリは、テスト実行方法の lint の層に actionlint（workflow の書き方・式・参照・`run:` のシェル）を含める。Git フックと CI では動かさない（規約『Git フックと CI で動かすもの』のまま） |
| 設計書とファイルの突き合わせ | 入口が `trigger` の workflow のインターフェース定義の、起動の条件（`entry`）・リクエスト・排他（`exclusivity`）・step の `name`・`if` が、workflow のファイルの `on`・`inputs`・`concurrency`・step の `name`・`if` と一致するかを、テンプレート『インターフェース定義』の記載方法とレビュー観点で定める |

突き合わせは検査のスクリプトにせず、レビューで行う（スクリプトにするかはスコープ外に判断を書き、レビューで確定する）。
新しい規約は作らず、既存のテンプレートとチェックシートへ追加する。
