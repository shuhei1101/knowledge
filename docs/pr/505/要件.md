# 要件

## 要望

プラグイン slop-check の PostToolUse のフックが、ヒットした単語の 1 行（`systemMessage`）を利用者の画面に出すかを、設定で切り替えられるようにする。

- 既定は表示しない。設定で表示すると決めた端末だけ、今と同じ `AI slop を検知: {単語}（{ツール}）` の 1 行を出す
- モデルへの通知（`additionalContext`）は、設定に関係なく今のまま出す
- 書き込みを止めないこと・ヒットが無いときに何も出さないことは変えない
- 反映作業で、利用者の端末の設定を「表示する」にする
- 終了の条件: 設定が無い端末ではヒットしても `systemMessage` を出さず `additionalContext` だけを出し、表示すると設定した端末では今と同じ 1 行を出すことを、単体・結合テストで確認すること

設定は環境変数 `SLOP_CHECK_SHOW_ADDED` にし、`1` のときだけ表示する。利用者は Claude Code のユーザースコープの `settings.json` の `env` に記載する。

- 規約『Claude プラグインルール』の `settings-file-02`（`env` に記載するのは `{ツール名}_CONFIG` のパスだけ）から逸脱する
- 常駐のサーバーが無く、フックの子プロセスに `env` が渡るため、利用者が環境変数に決めた（[確認ログ](./確認ログ.yaml)）
