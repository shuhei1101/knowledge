# 要件

## 要望

プラグイン slop-check の PostToolUse のフックが、ヒットした単語の 1 行（`systemMessage`）を利用者の画面に出すかを、設定で切り替えられるようにする。

- 既定は表示しない。設定で表示すると決めた端末だけ、今と同じ `AI slop を検知: {単語}（{ツール}）` の 1 行を出す
- モデルへの通知（`additionalContext`）は、設定に関係なく今のまま出す
- 書き込みを止めないこと・ヒットが無いときに何も出さないことは変えない
- 反映作業で、利用者の端末の設定を「表示する」にする
- 終了の条件: 設定が無い端末ではヒットしても `systemMessage` を出さず `additionalContext` だけを出し、表示すると設定した端末では今と同じ 1 行を出すことを、単体・結合テストで確認すること

`未確定`: 設定の配置先と名前（決める工程: データ設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 環境変数（Claude Code の `settings.json` の `env` で指定する）。名前は alias-inject の `global.show_added` に合わせる（例: `SLOP_CHECK_SHOW_ADDED`） | 設定ファイルの取得と配置先の決まりを追加せずに済む | alias-inject と配置先が異なる |
| B | 端末の設定ファイル（例: `${XDG_CONFIG_HOME:-~/.config}/slop-check/settings.json`）の `global.show_added` | alias-inject と配置先とキーがそろう | 設定ファイルの配置先と取得を追加する |

推奨: A

slop-check は設定ファイルを持たず、標準ライブラリだけで動くフックに設定ファイルの取得を追加するより、`settings.json` の `env` で指定するほうが追加が少ない。
