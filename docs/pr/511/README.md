# 規約『トークン管理とコスト最適化』のプロンプトキャッシュに、書き込みの費用・明示のブレイクポイント・呼び出しの間隔を追加する

## 概要

プロンプトキャッシュを設計する人が、規約『トークン管理とコスト最適化』で、書き込みの費用・明示のブレイクポイント・呼び出しの間隔を考慮できるようにする。

## 背景

[#510](https://github.com/shuhei1101/knowledge/issues/510) の要望。
`docs/rule/python-llm-cost-cache.yaml` の「プロンプトキャッシュの設計」は、OpenAI を「自動（コード変更不要）」とし、書き込みの費用・明示のブレイクポイント・呼び出しの間隔・書き込みのトークンのキー・エイリアスのモデルの記載が無く、今のプロバイダーの仕様と合っていない。
