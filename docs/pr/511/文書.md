## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `prompt-cache-04` | OpenAI の行の仕組みを、モデルの世代によって自動のままの世代と、書き込みの費用・明示のブレイクポイントがある世代に分かれる記載にする | 世代の境のモデル名は書かず、公式のドキュメントを参照する |
| 明示のブレイクポイント | 項目を追加し、毎回変わる末尾を書き込みの対象から外すため、変わらない部分の最後に明示のブレイクポイントを指定する | Anthropic の `cache_control` と OpenAI のパラメータ名は公式のドキュメントで裏付ける |
| 呼び出しの間隔 | `prompt-cache-05` の後に項目を追加し、呼び出しの間隔が保持の時間より長い用途ではキャッシュを前提にしない | 保持の時間の値は書かない |
| `prompt-cache-06` | ログのキーに書き込みのトークンのキーを追加する | 費用の計算に要る |
| エイリアスのモデル | 項目を追加し、中身が入れ替わるエイリアスのモデルは使用量で実測する | モデル名の例は書かない |
| メタデータ | `sources` の OpenAI の URL を今の公式のドキュメントへ直し、`rev`・`last_reviewed` を上げる | - |
