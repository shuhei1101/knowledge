# 今ある E2E のテストと、E2E だけが使う部品を develop から削除する

## 概要

develop から、今ある E2E のテスト（`tests/e2e/`）と E2E だけが使う部品を削除する。設計書のシナリオは残す。

## 背景

[Issue #235](https://github.com/shuhei1101/knowledge/issues/235) の要望。
0.x の間は E2E を実行せず修正もしないため、今ある E2E は仕様の変更で古くなり、エージェントが参照して誤解するノイズになる。
話し合いで、全てのリポジトリの develop から E2E のテストと E2E だけが使う部品を削除し、シナリオは残すと決めた。
