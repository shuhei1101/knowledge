# 要件

## 要望

develop から、E2E のテストと E2E だけが使う部品を削除する。

| 対象 | 扱い |
| --- | --- |
| `tests/e2e/`（`conftest.py`・単一ユースケースと複合ユースケースのテスト） | 削除する |
| E2E だけが使う設定・開発コマンド・CI のジョブ・管理用の YAML の行 | 無い（`pytest.ini`・`pyrightconfig.json`・`ruff.toml` は `tests/` 全体を指し、`.github/workflows/` に E2E のジョブは無く、`tests/` に `files.yaml` は無い） |
| 設計書の E2E の記述（フォルダの構成・テスト実行方法・インターフェース定義とモジュール構成の notes） | 削除後の状態に合わせる |
| シナリオと `test_file` | 残す（作り直すときの対応のマーカー） |
| 結合テストと共有する部品 | 無い（`tests/e2e/` の外に E2E が参照する部品は無い） |

終わりの条件は、`tests/e2e/` が無く、単体テスト・結合テスト・lint が全て通り、`scripts/check_all.py` で全ての文書の検査が通ること。
