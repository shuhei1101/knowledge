# 規約『テストの種類と配置』の結合テストと E2E テストの配置を、規約『V字モデル』の対応表に統一する

## 概要

Python のテストを作る人が、規約『テストの種類と配置』と規約『V字モデル』のどちらを参照しても、結合テストと E2E テストを同じ単位・同じ場所に配置できるようにする。

## 背景

[Issue #380](https://github.com/shuhei1101/knowledge/issues/380) の要望。
規約『V字モデル』（`dev-v-model`）の対応表は、結合テストを `tests/integration/{サブシステム名}/` にインターフェース定義・画面設計・部品設計の 1 つ = 1 ファイルで、E2E テストを `tests/e2e/複合ユースケース/`・`tests/e2e/単一ユースケース/` に配置すると定める。
規約『テストの種類と配置』（`python-testing-layers`）は、結合テストを「src をミラー・1 ファイル = 1 ユースケース」とし、E2E テストを `e2e/` の下で分けていない。
[#374](https://github.com/shuhei1101/knowledge/issues/374)（作業 PR [#379](https://github.com/shuhei1101/knowledge/pull/379)）の現状調査で見つかり、スコープ外として切り出した。
