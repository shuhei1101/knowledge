# 要件

## 要望

規約『テストの種類と配置』（`docs/rule/python-testing-layers.yaml`）の結合テストと E2E テストの配置・単位を、規約『V字モデル』（`docs/rule/dev-v-model.yaml` の `mapping-01`）の対応表に合わせる。

| 項目 | 今 | 合わせた後 |
| --- | --- | --- |
| `file-placement-01` のツリーの `integration/` | src をミラー・1 テストファイル = 1 ユースケース | `{サブシステム名}/` の下に、インターフェース定義・画面設計・部品設計の 1 つ = 1 テストファイル |
| `file-placement-01` のツリーの `e2e/` | `e2e/` だけ | `複合ユースケース/`・`単一ユースケース/` の下に、シナリオ 1 つ = 1 テストファイル |
| `integration-test-01` の結合テストの単位 | 1 ファイル 1 ユースケース、条件分岐ごとに `test_*` 関数 | インターフェース定義・画面設計・部品設計の 1 つ = 1 ファイル、テスト関数は対応表の「ファイルの中の対応」のとおり |
| `test-policy-01` の結合テストの目的 | ユースケース 1 単位を通しで確認 | サブシステムの境界（インターフェース定義・画面設計・部品設計）の 1 つを確認 |
