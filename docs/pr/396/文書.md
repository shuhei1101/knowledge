| テンプレート『判定フローチャート』 | 記載例の判定フローを map（Mermaid の `flowchart` のノードの形状で開始・判定・アクション・終端を分け、線のラベルは `YES` / `NO`）と補足 `map-data` で記載し、注記を `notes` の `annotations` と行頭の `※[ID]: 本文` で記載する。ノードの種類の表・`※N` の採番・セクション一覧の注記の行も書き換え、座標の配置の決まり（一本道の配置）を削除する。`write_docs` で書き込む | ノードの種類ごとの外観は、mdmark の設定 `map.kinds` を使用せず Mermaid の形状で分ける。全ての文書の検査は設定ファイルを参照せずに map を点検し、`map.kinds` に無いクラスは誤りになるため |
| 判定フローチャート 26 件と規約 3 件の図 | `flow` の定義の JSON をスクリプトで Mermaid の `flowchart` へ書き換え、ノードの名前の `※n` を補足 `map-data` の `annotations` へ移す。`※n` の注記の項目は、図の項目の本文の `※[ID]: 本文` の定義へ移し、注記だけの項目は削除する | 注記の ID は `{文書の ID から flowchart- を除いた名前}-n{元の番号}` にし、文書をまたいで重ならないようにする。ノードの ID の `-` は map の Mermaid として解釈されないため `_` にする |
