# 判定フローチャートの図を mdmark の map へ書き換え、※n の注記を mdmark の注記の記法へ移す

## 概要

判定フローチャートを読む人が、図のノード・線と本文から注記の本文をツールチップで参照できるようにする。
テンプレート『判定フローチャート』の `※n` の注記の書き方を mdmark の注記の記法に書き換え、既存の判定フローチャートの `※n` を注記へ移す。

## 背景

[#173](https://github.com/shuhei1101/knowledge/issues/173) の要望（話し合いの検討事項 D-37 の A）。
今の書き方はノードの名前に `※n` を付け、図の下に注記の項目を配置するため、読む人が図と注記を行き来する必要がある。

mdmark の注記の記法（`※[ID]` で参照し、行頭の `※[ID]: 本文` で定義する）は [shuhei1101/mdmark#562](https://github.com/shuhei1101/mdmark/pull/562)（起点 [shuhei1101/mdmark#304](https://github.com/shuhei1101/mdmark/issues/304)）で mdmark の develop に入った。
図のノードと線から注記を参照できるのは map の図（Mermaid と補足 `map-data` の `notes` の `annotations`）だけである。
今の判定フローチャートは座標で記載する `<!-- flow -->` の図で描いているが、`flow` の範囲は mdmark v0.13.0（今の `MDMARK_TAG`）で廃止され、範囲の中身を描かずに記載の警告を出す。
