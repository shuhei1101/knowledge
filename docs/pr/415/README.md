# 結合テストの実行範囲と並列の数の判定フローチャート 2 件と、テスト実行方法・インターフェース定義・画面設計のスキーマとテンプレートへの任意の項目を追加する

## 概要

作業 PR で結合テストを実行する人が、変更したファイルから実行する結合テストの範囲を、端末の資源から並列の数を、knowledge の判定フローチャートとテスト実行方法の層の項目で決められるようにする。

## 背景

[Issue #411](https://github.com/shuhei1101/knowledge/issues/411) の要望。
作業 PR の結合テストの全件の実行に 1 時間ほどかかり、作業 PR ごとの待ち時間になっている。
[ai-monitor#3358](https://github.com/shuhei1101/ai-monitor/issues/3358)（作業 PR [ai-monitor#3483](https://github.com/shuhei1101/ai-monitor/pull/3483)）で、範囲と並列の数を判定フローチャートとテスト実行方法の表で決めることになり、判定フローチャート『テストの実行場所』と同じく全てのプロジェクトで同じ判定を使用するため、knowledge に配置すると決めた。
ai-monitor#3483 はこの作業 PR に依存し、`design-schemas` のタグが入った後に参照を上げる。
