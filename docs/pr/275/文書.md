## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 新設の 8 種類のスキーマ | 既存の `schemas/design/*.schema.yaml` と同じ書き方（`x-kind`・`x-id-prefix`・`title`・`description`・`x-rules`・`examples`、共通の定義の `$ref`）で、案のキーの表の説明と使用先を `description`・`x-rules` に写す | ID を接頭辞で持たない 3 種類（`agent_flow`・`eval_criterion`・`eval_case`）は `x-id-prefix` を持たない |
| `type` で持つキーを分ける種類 | `llm_call` の `type`、`agent_flow` の `type` と `steps[].calls[].type`、`eval_criterion` の `method` は、`oneOf` か `if`/`then` で種類ごとの必須を検査する | 既存のスキーマの判別の書き方に合わせる |
| インターフェース定義 | `read_only`・`destructive` を任意の boolean として追加する | 既存の設計書は検査を通ったまま |
| 共通の型 | `agent`・`llm_call` の `model` と、`launch`・`llm_call` の `timeout` を `common.schema.yaml` の `$defs` に置く | メタスキーマの「種類をまたぐ型は共通の定義に置く」に合わせる |
| テンプレート『スキル』 | `template-skill.yaml`・`skill.schema.yaml`・`rules.yaml` の行を削除し、`dev-docs.yaml` の `skill` の配信元は残して `schema` だけ替える | `text-review.yaml` の配信と用語の照合を続ける |
| `dev-docs.yaml` の `skill` の配信元 | `agent_flow` の文書は `kind` を持たないので、`converter`（`knowledge-markdown`）を外し、`metadata` を `title`・`summary`・`tags` から引く | `validators` の `knowledge-checks` は `kind` に依らないので残す |
| 変換のスクリプトの結合テスト | `test_normal_when_kind_specific_keys` の `kind: skill` を、`schemas/` の直下に固有のキーを持つスキーマがあるほかの種類に替える | `skill.schema.yaml` を削除すると、ケースが読むスキーマが無くなる |
| `text-review.yaml` | 今の入力・手順・分岐を、`agent_flow` の `type: skill`（`skill.path` は `skills/text-review/SKILL.md`）と `steps[]` に写す | SKILL.md の生成はスコープ外 |
