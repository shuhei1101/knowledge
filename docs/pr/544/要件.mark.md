# 要件

## 要望

knowledge の SKILL.md の自動生成を廃止し、SKILL.md をスキルの設計書（`docs/skill/`）を見ながら手で記載するファイルにする（[ユーザーの判断](https://github.com/shuhei1101/knowledge/pull/544#issuecomment-7074367837)）。
設計書は実装に要る項目の記載漏れを防ぐためのもので、SKILL.md には設計書に無い細かい記述も要るため、設計書と SKILL.md の二重管理にする。
設計書と SKILL.md の食い違いはレビューで確認し、自動の比較もしない。

- 独自の生成のコマンド（`scripts/build_skills.py`・ロック・単体と結合のテスト・IF-312-1・MOD-312-1・SC-312-1）を削除する
- 全ての文書の検査（IF-72-3 / `scripts/check_all.py`）から、SKILL.md と生成元の比較を削除する
- `project-index skill-md` は配信元の設定に登録しない。`docs/skill/` の置き場所と種類の ID `skill` は今のままにする
- SKILL.md の生成元のコメント（設計書から生成した・このファイルを修正しない旨）を削除する
- SKILL.md を生成すると書いている記述（開発コマンド・フォルダ構成・README・`agent_flow` のスキーマとテンプレート・判定フローチャート『機能を呼ぶインターフェースの選び方』・`files.yaml` の概要文）を、設計書を参照して手で記載する記述に改める
