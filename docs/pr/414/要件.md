# 要件

## 要望

テスト実行方法 [TP-72-1](https://github.com/shuhei1101/knowledge/blob/99c4a8fe22de9638b4e089ac480978cf8e65530a/docs/test-procedure/TP-72-1.yaml) で `location: runner` の層を、`run_runner` でランナーで回し、手元の `run_all` の結果と突き合わせる。

| 層 | 終わりの条件 |
| --- | --- |
| TL-2 単体テスト（バック） | `run_runner` の実行が成功し、Python 3.14 の `tests/unit` と Python 3.12 の `tests/unit/slop-check` のそれぞれで、passed・skipped の件数が手元の `run_all` と一致する |
| TL-3 結合テスト（バック） | `run_runner` の実行が成功し、`tests/integration` の passed・skipped の件数が手元の `run_all` と一致する |

件数が一致しない、またはランナーでだけ失敗する場合は、原因を調べて `.github/workflows/test.yml` かテストを修正し、一致するまで回し直す。
