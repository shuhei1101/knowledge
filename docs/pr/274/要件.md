# 要件

## 要望

- knowledge のフォルダ構成の設計書 `docs/layout/LAY-72-1.yaml` を、テンプレート『フォルダ構成』（`schemas/design/layout.schema.yaml`）の書式で 1 枚作る
  - リポジトリの直下からの全てのフォルダとファイルを `entries[]` の入れ子で記載する
  - 生成物・複製・一時ファイルは `gitignore[]` に記載し、生成物・複製のエントリには `generated_from` を記載する
  - 中身の種類は `content_types` で記載する
- 作った設計書を規約『フォルダ構成の切り方とレビュー』（`dev-folder-layout`）のレビューの観点で確認し、見つかった問題を問題ごとに別の Issue へ起票する（この PR では対処しない）
- 既存の設計書から #265 で廃止したキーを除き、その内容を `LAY-72-1` へ移す
  - [ARCH-72-1](https://github.com/shuhei1101/knowledge/blob/11150b1/docs/architecture/ARCH-72-1.yaml) の `repository.layout`
  - [MOD-72-1](https://github.com/shuhei1101/knowledge/blob/11150b1/docs/module/MOD-72-1.yaml)・[MOD-148-1](https://github.com/shuhei1101/knowledge/blob/11150b1/docs/module/MOD-148-1.yaml) の `directory`
- `LAY-72-1` が dev-docs の検索と全ての文書の検査（`scripts/check_all.py`）の対象に入る

`未確定`: `LAY-72-1` を検査するスキーマの配置（決める段: モジュール構成設計のレビュー）

knowledge の設計書は `dev-docs.yaml` で `schemas/` 直下の AI Monitor の配布物のコピーで検査する。
今のコピー（`ai-monitor-version.ini` の取り込み）には `layout.schema.yaml` が無く、AI Monitor の v0.4.0 はまだリリースされていない。
