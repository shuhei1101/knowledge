# 規約『ドキュメント管理』とスキーマの rev の記述を dev-docs の write_docs の挙動と一致させる

## 概要

規約『ドキュメント管理』のメタデータの表と共通のスキーマの `rev` の説明を、dev-docs の `write_docs` の挙動と一致させる。

## 背景

[Issue #151](https://github.com/shuhei1101/knowledge/issues/151) の要望。
規約『ドキュメント管理』（`docs/rule/dev-document-management.yaml`）のメタデータの表は、`rev` を「変更ごとに増えるバージョン。書き込みのツールが付ける」と定めているが、dev-docs の `write_docs` の `text_edits` で本文を書き込んでも `rev` は増えない。
[#150](https://github.com/shuhei1101/knowledge/pull/150)（起点 Issue [#147](https://github.com/shuhei1101/knowledge/issues/147)）のレビューで、reviewer が対象外の逸脱として報告した。
