## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 記録の参照 | 一覧の行ごとに記録の本文を参照し、技法を 1 文書の単位に切り分ける | 調べた記録そのものは記載せず、結論と確認した記録の要点だけを記載する |
| 配置先の判定 | 技法ごとに、ノウハウ・規約・knowledge に配置しないもののどれかを規約『ドキュメント管理』の `knowhow-01`・`knowhow-02` で判定し、判定の一覧をこの計画書に記載してレビューで確定する | 規約に該当するものは `docs/rule/` へ。既存の規約・ノウハウと同じ内容なら登録しない |
| ノウハウの文書 | `write_docs` で `kind: knowhow` の文書を作る。ID は `knowhow-{scope}-{topic}`（`scope` は `script`・`direction`・`video`・`prompt` などの英語の 1 単語）、`visibility` は `internal`、`last_reviewed` は登録した日 | `necessity`・`scenes`・`cases`・`evidence`・`confidence` はスキーマの `x-rules` で決める |
| タグ | 付ける前に `search_docs` の `group_by: tags` で使用中のタグを確認し、同じ意味のタグを再利用する | `topic:ノウハウ` は全ての文書に付ける |
| 出典 | 要件の `未確定`（出典の持ち方）の決定に従う | - |
