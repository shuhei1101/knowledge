# ノウハウの一覧 A-157 の 21 件を、種類「ノウハウ」の文書として登録する

## 概要

利用者とエージェントが、aituber の話し合いで得た台本・演出・素材のデザイン・プロンプトなどの知見を、knowledge の種類「ノウハウ」（`docs/knowhow/`）から参照できるようになる。

## 背景

[Issue #453](https://github.com/shuhei1101/knowledge/issues/453) の要望。
ノウハウの一覧 A-157（話し合いのワークスペースの資料）の 21 件は、knowledge に移す先が無かった。
[#418](https://github.com/shuhei1101/knowledge/issues/418)（作業 PR [#451](https://github.com/shuhei1101/knowledge/pull/451)）で、種類「ノウハウ」・テンプレート『ノウハウ』・規約『ドキュメント管理』の規約とノウハウの分け方が develop に入った。
