# 要件

## 要望

直下の配信元の設定 `dev-docs.yaml` の `instructions` の後に `when` を追加し、knowledge で検索する場面を 1 行ずつ記載する。

- 1 行目に最もよく使用する場面（コードの作成・レビューの前に言語・フレームワークの規約を確認する）を記載する
- 続く行に、設計書・文書の作成の前のテンプレートと記載方法の規約の確認と、判断に迷ったときの判定フローチャートの参照を記載する
- 各行は対応表『AI slop の単語の対応表』の OK の単語で記載する（Issue の記載の一案の「書く」「確かめる」「引く」は置き換える）

### 確認

- 全ての文書の検査（`scripts/check_all.py`）が通る
- `dev-docs.yaml` が project-index のスキーマの検査を通る（`describe` の一覧での表示は、develop へマージした後に配信元を読み込み直して確認する）
