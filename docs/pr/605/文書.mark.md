| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 画面設計のスキーマ（画面全体の欄） | `retained_state[]`（`what`・`store`・`key`・`save_on`・`restore_on`・`precedence`・`reset_when`）・`panes[]`・`shortcut`・`leave_guard`・`screen_type` を追加する。`screen_type` ごとに必須の要素の `kind` を `if` / `then` で検査する | Issue の表の 1・2・11・12 |
| 画面設計のスキーマ（要素の欄） | `icon`・`label_display`・`accessible_name`・`tooltip`・`narrow`・`table`・`tabs`・`close`・`initial_focus`・`return_focus`・`modal`・`disabled_reason`・`confirm`・`feedback`・`toggle_state`・`live`・`history`・`resets`・`shortcut` と、表の列の `sortable`・`pinnable`・`hideable` を `properties` に追加する | Issue の表の 3・4・6〜11 |
| 画面設計のスキーマ（必須・禁止） | #600 から移した種類ごとの必須・禁止を、#603 の `kind` を判別子にした `allOf` の `if` / `then` に `required` と `{欄: false}` で追加する。条件は各欄の `x-rules` に記載する | `additionalProperties: false` を保つ |
| 画面設計のスキーマ（文言の量） | 欄を追加せず、`label`・`hint` の `x-rules` から規約を参照する。`hint` は入力の種類以外で禁止にする | Issue の表の 5 |
| 部品設計のスキーマ | `persisted_state[]`（画面設計の `retained_state` と同じ構造を共通の定義から参照する）・`states[].viewport`（`desktop`・`mobile`）を追加し、`accessibility` を `accessible_name`・`label_display` などの構造にする | - |
| `x-rules` の参照先 | 欄ごとに Issue の表の規約の項目と、#604 で追加した規約（`ui-layout#splitter-01`・`ui-input-wording#storage-key-01`・`#retention-design-01` など）を `id:` のリンクで参照する | - |
| 記載例 | 両スキーマの `examples` を新規の欄と必須・禁止に合わせる | スキーマの検査で `examples` を検査する |
| テンプレート | `scripts/build_templates.py`・`scripts/build_markdown_templates.py` で再生成する | 手で編集しない |
| チェックシート | モック・実装した画面・部品のレビューの観点に、新規の欄のとおりかを確認する項目を追加し、保持の観点は `retained_state` を参照する | - |
| 規約 | `ui-input-wording#retention-design-01` から記載する欄（`retained_state`）を参照する | - |
| 既存の `io` の enum | 新規の enum と表記をそろえるかを、ドキュメント修正の工程で決める | `未確定` |
