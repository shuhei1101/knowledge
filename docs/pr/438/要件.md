### #419: 種類「ノウハウ」のスキーマ

`schemas/knowhow.schema.yaml` を追加する。
共通のメタデータ（`schemas/knowledge-common.schema.yaml#/$defs/metadata`）を使用し、次の項目を持たせる。

| 項目 | 内容 |
| --- | --- |
| 従う必要があるかのキー | 規約のように従う必要があるか、知っていると質が上がる参考かを表すキー |
| キーで条件を分ける項目 | 取り込みのスキル craft-intake が返却する項目（技法・使用する場面・実例・出典・確からしさ）に合わせる |

種類は `knowhow`、従う必要があるかのキーは `necessity`（`must`・`reference`）で確定した（[確認ログ](./確認ログ.yaml)）。

既存の文書・`rule.schema.yaml`・`project-index.yaml` は変えない。

### #432: `clicks[].href` の `id:` のリンク

`schemas/design/common.schema.yaml` の共通の型 `flowchart` の `clicks[].href` の `description` に、相対パス + アンカーに加えて `id:{文書の ID}`・`id:{文書の ID}#{項目のパス}` を書けることを追加し、`examples` に `id:` のリンクを追加する。
`clicks` を持つテンプレート（`template-architecture.yaml`・`template-dataflow.yaml`）を `scripts/build_templates.py` で生成し直す。
検査の結果を変えないため、develop へマージした後に `design-schemas/v*` の最新のタグのパッチを上げたタグを作成する（反映作業）。
