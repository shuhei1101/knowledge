## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 種別のスキーマの `tags`・`aliases` | `common.schema.yaml`・`index.schema.yaml` を除く種別の最上位の `properties` に、`common.schema.yaml#/$defs/tags`・`$defs/aliases` を指すキーを追加する | `layout` はそのまま。`agent_flow`・`eval_criterion` は要件.md の未確定の推奨案 A で `aliases` だけを追加する |
| 管理用の YAML のスキーマ | `files.items.properties` に `id`・`aliases`・`inject_when` を追加する。`inject_when` は `knowledge-common.schema.yaml#/$defs/inject_when` を参照し、`id`・`aliases` はその場に定義する | `id` は他のプロジェクトの ID（例 `PH-3038-29`）を通すため、英小文字のケバブケースの `$defs/id` を参照しない。`additionalProperties` は閉じないまま変えない |
| 検索・配信の持ち主の記述 | `schemas/design/` の「dev-docs の検索で」「dev-docs の配信で」「dev-docs が配下の文書の ID を…」を project-index にする | 「dev-docs の画面…」は変えない |
| テンプレート | `uv run --frozen --script scripts/build_templates.py` で生成し直す | 生成のスクリプトは変えない |
| 確認 | 全ての文書の検査（`scripts/check_all.py`）を実行する | ログを `テスト結果/` に配置する |
| 設計書のスキーマのタグ | develop へマージした後に、`design-schemas/v8.0.0` のマイナーを上げたタグを squash commit へ打ち、shuhei1101/ai-monitor#3430 へ連絡する | 反映作業 |
