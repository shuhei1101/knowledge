# 要件

## 要望

dev-docs の文書の MCP・管理の MCP のツールの完全名を、次のとおり project-index のプラグインの完全名に書き換える。

| 今 | 書き換えた後 |
| --- | --- |
| `mcp__plugin_dev-docs_dev-docs__{ツール名}` | `mcp__plugin_project-index_project-index__{ツール名}` |
| `mcp__plugin_dev-docs_dev-docs-admin__{ツール名}` | `mcp__plugin_project-index_project-index-admin__{ツール名}` |

- 対象は `skills/text-review`・`docs/skill/text-review.yaml`・`plugins/slop-check`・設計書（SC-148-1・IF-148-1・MOD-148-2）・`tests/`（unit・integration の slop-check）
- `slop_check.py` の `MCP_TOOLS` の MCP サーバーを見分ける単語 `dev-docs` を `project-index` にし、`mcp__plugin_project-index_project-index__write_docs` を照合の対象にする
- 規約を読む案内（`NOTICE_TAIL`・スキル text-review）は `mcp__plugin_project-index_project-index__search_docs` を指す
- 修正した後に slop-check の単体テスト・結合テストと `uv run --frozen --script scripts/check_all.py` の合格を確かめる
- [shuhei1101/dev-docs#163](https://github.com/shuhei1101/dev-docs/pull/163) のマージと同じ時期に入れる
