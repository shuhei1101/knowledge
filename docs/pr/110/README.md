# 判定フローチャートの本文の出典の表を、メタデータの sources へ移す

## 概要

判定フローチャートを読む AI が、本文で決めたことだけを読み、参考にした出典はメタデータの `sources` から引けるようになる。

## 背景

[Issue #105](https://github.com/shuhei1101/knowledge/issues/105) の要望。
react移行計画の D-59 で、参考にした公式ドキュメントの URL・ライブラリとバージョン・確かめた日はメタデータに持たせ、本文には決めたことだけを書くと決めた。
[PR #104](https://github.com/shuhei1101/knowledge/pull/104)（起点 Issue [#101](https://github.com/shuhei1101/knowledge/issues/101)）が `schemas/common.schema.yaml` の `metadata` に `sources` を追加して規約の出典を移したが、規約以外の種類の文書は対象外で、判定フローチャートの本文に出典の表が残っている。
