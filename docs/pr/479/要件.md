# 要件

## 要望

workflow のテストで、`gh workflow run` の出力から実行の ID を取った後、`gh run watch` を呼ぶ前に、実行を API で参照できるまで待つ。

- 待ち方は [#476](https://github.com/shuhei1101/knowledge/pull/476) のテスト実行方法 TP-72-1 の `run_runner` と同じにする。`gh api "repos/{owner}/{repo}/actions/runs/{ID}?exclude_pull_requests=true"` を 1 秒おきに最大 10 回試し、参照できなければ失敗で終える
- 規約『GitHub Actions の workflow のテスト』の steps-01 の手順 2 と 3 の間に、実行を API で参照できるまで待つ手順を入れる
- `tests/e2e/workflow/conftest.py` の `_watch` の前に同じ待ちを入れ、10 回で参照できなければ、実行の ID を含むメッセージでテストを失敗にする
- 修正した conftest で workflow の E2E テストを 1 つ実行し、実行の結論を受け取れることを確認する
