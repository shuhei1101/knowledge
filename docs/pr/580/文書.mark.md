## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 観点の要素 | ID（`aspect-{ページのスラッグ}-{2 桁の番号}`）・観点名・確認すること・補足・タグ（`target:`・`process:`。`target:` を 1 つ以上）・公開範囲を持つ | 要素のキーは [shuhei1101/ai-monitor#3826](https://github.com/shuhei1101/ai-monitor/pull/3826) の `schemas/review-aspect.schema.yaml` にそろえる |
| ファイルの配置 | 要件の `未確定` の案で決める | `未確定`（決める工程: インターフェース定義設計） |
| 配信の行 | 観点の要素を `records` で 1 件ずつ文書にする行を追加し、`metadata` の `tags` を要素のタグから取る。`checksheet` の行は残し、ページは引き続き 1 文書で配信する | - |
| `nav` | チェックシートのまとまりの下に、観点の文書のまとまりを追加する | - |
| `checksheet-review-common` | 表の 20 行を要素へ書き換え、各要素に `target:共通` を付ける。概要の項目と `related` は残す | 工程に限られる観点には `process:` も付ける |
| テンプレート | `template-checksheet` に、観点を要素で持つときの書式を追加する | - |
