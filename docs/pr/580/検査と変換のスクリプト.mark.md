## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| knowledge-checks | 観点の要素の ID の重複を、`items[].id` とは比べずに `aspects[]` の中で違反にする | `id:` の参照の実在は今の検査が全ての文字列に適用し、観点の `description`・`note` も対象になる |
| knowledge-markdown | 変えない。`aspects` は種類に固有のキーとして、スキーマの `title` の列名の表で出る | - |
| 全ての文書の検査 | 変えない。同じファイルは最初に当たった `checksheet` の行で 1 件にして検査する | 配信の行は `checksheet` の行の後ろに配置する |
| 単体テスト | 観点の要素の ID の重複の違反を確認するテストを追加する | - |
| 結合テスト | 文書の違反の検査に、正常系（観点の ID の重複）のテストを追加する | - |
