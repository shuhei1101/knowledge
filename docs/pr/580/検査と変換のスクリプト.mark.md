## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| knowledge-checks | 観点の要素の ID の重複と、`description`・`note` の `id:` の参照先の実在を違反にする | ID の重複は `items[].id` とまたいで判定するかをインターフェース定義設計で決める |
| knowledge-markdown | チェックシートのページの Markdown に、観点を ID・観点名・確認すること・補足・タグの表で出す | ファイルの配置が案 B なら、観点のファイルの変換を決める |
| 全ての文書の検査 | 追加した `records` の行のファイルに、行の `schema` の検査と文書の違反の検査を適用する | - |
| 単体テスト | 観点の要素の ID の重複・参照先の不在の違反と、観点の表の変換を確認するテストを追加する | - |
| 結合テスト | 全ての文書の検査が追加した行のファイルを含めて合格することを確認する | - |
