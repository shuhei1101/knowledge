## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| タブの並び | 入口（はじめに・使い方）→ 抽象（設計書）→ 詳細（規約・コード）→ 参照用（リファレンス・用語集）の順を決まりにし、自動の並び（ファイル名の順）に任せず `nav.tabs[]` で順を指定する | 具体的な順は `未確定`（[要件](./要件.md)） |
| タブの数 | 出典の裏付けが取れたら、最上位のタブの数の上限を決まりにする。設計書の種類はタブ「設計書」1 つにまとめ、種類をサイドバーのグループにする | - |
| サイドバー | タブの中の文書は `group` か `auto.group_by` でグループにする（機能の単位など）。入れ子の深さと 1 つの一覧の件数の目安は、出典の裏付けが取れたものだけを決まりにする | - |
| 目次 | `kind: index` の文書を `auto.filter` で除き、タブとサイドバーに並べない | `@folder` の先頭の `index.yaml` も除く |
| 配置場所と名前 | 推奨は新しい規約 `docs/rule/dev-docs-navigation.yaml`（『開発ドキュメントのナビゲーション』） | `未確定`（[要件](./要件.md)） |
