# MCP のポートの台帳を規約から削除し、端末のローカルの ~/.config/mcp-ports.yaml を参照する

## 概要

規約『MCP サーバー作成ルール』の既定のポートの台帳の表を削除し、台帳は端末のローカルの `~/.config/mcp-ports.yaml` を参照する記載に変更する。

## 背景

[Issue #78](https://github.com/shuhei1101/knowledge/issues/78) の要望。
規約『MCP サーバー作成ルール』（`docs/rule/claude-mcp.yaml`）の `registration-12` は、他リポジトリの MCP サーバーの環境変数と既定のポートを表で持つ。
knowledge は公開リポジトリのため他リポジトリのポートの一覧を記載せず、サーバーを追加するたびに Issue・PR を作成せずに済むよう、台帳を Git の外の `~/.config/mcp-ports.yaml` に移す。
`~/.config/mcp-ports.yaml` は作成済みで、表の 7 行と aituber（`AITUBER_PORT`・8785）を記載している。
