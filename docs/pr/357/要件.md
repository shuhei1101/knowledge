# 要件

## 要望

規約『VS Code 拡張機能の配布』（`docs/rule/dev-vscode-extension-distribution.yaml`）の `publish-01` を、Marketplace へは Trusted Publishing でタグから CI で公開する決まりに書き直す。

- ユーザーに、Marketplace の publisher 管理画面の Trusted Publishing でポリシー（Repository owner・Repository・Workflow のファイル名・Environment）の登録を依頼する
- 公開のジョブに `permissions: id-token: write` を付け、`vsce publish --oidc` で公開する
- CI の公開の工程ができるまでは、.vsix を publisher 管理画面からアップロードして公開する
- グローバル PAT では公開しない
- Open VSX へは公開しない（ユーザーの回答。確認ログ）

終わりの条件:

- 規約『VS Code 拡張機能の配布』に、Marketplace へ Trusted Publishing でタグから公開する決まり（ポリシーの登録の依頼・`id-token: write` と `vsce publish --oidc`・CI ができるまでの .vsix の手動アップロード）がある
- 規約『VS Code 拡張機能の配布』に、Open VSX へは公開しない決まりがある
- `uv run --frozen --script scripts/check_all.py` が合格する
