# 要件

## 要望

規約『ルール索引への登録』（`dev-rule-index-registration`）の強制注入の 4 つの基準で、次の 2 件を `rules.yaml` に掲載するかを判定し、満たすものをエントリとして追加する。

| 規約 | ai-monitor で案内していた場面（`paths`） |
| --- | --- |
| 『V字モデル』（`dev-v-model`） | `**/docs/generated/**/*.md` |
| 『プロジェクト名の表記』（`convention-project-name`） | `**/docs/**`・`**/README.md` |

追加するエントリは、同規約の `paths` の記載と `read_tool` の記載（`search_docs` に `source`: `knowledge`・文書の ID の `filter`・`view: full`・`outside_scope: true`）に従う。

2 件とも 4 つの基準を満たすと判定し、次の場面で掲載する。

| 規約 | 本文の文字数 | 案内する場面 | 場面を選んだ理由 |
| --- | --- | --- | --- |
| 『V字モデル』 | 3709 | `**/tests/{unit,integration,e2e,nfr,external}/**` の書き込みと、対応表に載る設計書（非機能要件・アーキテクチャ図・シナリオ・インターフェース定義・画面設計・部品設計・モジュール構成）のフォルダの書き込み・`write_docs` の書き込み | 対応表のテストの場所と設計書の種類で、設計書を記載するときとテストを新設するときに届く。どちらの書き込みも、広い glob で先に案内される規約とテンプレートの例外に該当するスキーマを除いた合計は 10KB 以内 |
| 『プロジェクト名の表記』 | 909 | `**/README.md`・`**/docs/guide/*.{md,yaml}` と、`write_docs` の `guide-` で始まる ID の書き込み | 規約の表示側の対象のうち、ルートの `README.md` と公開ドキュメントのページの見出し・本文に絞る。`**/docs/**` は「glob が狭い」を満たさない |
