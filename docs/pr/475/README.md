# 動画の演出の技法と、セリフの採点観点とプロンプトの技法を、種類「ノウハウ」の文書として登録する

## 概要

利用者とエージェントが、aituber の話し合いで得た動画の演出（SE・BGM・背景・エフェクト・ズーム）の技法と、セリフの採点観点とプロンプトの技法を、knowledge の種類「ノウハウ」（`docs/knowhow/`）から参照できるようになる。

## 背景

[Issue #474](https://github.com/shuhei1101/knowledge/issues/474) の要望で、[#465](https://github.com/shuhei1101/knowledge/issues/465)（ノウハウの一覧 A-157 の No 14〜17）と [#466](https://github.com/shuhei1101/knowledge/issues/466)（No 18〜20）を 1 本の作業 PR で行う束。
[#453](https://github.com/shuhei1101/knowledge/issues/453)（作業 PR [#460](https://github.com/shuhei1101/knowledge/pull/460)）で No 1〜9 を登録し、No 10〜20 は約 200 の技法があるため分野ごとの後続の Issue に分けると決まった（[確認事項](https://github.com/shuhei1101/knowledge/pull/460#discussion_r4597421534)）。
