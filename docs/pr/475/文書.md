## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 記録の参照 | R-23・R-24・R-39・R-40・R-44・R-47・R-48・A-68・A-69 の本文を参照し、技法を 1 文書の単位に切り分ける | 調べた記録そのものは記載せず、結論だけを記載する |
| 配置先の判定 | 技法ごとに、ノウハウ・規約・knowledge に配置しないもののどれかを `knowhow-01`・`knowhow-02` で判定し、判定の一覧をこの計画書に記載してレビューで確定する | 既存の `knowhow-direction-*`・規約『プロンプトファイル』と同じ内容なら登録せず、既存の文書を指す |
| ノウハウの文書 | `write_docs` で `kind: knowhow` の文書を作る。ID は演出が `knowhow-direction-{topic}`、採点観点とプロンプトが `knowhow-prompt-{topic}`（採点観点が `prompt` に当たらない場合は英語の 1 単語の `scope` を決めて判定の一覧に記載する）。`visibility` は `internal`、`last_reviewed` は登録した日 | `necessity`・`scenes`・`cases`・`evidence`・`confidence` はスキーマの `x-rules` で決める |
| 既存のノウハウの実例 | `knowhow-prompt-open-ended-line` の `cases` に A-68・A-69 の PoC の結論を加える | 他のキーの文章は変えない |
| タグ | 付ける前に `search_docs` の `group_by: tags` で使用中のタグを確認し、同じ意味のタグを再利用する | `topic:ノウハウ` は全ての文書に付ける |
| 出典 | 記録が持つ Web の URL を `sources` にする | 手元のパスを記載しない（#460 の[確認事項](https://github.com/shuhei1101/knowledge/pull/460#discussion_r4597420523)の決定） |

### 記録ごとの判定

記録の行ごとに、規約『ドキュメント管理』の `knowhow-01`・`knowhow-02` で配置先を判定した。
いずれも守らなくても成り立つが知っていると質が上がる知見で、複数のプロジェクトで使用できるため、規約ではなくノウハウにした。
