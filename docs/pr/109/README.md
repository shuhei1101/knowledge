# テンプレートの例に残る mypy と Python 3.12 を pyright strict と Python 3.14 に揃える

## 概要

テンプレートを使って設計書を書く AI が、Python の規約と同じ型検査（pyright strict）と Python のバージョン（3.14）の例を参照できるようになる。

## 背景

[Issue #102](https://github.com/shuhei1101/knowledge/issues/102) の要望。
[PR #100](https://github.com/shuhei1101/knowledge/pull/100) で Python の規約の型検査を pyright（basedpyright）strict に（D-41）、Python のバージョンを 3.14 に（D-42）改めたが、テンプレートの例には前の値（mypy・Python 3.12）が残っている。
PR #100 の確認事項（[スレッド](https://github.com/shuhei1101/knowledge/pull/100#discussion_r4418198350)）で、別の作業 PR で改訂すると決まった。
