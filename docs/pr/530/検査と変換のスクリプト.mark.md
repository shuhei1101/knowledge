## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ネットミームの検査 | 新規の検査のスクリプト `memes/scripts/meme_checks.py`（IF-514-1 の `meme-checks`）で、下の 2 行を検査する | ネットミームの行だけに指定し、作品の行には指定しない。`knowledge_checks.py` は変えない |
| 作品の実在 | ネットミームの `work` が、新規の配信元の作品の `id` に実在しなければ違反にする | 書き込みの検査と全ての文書の検査の両方 |
| タグの語彙 | 作品とその用語の作品・話題のタグ（`topic:{名前}`）が一致すること、ネットミームが内容の分類のタグ（`topic:セリフ` など 7 つ）をちょうど 1 つ持つことを検査する | 場面のタグは語彙を固定しないため検査しない。違反は IF-514-1 の結合テストで確認する |
| 型の検査 | `styles[].type: parody` の `patterns` の有無はスキーマの `if`・`then` で検査し、スクリプトでは検査しない | 違反は全ての文書の検査（IF-72-3）の正常系で確認する |
| 全ての文書の検査 | 規約の配信元に加え、新規の配信元の設定の `documents[]` が指す文書にもスキーマの検査と上の検査を適用する | - |
