## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 配信元の設定 | 新規の配信元の設定のファイルに、作品とネットミームの `documents[]` の 2 行・検査・`direct_commit`（`branch: develop`・`kinds` に 2 つの種類）を記載する。`alias_type` は持たせない | 配置先と ID は `要件.mark.md` の `未確定` |
| スキーマ | 作品とネットミームのスキーマを `schemas/` に新規作成する。条件があるキーは `if`・`then` にする | キーは MindStella の資料『データ: ネットミーム』のとおり |
| 共通のキーへの対応 | `documents[].metadata` で `name`・`description`・`tags`・`related` を対応させ、`status` には対応させない | ネットミームの `description` は `context` と `use_when` をつないだ文 |
| 検索の分離 | 規約の配信元の `documents[]`・`files.yaml` の範囲から、新規の配信元のフォルダを除外する | 規約の検索の結果とタグの集計に混ざらない |
| 使い方 | 新規の配信元を端末の設定の `sources[]` に登録する手順と、`direct_commit.scope` の記載を追加する | - |
