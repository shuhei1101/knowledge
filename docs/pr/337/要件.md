# 要件

## 要望

knowledge の文書の検査（書き込みの検査 `knowledge_checks.py` と全ての文書の検査 `check_all.py`）が maid を呼ばず、maid が PATH に無くても検査を始める。

### 規約

- 規約 `docs/rule/dev-yaml.yaml` の `inspection-04` の「mermaid の文法など」の例、`inspection-05`（mermaid の検査）、`tool:mermaid` のタグを削除する

### 検査と変換のスクリプト

- `scripts/_maid.py` を削除し、`knowledge_checks.py`・`check_all.py` から maid の在りかの確認・mermaid のブロックの検査・maid が無いときの終了コード 2 を削除する
- `scripts/files.yaml`・`ruff.toml` の `_maid.py` の記述を削除する
- テスト（unit・integration）の maid の差し替えと、maid の検査のテスト（`tests/unit/scripts/test_maid.py` 等）を削除する

### 設計書

- 単一ユースケース『開発者が文書の違反を検査する』（SC-72-6）の maid の確認と、maid が見つからないときの異常シナリオを直す
- 単一ユースケース『エージェントが knowledge の文書を書き込む』（SC-72-5）の mermaid の違反を前提にした異常シナリオを、別の違反（ID の重複 等）へ置き換え、maid を入れる前提条件を削除する
- インターフェース定義・モジュール構成・外部ライブラリ・アーキテクチャ図・開発コマンド・非機能要件・テスト実行方法・配置の maid の記述を削除する（要件.yaml の `docs`）
