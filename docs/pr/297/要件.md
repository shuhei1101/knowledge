# 要件

## 要望

着手の時点の次のファイルで、対応表のコピー（`plugins/slop-check/hooks/post-tool-use/word-list-ai-slop.json`）の照合にヒットする単語を、対応表『AI slop の単語の対応表』（`docs/word-list/word-list-ai-slop.yaml`）の OK の単語へ置き換える。

| フォルダ | ファイル |
| --- | --- |
| `docs/changelog.yaml` | 同左 |
| `docs/guide` | `guide-setup-apply-rule-index.yaml`・`guide-setup-docs-mcp.yaml`・`guide-setup-import-rule-changes.yaml`・`guide-setup-install-plugin.yaml` |
| `docs/decision-table` | `decision-table-alias-exclusion.yaml`・`decision-table-dataflow.yaml`・`decision-table-poc.yaml` |
| `docs/skill` | `text-review.yaml` |
| `docs/checksheet` | `checksheet-design-change-impact.yaml` |

- 変更履歴は、過去のバージョンの行も対象にする。行の `body` は PR の要約の文で、PR へのリンクと要約の内容は変えずに単語だけを置き換える
- NG の単語でないと意味が通らない箇所（引用・固有の名前・コマンドやキーの値など）は残す
- 修正した後に `uv run --frozen --script scripts/check_all.py` の合格を確かめる
