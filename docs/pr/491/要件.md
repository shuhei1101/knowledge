# 要件

## 要望

`schemas/design/common.schema.yaml` の次の 2 つの `pattern` を、IF-6 の制約「参照の型の項目のパス」の書き方（`[...]` の中の対応の取れた `[` `]` は値の一部、対応の取れない `[` `]` は記載方法の誤り）に合わせる。

- 共通の型 `ref`（55 行目）
- 共通の型 `related_item` の `item`（`refs[].item`。97 行目）

今の `pattern` は `[...]` の外の `]` を許可するため、`IF-6#request[operations[].fields].description` は `[operations[]` と `.fields]` に分かれて一致し、断られていない。
一方で、対応の取れない `[` `]` を含む値（`#notes[a[b]`・`#x]`）も一致する。

`pattern` の `[...]` の部分は、中に `[` `]` を含まない文字か、`[` `]` を含まない `[...]` を並べたもの（`\[(?:[^\[\]]|\[[^\[\]]*\])*\]`）にする。
`[...]` の外の文字は、空白・`[`・`]` 以外（`[^\s\[\]]`）にする。

| 値 | 今 | 変更後 |
| --- | --- | --- |
| `IF-6#request[operations[].fields].description` | 一致する | 一致する |
| `#notes[a[b]]` | 一致する | 一致する |
| `IF-12#flows[正常系]`・`#functions[main#3]`・`CFG-3#`・`#notes[main.py の補足]`（今の `examples`） | 一致する | 一致する |
| `#notes[a[b]`（`[` の対応が取れない） | 一致する | 一致しない |
| `#x]`（`]` の対応が取れない） | 一致する | 一致しない |
| `#a[b[c[d]]]`（`[...]` の中に 2 段以上の入れ子） | 一致する | 一致しない |

develop の `docs/` の設計書の参照の値（`{ID}#` で始まる文字列と `item` の値の 290 件）に、変更後に一致しなくなる値は無い。

`未確定`: 対応の取れない `[` `]` を含む値を `pattern` で断るか（決める段: ドキュメント修正）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 上のとおり `pattern` を IF-6 の書き方に合わせ、対応の取れない `[` `]` と 2 段以上の入れ子を断る | 検査が IF-6 の書き方と一致し、`write_docs` が誤りにする値を検査の段階で返せる | 今一致する値を断るため、knowledge の外の設計書にその値があると検査の結果が変わる |
| B | `pattern` は変えず、`x-rules`・`examples` だけを追加する | 今一致する値の検査の結果を変えない | 対応の取れない `[` `]` を含む値を検査で返せない |

推奨: A

要望は IF-6 の書き方への追随で、今の `pattern` は対応の取れた値を偶然一致させているだけのため。
ドキュメント修正で、`design-schemas/v*` を参照するリポジトリの設計書にも一致しなくなる値が無いかを確かめ、あればタグのメジャーを上げる。

`ref` の `x-rules` に「`[...]` の中の対応の取れた `[` `]` は値の一部として読む」決まりを、`examples` に `IF-6#request[operations[].fields].description` を追加する。
`related_item` の `item` は `x-rules` で「`ref` の `#` より後と同じ」と定めているため、`x-rules` を変えない。

`pattern` を写した `docs/template/template-*.yaml` のキーの表は、`scripts/build_templates.py` で生成し直し、手で編集しない。

develop へマージした後に、`design-schemas/v*` のタグを打つ（反映作業）。

### 完了の条件

- 上の表の値が、変更後の列のとおりに `pattern` に一致する・一致しない
- 全ての文書の検査（`scripts/check_all.py`）が通る
- develop へマージした後に `design-schemas/v*` のタグを打っている
