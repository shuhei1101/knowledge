## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| データのスキーマ | `schemas/design/data.schema.yaml` を、案 A-143 のキーの一覧（`fields[].immutable` を除く）と、実例「データ: 動画」から抜き出した見本の YAML で作る。`fields[].type` は論理の型の `enum` にする | キーごとに `examples` を記載する |
| データの決まり | トップの `x-rules` に、書き込みの単位ごとに 1 ファイル・同じ使われ方をするデータだけを 1 つのオブジェクトにまとめる・持ち主のオブジェクトを 1 つ決めてほかは `ref` で参照する・関連の図を記載しない、を記載する。`fields[].title` の `x-rules` に、画面のラベルと同じ名詞にして動詞を入れない、を記載する | 悪い例（`作成した時刻`）を `x-bad-examples` に記載する |
| データのテンプレート | `TEMPLATE_IDS` に `data` を登録し、生成のコマンドで `docs/template/template-data.yaml` を作る。メタデータ（`id`・`name`・`description`・`tags`）は手で記載する | 本文（`items`）は生成物 |
| ER 図のキー | `tables[].source`（必須）・`tables[].columns[].source`・`tables[].indexes[].where`・`tables[].transaction` を追加し、トップの `examples` に値を記載する | - |
| ER 図の説明 | `description` と `x-rules` に、DB 設計のレイヤーで、`tables[].source` でデータのオブジェクトとキーを指し、項目の意味・一意の範囲・状態の遷移はデータに従うことを記載する | `template-er.yaml` を生成し直す |
