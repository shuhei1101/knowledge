# 要件

## 要望

データの設計書の種類（data）を `schemas/design/` に追加して `docs/template/` にテンプレートを生成し、『ER図』を、上のレイヤーのキーを指す DB 設計のレイヤーにする。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| レイヤー | 「データ」（オブジェクトの構造）は利用者がレビューし、項目と意味・まとまりの境界・識別子と一意の範囲（冪等の鍵）・ほかのまとまりへの参照・状態と遷移・保持と削除・読み書きするインターフェースを持つ。『ER図』は DB 設計のレイヤーで、テーブルの分け方・物理名・型・制約・インデックス・トランザクションの境界を持ち、レビュアーが確認する |
| スキーマ | `schemas/design/data.schema.yaml` を追加する。`x-kind` は `data`、`x-folder` は `docs/data`、`x-id-prefix` は `DATA`、`title` は `データ: {オブジェクトの名前}` |
| キー | 案 A-143 のキーの一覧に従う（`id`・`title`・`lead`・`datastore`・`fields[]`（`key`・`title`・`type`・`required`・`description`・`example`・`unique`・`ref`）・`keys[]`（`fields`・`where`・`used_by`）・`states[]`（`field`・`transitions[]`（`from`・`to`・`trigger`））・`lifecycle[]`（`key`・`growth`・`retention`・`deletion`）・`usage[]`（`interface`・`access`・`fields`）・`refs`・`notes`）。`fields[].immutable` は持たない |
| `fields[].type` | `string`・`int`・`bool`・`datetime`・`enum`・`object`・`array`・`ref` の論理の型だけを持ち、データベースの型を持たない |
| 決まり | スキーマの `x-rules` に次を記載する。1 ファイル = 書き込みの単位（1 つのトランザクションで整合を保つ）のオブジェクト 1 つ。1 つのオブジェクトにまとめるのは同じ使われ方をするデータだけにし、種類ごとに使用するキーが分かれるものは種類ごとに別のオブジェクトにする。論理名（`fields[].title`）は画面のラベルと同じ名詞にし、動詞を入れない。関連の図を記載せず、親子の関連はキーの入れ子、ほかのまとまりとの関連は `ref` で表す。1 つのデータが 2 つのオブジェクトにまたがるときは、持ち主のオブジェクトを 1 つ決め、ほかは `ref` で参照する |
| 見本 | スキーマの `examples` は、実例「データ: 動画」（A-140）から抜き出して記載する |
| 『ER図』のキー | `er.schema.yaml` に `tables[].source`（必須）・`tables[].columns[].source`・`tables[].indexes[].where`・`tables[].transaction` を追加する |
| 『ER図』の説明 | `er.schema.yaml` の `description`・`x-rules` に、DB 設計のレイヤーで、項目の意味・一意の範囲・状態の遷移は「データ」に従うことを記載する |
| テンプレート | `scripts/build_templates.py` の `TEMPLATE_IDS` に `data` を登録し、生成のコマンドで `docs/template/template-data.yaml` を作り、`template-er.yaml` を生成し直す。CI の全ての文書の検査で、スキーマとテンプレートが一致する |
| 規約『V字モデル』 | 行を追加しない。『ER図』にも行が無く、データの構造は、`usage[]` で読み書きするインターフェースの結合テストが確認する |
| スキーマのタグ | 必須の `tables[].source` で既存の ER 図の設計書が検査を通らなくなるため、`design-schemas` のメジャーを上げたタグ（`design-schemas/v5.0.0`）を作成する（反映作業）。[#210](https://github.com/shuhei1101/knowledge/issues/210) は close 済みのため、同じメジャーにまとめない |
