# 要件

## 要望

#484・#481 で出典の URL が見つからなかった台本の技法について、Web 検索とは別の経路（画像の PDF のページを画像にして参照する・書籍と論文の書誌や出版社のページ・Reddit や YouTube の字幕以外の書き起こし）で出典を確認する。
確認できた技法は、テンプレート『ノウハウ』のとおり 1 技法 1 文書で `docs/knowhow/knowhow-script-{topic}.yaml` に登録するか、#484・#481 で登録した既存の文書へ追記する。
既存の文書と同じ内容の技法は新規に登録せず既存の文書を指す。
確認できなかった技法は、調べた出典・経路と確認できなかったことを `文書.md` の判定の一覧に記録して打ち切る。
公開リポジトリに手元のパスを記載しない（#460 の[確認事項](https://github.com/shuhei1101/knowledge/pull/460#discussion_r4597420523)の決定）。
判定と書き方は #470・#481 の `文書.md` の `## 変更方針` に合わせる。
登録・追記した文書は、書き込みの検査と全ての文書の検査に通る。
