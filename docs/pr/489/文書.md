## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 判定と書き方 | #470 の [docs/pr/470/文書.md](https://github.com/shuhei1101/knowledge/blob/c0cc874/docs/pr/470/%E6%96%87%E6%9B%B8.md) と #481 の `文書.md` の `## 変更方針` と同じ | ID は `knowhow-script-{topic}`、`visibility` は `internal`、`last_reviewed` は登録した日 |
| 調べる単位 | 技法ではなく出典ごとに調べ、1 つの出典で確認できた技法をまとめて判定する | 例: 中田 2014 の 1 本で 4 技法 |
| 画像の PDF | PDF のページを PyMuPDF で PNG にし、画像を直接参照して本文を確認する | `uv run --with pymupdf` で一時の環境に入れる。sudo を要する `tesseract`・`ocrmypdf`・`pdftoppm` は導入しない |
| 書籍・論文 | 書誌・出版社のページ・機関リポジトリ・CiNii・J-STAGE の抄録や目次で、該当する記述を確認する | 書誌だけで記述を確認できない出典は、確認できなかったものとして扱う |
| 発言・講評 | 番組・講義の書き起こし（記事・Reddit・YouTube の概要欄やコメントの書き起こし）で、該当する発言を確認する | 字幕の自動生成は出典にしない |
| 登録と追記 | 既存の `knowhow-script-*` と同じ技法の部分は、`write_docs` の `update` でその文書の記述と `sources` に追記し、既存の記述は変えない | 新規の技法は 1 技法 1 文書で `create` |
| 確認できなかった技法 | 調べた出典・経路と確認できなかったことを `## 技法ごとの判定` に記録し、`要件.yaml` のスコープ外に `plan: none` で挙げる | #485・#486 の終了の条件のとおり、この作業 PR で打ち切る |

## 技法ごとの判定

出典の URL はスキーマの `sources[].url` で必須のため、URL を開いて該当する記述を本文で確認できた出典だけで文書を作った。
`confidence` は登録した `evidence` からスキーマの `x-rules` で決めた（研究 1 本だけの技法は `low`）。
確認できなかった技法は登録せず、この PR で打ち切る（#485・#486 の終わりの条件）。
