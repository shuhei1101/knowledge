# 要件

## 要望

プラグイン knowledge は直下（`.claude-plugin/plugin.json`・`skills/`）、プラグイン slop-check は `plugins/slop-check/` のまま移さず、knowledge だけを直下に配置する理由をフォルダ構成の設計書 LAY-72-1 に記載して、配置の決まりを明示する（確認ログの決着: 案 C）。

- 理由: スキル text-review は、文書の MCP の無い端末では `${CLAUDE_PLUGIN_ROOT}/docs/rule/{ID}.yaml` の規約を参照する（`skills/text-review/SKILL.md`・`docs/skill/text-review.yaml`）。マーケットプレイスから入れたプラグインは `source` のフォルダだけがキャッシュへコピーされるため、`source` を直下（`./`）にして `docs/rule/` をキャッシュに含める（[#98](https://github.com/shuhei1101/knowledge/pull/98) の決定）
- LAY-72-1 の補足「プラグインの配置」に、この理由と、knowledge 以外のプラグインを `plugins/{plugin}/` に配置する決まりを記載し、`.claude-plugin/` と `plugins/` のエントリの `contents` から補足を参照する
- プラグインのファイル・`marketplace.json`・`dev-docs.yaml`・シナリオは変えない
