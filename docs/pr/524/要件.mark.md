# 要件

## 要望

UI の規約に、説明のツールチップを出す要素（情報のアイコン・アイコンだけのボタン・略語など）でも、マウスのカーソルを `help`（はてな）にしない決まりを追加する。
追加した後の規約を参照すれば、どの画面でも `cursor: help` を使用しないことが分かる。

決まりは、規約『[ボタンのラベル](https://github.com/shuhei1101/knowledge/blob/7de37a5/docs/rule/ui-button-label.yaml)』のグループ「ツールチップ」に追加する。
ボタンでない要素（情報のアイコン・略語）にも当てはまることは、項目の文で示す。
