# 要件

## 要望

UI の規約に、説明のツールチップを出す要素（情報のアイコン・アイコンだけのボタン・略語など）でも、マウスのカーソルを `help`（はてな）にしない決まりを追加する。
追加した後の規約を参照すれば、どの画面でも `cursor: help` を使用しないことが分かる。

`未確定`: 決まりを追加する規約（決める段: ドキュメント修正のレビュー）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 規約『[ボタンのラベル](https://github.com/shuhei1101/knowledge/blob/7de37a5/docs/rule/ui-button-label.yaml)』のグループ「ツールチップ」に、ツールチップを出す要素のカーソルの項目を追加する | ツールチップの決まりが既にあるグループに並び、タグ `topic:ツールチップ` で検索できる | 規約の対象がボタンで、情報のアイコンなどボタンでない要素にも有効なことを、項目の文で示す必要がある |
| B | 規約『[操作とアクセシビリティ](https://github.com/shuhei1101/knowledge/blob/7de37a5/docs/rule/ui-operation-accessibility.yaml)』の決まりの表に、カーソルの行を追加する | ポインターの操作の決まりとして、要素の種類によらず有効になる | ツールチップの決まりと別の規約に分かれる |

推奨: A

要望の対象は説明のツールチップを出す要素で、ツールチップの決まりを持つ規約に並べると、ツールチップを付けるときに同じ箇所で参照される。
