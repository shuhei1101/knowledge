# UI の規約に、マウスのカーソルを help（はてな）にしない決まりを追加する

## 概要

UI の規約に、説明のツールチップを出す要素でもマウスのカーソルを `help`（はてな）にしない決まりを追加する。

## 背景

[Issue #523](https://github.com/shuhei1101/knowledge/issues/523) の要望。
mdmark の情報のアイコンにポインターを合わせると、マウスのカーソルが `help` になる（[mdmark#760](https://github.com/shuhei1101/mdmark/issues/760)）。
利用者はこのカーソルをどの画面でも使用しないことを求めているが、UI の規約にカーソルの種類の決まりが無い。
