# 操作の後の結果はまずアイコンの変化だけで伝えられないかを考える決まりを UI の規約に追加する

## 概要

画面の操作の結果を伝えるときに、文字の通知を追加する前に、アイコンの変化だけで伝えられないかを先に検討する決まりを UI の規約に追加する。

## 背景

[Issue #506](https://github.com/shuhei1101/knowledge/issues/506) の要望。
[shuhei1101/mdmark#700](https://github.com/shuhei1101/mdmark/pull/700) のモックで、Markdown のコピーのボタンを押した後に、アイコンをチェックに替えたうえで「Markdown をコピーしました」の通知も出す案を作り、ユーザーから「コピー完了時はチェックマークになるだけでいい」と返信を受けた（[コメント](https://github.com/shuhei1101/mdmark/pull/700#discussion_r4628702372)）。
develop の UI の規約には、操作の後の結果をアイコンの変化で伝える決まりが無い。規約『ボタンのラベル』の項目『アイコンと文字の使い分けの決まり』はアイコンだけにしてよい操作を、規約『入力と文言』の項目『エラーと通知の決まり』は通知の閉じ方と操作の数を定める。
