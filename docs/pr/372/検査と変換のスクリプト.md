## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 配信の設定 | 直下の `dev-docs.yaml` を `git mv` で `project-index.yaml` にする | 中身は変えない |
| 読み込む設定のファイル名 | `_common.py` の `CONFIG` を `"project-index.yaml"` にする。旧名へのフォールバックは置かない | 読み込む箇所は `CONFIG` を参照しているため、定数の値だけで切り替わる |
| yamllint の対象 | `check_all.py` の `YAMLLINT_EXTRA` を `("project-index.yaml", "rules.yaml")` にする | - |
| メッセージ | 設定が無い・読み込めないときのメッセージ（`{名前} がありません` 等）と違反の `fix` を `project-index.yaml` にする | 終了コード・違反の件数は変えない |
| 設計書（IF・MOD） | `dev-docs.yaml` の記述と、MOD-72-2・MOD-72-6 の定数の値を `project-index.yaml` にする | 処理・例外・テスト観点は変えない |
| テスト | 一時フォルダに配置する設定のファイル名・期待するメッセージ・直下の設定のコピー元を `project-index.yaml` にする | 観点は変えない |
| コメント・docstring・`files.yaml`・`.yamllint.yaml` | `dev-docs.yaml` の記述を `project-index.yaml` にする | - |
