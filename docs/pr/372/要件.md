# 要件

## 要望

- 直下の `dev-docs.yaml` を `git mv` で `project-index.yaml` へ改名する（中身は変えない）
- 改名の後、`docs/changelog.yaml`・`docs/pr/` を除くリポジトリの全てのファイルで、knowledge の配信の設定を指す `dev-docs.yaml` の記述を `project-index.yaml` にする。
  終わりの条件は、`git grep -n "dev-docs\.yaml" -- . ':!docs/pr/' ':!docs/changelog.yaml'` が 0 件になること
- 検査と変換のスクリプトが読み込む設定のファイル名（`scripts/_common.py` の `CONFIG`）と、yamllint を適用する直下のファイル（`scripts/check_all.py` の `YAMLLINT_EXTRA`）を `project-index.yaml` にする。
  スクリプトは `dev-docs.yaml` を読み込まない（project-index の旧名の読み込みは project-index が持つ）
- 単体・結合テストが一時フォルダに配置する設定のファイル名と、設定が無いときの標準エラー・違反のメッセージを `project-index.yaml` にし、単体・結合テストと全ての文書の検査（`scripts/check_all.py`）が全て pass する
- 使い方『knowledge を project-index の配信元に登録する』から、`project-index.yaml` が無いとき `dev-docs.yaml` を読み込む旨の文を削除する
- 端末の設定のうち、knowledge の `dev-docs.yaml` を直接指す次の 2 か所を、マージの後に `project-index.yaml` へ書き換える（反映作業）

  | 端末の設定 | 書き換える行 |
  | --- | --- |
  | `~/.config/project-index/settings.yaml` | `sources[]` の `id: knowledge` の行の `config` |
  | `~/.config/alias-inject/settings.yaml` | `global.repositories` の knowledge の行の `config` |
