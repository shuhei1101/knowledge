# 要件

## 要望

`rules.yaml` の設計書の Schema（`schemas/design/` の種類ごとの Schema と `glossary.schema.yaml`）を案内する全てのエントリで、案内の `ツール:` の行のとおりにツールを呼べば、エラーにならずに Schema の本文が返り、そのルールが既読になる。
規約『ルール索引への登録』の項目『read_tool の記載』を、`rules.yaml` と同じ記載に統一する。

Schema のエントリの `read_tool` は、`search_docs` を `{"source": "knowledge", "filter": {"field": "id", "op": "eq", "values": ["schemas/design/{種類}.schema.yaml"]}, "view": "full", "outside_scope": true}` で呼ぶ記載にする（knowledge が配信する Schema のファイルの文書を参照する）。
