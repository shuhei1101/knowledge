# 要件

## 要望

TL-2 の `run_all` が、次の構造で 2 つの pytest を回し、どちらかが失敗したら失敗で終わる。

```bash
(rc=0; {Python 3.14 の pytest tests/unit} || rc=1; {Python 3.12 の pytest tests/unit/slop-check} || rc=1; exit $rc)
```

- 2 つの pytest のコマンド（Python のバージョン・`--with` の依存とバージョン・対象のフォルダ）は変えない
- `.github/workflows/test.yml` の `layer` が `unit` のときのコマンドも、`run_all` と同じコマンドにする（[テストの全件実行のワークフロー](https://github.com/shuhei1101/knowledge/blob/8b2f90afc280a0fb2683a878b03a3e17ea6b4bc0/docs/interface/IF-352-1.yml.yaml) の制約「層の全件を回すコマンド」）
- 同じ逸脱は、develop の `docs/test-procedure/` と `.github/workflows/` で上の 2 か所だけ（`run_runner` の `&&` は、前のコマンドの結果を後のコマンドが使用するため対象外）
