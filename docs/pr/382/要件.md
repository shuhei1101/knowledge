# 要件

## 要望

| 規約 | 決めること |
| --- | --- |
| トップレベルレイアウト + feature 内構造 | `top-level-01` のツリーに、`server/` と並べてデスクトップの画面の入口 `ui/`（任意: GUI・トレイを持つとき）を加える |
| トップレベルレイアウト + feature 内構造 | `server/` のセクションと同じ粒度で `ui/` のセクションを新設し、構成例（画面ごとのウィンドウのフォルダ・スレッドの橋渡し・スタイル）と、`ui/` が `features/` を直に import せず `main.py` が組んだ関数を呼ぶ依存の向きを定める |
| 依存方向のルール | `overview` の図の最上位の層に `ui` を加え、`ui` が `features`・`integrations` を import せず `main.py` が組んだ関数を呼ぶ項目を依存方向のルールに加える。依存方向チェックの方法を layers・independence・forbidden 契約での検査に改める |
| pyproject.toml 標準テンプレート | import-linter の layers 契約の先頭を `mypkg.server \| mypkg.ui` にし、`ui` から `features`・`integrations` への import を禁じる forbidden 契約を加える |

既存の配置は変えず、任意のフォルダを 1 つ加える。
