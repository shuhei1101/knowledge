## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| トップレベルのツリー | `top-level-01` の `server/` の行の隣に `ui/`（デスクトップの画面の入口。任意: GUI・トレイを持つとき）の行を加える | 既存の行は変えない |
| `ui/` の構成例 | `server/` のセクションと同じ group の構成で `ui/` のセクションを新設し、`windows/`（画面ごとのウィンドウ）・スレッドの橋渡し・スタイル・トレイのファイルを並べたツリーを記載する | ファイル名は voice-paste の `src/voice_paste/ui/` を参考にし、GUI のライブラリに依らない名前にする |
| `ui/` の依存の向き | `ui/` は `features/`・`integrations/` を import せず、`main.py` が組んだ関数を受け取って呼ぶと定める | 型だけの参照の扱いは規約『依存方向のルール』の `type-only-import-01` に従う |
| description | 配置方法を定める対象の並びに `ui` を加える | - |
| 層の図 | 規約『依存方向のルール』の `overview` の最上位を `features / server / ui` の並びにし、`ui` が `features`・`integrations` を import せず `main.py` が組んだ関数を呼ぶことを依存方向のルールの項目（`dependency-rules-04`）に加える | `same-layer-patterns-01` の表は同層参照のパターンで、`ui` から `features` への向きは同層でないため変えない |
