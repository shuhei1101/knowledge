## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 生成物 | `docs/template/markdown/{種類}.md`（雛形）と記載例のファイルを、種類ごとに置く | ファイル名は設計の段で決める |
| 配信 | `project-index.yaml` に、`docs/template/markdown/*.md` を glob で指し、`records: files`・`body_file: path` の管理用の YAML を持つ行を加え、`nav` の「テンプレート」のグループにその行の `auto` を加える | 種類が増えても書き換えは要らない |
| タグ | Markdown か YAML かを表すタグは付けない | `documents[]` の行で区別する |
