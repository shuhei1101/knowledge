# 既存の文書を表し方の優先順位で表へ書き換え、AI slop・メタデータ・lint の違反を修正する

## 概要

knowledge の既存の文書を表し方の優先順位で表へ書き換え、不要な文と AI slop を修正し、メタデータを付け直し、lint の違反を修正して lint の全てのルールを error にする。

## 背景

[#145](https://github.com/shuhei1101/knowledge/issues/145) の要望。
規約『表し方の優先順位』・『タグと用語の登録』・対応表『AI slop の単語の対応表』が新しくなり、既存の文書は古い書き方のまま残っている。
[PR #176](https://github.com/shuhei1101/knowledge/pull/176) で追加した markdownlint・textlint は、既存の文書の違反があるルールを警告にしており、移行で違反を修正した後に error へ切り替えると決めている。
2026-11-09 のユーザーの依頼で、Mermaid の置き換え・本文の ID とパスの移動・管理用の YAML の関連は範囲から除外した。

## 計画書

| ファイル | 中身 |
| --- | --- |
| `要件.md` | 要望の整理と着手時の lint の警告 |
| `文書.md` | 文書の計画書 |
| `検査と変換のスクリプト.md` | 検査と変換のスクリプトの計画書 |
