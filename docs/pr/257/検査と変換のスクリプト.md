## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| lint の設定 | `.markdownlint-cli2.jsonc` の `"warning"` の指定と、`.textlintrc.json` の `"severity": "warning"` を削除し、error にする | ルールの閾値（`max`・`min_interval` など）は変えない |
| インターフェース定義 | 制約『警告にするルール』を、既定の設定に警告にするルールが無い構造へ修正する。警告の行を出す仕組みと終了コードの扱いは残す | 警告の仕組みは、今後ルールを追加するときに使用する |
| 結合テスト | `test_normal_when_only_warnings` は、警告の設定を書いた lint のフォルダを `--lint-dir` で指定する構造へ修正する | 一時のフォルダに設定を書き、`node_modules` は既定の lint のフォルダのものを使用する |
| 開発コマンド | 全ての文書の検査の結果の記述を、切り替えた後の実行の結果（警告 0 件）へ修正する | - |
