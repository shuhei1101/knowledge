# 開発ドキュメントのタブ「設計書」のグループ「シナリオ」を手順の順の page の並びにする

## 概要

利用者が dev-docs の画面のタブ「設計書」のグループ「シナリオ」で、シナリオを利用者の手順の順に参照できるようになる。

## 背景

[Issue #457](https://github.com/shuhei1101/knowledge/issues/457) の要望。
[#455](https://github.com/shuhei1101/knowledge/pull/455) でグループ「シナリオ」を `auto`（`document: scenario`）で並べたため、シナリオが ID の順に並んでいる。
規約『開発ドキュメントのナビゲーション』の `sidebar-02` は、`auto` の並びが手順の順と違うときは `page` を並べて順を指定すると定める。

## 計画書

| ファイル | 中身 |
| --- | --- |
| [要件](./要件.md) | 要望の整理 |
| [文書](./文書.md) | 文書のサブシステムの計画書 |
