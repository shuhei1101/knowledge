# knowledge の文書の語を、語の選び方の規約に合わせて修正する

## 概要

knowledge の `dev/`・`docs/`・テンプレート・README の語を、規約『文章の書き方』の `## 語の選び方` に合わせて修正する。

## 背景

[Issue #46](https://github.com/shuhei1101/knowledge/issues/46) の要望。
見出し・表の列名・項目名に「節」「形」「段」「足す」「版」などの和語・一字の語が多く、読み手が元の語を推測しないと意味が決まらないと、利用者から繰り返し指摘されている。
エージェントが毎回読む規約・テンプレートがこれらの語を多く使っており、出力がそれに寄るため、[#34](https://github.com/shuhei1101/knowledge/issues/34)（[#52](https://github.com/shuhei1101/knowledge/pull/52)）で入った規約に合わせて元の文書を修正する。
テンプレートは各プロジェクトへ複製されるため、各プロジェクトの同じ型の Issue より先に knowledge を修正する。
