# 要件

## 要望

規約『VS Code 拡張機能の配布』（`docs/rule/dev-vscode-extension-distribution.yaml`）に、拡張機能のアイコンの項目を追加する。

- 拡張機能を初めて公開する前に、アイコンを作って `package.json` の `icon` に登録する
- アイコンの図案は、作る側が SVG で案を作り、ユーザーに確認してから決める
- 決まった SVG を原本としてリポジトリに置き、PNG に書き出して、`package.json` の `icon` に PNG のパスを書く（Marketplace は `icon` に SVG を受け付けず、128×128px 以上の PNG を求める）

追加した項目が、アイコンを作る・登録するエージェントに注入されるかを `rules.yaml` で確かめ、当たらない場合は `paths` を追加する。

終わりの条件:

- 規約『VS Code 拡張機能の配布』に、初めて公開する前にアイコンを SVG の案でユーザーに確認して決め、PNG に書き出して `package.json` の `icon` に登録する項目がある
- `uv run --frozen --script scripts/check_all.py` が合格する
