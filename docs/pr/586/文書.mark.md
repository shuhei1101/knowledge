## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 観点の要素 | 表の 1 行を `aspects` の 1 要素にし、項目の列を `name`（観点名）と `description`（確認すること）に、補足の列を `note` に移す。補足が `-` の行は `note` を持たない | キーは `checksheet-review-common` にそろえる |
| 表の項目 | 観点を移し終えた `items[]` の表の項目を削除し、概要の項目は残す | 表の前後に観点の説明の文があれば概要の項目へ移す |
| `target:` のタグ | ページの成果物の種類のタグを全ての要素に付け、`main: true` にする（例: `checksheet-review-poc` は `target:PoC`） | 語彙は shuhei1101/ai-monitor#3826 の `review-aspects-*.yaml` の値から選ぶ |
| `process:` のタグ | 特定の工程でだけ確認する観点に、その工程のタグを付ける | 工程を限らない観点には付けない |
| 観点の ID | `aspect-{ファイル名から checksheet- を除いた名前}-{2 桁の番号}`（例: `aspect-review-poc-01`）を表の行の順に振る | - |
| `rev` | 書き換えた各ページの `rev` を 1 つ上げる | - |
