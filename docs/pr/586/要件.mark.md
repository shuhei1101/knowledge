# 要件

## 要望

- `checksheet-review-common` を除く `checksheet-review-*` の 15 ページの観点（表の行）を、#580 で決めた構造の `aspects` の要素へ書き換える。観点 1 件 = 1 要素とし、各要素は ID・観点名・確認すること・補足・公開範囲と、成果物の種類（`target:`）・工程（`process:`）のタグを持つ
- タグの語彙は #580 と同じく、[shuhei1101/ai-monitor#3826](https://github.com/shuhei1101/ai-monitor/pull/3826) の `docs/checksheet/review-aspects-*.yaml` の `target:`・`process:` の値にそろえる。各要素は `target:` を 1 つ以上持ち、ページの成果物の種類のタグを `main: true` にする
- 観点の ID は `aspect-{ファイル名から checksheet- を除いた名前}-{2 桁の番号}` にする
- ページの ID・`related`・概要の項目は変えず、ID でページを取得する利用者は引き続きページを取得できる
- 書き換えた後、全ての文書の検査（`scripts/check_all.py`）が 15 ページと観点の文書で違反を出さない
- `search_docs` を `source: knowledge`・種類 `review_aspect` と各ページの成果物の種類のタグで絞ると、そのページの観点が 1 件ずつ返ることを確認する
