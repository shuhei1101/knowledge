Mermaid の生成は描く側（dev-docs・ai-monitor の `design_docs publish`）が持つ。
knowledge は、スキーマの `er`・`state_transitions` の `x-used-by` に、生成で Mermaid の `erDiagram`・`stateDiagram-v2` にすることを記載する。

| 案 | 内容 |
| --- | --- |
| A | knowledge が持つ。変換のスクリプトで設計書の `er`・`state_transitions` を `erDiagram`・`stateDiagram-v2` にする |
| B | 描く側が持つ。knowledge はスキーマに生成する図の種類を記載する |

採用: B

knowledge の変換（`knowledge_markdown.py`）は knowledge 自身の文書だけに当たり、knowledge は ER図・状態遷移の設計書を持たない。
他のプロジェクトの設計書は、dev-docs の `features/convert/diagrams.py` と ai-monitor の `features/design_docs/diagrams.py` が `x-diagram` の値から図を組み立てている。
A にすると、描く側が knowledge のスクリプトを呼ぶ依存が新しく増える。
