# 画面設計のスキーマの要素の kind を英語の enum にし、種類ごとに今ある欄の必須と禁止を決める

## 概要

画面を設計する人が、画面設計の要素の種類を決まった英語の一覧から選び、種類ごとに要る欄の記載漏れと要らない欄の記載を検査で見つけられるようになる。

## 背景

[Issue #600](https://github.com/shuhei1101/knowledge/issues/600) の要望。
画面設計のスキーマ（`schemas/design/screen.schema.yaml`）の要素の `kind` は enum の無い文字列で、各プロジェクトの画面設計書には HTML の要素名（`div`・`a`・`h1`・`p`）・部品の名前・日本語（`列`・`エンプティステート`）が混ざっている。
種類で欄の必須・禁止を分けられないため、種類にだけ要る決まりが `label`・`initial_value`・`constraints`・`description` の自由文に入り、実装で抜ける。
今のスキーマに無い欄の追加と、その欄の種類ごとの必須・禁止は後続の [#602](https://github.com/shuhei1101/knowledge/issues/602) が扱う。
各プロジェクトは設計書のスキーマを `design-schemas/v*` のタグで指すため、検査に通らなくなる変更はメジャーを上げたタグで配る。
