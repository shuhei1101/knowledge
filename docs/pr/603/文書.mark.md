## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 画面設計のスキーマ（`kind`） | `elements[].kind` に英語の enum（`button`・`link`・`toggle`・`input`・`textarea`・`select`・`checkbox`・`radio`・`tabs`・`nav`・`sidebar`・`pane`・`splitter`・`disclosure`・`list`・`board`・`table`・`table_column`・`dialog`・`popover`・`tooltip`・`heading`・`label`・`image`・`alert`・`toast`・`progress`・`separator`）を持たせ、値ごとの意味を `kind` の `x-rules` に記載する | 語彙は Issue の表の種類に、各プロジェクトの画面設計書で使用している種類を役割でまとめた値を加えた。表 1 |
| 画面設計のスキーマ（必須・禁止） | 要素の `allOf` に `kind` を判別子にした `if` / `then` を追加し、今ある欄の種類ごとの必須を `required`、禁止を `{欄: false}` で指定する。`items` の `properties` と `additionalProperties: false` は保つ。条件は各欄の `x-rules` に記載する | 表 2。今のスキーマに無い欄は #602 が扱う |
| 部品設計のスキーマ | 引数の `type` を英語の enum（`string`・`integer`・`number`・`boolean`・`enum`・`object`・`array`・`function`・`component`）にし、`enum` の引数に `choices` を必須、`boolean`・`object`・`array`・`function`・`component` の引数に `choices` を禁止、`component` の引数に `component` を必須、ほかの型に `component` を禁止、`required` が `true` の引数に `default` を禁止にする | 部品設計に要素の種類は無いため、種類で欄の要否が分かれる引数に当てる。`オブジェクトの配列` は `array` と重なるため `array` にまとめた（メタスキーマの `enum` は互いに重ならない値だけにする決まり）。各プロジェクトで使用している `関数` を `function` として加えた |
| 記載例 | 両スキーマの `examples` を enum と必須・禁止に合わせる | スキーマの検査で `examples` を検査する |
| テンプレート | `scripts/build_templates.py`・`scripts/build_markdown_templates.py` で再生成する | 手で編集しない |
| 設計書のスキーマのタグ | 既存の設計書が検査で落ちるため、マージの後に `design-schemas/v*` のメジャーを上げたタグを作る | 反映作業 |

表 1: 各プロジェクトの画面設計書の `kind` の値と、まとめた先

| 使用している値 | まとめた先 | 理由 |
| --- | --- | --- |
| `a` | `link` | HTML の要素名で、役割は別の画面・場所へ移る要素 |
| `div`・`section`・`region`・`container`・`group`・`form`・`header`・`aside`・`article`・`panel`・`window` | `pane` | HTML の要素名か区画の言い換えで、役割は画面を分けた区画 |
| `h1`・`heading` | `heading` | 区画の見出し |
| `p`・`status`・`badge`・`chip` | `label` | 文字を出す要素。押せるチップは `button` |
| `menu`・`menu_item` | `popover`・`button` | メニューは浮いた区画、項目は押すと操作を始める要素 |
| `switch` | `toggle` | 切り替えた時点で反映する |
| `segment` | `radio` | 並べた選択肢から 1 つを選ぶ |
| `notification` | `alert`・`toast` | 出し続けるか、消えるかで分ける |
| `skeleton`・`スケルトン` | `progress` | 読み込み中の表示 |
| `icon`・`figure` | `image` | 画像・アイコン・図 |
| `details` | `disclosure` | 見出しを押して開閉する区画 |
| `drag_handle` | `splitter` | 境目をドラッグして大きさを変える |
| `sheet` | `dialog` | 画面に重ねて後ろを操作させない区画 |
| `列`・`行` | `table_column`・`table` | 表の列と表。行は表の中身として表に記載する |
| `button（アイコン）` | `button` | アイコンだけかは種類と重なる事柄で、#602 が欄にする |
| `エンプティステート`・`取得失敗の表示` | `pane` | 部品の名前で、`component` に部品設計を指す |

| 欄 | 記載できる種類 | 必須の種類 |
| --- | --- | --- |

| `placeholder`・`autocomplete` | `input`・`textarea`・`select` | - |
| `min_length`・`max_length`・`pattern`・`charset`・`inputmode`・`prefix`・`suffix` | `input`・`textarea` | - |
| `range` | `input` | - |
| `options` | `select`・`radio`・`checkbox` | `select`・`radio` |
| `sorting` | `table_column` | - |
| `align` | 全て | `table_column` |
| `count_limit` | 全て | `table`・`list`・`board` |
| `pending_state` | `label`・`heading`・`image`・`tooltip`・`progress`・`separator` を除く全て | - |
| `overflow` | 全て | 今の `io`・`fixed_area` の条件のまま |
