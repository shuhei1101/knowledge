## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 画面設計のスキーマ（`kind`） | `elements[].kind` に英語の enum を持たせ、値ごとの意味を `description` か `x-rules` に記載する | 語彙は Issue の表の種類を起点に、各プロジェクトの画面設計書で使用している種類を受けられるように決める |
| 画面設計のスキーマ（必須・禁止） | 要素の `allOf` に `kind` を判別子にした `if` / `then` を追加し、今ある欄の種類ごとの必須を `required`、禁止を `{欄: false}` で指定する。`items` の `properties` と `additionalProperties: false` は保つ | 組は Issue の表のうち今ある欄の行を起点にする。今のスキーマに無い欄は #602 が扱う |
| 部品設計のスキーマ | 引数の `type` を enum にし、`choices`・`component`・`default` の要否を `type`・`required` を判別子にした `if` / `then` で指定する | 部品設計に要素の種類は無いため、種類で欄の要否が分かれる引数に当てる |
| 記載例 | 両スキーマの `examples` を enum と必須・禁止に合わせる | スキーマの検査で `examples` を検査する |
| テンプレート | `scripts/build_templates.py`・`scripts/build_markdown_templates.py` で再生成する | 手で編集しない |
| 設計書のスキーマのタグ | 既存の設計書が検査で落ちるため、マージの後に `design-schemas/v*` のメジャーを上げたタグを作る | 反映作業 |
