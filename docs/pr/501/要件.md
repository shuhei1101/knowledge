# 要件

## 要望

- 起点 Issue の「記載してほしい内容」の 4 項目（試したライブラリと書き出せたか・書き出しの注意・動きの付け方の好み・書き出しの方式の比較）を、テンプレート『ノウハウ』のとおり 1 技法 1 文書で `docs/knowhow/` に登録する
- 項目ごとに、規約『ドキュメント管理』の規約とノウハウの分け方（`knowhow-01`）と知見の配置先（`knowhow-02`）で配置先を判定する。調べた結果そのもの（比較表・測定値）は話し合いのワークスペースに残し、ノウハウには結論・出典と確認した記録の要点だけを記載する
- 既存の `knowhow-design-material-template` の「素材そのものには動きを付けず」と、利用者のコメント（説明に合わせて 1 行ずつ出す・グラフが伸びる動きは付けてよい・なめらかに大きさを変える・回転する動きは付けない）の食い違いを解く
- 出典は、話し合いの資料（A-189・A-188・R-16・R-29・R-43）と利用者のコメント（TH-1071・TH-1261・TH-1263）の要点を起点 Issue #500 のコメントにまとめ、その URL を `sources` にする。手元のパスは記載しない。公開の URL を持つ出典（Playwright・Mediabunny・HyperFrames などの公式）は、その URL を記載する
- ノウハウの `visibility` は `internal` にする
- 登録・改訂した文書は、書き込みの検査と全ての文書の検査に通る

`未確定`: 既存の `knowhow-design-material-template` との食い違いの解き方（決める工程: ドキュメント修正のレビュー）

| 案 | 内容 |
| --- | --- |
| A | 既存の文書の使用方法の「素材そのものには動きを付けず」を、動きの付け方の好みに合わせて改訂し、名前の「回転・拡大の動きを付けない」は残す |
| B | 既存の文書は変えず、新規の文書から既存の文書を指して例外（1 行ずつ出す・グラフが伸びる）を記載する |

推奨: A

同じ題材（素材の動き）の知見が 2 つの文書で食い違ったまま残ると、参照したエージェントがどちらに従うかを決められないため。
