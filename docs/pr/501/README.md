# 動画の素材に動きを付けるライブラリと、動画に書き出すときの注意を、ノウハウの文書に登録する

## 概要

動画の素材を作成するエージェントが、素材に動きを付けるときに使用するライブラリと、動画に書き出すときの注意と、動きの付け方の好みを、knowledge の種類「ノウハウ」（`docs/knowhow/`）から参照できるようになる。

## 背景

[Issue #500](https://github.com/shuhei1101/knowledge/issues/500) の要望。
話し合いのワークスペースで、素材のテンプレートの PoC（GSAP・Chart.js・three.js・CSS・SVG）と、書き出しの方式の調査をした。
develop には [#460](https://github.com/shuhei1101/knowledge/pull/460) で登録した `knowhow-design-material-template`（素材そのものに動きを付けない）があり、利用者のコメント（1 行ずつ出す・グラフが伸びる動きは付けてよい）と食い違う。
