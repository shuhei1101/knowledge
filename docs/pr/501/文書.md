## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文書の切り分け | 4 項目を、技法ごとに次の文書の案に切り分け、ドキュメント修正のレビューで確定する | 下の表 |
| ノウハウの文書 | `write_docs` で `kind: knowhow` の文書を作成する。ID は `knowhow-{scope}-{topic}`、`visibility` は `internal`、`last_reviewed` は登録した日 | `necessity`・`scenes`・`cases`・`evidence`・`confidence` はスキーマの `x-rules` で決める |
| 既存の文書の改訂 | `knowhow-design-material-template` の使用方法の 3 番目を、動きの付け方の好みに合わせて `text_edits` で書き換え、出典に利用者のコメントを追加する。変更しない文言は維持する | 要件の `未確定` の推奨 A |
| 時期で変わる値 | ライブラリのバージョン・ライセンス・保守の状況・測定値は記載せず、公式の URL を出典にする | 規約『文章の書き方』 |
| 試していないライブラリ | anime.js・Motion・Lottie・Rive・D3・ECharts・p5.js・PixiJS は、書き出せたと記載しない | PixiJS は 1 つ前の話し合いの R-29 の記載だけ |
| タグ | 付ける前に `search_docs` の `group_by: tags` で使用中のタグを確認し、同じ意味のタグを再利用する | `topic:ノウハウ`・`topic:動画`・`topic:素材`・`topic:アニメーション` を再利用する |
| 出典 | 話し合いの資料と利用者のコメントの要点を起点 Issue #500 のコメントにまとめ、その URL を `sources` にする | 要件のとおり |
