## 要望

`docs/`（`docs/pr/`・`docs/word-list/`・生成物の `docs/template/` を除く）と `schemas/` の文書で、対応表 `docs/word-list/word-list-ai-slop.yaml` の 12 単語の行（`iriguchi`・`owari`・`ji`・`obi`・`ukeguchi`・`soto-no`・`yurusu`・`tooshi`・`atarashii`・`kimaru`・`furui-ko`）の `pattern`（`allow` を除く）にヒットする箇所を、文脈に合う `ok` の置き換え先へ置き換える。

- 対応表の `allow` にある使い方（「新しい順」「古い順」等）と、`note` の意味に当たらない使い方・置き換えると意味が変わる箇所は残す

- 文書の ID・構造・スキーマのキーは変えない
- 終わりの条件: 置き換えた後に対象の範囲を同じ `pattern` で走査し、残ったヒットが全て残す理由（`allow`・意味が違う使い方）を持つこと。`check_all.py` が全件 pass すること
