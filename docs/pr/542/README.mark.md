# ヒューマンエスカレーションの表・確認観点の表のスキーマとテンプレートと、精度評価の観点の決め方を追加する

## 概要

どのプロジェクトでも、エージェントフローを持つ機能のヒューマンエスカレーションの表・確認観点の表を knowledge のテンプレートとスキーマで作成して検査を受けられ、精度評価の観点の抜けと確認の方法を knowledge の文書で判定できるようにする。

## 背景

[Issue #541](https://github.com/shuhei1101/knowledge/issues/541) は、次の 2 件の束。

- [#540](https://github.com/shuhei1101/knowledge/issues/540): 「該当すれば必ず利用者に判断を仰ぐ項目」と「レビュアーが確認する項目」の書式の原本が、Git 管理外の話し合いの資料（A-207・A-214）にしかない。[shuhei1101/ai-monitor#3745](https://github.com/shuhei1101/ai-monitor/issues/3745)（knowledge のテンプレートを AI Monitor の手順に入れる）がこの作業 PR の完了を待っている
- [#537](https://github.com/shuhei1101/knowledge/issues/537): 判定フローチャート『精度評価をするか』で精度評価をすると判定した後に、どの観点を設けるか・観点の確認の方法（`rule`・`llm`・`human`）をどれにするかを決める文書が無い。『テンプレート: 精度評価の観点』は、語彙の表の列と、採点のモデルが出力を受け取れないときの `human` の扱いを持たない
