## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| インターフェース定義 | IF-201-1 の出力のキーの表に、`x-used-by` の文を改行でつないだ使用先の列を追加する。`x-used-by` が無いキーは空にする | 列の位置はインターフェース定義設計で決める |
| モジュール構成 | MOD-201-1 のキーの表の列と、行を組み立てる関数に `x-used-by` の処理を追加する | - |
| 単体テスト | `x-used-by` を持つキーと持たないキーの行の組み立てを追加する | `tests/unit/scripts/test_build_templates.py` |
| 結合テスト | `x-used-by` を持つスキーマから、使用先の列を持つテンプレートが生成されることを追加する | `tests/integration/scripts/test_build_templates.py` |
| 確認 | 単体・結合テスト・lint と全ての文書の検査を実行する | ログを `テスト結果/` に配置する |
