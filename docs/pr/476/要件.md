# 要件

## 要望

テスト実行方法の `run_runner` で、`gh workflow run` の出力から実行の ID を取った後、`gh run watch` を呼ぶ前に、実行を API で参照できるまで待つ。

- 待ち方は [shuhei1101/project-index#139](https://github.com/shuhei1101/project-index/pull/139)（TP-1）・claude-balancer の TP-275-1 と同じにする。`gh api "repos/{owner}/{repo}/actions/runs/$run_id?exclude_pull_requests=true"` を 1 秒おきに最大 10 回試し、参照できなければ `実行 {run_id} を 10 秒参照できません` を標準エラーに出して終了コード 1 で終える
- 対象は TP-72-1 の単体テスト（TL-2）と結合テスト（TL-3）の `run_runner`、テスト実行方法のスキーマの `run_runner` の `examples`、スキーマから生成するテンプレート『テスト実行方法』
- スキーマの `run_runner` の `x-rules` に、実行を参照できるまで待ってから終わるまで待つ決まりを追加し、他のプロジェクトのテスト実行方法も同じ記載方法にそろえられるようにする
- 修正した TP-72-1 の単体テストの `run_runner` をランナーで実行し、集計の行を受け取れることを確認する
- develop へマージした後に、`design-schemas/v*` のタグを作成する（反映作業）
