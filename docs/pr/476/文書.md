## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| TP-72-1 の `run_runner` | TL-2・TL-3 の `run_id=${run_url##*/}` と `gh run watch` の間に、`gh api "repos/{owner}/{repo}/actions/runs/$run_id?exclude_pull_requests=true"` を 1 秒おきに最大 10 回試し、参照できなければ `実行 $run_id を 10 秒参照できません` を標準エラーに出して終了コード 1 で終えるサブシェルを `&&` でつなぐ | ログの取得（`gh run view "$run_id" --log`）は変えない |
| スキーマの `x-rules` | `run_runner` に、起動した実行を API で参照できるまで待ってから終わるまで待ち、参照できなければ失敗で終える決まりを 1 行追加する | - |
| スキーマの `examples` | TL-1 の `run_runner` を TP-72-1 と同じコマンドに修正する | - |
| テンプレート | `scripts/build_templates.py` で再生成し、手で編集しない | - |
| 設計書のスキーマのタグ | develop へマージした後に `design-schemas/v*` のパッチを上げたタグを作成する（反映作業） | 例と `x-rules` の文の修正で、既存の設計書の検査の結果を変えない |
