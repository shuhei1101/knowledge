# 要件

## 要望

単一 UC のシナリオ『エージェントが knowledge の文書を書き込む』（SC-72-5）に、次の異常シナリオを追加する。

- Markdown の本文のキーの値が mdmark の点検で `diagram_invalid` か `syntax_warning` を出すとき、dev-docs の `write_docs` は作業ツリーの文書を変えずに `isError` を返す
- 応答の違反は、パスが Markdown の本文のキー、決まりが mdmark の種類と行、直し方が mdmark の内容になる（dev-docs の [文書の書き込み](https://github.com/shuhei1101/dev-docs/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E3%82%A4%E3%83%B3%E3%82%BF%E3%83%BC%E3%83%95%E3%82%A7%E3%83%BC%E3%82%B9%E5%AE%9A%E7%BE%A9/%E9%96%8B%E7%99%BA%E3%83%89%E3%82%AD%E3%83%A5%E3%83%A1%E3%83%B3%E3%83%88%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC/%E6%96%87%E6%9B%B8%E3%81%AE%E6%9B%B8%E3%81%8D%E8%BE%BC%E3%81%BF.yaml) の異常系（Markdown の値に mdmark の警告がある）と同じ）

シナリオの `preconditions` に、`check --text` を持つ mdmark の CLI が Linux 側に入り、PATH から引けることを追加する。
E2E テストは追加しないため、追加する異常シナリオは `test` を持たない。
