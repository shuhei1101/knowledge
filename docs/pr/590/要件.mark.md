# 要件

## 要望

`schemas/design/screen.schema.yaml` の `$defs` の要素の `count_limit.type` の `description` を、`。` が 2 つ以下（2 文以内）にする。

- 今の記述: `上限を超えたときに、折り返して全て出す（`wrap`）・超えた分を件数でまとめる（`summarize`。「+3」と出す）・読み込みを分ける（`paginate`。ページネーション・続きの読み込み）のどれにするか。`

括弧の中の補足（「+3」と出す・ページネーション・続きの読み込み）は、「。」を使用せずに残す。

スキーマから生成する `docs/template/template-screen-design.yaml` と `docs/template/markdown/screen-design.md`・`screen-design.example.md` を、`scripts/build_templates.py`・`scripts/build_markdown_templates.py` で再生成する。

終了の条件:

- `tests/integration/scripts/test_check_all.py::test_normal_when_repository_schemas` が pass する
- `schemas/design/` の全てのスキーマで、`。` が 3 つ以上の `description` が 0 件になる
- `count_limit.type` の検査の結果（`enum`・必須）は変えない

同じ型の箇所は、`schemas/design/` の全てのスキーマをテストと同じ条件で調べ、この 1 件だけが該当した。
