## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `knowledge_markdown.py` | 表を包むマーカーを `<!-- table: {"kind": "data"} -->` で出す | 閉じるマーカー `<!-- /table -->` は変えない |
| `build_templates.py` | `_TABLE_OPEN` を同じ JSON の記載にする | 生成し直したテンプレートと一致させる |
| テスト | 単体・結合の期待値を JSON の記載へ書き換える | 結合テストの実行範囲は実行の前に表にして reviewer の確認を受ける |
