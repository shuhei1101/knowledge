| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設計書（シナリオ・インターフェース定義・モジュール構成） | 例と出力の記載を JSON の記載（`<!-- table: {"kind": "data"} -->`）へ書き換える | `<!-- embed: ... -->` は knowledge 独自のマーカーのため変えない。全ての文書の検査が `legacy_mark` を違反にしないことを確かめる場面（SC-72-6・IF-72-3）の条件の `<!-- table: data -->` も変えない |
