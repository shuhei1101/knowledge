# 要件

## 要望

- 規約『E2E テスト（Playwright）』の `folder-responsibility-01` のツリーから `{domain}/`・`usecases/` を除外し、規約『V字モデル』の対応表の `複合ユースケース/`・`単一ユースケース/` を配置する
- 2 つのフォルダの spec は、シナリオの `test_file` が指すファイルにする
- `pages/`・`fixtures/`・`helpers/`・`.auth/`・`reports/`・`snapshots/`・`global.setup.ts`・`global.teardown.ts` の置き場所を決め、同じ規約の `playwright-config-01`（`testDir`）・`playwright-config-03`（`storageState`）・`rules-05`（`snapshotPathTemplate`）のパスと、規約『Test Fixtures（Data Factory）』の `factory-as-fixture-01` の `tests/e2e/fixtures.ts` を、決めた置き場所に合わせる
- 終わりの条件: `docs/rule/` に `tests/e2e/` の下を `{domain}/`・`usecases/` で分ける記載が無く、2 つの規約が指す `tests/e2e/` 配下のパスがツリーの中にある

支援のフォルダの置き場所（ドキュメント修正の工程で案 A に決めた）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `tests/e2e/` の直下に `複合ユースケース/`・`単一ユースケース/` と並べて配置する | `testDir`・`storageState`・`snapshotPathTemplate` のパスが変わらない | `tests/e2e/` の直下に spec のフォルダと支援のフォルダが混ざる |
| B | `tests/e2e/support/` の下にまとめる | `tests/e2e/` の直下が 2 つのユースケースのフォルダと setup・teardown だけになる | 3 つの項目と `tests/e2e/fixtures.ts` のパスを全て書き換える |

採用: A

Playwright は `testMatch` に合う spec だけを実行するため、支援のフォルダが並んでいても実行の対象は変わらない。
