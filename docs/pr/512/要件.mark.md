# 要件

## 要望

AI Monitor の develop の README の生成（`python -m ai_monitor.design_docs publish`）で `docs/` と各フォルダの目次を生成し直し、目次のファイル名を `README.mark.md` にする。
生成し直した後、`docs/` の下に目次の `README.md` が残らない。
目次を指す `docs/files.yaml` の行・フォルダ構成の設計書・開発コマンドの記載を `README.mark.md` に合わせ、全ての文書の検査が違反 0 件で終わる。

直下の `mdmark.config.yaml` を読む `mdmark check` で、`docs/pr/` のマージ済みの記録に `plain_md_with_marks` が出るかを確認する。
出る場合は `mdmark.config.yaml` に `check.suggestMarkExtension: false` を記載する。

`docs/pr/` のマージ済みの記録は移さない（スコープ外）。
