### mdmark の提案

`npx -y github:shuhei1101/mdmark#v0.13.0 check` は `plain_md_with_marks` を出さず、ずれ 0 件で終わった。
mdmark `v0.13.0` の `check` が点検するのは設定の索引と `build` が指す文書だけで、knowledge の `mdmark.config.yaml` はどちらも持たないため、`docs/pr/` は点検の対象にならない。
`check.suggestMarkExtension: false` は記載しない。
