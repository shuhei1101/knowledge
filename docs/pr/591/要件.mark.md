# 要件

## 要望

書き込みの検査（`on: [write]` の validators）で、書き込む文書に全ての文書の検査と同じ設定の markdownlint-cli2（`scripts/lint/.markdownlint-cli2.jsonc`）・yamllint（`scripts/lint/.yamllint.yaml`）・mdmark の map の点検を適用し、error の違反があれば違反として返却して書き込みを止める。

- 直コミット（`write_docs` の `commit`）と作業ツリーへの書き込みの両方に適用する
- markdownlint-cli2 は Markdown の項目、yamllint は文書の YAML の全体、map の点検は `<!-- map -->` を含む項目に適用する
- map の点検は、npx で mdmark を取得せず、project-index の書き込みの点検と同じ PATH の mdmark の CLI を呼ぶ
- 違反は、全ての文書の検査と同じく元の文書の行と項目のパス（yamllint はファイル全体の `-`）で返却する。warning の違反は書き込みを止めない
- 違反の無い文書の書き込みの結果は変えない
- 1 文書あたりの処理時間は、追加する lint の呼び出しを含めて非機能要件の [検査と変換のスクリプトの 1 文書あたりの処理時間](https://github.com/shuhei1101/knowledge/blob/e137163/docs/nonfunctional/NFR-72-1.yaml)（20 秒）に収める
- 書き込む作業ツリーに markdownlint-cli2 が無いとき・mdmark の CLI が PATH に無いときと、markdownlint-cli2・mdmark が失敗したときは、書き込みを止め、修正の仕方を案内する違反を返却する（textlint と同じ扱い）
- lint は `knowledge_checks.py` の中で `_lint.py` の呼び出しを使用して適用し、`project-index.yaml` の `validators` は変えない
