## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| markdownlint-cli2 の適用 | 書き込む文書の Markdown の項目を `collect_sources` で取り出し、textlint と同じ一時の `.md` に markdownlint-cli2 を呼ぶ | 全ての文書の検査と同じ `.markdownlint-cli2.jsonc` |
| yamllint の適用 | 標準入力の文書の YAML 全体に `run_yamllint` を `.yamllint.yaml` の設定で当てる | 書き込みの検査が受けるのは `docs/` の文書だけで、`schemas/` 用の設定は使用しない |
| map の点検の適用 | `collect_map_sources` で取り出した項目に、PATH の `mdmark` を指定して `run_map_check` を当てる | map を含む項目が無いときは mdmark を呼ばない。全ての文書の検査は npx の `MDMARK_REF` のまま（`mdmark_npx_command`） |
| 違反の返却 | error の違反を、textlint と同じ `{行} 行目: {ツール}/{ルール}: {内容}` の違反にして既存の違反と同じ配列で返却する。warning は返却しない | - |
| CLI が無い・失敗したとき | 書き込みを止め、markdownlint-cli2 は `npm ci --prefix scripts/lint`、mdmark は CLI の入れ方を案内する `path: $` の違反を返却する | textlint と同じ扱い |
| 処理時間 | 最も大きい文書と map を含む文書の書き込みの検査を実測し、20 秒に収まるかを確認する | npx で取得すると、キャッシュが空のときに 56.6 秒かかったため（`
