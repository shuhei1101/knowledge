# 要件

## 要望

テンプレート『テンプレート』『判定フローチャート』『セットアップ手順』の配置先・ファイル名・見出し・書式の記述を、規約『ドキュメント管理』（`docs/rule/dev-document-management.yaml`）の `置き方`（文書の正本は YAML）・`フォルダ`（`docs/` の下は種類だけのフォルダ、ファイル名は ID、参照は ID）に合わせる。
変更する記述以外の文言と、各テンプレートの項目の `id` は変えない（規約『既存文章の維持』。`template-constant` が `template-template#table-rule-common-01` を参照している）。

### テンプレート『テンプレート』（`docs/template/template-template.yaml`）

- `overview`: 配置先 `dev/テンプレート/{対象}.md`（例: `dev/テンプレート/外部API.md`）と、用語の使い分けの `dev/テンプレート/*.md`・`dev/テンプレート/テンプレート.md` を、`docs/template/template-{対象}.yaml`（ファイル名は `id`）に合わせる
- `lead-01`: 記述例の配置先 `dev/{分類}/{ページ}.md`（例: `dev/設計書/外部API/OpenAI.md`）を、`docs/{種類}/{ID}.yaml` に合わせる
- `section-list-01`・`lead-01`・`section-list-code-01`・`section-name-01`: 実体ファイルの H2 見出し（`## {セクション名}`）と ` ```markdown ` の記述例を前提にした書式を、YAML の文書（メタデータ `name`・`description` と `items` の `id`・`group`・`name`・`body`）を前提にした書式に合わせる
- `lead-summary-rule-01`: 冒頭リードを「1 行目のタイトル直下に置く文章」、セクション定義を「冒頭リード / `## 概要`」とした記述を、`lead-01` と同じ定義（冒頭リードは `overview` の項目の本文、概要文はメタデータ `description`）に合わせる

### テンプレート『判定フローチャート』（`docs/template/template-flowchart.yaml`）

- `file-naming-01`: ファイル名の例 `シナリオ.md`・`複合ユースケース単一ユースケース.md` を、`id` をファイル名にした `docs/flowchart/flowchart-{対象}.yaml` に合わせる
- `title-01`: 見出し `# {対象作業} 判定フローチャート` をファイル名と一致させる記述を、メタデータ `name` に `{対象} 判定フローチャート` を書き、`description` に何を判定するかの 1 行を書く記述に合わせる
- `section-list-01`・`mermaid-block-01`: タイトルと Mermaid ブロックの並びを、`items` の項目（`overview` と、Mermaid ブロックを `body` に持つ項目）に合わせる

### テンプレート『セットアップ手順』（`docs/template/template-setup-procedure.yaml`）

- `overview`: 配置先 `docs/使い方/セットアップ手順/{操作}.md` と、`index.yaml` への行の追加・README の再生成の記述を、`docs/guide/guide-setup-{対象}.yaml`（ファイル名は `id`、タグ `topic:セットアップ手順`）に合わせる
- `lead-01`: 1 行目を `# {操作}` にしてファイル名と一致させる記述を、メタデータ `name` に `{対象}を{動詞}する` を書く記述に合わせる
- `section-list-01` と各セクションの項目: `## 前提`・`## 手順` などの H2 見出しと、`./{操作}.md` の相対リンクを前提にした記述例を、`items` の項目（`group`・`name`）と ID での参照（`[表示](id:{ID})`）に合わせる

md のページへの扱いは、`rules.yaml` から 3 つのテンプレートの md の glob を削除する（[確認ログ](./確認ログ.md)）。
