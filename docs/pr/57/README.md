# MCP の規約に、format・会話キーの引数・1 セッション 1 回の注入・区間の差分のツール・プラグインでの配り方を追加する

## 概要

MCP サーバーを作る人が、読み取りのツールの `format`・会話キーの受け方・1 セッション 1 回の注入・区間の差分のツール・照合する語の一覧のツールと、開発ドキュメントサーバーにつなぐ MCP をプラグインで配る方法を、規約から読めるようになる。

## 背景

[Issue #56](https://github.com/shuhei1101/knowledge/issues/56) の要望。
[#42](https://github.com/shuhei1101/knowledge/issues/42)（[#48](https://github.com/shuhei1101/knowledge/pull/48)）で `mcp.md` に読み取りのツールの決まりが入ったが、その後に knowledge のワークスペース `tmp/mcpベストプラクティス検討` の話し合いで決めたこと（D-28・D-62・D-63・D-64・D-65・D-66・D-70・D-82・D-83）が規約に無い。
`## 登録` はプロジェクト用の登録先をリポジトリ直下の `.mcp.json` としており、別のプロジェクトで作業しているときに文書の MCP を使えない。
