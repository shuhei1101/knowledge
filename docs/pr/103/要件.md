# 要件

## 要望

規約『Claude 共通』（`claude-common`）の `sentence-style-01`（文の書き方の良い例と悪い例）の例文に、存在しないパス（`html/shared/vendor.md`・`html/tooling/tsc運用.md`）の参照が 1 つも残っていない。

良い例の 2 行（`外部依存がどうしても…`・`dev ツール…`）と悪い例の 1 行から、参照の括弧（`（`html/shared/vendor.md`）`・`（`html/tooling/tsc運用.md`）`）を外す。
例文のそれ以外の文言と、良い例の箇条書きのインデント・悪い例の 1 行の長さの対比はそのまま残す。

参照を ID にせず括弧を外すのは、この例文が見せるのは文の折り返しで、参照先を読ませるためのものではないため。
ID のリンク（`[html/shared/vendor](id:html-shared-vendor)`）にすると、コードブロックの中ではリンクとして働かず、参照の書き方の見本として読まれる。
