# 規約『タグと用語の登録』に、タグの形式（オブジェクトの配列・文字列の配列）の使い分けを追加する

## 概要

タグを持つデータを設計する人が、タグの形式（オブジェクトの配列か、文字列の配列か）を、規約『タグと用語の登録』から決定できるようにする。

## 背景

[Issue #554](https://github.com/shuhei1101/knowledge/issues/554) の要望。
knowledge の設計書・規約のタグは、オブジェクトの配列（`tags[].name` と、主題のタグの `tags[].main`）で持つ。
aituber のデータ（ゲームの情報など）は、主題のタグが要らないので、文字列の配列で持つ。
2 つの形式の使い分けが規約に無く、話し合いで、knowledge は今のまま、主題のタグが要らないものは文字列の配列にすると決定した。
