# 規約の索引を当てる

この規約を使う環境を新しく用意したときに実行する。

## 前提

- rule-inject のプラグインを Claude Code に入れてある（[rule-inject のセットアップ](https://github.com/shuhei1101/rule-inject/blob/master/docs/%E4%BD%BF%E3%81%84%E6%96%B9/%E3%82%BB%E3%83%83%E3%83%88%E3%82%A2%E3%83%83%E3%83%97.md)）

## 手順

#### このリポジトリを clone する

```bash
git clone https://github.com/shuhei1101/knowledge.git {clone する先}
```

clone した先の絶対パスを次の手順で使う。

#### 索引のパスを環境変数に書く

`~/.claude/settings.json` の `env` に書く。

```json
{
  "env": {
    "RULE_INJECT_INDEXES_USER": "{clone した先の絶対パス}/rules.yaml"
  }
}
```

ほかの索引も使うときは、カンマで区切って並べる。
絶対パスか `~` で始まるパスで書かないと索引が読まれず、規約が案内されない。

## 反映

`再起動`（Claude Code を起動し直す）。

## 確認

#### 規約が案内される

索引の `paths` に当たるファイルを Claude Code で触ると、当たる規約の場所が案内される。

## 元に戻す

`~/.claude/settings.json` の `RULE_INJECT_INDEXES_USER` からこの索引のパスを消し、Claude Code を起動し直す。
clone した先は残るので、要らなければ消す。
