# 規約の変更を取り込む

手元の規約を最新にしたいときに実行する。

## 前提

- [規約の索引を当てる](./規約の索引を当てる.md)

## 手順

### master の最新を取り込む

```bash
git -C {clone した先} pull
```

変更を知らせる仕組みは無く、取り込まない限り古い規約が案内され続ける。

## 反映

`即時`（rule-inject は索引を呼ばれるたびに再読み込みする）。
そのセッションで既に読んだ規約は案内されないため、変わった本文を読ませるときは新しいセッションを開く。

## 確認

#### 手元が master の最新に揃っている

```bash
git -C {clone した先} status -sb
```

1 行目に `[behind` が出ない。

## 元に戻す

pull の直後に、取り込む前の commit へ戻す。

```bash
git -C {clone した先} reset --hard ORIG_HEAD
```

次に pull すると、戻した変更もまた取り込まれる。
