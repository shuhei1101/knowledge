# セットアップ

各環境で規約の索引を当てる手順

規約はただの Markdown で、どの環境でもそのまま読める。
リポジトリの直下の `rules.yaml` は、どのファイルを触るときにどの規約を読むかを並べた索引で、[rule-inject](https://shuhei1101.github.io/rule-inject/) の索引の書式で書いてある。

## 索引を当てる

<!-- steps -->

1. このリポジトリを clone する
2. `~/.claude/settings.json` の `env` で、`RULE_INJECT_INDEXES_USER` に clone した先の `rules.yaml` の絶対パスを書く。ほかの索引と並べるときはカンマで区切る
3. Claude Code を起動し直す

<!-- /steps -->

## 規約の変更を取り込む

clone した先で pull する。
変更を知らせる仕組みは無い。
